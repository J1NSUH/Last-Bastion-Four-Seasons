# UX And Screen Flows

이 문서는 **Last Bastion: Four Seasons**의 화면 흐름과 플레이어 경험 기준을 정리합니다.

목표는 멋진 화면을 먼저 만드는 것이 아니라, 협동 판단이 빠르게 일어나는 화면을 만드는 것입니다.

## UX 원칙

- 플레이어는 항상 "무엇이 위험한지"를 먼저 알아야 합니다.
- 웨이브 겹치기는 보상 버튼처럼 보이면 안 됩니다.
- 카드 사용은 빠르고, 대상 선택은 명확해야 합니다.
- 협동 판단은 투표와 핑으로 보조하되, 전투 템포를 끊으면 안 됩니다.
- 공포 연출은 정보 가독성을 희생하지 않습니다.

## 정보 레이어 원칙

전투 화면의 정보는 한 번에 모두 같은 강도로 보이면 안 됩니다.

정보 레이어:

| 레이어 | 역할 | 예시 |
| --- | --- | --- |
| 생존 레이어 | 즉시 반응해야 하는 위험 | 기지 피해, 보스 도달, 붕괴 직전 구조물 |
| 전술 레이어 | 다음 행동을 고르는 정보 | 경로 변화, 도발 연결, 수리 요청 |
| 자원 레이어 | 카드 사용 판단 | 마나, 드로우 게이지, 버리기 횟수 |
| 협동 레이어 | 파티 의사결정 | 웨이브 겹치기 투표, 상점 투표, 핑 |
| 분위기 레이어 | 심리적 압박 | 보스 실루엣, 저음, 조명 변화 |

위험이 겹치면 생존 레이어가 항상 우선합니다.

분위기 레이어는 생존 레이어와 전술 레이어를 가리면 안 됩니다.

## 전체 화면 흐름

```text
타이틀
-> 메인 메뉴
-> 로비 / 인원 선택
-> 직업 선택
-> 런 설정
-> 전투 화면
-> 라운드 보상
-> 이벤트 / 상점
-> 보스 예고
-> 보스전
-> 보스 결과 요약
-> 개인 보스 카드 보상
-> 아티팩트 선택
-> 챕터 상점
-> 다음 일자 예고
-> 승리 / 패배 결과
```

MVP에서는 아래 흐름만 완성해도 충분합니다.

```text
직업 선택
-> 10일 테스트 런
-> 라운드 보상
-> 상점
-> 침묵의 거상
-> 보스 후 성장 선택
-> 결과 화면
```

### 첫 플레이 화면 흐름

첫 플레이는 메뉴 설명보다 바로 작은 전투로 들어가는 편이 좋습니다.

```text
직업 선택
-> 8장면 튜토리얼
-> 10일 테스트 런
-> 첫 보스 결과
-> 첫 성장 선택 맛보기
-> 결과 화면 / 다시 하기
```

첫 플레이 중에는 화면 중앙을 막는 긴 설명창을 쓰지 않습니다.

힌트는 전장 위 하이라이트, 버튼 아래 짧은 이유, 결과 화면의 한 줄 제안으로 나눠 보여줍니다.

### 온보딩 정보량 제한

첫 10일 안에는 새 정보가 동시에 2개 이상 뜨지 않게 관리합니다.

| 시점 | 허용 정보 | 숨기거나 약하게 둘 정보 |
| --- | --- | --- |
| 1~2일 | 경로, 설치, 길막 불가 | 상점, 아티팩트, 보스 상세 |
| 3~4일 | 빠른 적, 군집 처리 | 파괴형, 방해형 |
| 5일 | 첫 상점과 간단 정비 | 아티팩트 교체, 이벤트 |
| 6~7일 | 구조물 파괴와 재건 | 복잡한 수리 경제 |
| 8일 | 웨이브 겹치기 템포 | 보상/효율 표현 |
| 9일 | 우선 처치 | 여러 방해형 동시 등장 |
| 10일 | 보스 부위와 접근 압박 | 최종 보스급 공간 압박 |

## 메인 메뉴

필수 버튼:

- 새 런
- 이어하기
- 설정
- 도감
- 종료

MVP에서는 새 런, 설정, 종료만 있어도 됩니다.

메인 메뉴 배경은 화려한 전투 장면보다, 먼 곳에서 느리게 다가오는 거대한 실루엣이 좋습니다.

### 런 이후 메타 진행 화면

결과 화면에서 메인 메뉴로 돌아가기 전에 `post_run_meta_flow`를 짧게 보여줄 수 있습니다.

| 항목 | 내용 | 금지선 |
| --- | --- | --- |
| 런 기록 수집 | 도달 일자, 만난 적, 보스 부위, 마지막 방어선 태그 | 개인 딜량/처치 수 순위 표시 금지 |
| 학습 태그 정리 | 반복된 실패 원인, 포기한 약점, 자주 쓴 대응 | 개인 책임 태그 표시 금지 |
| 정보/훈련 해금 | 적 도감, 보스 기록, 훈련 장면 | 영구 스탯 증가 보상처럼 표시 금지 |
| 선택지 해금 후보 | 새 카드/아티팩트/외형 후보 | 정답 빌드처럼 강조 금지 |
| 다음 런 준비 | 다음에 시도할 운영 1~2개 | 특정 직업 필수처럼 보이는 추천 금지 |
| 프로필/연대기 저장 | 파티 기록, 발견 기록, 해금 상태 | 승률 보정이나 보상 배율 표시 금지 |

메타 진행 화면은 보상 폭죽보다 조용한 기록장에 가깝게 연출합니다.

플레이어가 바로 새 런을 시작하고 싶으면 3초 뒤 건너뛰기 버튼을 보여줍니다.

#### 메타 진행 3단 화면

`post_run_meta_flow`는 결과 회고 직후 아래 3단으로 압축해서 보여줍니다.

| 영역 | 보여줄 것 | 상호작용 | 금지선 |
| --- | --- | --- | --- |
| 이번 런 기록 | 도달 구간, 처음 본 적/보스 부위, 마지막 방어선 태그 | 기록 자세히 보기 | 딜량/처치 순위 |
| 새로 열린 것 | 도감/훈련/카드 풀/아티팩트 풀/외형 후보 중 최대 2장 | 3줄 보기, 1분 연습, 보관함 | 파워 증가처럼 번쩍이는 연출 |
| 다음 판 메모 | 결과 회고에서 넘어온 운영 제안 1개 | 메모로 가져가기, 새 런으로 | 자동 빌드 적용 |

한 번에 보이는 메타 카드는 최대 4장입니다.

새로 열린 항목이 많아도 `모두 보기` 목록으로 접고, 결과 직후 화면을 오래 붙잡지 않습니다.

#### 메타에서 재방문으로 넘어가는 방식

메타 화면의 재방문 제안은 "해야 할 숙제"가 아니라 "방금 헷갈린 장면을 1분만 만져볼 기회"로 보여줍니다.

| 버튼 | 동작 |
| --- | --- |
| 1분 연습 | 연결된 `TrainingScenarioProfile`을 별도 전장으로 엽니다. |
| 3줄 보기 | 도감 카드만 열고 바로 돌아올 수 있습니다. |
| 메모로 가져가기 | 새 런 준비 화면의 한 줄 목표로 저장합니다. |
| 나중에 | 최근 추천 목록에 저장하고 메타 화면을 닫습니다. |

`나중에`를 선택해도 해금, 보상, 난이도, 새 런 시작 가능 여부는 바뀌지 않습니다.

같은 제안을 두 런 연속 닫으면 다음 런 종료까지 큰 카드로 다시 띄우지 않습니다.

#### 도감/훈련장 샘플 화면

도감 카드는 기본 상태에서 정확히 3줄만 보여줍니다.

| 줄 | 역할 | 예시 |
| ---: | --- | --- |
| 1 | 행동 | 빠르게 첫 굴곡을 지나갑니다. |
| 2 | 위험/저항 | 짧은 경로를 열어두면 바로 기지에 닿습니다. |
| 3 | 대응 | 둔화, 도발, 넉백으로 몇 초를 벌어둡니다. |

세부 설명은 접힌 영역으로 두고, 기본 카드에는 정답 빌드나 특정 직업을 표시하지 않습니다.

MVP 기본 도감 카드:

| 카드 | 기본 행동 |
| --- | --- |
| 빠른 적 | 짧은 경로와 첫 굴곡을 읽기 |
| 파괴형 | 터질 구조물과 후방 재건 위치를 정하기 |
| 방해형 | 두 번째 방해 전에 집중 화력으로 끊기 |
| 표식 구조물 | 살릴 축과 버릴 축 나누기 |
| 웨이브 겹치기 | 호출과 보류를 보상 없이 판단하기 |
| 보스 부위 | 본체보다 먼저 볼 부위 1개 정하기 |

훈련 장면 화면:

| 영역 | 표시 |
| --- | --- |
| 상단 | 재방문 이유 1문장, 남은 시간, 닫기 |
| 중앙 | 작은 전장과 현재 활성 방향 안의 스폰 |
| 하단 | 고정 훈련 손패, 대응 태그, 다시 시도 |
| 종료 | 사용한 대응 태그, 다른 가능성 최대 2개, 메모로 가져가기 |

훈련 결과에는 점수, 등급, 성공률, 개인 평가를 표시하지 않습니다.

솔로 훈련에서는 모든 실제 스폰과 방어 대상이 동쪽 전선 안에만 표시됩니다.

### 내부 플레이테스트 대시보드 화면

플레이테스트 대시보드는 플레이어 결과 화면이 아니라 제작자가 보는 내부 화면입니다.

따라서 화려한 리워드 연출보다 빠른 비교, 원인 분리, 다음 조정 후보가 먼저 보여야 합니다.

```text
상단 런 스트립
-> 패널 카드 그리드
-> 위험 신호 드릴다운
-> 다음 빌드 액션 큐
```

| 영역 | UI 형태 | 표시 밀도 | 금지선 |
| --- | --- | --- | --- |
| 상단 런 스트립 | 얇은 고정 바 | 한 줄, 최대 7개 칩 | 개인 이름/딜량/처치 순위 칩 |
| 패널 카드 그리드 | 2열 카드 또는 넓은 화면 4열 카드 | 카드당 핵심 수치 1~3개 | 카드 안에 원본 로그 표 삽입 |
| 위험 신호 드릴다운 | 우측 패널 또는 하단 시트 | 조건, 이벤트, 관찰 메모, 가능한 의미 | 위험 신호를 곧바로 정답 조정으로 표시 |
| 다음 빌드 액션 큐 | 작은 작업 목록 | 가설 문장, 확인 문서, 다시 볼 지표 | 자동 패치, 자동 난이도 보정 버튼 |

색상은 상태를 보조할 뿐, 유일한 구분 수단이 되면 안 됩니다.

| 상태 | 표시 |
| --- | --- |
| 정상 | 얇은 체크 아이콘과 중립 배경 |
| 주의 | 삼각 경고 아이콘, 원인 텍스트 1줄 |
| 위험 | 굵은 경고 아이콘, 드릴다운 기본 펼침 |
| 비교 불가 | 점선 테두리, 누락 필드 이름 표시 |

패널 카드를 눌렀을 때 첫 화면에 보이는 문장은 항상 아래 순서를 따릅니다.

1. 이 패널의 질문
2. 가장 큰 신호
3. 가능한 의미
4. 먼저 확인할 원본 이벤트
5. 다음 테스트 가설

대시보드 UI는 아래 버튼만 MVP에 둡니다.

| 버튼 | 역할 |
| --- | --- |
| 같은 조건 비교 | 같은 `runMode`, `playerCountAtStart`, `activeDirections` 런만 나란히 봄 |
| 원본 이벤트 보기 | 선택 패널과 연결된 이벤트 3~5개 펼침 |
| 관찰 메모 연결 | 관찰자 메모를 패널과 이벤트에 연결 |
| 가설로 저장 | 다음 빌드 액션 큐에 남김 |
| 보류 | 아직 수치 조정하지 않고 다음 테스트로 넘김 |

`가설로 저장`은 게임 데이터를 직접 바꾸지 않습니다.

웨이브 겹치기 패널에는 보상, 골드, 희귀도, 카드 후보 수 그래프를 두지 않습니다.

방어선 패널은 `activeDirections` 밖 방향을 흐린 배경 방향으로만 보여줄 수 있으며, 피해 방향이나 실패 방향 목록에는 넣지 않습니다.

### 도감/훈련장 화면

도감과 훈련장은 메인 메뉴에서 열 수 있고, 패배/결과/메타 진행 화면에서도 바로 연결됩니다.

`knowledge_revisit_flow`는 아래 흐름을 사용합니다.

| 항목 | 내용 | 상호작용 |
| --- | --- | --- |
| 왜 보기 | 연결된 패배 원인, 처음 만난 적, 보스 부위, 회고 태그 | 이유 카드 1장만 표시 |
| 무엇 보기 | 적/보스/구조물/상태이상/겹치기/직업 역할 탭 | 한 번에 탭 1개만 선택 |
| 도감 카드 | 행동, 저항, 대응 태그, 피해야 할 오해 | 3줄 요약과 자세히 보기 |
| 훈련 시작 | 30~60초 미니 장면 | 보상 없음, 건너뛰기 가능 |
| 대응 비교 | 사용한 대응 태그와 다른 가능성 1~2개 | 점수 대신 태그 비교 |
| 다음으로 | 새 런 준비, 즐겨찾기, 관련 도감 저장 | 자동 빌드 적용 없음 |

훈련장은 플레이어가 실험하는 공간이지 시험장이 아닙니다.

실패해도 실패 화면을 다시 띄우지 않고, 같은 장면을 바로 다시 시작하거나 결과 화면으로 돌아갑니다.

### 재방문 진입 카드

도감/훈련장으로 들어갈 때는 먼저 "왜 이걸 다시 보는지"를 한 장만 보여줍니다.

| 출처 | 이유 카드 문장 | 바로가기 |
| --- | --- | --- |
| 패배 분석 카드 | `동쪽 돌파형 누수가 반복되었습니다.` | 빠른 적 늦추기 훈련 |
| 결과 회고 | `마지막 방어선이 후방으로 두 번 밀렸습니다.` | 경로 연장 도감 |
| 메타 해금 | `처음 만난 방해형 적이 기록되었습니다.` | 방해형 도감 |
| 메인 메뉴 | `최근 많이 본 항목` 또는 즐겨찾기 | 도감/훈련 선택 |

이유 카드는 원인 설명을 1문장으로 끝내고, 바로 아래에 선택지를 둡니다.

| 버튼 | 역할 |
| --- | --- |
| 1분 연습 | 연결된 훈련 장면 시작 |
| 3줄 보기 | 도감 카드만 열기 |
| 메모로 가져가기 | 새 런 준비 화면에 운영 메모로 저장 |
| 닫기 | 결과 화면이나 메인 메뉴로 복귀 |

`1분 연습`은 기본 강조 버튼이지만, 건너뛰기가 항상 같은 위계로 보여야 합니다.

재방문 완료 여부로 새 런 시작 버튼을 잠그지 않습니다.

### 훈련장 미니 장면 UI

훈련 장면은 실제 런 UI를 줄여 쓰되, 정보량을 전투보다 훨씬 낮춥니다.

| 영역 | 표시 | 금지선 |
| --- | --- | --- |
| 상단 목표 | 이번 장면의 한 가지 질문 | 여러 목표 동시 표시 |
| 전장 | 작은 경로, 필요한 구조물 자리, 목표 적 | 비활성 방향 스폰 |
| 손패 | 고정 훈련 카드 또는 역할 태그 카드 3~5장 | 실제 덱 변경처럼 보이는 표시 |
| 힌트 | 10초 뒤 약한 힌트, 25초 뒤 위치 후보 | 처음부터 정답 배치 표시 |
| 종료 | 다시 시도, 도감 보기, 새 런 메모, 나가기 | 실패 화면, 점수, 등급 |

훈련 성공 문구는 칭찬 점수가 아니라 관찰 문장입니다.

```text
돌파형이 기지에 닿기 전 5초를 더 벌었습니다.
다음 런 메모: 첫 굴곡에서 늦추기
```

훈련 실패 문구도 실패 판정이 아니라 다시 볼 선택지를 줍니다.

```text
이번에는 돌파형이 첫 굴곡을 너무 빨리 지나갔습니다.
다시 시도하거나 경로 연장 도감을 볼 수 있습니다.
```

솔로에서 열린 훈련은 동쪽 전선만 실제 스폰 방향으로 사용합니다.

다른 방향의 원본 웨이브 의도는 동쪽 안의 경로 길이, 적 역할, 구조물 위치로 번역합니다.

## 로비

로비의 목적은 파티가 이번 런의 기본 조건을 확인하는 것입니다.

표시 정보:

- 플레이어 목록
- 선택한 직업
- 준비 상태
- 난이도
- 런 길이
- 음성/핑 상태

결정:

- 호스트가 런 설정을 변경합니다.
- 모든 플레이어가 준비해야 시작합니다.
- 직업 중복은 MVP에서는 허용하지 않습니다.

직업 중복은 나중에 변칙 모드로 열 수 있습니다.

기본 협동 밸런스는 네 직업이 서로 다른 역할을 맡는 상태에서 먼저 검증합니다.

### 새 런 준비 흐름

새 런 준비는 `new_run_setup_flow`를 사용합니다.

| 항목 | 내용 | 금지선 |
| --- | --- | --- |
| 제안 확인 | 결과 회고/도감/훈련장에서 온 다음 런 제안 1~2개 | 자동 빌드 적용 금지 |
| 인원/방향 확인 | 현재 시작 인원수와 활성 침공 방향 미리보기 | 시작 후 방향 재계산 금지 |
| 런 길이 선택 | 10일 테스트, 30일 MVP, 100일 표준 | 겹치기 보상 모드 표시 금지 |
| 직업 선택 | 역할, 시작 덱, 파티 역할 빈틈 | 필수 직업, 정답 조합 표시 금지 |
| 준비 합의 | 이번 런에서 시험할 운영 문장 1개 | 자동 추천 강제 금지 |
| 시작 확정 | `playerCountAtStart`, `activeDirections`, `scalingProfileId`, 시드 확정 | 시작 뒤 기준값 변경 금지 |

로비의 추천 문구는 선택을 대신하지 않습니다.

새 런 준비 화면 배치:

| 영역 | 위치 | 내용 | 기본 상태 |
| --- | --- | --- | --- |
| 참고 메모 | 상단 얇은 줄 | 결과/메타/도감에서 온 제안 최대 2개 | 접을 수 있음 |
| 방향 미리보기 | 좌측 또는 상단 | 현재 로비 인원, 활성/비활성 방향 지도 | 인원 변경 시 갱신 |
| 런 길이 | 방향 미리보기 아래 | 10일 테스트, 30일 MVP, 100일 표준 | 마지막 선택 기억 |
| 직업 슬롯 | 중앙 | 플레이어별 직업, 준비 상태, 시작 덱 보기 | 빈 슬롯 강조 |
| 역할 힌트 | 우측 작은 패널 | 현재 조합의 강한 대응/빈 대응 태그 | 접힌 상태 가능 |
| 파티 의도 | 하단 고정 줄 | 이번 런에서 시험할 한 문장 | 비워도 시작 가능 |
| 시작 버튼 | 하단 우측 | 모두 준비 시 활성화 | 잠금 전 확인 |

참고 메모 처리:

| 상태 | 표시 |
| --- | --- |
| 메모 0개 | "이번 런에서 새로 시험할 한 줄을 정할 수 있습니다." |
| 메모 1개 | 한 줄 메모와 도감/훈련장 버튼 1개 |
| 메모 2개 | 작은 칩 2개, 하나를 파티 의도로 가져가기 가능 |
| 접은 메모 | 아이콘과 개수만 표시 |

참고 메모는 직업 카드 위에 떠 있어도 직업을 자동 선택하지 않습니다.

역할 힌트는 "부족함"보다 "이번 조합에서 약하게 보이는 대응"이라고 씁니다.

좋은 역할 힌트:

```text
현재 조합은 후열 방해형을 직접 끊는 카드가 적습니다.
```

나쁜 역할 힌트:

```text
원소술사가 필요합니다.
```

시작 전 확인:

| 확인 항목 | 문구 방향 |
| --- | --- |
| 인원/방향 | 시작하면 이 방향으로 고정됩니다. |
| 런 길이 | 예상 시간만 보여주고 보상 차이를 만들지 않습니다. |
| 직업 | 각 플레이어가 직접 고른 직업입니다. |
| 의도 | 메모이며 자동 세팅이 아닙니다. |

런 길이 선택 화면에는 예상 시간을 짧게 표시합니다.

| 런 길이 | 표시 시간 | 금지선 |
| --- | ---: | --- |
| 10일 테스트 | 12~18분 | 빠른 클리어 보상 표시 금지 |
| 30일 MVP | 30~45분 | 시간 단축 보상, 희귀도 보정, 보상 모드 표시 금지 |
| 100일 표준 | 75~100분 | 웨이브 겹치기 보상 모드처럼 표시 금지 |

30일 MVP의 표시 시간은 30일 보스 결과 요약까지입니다.

`계속하기` 이후 31일 준비 상점은 다음 구간 준비로 표시하고, MVP 완료 시간에 더하지 않습니다.

좋은 문구:

```text
지난 런에서 방해형 대응이 늦었습니다. 이번 런에서는 우선 처치 핑을 자주 써볼 수 있습니다.
```

나쁜 문구:

```text
이번에는 수호자를 반드시 선택하세요.
```

## 직업 선택 화면

직업 선택 화면은 상세 수치보다 역할이 빨리 읽혀야 합니다.

각 직업 카드에 표시할 정보:

- 이름
- 역할 아이콘 2~3개
- 한 줄 설명
- 대표 키워드
- 시작 덱 미리보기
- 난이도

직업 한 줄 설명:

| 직업 | 설명 |
| --- | --- |
| 수호자 | 적을 끌어들이고 맞으면서 시간을 버는 방어 중심 직업 |
| 건축가 | 경로를 비틀고 구조물 파괴를 피해로 바꾸는 미로 설계자 |
| 원소술사 | 킬존에 모인 적을 광역 피해와 제어로 정리하는 화력 담당 |
| 땜장이 | 수리와 오라로 방어선의 수명을 늘리는 지원가 |

## 런 설정 화면

MVP 런 설정:

- 10일 테스트
- 30일 MVP 런

출시 후보 런 설정:

- 30일 단기 런
- 100일 표준 런
- 사용자 지정 런

런 설정에서 웨이브 겹치기 보상 관련 옵션은 제공하지 않습니다.

웨이브 겹치기는 난이도나 보상 모드가 아니라 템포 조절 시스템입니다.

### 활성 침공 방향 표시

런 설정 화면과 로비에서는 현재 인원수로 열리는 침공 방향을 보여줍니다.

표시 예시:

```text
현재 인원: 2명
활성 침공 방향: 북쪽, 동쪽
```

인원수별 표시:

| 인원수 | 표시 |
| ---: | --- |
| 1명 | 동쪽만 활성 |
| 2명 | 북쪽, 동쪽 활성 |
| 3명 | 서쪽, 북쪽, 동쪽 활성 |
| 4명 | 네 방향 모두 활성 |

비활성 방향은 맵 미리보기에서 어둡게 표시합니다.

비활성 방향에 "안전 보상", "추가 보상" 같은 문구를 붙이지 않습니다.

방향이 늘어나는 것은 보상이 아니라, 인원수에 맞춘 전장 분담입니다.

## 전투 화면

전투 화면은 가장 중요한 화면입니다.

레이아웃 기준:

```text
[상단 좌측] 다음 웨이브 예고
[상단 중앙] 일자 / 계절 / 웨이브 진행도
[상단 우측] 배속 / 웨이브 겹치기 투표

[중앙] 전장

[좌측] 기지 체력 / 파티 골드 / 보스 파편
[우측] 핑 로그 / 위험 알림

[하단] 손패 / 마나 / 드로우 게이지 / 버리기 횟수 / 손패 계획 요약
```

손패 계획 요약은 현재 카드들을 바로 사용 가능, 대상 대기, 마나 부족으로 묶어 보여줍니다.

추천 행동은 자동 정답이 아니라, 초반 1~2라운드에서 플레이어가 현재 손패를 해석하는 데 쓰는 짧은 기준입니다.

대상 대기 카드는 `Wait enemy`, `Wait damage`처럼 왜 기다리는지 버튼에서 먼저 말해야 합니다.

대기 중이던 카드가 적 출현, 구조물 피해, 마나 회복 때문에 바로 사용 가능해지면 하단 손패 계획에 `Ready now` 전환 큐를 한 번 보여줍니다.

처치가 발생하면 하단 자원 영역의 `Combat gains` 줄에 마지막 처치로 얻은 마나, 골드, 드로우 게이지, 보상 드로우 결과를 짧게 보여줍니다.

처치 자원으로 새 카드가 바로 사용 가능해지면 `Combat follow-up` 로그를 남기고, 빠른 행동 버튼이 같은 후속 카드를 표시합니다.

직업 효과가 발동하면 `Class effects` 줄에 누적 요약을 표시하고, 라운드 리포트에는 이번 라운드에 실제 발동한 효과만 짧게 남깁니다.

구조물 파괴나 계획 붕괴 뒤에는 추천 설치 타일을 `B`로 표시하고, 전술 힌트에 `Rebuild` 줄을 추가해 다음 방어선 판단으로 연결합니다.

손패가 가득 차 보상 드로우가 보류되거나 다음 처치가 드로우를 터뜨릴 수 있으면 `Hand pressure` 줄에서 먼저 경고합니다.

손패 압박 중 바로 쓸 카드가 있으면 버리기 버튼은 먼저 카드를 사용해 빈칸을 만들라고 안내합니다.

바로 쓸 카드가 없고 마나 부족 카드만 남았거나 손패 압박이 드로우 손실로 이어질 때는 버리기 버튼, 후보 카드 슬롯, 선택 카드 상세창이 버리기 이유를 제안합니다.

버리기 직후에는 새로 사용 가능해진 카드나 여전히 막힌 이유를 `Discard follow-up` 로그로 짧게 남기고, 빠른 행동 버튼이 같은 후속 카드를 `Follow-up`으로 표시합니다.

이 제안은 카드 사용을 대신하지 않으며, 버리기 횟수와 마나 회복 규칙은 그대로 따릅니다.

### 전투 화면 상태

전투 화면은 현재 상태에 따라 강조하는 UI가 달라집니다.

| 상태 | 강조 | 낮추는 정보 |
| --- | --- | --- |
| 준비 중 | 다음 웨이브 방향, 설치 가능 타일, 시드 마나 | 적 체력 세부 수치 |
| 웨이브 진행 중 | 기지 위험, 카드 사용, 구조물 체력 | 상점/장기 성장 정보 |
| 웨이브 겹침 중 | 활성 웨이브 수, 적 밀도, 버리기 횟수 | 보상 기대 표현 |
| 보스전 | 보스 경로, 부위 체력, 다음 패턴 | 일반 웨이브 세부 목록 |
| 보상 선택 | 카드 후보, 현재 덱, 거절 | 전투 HUD |
| 상점 | 파티 골드, 다음 압박, 제거/강화 비용 | 전투 알림 |

### 파티 소모품 퀵슬롯

상점에서 산 소모품과 일회성 주문은 손패가 아니라 파티 공유 퀵슬롯에 표시합니다.

기본 슬롯은 2개입니다.

| 상태 | 표시 |
| --- | --- |
| 빈 슬롯 | 작은 빈 아이콘과 `소모품 없음` 툴팁 |
| 사용 가능 | 아이콘, 남은 유효 웨이브, 사용 창 배지 |
| 사용 불가 | 회색 아이콘과 불가 이유 |
| 만료 임박 | 노란 테두리와 남은 일자/웨이브 |
| 전투 중 사용 | 1초 예고 핑, 사용 플레이어 이름, 대상 하이라이트 |

소모품 퀵슬롯은 카드 손패보다 작게 표시합니다.

카드처럼 드로우되거나 버려지는 것처럼 보이면 안 됩니다.

소모품 사용 버튼에는 보상, 효율, 희귀도, 겹치기 보너스 같은 문구를 쓰지 않습니다.

### 웨이브 겹치기 투표 UX

웨이브 겹치기 투표는 전투를 멈추는 회의가 아니라, 전투 중 짧게 뜨는 파티 템포 확인입니다.

상단 우측 버튼 문구는 `다음 웨이브 당기기`를 기본으로 사용합니다.

M0 영어 프로토타입에서는 같은 의미로 `Pull next wave`를 사용하고, 투표 중 동의 버튼은 `Approve pull`, 보류 버튼은 `Hold pull`로 표시합니다.

버튼 주변에는 보상, 효율, 희귀도, 추가 선택지 같은 기대 문구를 두지 않습니다.

위험 이유는 내부 태그가 아니라 `damaged structures`, `enemy density rising`, `hand near full`, `base HP low`처럼 바로 읽히는 짧은 라벨로 표시합니다.

위험 미리보기 첫 줄은 `Pull check: pull/prepare/hold/blocked`처럼 결론을 먼저 표시하고, 아래에 전선, 구조물, 손패 압박 이유를 붙입니다.

두 번째 판단 줄은 `Pull tempo: hold/prepare/ready` 형식으로 다음 스폰 응답과 해당 전선 방어 상태를 연결합니다. 이 줄은 당기기를 보상 선택이 아니라 현재 전선이 더 빠른 스폰을 견딜 수 있는지 확인하는 템포 선택으로 읽히게 합니다.

호출이 확정되면 `Pull impact` 줄을 즉시 추가해 겹침 깊이, 당긴 라운드, 활성 큐, 다음 스폰을 보여줍니다. 같은 줄에 `No bonus rewards`를 유지해 압박 증가와 보상 증가를 분리합니다.

| 상태 | 화면 표시 | 기본 처리 |
| --- | --- | --- |
| 제안 가능 | 현재 겹침 수, 다음 웨이브 방향, 위험 수준 | 버튼 또는 `wave_pull_suggest` 핑으로 제안 |
| 위험 미리보기 | 다음 `WaveSpawnPlan`의 방향, 적 역할, 겹치기 위험 이유 | 작은 패널로 2~3초 안에 읽힘 |
| 투표 중 | 당기기/보류 버튼, 남은 시간, 동의 수 | 시간 초과 시 보류 |
| 당기기 확정 | 짧은 카운트다운, 스폰 방향 게이트 강조 | 예고된 방향에서만 스폰 |
| 보류됨 | 보류 이유 태그와 짧은 쿨다운 | 전투 흐름을 멈추지 않고 접음 |
| 당기기 불가 | 한도 도달, 다음 웨이브 미확정, 보스일 제한 등 이유 표시 | 버튼 비활성화 |

보류 버튼은 실패나 거절이 아니라 전술 응답입니다.

좋은 보류 문구:

```text
보류: 동쪽 바리케이드 표식 해소 후 다시 호출
```

나쁜 보류 문구:

```text
호출이 실패했습니다
```

기지 체력이 30% 이하가 되면 투표 UI는 자동으로 전원 동의 상태로 바뀝니다.

이때 이미 과반수가 동의했더라도 즉시 호출하지 않고, 부족한 동의를 기다리거나 보류로 종료합니다.

### 중단/재개 UI 흐름

세션 중단과 재개는 `session_resume_flow`로 표시합니다.

| 항목 | 표시 | 금지선 |
| --- | --- | --- |
| 저장점 배지 | `저장됨`, 일자, 상점/보스/하루 시작 상태 | 전투 중 수동 저장 버튼을 MVP에 노출하지 않음 |
| 끊김 감지 배지 | 플레이어 이름 옆 작은 연결 상태 | 화면 중앙을 막는 실패 연출 금지 |
| 직업 보류 패널 | 해당 직업 카드 잠김, 구조물 유지 표시 | AI가 대신 플레이 중처럼 보이는 문구 금지 |
| 복귀 패널 | 현재 일자, 진행 중 웨이브, 남은 투표 시간 | 방향/난이도 재계산 안내 금지 |
| 장기 이탈 알림 | 다음 안정 저장점까지 보류 유지 | 남은 플레이어 보상/페널티 문구 금지 |
| 재개 확인 | 같은 직업으로 복귀, 손패/마나 복원 | 새 선택지 뽑기나 보상 되돌리기처럼 표시 금지 |

좋은 문구:

```text
건축가가 잠시 보류 상태입니다. 구조물은 유지되며 개인 카드는 사용되지 않습니다.
```

나쁜 문구:

```text
건축가 이탈 보상으로 추가 카드 후보가 열렸습니다.
```

비활성 방향은 재개 UI에서도 어둡게만 표시합니다.

복귀 화면에서 현재 접속 인원으로 활성 방향이 바뀌는 것처럼 보이면 안 됩니다.

상태가 바뀔 때 UI가 갑자기 재배치되면 안 됩니다.

같은 정보는 가능한 한 같은 위치에 남아 있어야 합니다.

## 예고와 피드백 루프

예고 UI는 공포를 줄이는 장치가 아닙니다.

알고도 막아야 하는 압박을 만들어, 실패했을 때 납득 가능한 원인을 남기는 장치입니다.

### 위험 정보 흐름

하루 시작 예고

활성 방향, 주요 적 역할, 겹치기 친화도, 계절 타일 위험을 보여줍니다.

준비 중 전장 미리보기

실제 스폰 방향, 예상 경로, 설치 위험 권역, 파괴 표식 후보를 전장 위에 겹쳐 보여줍니다.

웨이브 시작 확인

예고와 실제 스폰이 일치하는지 확인시키고, 첫 위험 적이 등장하는 방향을 강조합니다.

전투 중 위험 승격

기지 도달, 구조물 파괴, 손패 막힘, 보스 패턴처럼 즉시 판단이 필요한 정보만 더 큰 경고로 올립니다.

웨이브 후 짧은 정산

가장 많이 뚫린 방향, 가장 오래 버틴 구조물, 사용한 대응 태그를 3초 이내로 요약합니다.

패배 분석

패배했다면 원인 카드 3장 이하로 "다음에 바꿔볼 지점"을 보여줍니다.

### 예고 정보 계층

| 정보 | 표시 시점 | 표시 위치 | 숨기면 안 되는 경우 |
| --- | --- | --- | --- |
| 활성 방향 | 런 시작, 하루 시작 | 맵 가장자리, 상단 좌측 예고 | 모든 웨이브 |
| 실제 스폰 방향 | 하루 시작, 준비 중 | 방향 게이트와 경로선 | 일반 웨이브, 겹치기 투표 |
| 적 역할 | 하루 시작, 첫 등장 전 | 상단 좌측 아이콘, 우측 로그 | 첫 등장, 정예, 방해형 |
| 경로 변화 | 준비 중, 변화 3~5초 전 | 전장 위 경로선 | 낙엽, 결빙, 압력 권역 |
| 구조물 파괴 표식 | 피해 2.5~4초 전 | 구조물 위 표식과 타이머 | 파괴형, 보스 짓누르기 |
| 손패/마나 막힘 | 막힘 1초 이상 | 하단 손패 근처 | 드로우 손실, 버리기 가능 |
| 보스 치명 패턴 | 패턴 4~6초 전 | 중앙 상단, 대상 권역 | 기지 도달, 부위 방치 |
| 겹치기 위험 | 투표 전과 진행 중 | 상단 우측 투표 UI | 겹침 2개 이상, 친화도 높음 |

예고 문구의 방향명은 항상 현재 런의 활성 방향 중 하나여야 합니다.

원본 웨이브가 비활성 방향을 선호하더라도, UI에는 실제 대체된 활성 방향만 표시합니다.

비활성 방향은 어둡게 보일 수 있지만, 일반 웨이브 위험처럼 강조하지 않습니다.

### 웨이브 예고 카드 구성

하루 시작 예고 카드는 공략 정답이 아니라, 파티가 같은 질문을 보게 만드는 짧은 회의 안건입니다.

한 번에 크게 보이는 카드는 최대 3장입니다. 더 많은 정보가 필요하면 세부 펼침에 넣고, 전장 위 미리보기와 핑 후보로 보조합니다.

| 카드 유형 | 데이터 출처 | 보여줄 내용 | 금지선 |
| --- | --- | --- | --- |
| 질문 카드 | `WaveIntent` | 오늘 웨이브가 묻는 핵심 질문 | 새 규칙처럼 과장하거나 정답 빌드 표시 |
| 전선 카드 | `WaveSpawnPlan` | 실제 스폰 방향, 경로 성격, 도달 위험 | 비활성 방향을 위험처럼 강조 |
| 적 역할 카드 | `EnemyRoleProfile` | 주 적 역할 1~2개와 필수 예고 | 적 이름만 나열하고 역할을 숨김 |
| 대응 카드 | `ResponseTag` | 열려 있는 대응 태그 2~4개 | 특정 카드나 특정 직업을 필수처럼 표시 |
| 템포 카드 | 겹치기 친화도 | 다음 웨이브 호출 시 위험해지는 이유 | 보상, 효율, 희귀도 문구 |

예시:

```text
오늘의 질문: 표식된 구조물을 살릴까, 버릴까?
동쪽 짧은 경로: 파괴형이 먼저 들어옵니다.
열린 대응: 수리 창 / 희생 가치 / 후방 재건
```

예고 카드의 우선순위는 고정 순서가 아니라 위험도에 따라 정합니다.

처음 등장하는 적 역할, 기지 피해가 빠른 방향, 보스 치명 패턴, 겹치기 위험이 높은 웨이브가 먼저 보입니다.

### 위험 표시 문법

| 위험 | 표시 문법 | 예시 문구 |
| --- | --- | --- |
| 방향 압박 | 방향 화살표 + 경로선 + 적 역할 아이콘 | `빠른 적이 서쪽에서 접근합니다.` |
| 구조물 파괴 | 대상 구조물 테두리 + 짧은 타이머 | `동쪽 바리케이드가 표식되었습니다.` |
| 경로 변화 | 바뀔 경로를 점선으로 먼저 표시 | `낙엽 경로가 곧 바뀝니다.` |
| 손패 막힘 | 드로우 게이지 옆 작은 막힘 표시 | `패가 가득 차 다음 드로우가 지연됩니다.` |
| 겹치기 위험 | 현재 겹침 수 + 위험 이유 | `겹치기 위험 높음: 돌파형과 방해형 동시 접근` |
| 보스 패턴 | 대상 권역 + 중앙 카운트다운 | `짓누르기까지 4초` |

웨이브 겹치기 위험 문구에는 보상, 효율, 보너스라는 단어를 쓰지 않습니다.

### 경고에서 핑으로 이어지는 규칙

전투 중 자동 경고는 플레이어의 판단을 대신하지 않고, 지금 말해야 할 대상을 좁혀주는 역할만 합니다.

자동 경고와 플레이어 핑은 화면에서 분리해 보입니다.

| 구분 | 표시 | 조작 |
| --- | --- | --- |
| 자동 경고 | 회색/흰색 경고 테두리, 방향 라벨, 짧은 타이머 | 클릭하면 관련 핑 후보를 펼침 |
| 플레이어 핑 | 플레이어 색상, 이름표, 핑 아이콘 | 동의, 맡음, 취소, 세부 보기 가능 |
| 맡음 표시 | 작은 체크 또는 손 아이콘, 최대 2명 표시 | 맡은 플레이어가 직접 해제 가능 |
| 해소 표시 | 테두리가 얇아지고 로그에 한 줄 결과만 남음 | 전투 화면을 막지 않음 |

자동 경고가 바로 생성되는 상황:

- 기지 도달 예상 시간이 짧은 적이 생김
- 표식된 구조물이 곧 파괴됨
- 보스 패턴 대상 권역이 확정됨
- 손패가 가득 차 드로우 손실이 발생하려 함
- 겹치기 중 적 밀도와 구조물 피해가 동시에 높아짐

### 기지 도달 경고 단계

기지 도달 경고는 플레이어를 꾸짖는 알람이 아니라, 남은 몇 초 안에 할 말을 줄여주는 신호입니다.

| 단계 | 표시 조건 | 화면 처리 | 소리/진동 | 우선순위 |
| --- | --- | --- | --- | --- |
| `notice` | 예상 도달 6~10초 | 방향 가장자리 화살표, 얇은 경로 pulse | 없음 또는 매우 낮음 | 일반 위험 목록 |
| `warning` | 예상 도달 3~6초, 예상 피해 2 이상, 빠른 적 누수 가능 | 기지 외곽 도착 지점 링, 방향 라벨, 핑 후보 버튼 | 짧은 낮은 음 | 큰 경고 후보 |
| `critical` | 예상 도달 3초 이하, 기지 체력 1~9에서 피해 예상, 피해 후 0 도달 가능 | 중앙 상단 경고, 대상 방향 강한 테두리, 하단 손패 근처 작은 재확인 | 낮은 1회 pulse | 보스 치명 패턴과 같은 최상위 |
| `boss_reach` | 보스가 기지 외곽 경고권에 진입 | 보스 전용 5초 카운트다운, 보스 경로 강조 | 별도 보스 cue | 일반 경고로 접지 않음 |

기지 도달 경고는 동시에 크게 1개만 보여주는 것을 기본으로 합니다.

다른 구조물 경고가 떠 있어도, 기지 치명 경고가 생기면 구조물 경고는 우측 위험 목록으로 접습니다.

단, 보스 전용 5초 카운트다운은 기지 치명 경고가 생겨도 숨기지 않고 같은 상단 영역에서 분리합니다.

기지 경고의 방향명은 항상 현재 런의 활성 방향 중 하나여야 합니다.

솔로 플레이에서는 동쪽 경고만 실제 전투 위험으로 표시하고, 원본 웨이브의 다른 방향 의도는 동쪽 전선 안의 적 역할이나 경로 성격으로 번역합니다.

### 기지 위험 핑 후보 우선순위

기지 경고를 클릭하면 상황에 맞는 핑 후보를 2~4개만 보여줍니다.

첫 번째 후보는 정답이 아니라 가장 말하기 쉬운 후보이며, 플레이어가 확정하기 전까지 직접 핑으로 기록하지 않습니다.

| 상황 | 1순위 후보 | 보조 후보 | 숨기는 후보 |
| --- | --- | --- | --- |
| 빠른 적 1~2마리 누수 | 둔화/제어 요청 | 집중 화력, 경로 확인 | 수리 대상이 없으면 수리 요청 숨김 |
| 느린 대형 적 누수 | 집중 화력 | 후방 킬존 이전, 경로 확인 | 짧은 CC만으로 해결되는 것처럼 보이는 문구 |
| 구조물 파괴 후 경로가 짧아짐 | 경로 확인 | 후방 킬존 이전, 수리 요청 | 이미 파괴된 구조물 수리 |
| 치명 체력에서 피해 예상 | 후퇴/보류 | 둔화/제어 요청, 소모품 사용 후보 | 웨이브 호출 제안 |
| 보스 도달 카운트다운 중 일반 적 누수 | 집중 화력 | 둔화/제어 요청, 후방 킬존 이전 | 보스 카운트다운을 끄는 것처럼 보이는 후보 |

위험 핑 후보는 특정 직업을 요구하지 않고 대응 태그로 말합니다.

예를 들어 `원소술사가 얼려야 함`이 아니라 `둔화/제어 요청`으로 표시합니다.

M0 영어 프로토타입에서는 `Risk pings: east structure danger -> Repair request, Focus fire | candidate only until confirmed`처럼 표시해, 시스템 후보와 플레이어가 확정한 핑을 구분합니다.

후보 버튼을 누르면 그때만 `Risk ping confirmed`로 활동 로그에 기록하고, 누르지 않은 후보는 핑 한도나 플레이어 행동 기록에 포함하지 않습니다.

확정된 위험 핑이 특정 타일을 가리키면 맵에는 `P` 마커를 짧게 표시하고, 다음 전투 스텝이나 새로운 템포 결정이 일어나면 자동으로 접습니다.

기지 위험 핑은 플레이어 직접 핑 한도에 포함되지만, 시스템이 펼쳐둔 후보 상태는 한도에 포함하지 않습니다.

자동 경고가 제안할 수 있는 핑 후보:

| 경고 | 핑 후보 |
| --- | --- |
| 기지 도달 임박 | 집중 화력, 둔화/제어 요청, 경로 확인, 후방 킬존 이전, 후퇴/보류 |
| 구조물 파괴 임박 | 수리 요청, 희생 유지, 후방 재건 |
| 방해형 생존 | 우선 처치, 경로 격리, 보류 |
| 보스 부위 방치 | 부위 집중, 도발 위치 조정, 수리 요청 |
| 겹치기 위험 상승 | 보류, 경로 확인, 수리 요청 |

자동 경고는 동시에 크게 2개까지만 보입니다.

세 번째 위험부터는 우측 위험 알림 목록에 접어두고, 기지 피해나 보스 치명 패턴이 생기면 자동으로 우선순위를 바꿉니다.

플레이어가 직접 남긴 핑은 자동 경고보다 작은 소리와 짧은 흔들림을 쓰되, 소유자와 의도를 더 명확히 표시합니다.

핑을 누르지 않았다는 이유로 실패 리포트에서 개인 책임을 표시하지 않습니다.

### 웨이브 후 회수 카드

웨이브가 끝나면 방금 예고한 질문을 짧게 회수합니다.

성공 리포트는 칭찬 점수표가 아니라 "무엇이 통했는가"를 보여주고, 실패 리포트는 "다음에는 무엇을 바꿔볼 수 있는가"를 보여줍니다.

| 회수 항목 | 보여줄 내용 | 예시 |
| --- | --- | --- |
| 물었던 질문 | `WaveIntent`의 핵심 질문 | `표식 구조물을 살릴지 버릴지 묻는 웨이브였습니다.` |
| 실제 위험 | 가장 피해가 컸던 방향/적 역할/구조물 | `동쪽 전면 바리케이드가 연쇄 파괴되었습니다.` |
| 사용한 대응 | 실제 발생한 `responseTags` | `수리 창은 열렸지만 후방 재건은 쓰이지 않았습니다.` |
| 다음 연결 | 보상 후보, 상점 추천, 훈련장 링크 | `다음 보상에는 후방 재건 대응 후보가 우선 노출됩니다.` |

웨이브 후 회수 카드는 3초 안에 읽히는 요약을 기본으로 하고, 세부 분석은 패배 화면이나 도감/훈련장으로 넘깁니다.

### 최종 10일 예고

91일 이후 예고 UI는 새 정보를 많이 보여주기보다, 남은 선택을 압축해서 보여줍니다.

표시 정보:

- 마지막 10일 단계
- 오늘 확인할 핵심 약점 1개
- 다음 3일 안에 다시 등장할 압박
- 현재 유지 중인 핵심 아티팩트 1~2개
- 마지막 킬존 후보 위치

예시:

```text
최종 10일: 중반
오늘 점검: 구조물 파괴
다음 압박: 마지막 상점 -> 정예 분담
핵심 유지: 속삭이는 못 / 푸른 축전석
```

99일 예고에는 새 규칙 문구를 넣지 않습니다.

100일 예고는 보스 부위, 장기 압력 권역, 단계별 재배치 시간을 먼저 보여주고, 일반 동반 웨이브 정보는 그 아래에 둡니다.

### 경고 압축 규칙

한 화면에 동시에 크게 띄우는 경고는 1개만 둡니다.

보조 경고는 최대 2개까지 작은 칩으로 표시합니다.

우측 경고 로그는 최근 5개까지만 남기고, 같은 원인의 반복 경고는 하나로 묶습니다.

## 전투 HUD 우선순위

전투 중 가장 먼저 보여야 하는 정보:

1. 기지에 곧 도달하는 적
2. 곧 파괴될 구조물
3. 적 경로 변화
4. 보스 패턴 예고
5. 웨이브 겹치기 투표
6. 손패와 마나
7. 보상 가능 상태

UI가 바쁘면 손패보다 전장 위험이 우선입니다.

카드 게임이지만, 기지 방어 게임이라는 점을 잊으면 안 됩니다.

### 경고 단계

경고는 심각도에 따라 표시 위치와 소리를 다르게 합니다.

| 단계 | 조건 | 표시 방식 | 소리 |
| --- | --- | --- | --- |
| 주의 | 5초 안에 구조물 피해 예상 | 작은 테두리, 우측 로그 | 낮은 클릭음 |
| 위험 | 핵심 구조물 체력 30% 이하 | 구조물 위 경고, 핑 제안 | 짧은 경고음 |
| 치명 | 기지 피해 3초 전 | 기지 방향 화살표, 화면 가장자리 강조 | 가장 높은 우선순위 |
| 보스 치명 | 보스 기지 도달 예고 | 중앙 상단 카운트다운 | 저음과 짧은 박자 |

같은 단계 경고가 여러 개면 기지에 가까운 것부터 보여줍니다.

경고 로그는 최근 5개까지만 남깁니다.

전투 중 우측 로그가 너무 길어지면 오래된 주의 경고부터 접습니다.

### HUD 혼잡 완화

전투가 과밀해졌을 때 숨기거나 줄일 수 있는 정보:

- 낮은 피해 숫자
- 이미 안정적인 구조물 체력바
- 멀리 있는 일반 적 이름표
- 오래된 핑 로그
- 완료된 투표 결과

절대 숨기면 안 되는 정보:

- 기지 체력
- 현재 손패와 마나
- 설치 불가 이유
- 보스 패턴 예고
- 웨이브 겹치기 현재 수
- 패배 직전 경고

### 기지 체력 상태 표시

기지 체력은 숫자와 상태 배지를 함께 보여줍니다.

| 체력 | 상태 배지 | 표시 규칙 |
| ---: | --- | --- |
| 21~30 | 안정 | 작게 표시하되 항상 보임 |
| 10~20 | 위험 | 다음 상점 회복/경로 추천과 연결되는 노란 배지 |
| 1~9 | 치명 | 화면 가장자리 경고, 웨이브 겹치기 전원 동의 문구 |
| 0 | 붕괴 | 결과 화면으로 전환 |

기지 외곽 경고권에 적이 들어오면 방향, 예상 도달 시간, 예상 기지 피해를 함께 표시합니다.

같은 0.75초 안에 여러 적이 도달하면 `동쪽 누수 x3 / 피해 4`처럼 묶어서 보여줍니다.

묶음 표시는 화면을 정리하기 위한 것이며, 피해 감소처럼 보이면 안 됩니다.

## 웨이브 겹치기 UI

버튼 이름:

- `다음 웨이브 호출`

피해야 할 이름:

- `추가 보상`
- `고위험 고보상`
- `보너스 웨이브`
- `러시 보상`

투표 표시:

```text
다음 웨이브를 지금 호출할까요?
현재 겹침: 1 / 3
동의 2 / 4
남은 시간 6초
```

기지 체력 30% 이하:

```text
기지가 위험합니다.
전원 동의가 필요합니다.
동의 3 / 4
```

투표 결과:

- 호출: 짧은 카운트다운 후 다음 웨이브가 예고된 방향에서 시작됩니다.
- 보류: 페널티 없이 전투를 계속하며, 보류 이유를 짧게 남깁니다.
- 시간 초과: 자동 호출하지 않고 보류로 처리합니다.

투표 보류 후 같은 플레이어가 다시 제안할 수 있습니다.

단, 같은 웨이브에 대한 중복 제안은 기존 투표 UI에 합쳐 표시합니다.

버튼 비활성화 사유:

| 상태 | 문구 |
| --- | --- |
| 겹침 한도 도달 | 현재 호출 가능한 웨이브가 없습니다 |
| 보상 선택 중 | 보상 선택 후 호출할 수 있습니다 |
| 상점 화면 | 전투 중에만 호출할 수 있습니다 |
| 다음 웨이브 미확정 | 다음 웨이브를 준비 중입니다 |
| 튜토리얼 제한 | 먼저 기본 방어를 배워야 합니다 |

버튼 주변에는 골드, 카드, 희귀도와 관련된 강조를 붙이지 않습니다.

호출 성공음도 보상음이 아니라 경보음에 가깝게 만듭니다.

## 핑과 협동 요청 UI

핑은 채팅을 대체하는 짧은 전술 언어입니다.

핑은 명령이 아니라 제안입니다.

누군가 핑을 찍었다고 해서 다른 플레이어의 카드, 마나, 구조물 소유권이 자동으로 바뀌지 않습니다.

### 협동 콜 흐름

위험 인지

예고 UI나 전투 경고가 위험 방향, 적, 구조물을 보여줍니다.

핑 제안

플레이어가 위치나 대상을 찍어 "여기를 보자"는 짧은 제안을 남깁니다.

맡음 표시

다른 플레이어가 같은 핑에 체크하거나, `내가 볼게` 표시를 남깁니다.

행동 연결

요청형 핑을 누르면 관련 카드, 구조물, 경로 미리보기가 하이라이트됩니다.

해소

대상이 처치되거나 구조물이 수리되거나 위험 시간이 지나면 핑이 자동으로 접힙니다.

리포트 반영

웨이브 후 리포트는 어떤 대응 핑이 실제 행동으로 이어졌는지 짧게 남깁니다.

기본 핑:

| 핑 | 용도 | 표시 |
| --- | --- | --- |
| 수리 요청 | 곧 파괴될 구조물 지목 | 렌치 아이콘과 플레이어 색 |
| 화력 집중 | 우선 처치 대상 지목 | 조준 아이콘 |
| 경로 확인 | 미로 변경 위치 제안 | 얇은 경로 선 강조 |
| 도발 전환 | 수호자에게 어그로 요청 | 방패 아이콘 |
| 둔화/제어 요청 | 빠른 적의 진입 지점 표시 | 눈송이 또는 밀림 아이콘 |
| 후방 킬존 이전 | 방어선을 옮길 후보 위치 표시 | 깃발 아이콘 |
| 보스 부위 집중 | 함께 때릴 보스 부위 표시 | 큰 조준 아이콘 |
| 웨이브 호출 제안 | 투표 버튼 없이 의사 확인 | 작은 투표 말풍선 |
| 후퇴/보류 | 지금은 누르지 말자는 신호 | 손바닥 아이콘 |

핑은 4초 후 약해지고 8초 후 사라집니다.

같은 위치에 핑이 여러 개 찍히면 하나의 묶음으로 접습니다.

파티원이 같은 핑에 동의하면 아이콘이 커지는 대신, 작은 체크 수만 증가합니다.

`내가 볼게` 표시는 체크와 다릅니다.

체크는 동의이고, 맡음 표시는 실제 대응 의사를 뜻합니다.

맡음 표시는 최대 2명까지만 크게 표시하고, 나머지는 작은 숫자로 접습니다.

### 핑 우선순위

| 우선순위 | 핑 | 이유 |
| ---: | --- | --- |
| 1 | 기지 위험 핑 | 즉시 패배와 가장 가깝습니다. |
| 2 | 보스 치명 패턴 핑 | 파티 전체가 같은 타이밍을 봐야 합니다. |
| 3 | 구조물 수리/파괴 핑 | 방어선 붕괴를 막거나 계획된 붕괴를 유도합니다. |
| 4 | 화력 집중/보스 부위 핑 | 공동 목표를 맞춥니다. |
| 5 | 경로 확인/킬존 이전 핑 | 다음 준비나 장기 판단에 필요합니다. |
| 6 | 웨이브 호출 제안/보류 핑 | 투표 전 의사를 확인합니다. |

상위 핑이 뜨면 하위 핑은 투명도를 낮춥니다.

단, 하위 핑을 삭제하지는 않습니다.

### 스팸 방지

한 플레이어가 동시에 유지할 수 있는 직접 핑은 3개까지입니다.

4번째 핑을 찍으면 가장 오래된 직접 핑이 자동으로 접힙니다.

같은 플레이어가 같은 대상에 2초 안에 같은 핑을 반복하면 새 핑을 만들지 않고 기존 핑을 갱신합니다.

전투 경고가 만든 자동 핑은 플레이어 직접 핑 한도에 포함하지 않습니다.

자동 핑은 플레이어 이름 대신 `경고` 출처로 표시합니다.

### 요청형 핑

일부 핑은 버튼으로 바로 행동을 이어갈 수 있습니다.

예시:

- 수리 요청 핑을 누르면 내 수리 카드가 하이라이트됩니다.
- 웨이브 호출 제안 핑을 누르면 정식 투표 UI가 열립니다.
- 경로 확인 핑을 누르면 해당 위치의 배치 미리보기가 켜집니다.

요청형 핑은 자동으로 카드를 사용하지 않습니다.

플레이어의 자원 사용은 항상 직접 입력으로 확정합니다.

### 핑 해소 조건

| 핑 | 자동 해소 조건 |
| --- | --- |
| 수리 요청 | 대상 구조물이 안전 체력 이상으로 회복되거나 파괴됨 |
| 화력 집중 | 대상 적이 처치되거나 기지에 도달함 |
| 경로 확인 | 준비 단계 종료 또는 경로 미리보기 닫힘 |
| 도발 전환 | 도발 대상이 바뀌거나 대상 적이 사라짐 |
| 둔화/제어 요청 | 해당 적 무리가 첫 킬존을 통과함 |
| 후방 킬존 이전 | 새 구조물이 후보 위치에 설치되거나 웨이브 종료 |
| 보스 부위 집중 | 부위 파괴 또는 다음 보스 패턴 시작 |
| 웨이브 호출 제안 | 정식 투표 시작 또는 8초 경과 |
| 후퇴/보류 | 6초 경과 또는 치명 경고 해소 |
| 기지 위험 | 위험 적 처치, 도달 예상 6초 이상으로 회복, 기지 피해 적용, 또는 웨이브 종료 |

## 카드 사용 UX

카드 사용 흐름:

1. 카드 선택
2. 사용 가능 대상 강조
3. 대상 지정
4. 효과 미리보기
5. 사용
6. 카드가 버린 카드 더미로 이동

대상 미리보기:

- 설치 카드: 설치될 구조물과 경로 변화 표시
- 공격 카드: 피해 범위 표시
- 수리 카드: 회복량 표시
- 넉백 카드: 밀릴 방향 표시
- 도발 카드: 도발 범위 표시

사용 불가 사유:

- 마나 부족
- 대상 없음
- 경로 차단 불가
- 손패 한도 초과
- 보스 저항으로 효과 감소

### 카드 입력 확정

카드는 선택 즉시 사용되는 카드와 대상 지정 후 사용하는 카드로 나눕니다.

| 카드 유형 | 확정 방식 |
| --- | --- |
| 즉발 카드 | 선택 즉시 사용, 취소 시간 없음 |
| 대상 카드 | 대상 클릭 후 사용 |
| 설치 카드 | 설치 위치와 경로 미리보기 후 사용 |
| 범위 카드 | 범위 표시 후 클릭으로 확정 |
| 반응 카드 | 조건 발생 시 짧은 사용 창 표시 |

대상 지정 중 우클릭이나 취소 키를 누르면 카드 선택을 해제합니다.

대상 지정 중에도 전투는 멈추지 않습니다.

### 입력 실패 피드백

입력 실패 문구는 짧고 같은 자리에 표시합니다.

| 실패 이유 | 문구 |
| --- | --- |
| 마나 부족 | 마나가 부족합니다 |
| 대상 사라짐 | 대상이 사라졌습니다 |
| 경로 차단 | 기지로 향하는 경로가 필요합니다 |
| 보스 저항 | 보스에게 효과가 감소합니다 |
| 손패 가득 참 | 손패가 가득 찼습니다 |
| 이미 처리 중 | 이미 사용 중인 카드입니다 |

실패한 카드 사용은 마나를 소모하지 않습니다.

카드가 실패했을 때 손패 위치가 흔들리거나 사라지면 안 됩니다.

### 카드 실패 피드백 UX

카드 실패 피드백은 전투를 멈추는 설명창이 아니라, 카드 사용 직후 같은 위치에서 짧게 회수되는 문구입니다.

| 유형 | 표시 위치 | 유지 시간 | 카드/마나 소모 | 예시 |
| --- | --- | ---: | --- | --- |
| 사용 불가 | 손패 카드 위 | 1.2초 | 없음 | 마나가 부족합니다 |
| 조건 낮음 | 대상 또는 구역 위 | 1.4초 | 소모 | 적이 흩어져 효과가 낮습니다 |
| 대가 예고 | 카드 위 확인 칩 | 확정 전까지 | 없음 | 다음 드로우가 줄어듭니다 |
| 대가 적용 | 구조물/손패/게이지 옆 | 2.0초 | 소모 | 과부하 후유 피해가 남습니다 |
| 보스 약화 | 보스 체력바 옆 | 1.6초 | 소모 | 보스에게 약화된 효과로 적용됩니다 |
| 루프 차단 | 관련 게이지 툴팁 | 1.4초 | 추가 보상 없음 | 이 버리기는 보상을 발동하지 않습니다 |

표시 우선순위:

1. 기지 도달 경고
2. 보스 도달/부위 패턴 경고
3. 구조물 붕괴 직전 경고
4. 카드 사용 불가
5. 카드 조건 낮음/대가 적용
6. 루프 차단 안내

동시에 보이는 카드 실패 문구는 플레이어당 1개, 전장 태그는 화면 전체 2개까지입니다.

문구는 `왜 안 됐는지`보다 `다음에 무엇을 볼지`가 먼저 읽혀야 합니다.

금지 문구:

- 실수했습니다
- 잘못 사용했습니다
- 보상 손해
- 희귀도 손해
- 비활성 방향 위험
- 정답 배치

## 경로 표시 UX

경로는 항상 켤 수 있어야 합니다.

표시 단계:

- 기본: 적이 향하는 주요 경로만 표시
- 상세: 방향별 경로와 예상 도달 시간 표시
- 배치 중: 구조물 설치 후 바뀔 경로 미리보기
- 길막 시도: 막힌 경로를 붉게 표시하고 설치 불가

길막 불가 문구:

```text
기지로 향하는 경로가 필요합니다.
```

위험 허용 문구:

```text
경로가 크게 늘어납니다.
파괴형 적이 이 구조물을 노릴 수 있습니다.
```

보스 경로 문구:

```text
보스가 지나갈 폭이 필요합니다.
```

문구는 짧고 단호해야 합니다.

플레이어가 규칙과 싸우는 느낌보다, 전장의 물리 법칙을 이해하는 느낌이 나야 합니다.

### 경로 표시 색상

| 상태 | 표시 |
| --- | --- |
| 기존 경로 | 얇은 회색 선 |
| 새 경로 | 밝은 청록 선 |
| 위험한 우회 | 노란 선 |
| 설치 불가 | 붉은 타일 하이라이트 |
| 보스 경로 | 굵은 흰색 테두리 |

색만으로 구분하지 않고 선 굵기와 아이콘을 함께 사용합니다.

## 라운드 보상 화면

라운드 보상 화면은 빠르게 끝나야 합니다.

구성:

- 카드 3장
- 카드 거절 버튼
- 현재 덱 보기
- 파티 골드 표시

카드에 표시할 정보:

- 비용
- 희귀도
- 키워드
- 직업 태그
- 현재 덱과의 시너지 아이콘

웨이브를 겹쳤더라도 보상 화면에서 보너스 문구를 표시하지 않습니다.

겹친 웨이브가 여러 개라면 보상 선택을 순서대로 빠르게 처리합니다.

### 보상 선택 잠금 흐름

보상 선택 화면은 개인 판단을 빠르게 끝내고, 파티 토론은 상점으로 넘기는 화면입니다.

기본 상태:

```text
9일 정산
파티 골드 +18

[카드 후보 1] [카드 후보 2] [카드 후보 3] [골드 받기 +8]

덱 18장
이번 선택 후: 19장 또는 파티 골드 +8
```

카드 후보에는 아래 정보만 우선 표시합니다.

- 비용
- 희귀도
- 역할 태그
- 현재 덱에서 겹치는 카드 수
- 다음 1~3일 압박과 연결되는 짧은 이유

자세한 수치와 강화 가능성은 카드를 펼쳤을 때 보여줍니다.

보상 잠금 규칙:

| 상태 | 처리 |
| --- | --- |
| 선택 완료 | 해당 행을 잠그고 다음 행 또는 준비 완료 상태로 이동 |
| 골드 선택 | 개인 보상 거절로 기록하고 파티 골드 예상 합계에 더함 |
| 제한 시간 종료 | 미선택 행만 안전 후보로 임시 잠금 |
| 임시 잠금 되돌리기 | 상점 첫 유료 투표 전까지만 허용 |
| 저주 후보 | 자동 잠금 금지, 대상 플레이어 확인 화면으로 이동 |

멀티플레이에서는 각 플레이어가 자기 보상 행을 병렬로 처리합니다.

이미 끝낸 플레이어는 다른 사람의 화면을 강제로 볼 수 없고, 상점 미리보기, 현재 덱, 다음 예고만 열 수 있습니다.

보상 화면에서 쓰지 않는 문구:

- 지금 안 고르면 손해
- 파티를 위해 선택
- 최고 효율
- 보상 증가
- 겹치기 덕분에 추가

### 20~30일 영웅 후보 표시

영웅 후보는 큰 보상처럼 등장하지 않고, 이미 굴러간 운영을 확정할지 묻는 카드로 표시합니다.

기본 배치:

```text
22일 정산
파티 골드 +18

[희귀 후보] [영웅 후보: 준비된 운영] [덱 보완 후보] [골드 받기 +8]

영웅 후보 펼침:
지원 카드        1장 확인
강화/아티팩트    +1 동등 지원
최근 전투 증거   도발 구조물이 실제로 버팀
남는 대가        수리 효율 감소
```

카드 앞면에는 아래 정보만 표시합니다.

- 비용
- 희귀도
- 역할 태그
- `준비된 운영` 배지
- 남는 대가 1개

조건 세부값은 카드 펼침에서만 보여줍니다.

| 상세 행 | 표시 예시 | 표시하지 않을 것 |
| --- | --- | --- |
| 지원 카드 | 지원 카드 1장 확인 | 시작 카드만으로 충분함 |
| 동등 지원 | 장착 아티팩트 +1 | 아티팩트 보너스, 추가 보상 |
| 최근 증거 | 지난 전투에서 실제로 시간을 벌었습니다 | 처치 수, 클리어 시간, 겹치기 횟수 |
| 남는 대가 | 수리 효율이 낮아집니다 | 순수 상위호환, 무료 강화 |

게이트를 통과하지 못한 영웅 후보는 보상 3장에 잠긴 카드로 남기지 않습니다.

대신 같은 역할의 일반/희귀 하향 후보를 보여주고, 펼침 하단에 작은 이유 칩을 1개만 붙입니다.

| 실패 이유 | 표시 문구 |
| --- | --- |
| 실제 지원 카드 부족 | 이 운영을 받쳐줄 카드가 아직 부족합니다. |
| 런 중 선택 지원 부족 | 시작 덱만으로는 아직 확정하지 않습니다. |
| 최근 전투 증거 부족 | 최근 전투에서 이 운영이 충분히 드러나지 않았습니다. |
| 휴면 아티팩트 | 휴면 아티팩트는 지원으로 계산하지 않습니다. |
| 파편 부족 | 조건은 맞지만 조율 자원이 부족합니다. |

영웅 후보 표시 금지선:

- 영웅 후보에 추천 왕관, 큰 광채, 자동 선택 강조를 붙이지 않습니다.
- 게이트 실패를 빨간 실패, 벌점, 손실처럼 표시하지 않습니다.
- 하향 후보를 네 번째 선택지로 추가하지 않습니다.
- 웨이브 겹치기, 처치 수, 클리어 시간, 비활성 방향을 후보 이유로 쓰지 않습니다.
- 솔로에서는 북쪽/서쪽/남쪽 증거가 없어서 부족하다는 문구를 만들지 않습니다.

### 전리품 변형 카드 보상 표시

전리품 변형 카드는 보상 화면에서 "강화된 기존 카드"가 아니라 "기준 카드와 닮은 새 카드"로 보여야 합니다.

기본 배치:

```text
[일반 후보] [변형 후보] [일반 후보] [골드 받기 +8]

변형 후보 카드 상단:
희귀도 보석     변형 카드

제목
기준 카드: 화염구

효과 문구

[달라진 점: 범위 증가] [남는 약점: 예고 필요] [등장 이유: 킬존 지속 피해]
```

표면 규칙:

| 영역 | 보여줄 것 | 보여주지 않을 것 |
| --- | --- | --- |
| 카드 상단 | 희귀도, `변형 카드` 배지 | `+1`, 상급, 강화 배지 |
| 기준 카드 줄 | `기준 카드: {cardName}` | `{cardName} 강화`, `{cardName} 업그레이드` |
| 비교 버튼 | `차이 보기` | 강화 비교, 수치 상승 비교 |
| 상세 패널 | 기준 효과 1줄, 달라진 점, 남는 약점 | 상승 화살표 중심 비교, 추천 등급 |
| 선택 후 연출 | 새 카드가 덱에 추가됨 | 기존 카드 위에 덮어씌움 |
| 골드 버튼 | 일반 보상과 같은 위계 | 변형을 거절하면 손해라는 강조 |

보유한 기준 카드 수는 작은 덱 정보로만 표시할 수 있습니다.

단, 기준 카드를 대상으로 지정하는 프레임, 연결선, 교체 화살표는 쓰지 않습니다.

위험한 대가가 있는 변형 후보는 제한 시간 종료 시 자동 임시 선택하지 않고, 확인이 필요한 보상으로 남깁니다.

임시 선택 가능한 변형 후보도 잠금 배지에 `새 카드로 임시 선택`을 표시하고, 기존 카드 변경처럼 연출하지 않습니다.

금지 시각 요소:

- 망치 아이콘
- 위쪽 화살표
- 별 등급 상승
- 가격표
- 파티 투표 버튼
- 보유 카드 대상 프레임
- 웨이브 겹치기 보너스 광채
- 비활성 방향 전용 배지

### 첫 10일 보상 표시

첫 10일에는 카드 후보마다 짧은 역할 이유를 붙일 수 있습니다.

이 문구는 추천이 아니라 맥락 표시입니다.

예시:

| 표시 | 의미 |
| --- | --- |
| 방금 본 빠른 적 대응 | 직전 웨이브의 문제 태그와 연결 |
| 현재 덱의 수리 부족 보완 | 덱 태그의 빈틈을 약하게 보완 |
| 보스 부위 집중 준비 | 10일 보스 학습과 연결 |
| 카드 대신 골드 받기 | 덱을 가볍게 유지하는 선택 |

쓰지 않는 표시:

- 추천
- 정답
- 최고 효율
- 겹치기 보너스
- 희귀도 상승

### 첫 10일 회수 문구와 재방문 버튼

첫 10일의 회수 문구는 힌트 패널, 보상 이유, 웨이브 후 리포트, 패배 카드에서 같은 키를 사용합니다.

문구는 한 줄을 기본으로 하고, 두 줄을 넘기지 않습니다.

| 상황 | 표시 방식 | 예시 |
| --- | --- | --- |
| 웨이브 예고 | 작은 보조 문구 | 경로를 먼저 보고 첫 타워를 놓습니다. |
| 전투 중 반복 위험 | 경고 옆 짧은 문구 | 빠른 적은 첫 굴곡에서 늦춥니다. |
| 웨이브 후 리포트 | 회수 카드 첫 줄 | 표식 구조물은 살릴지 버릴지 먼저 정합니다. |
| 패배 카드 | 다음 시도 카드 | 보스는 본체보다 부위와 시간을 먼저 봅니다. |
| 보상 이유 | 후보 하단 맥락 태그 | 방금 드러난 약점과 연결 |

재방문 버튼:

| 버튼 | 동작 | 화면 처리 |
| --- | --- | --- |
| 짧게 연습 | 30~60초 훈련 장면 열기 | 현재 런과 분리된 작은 전장 |
| 3줄 보기 | 도감 카드 열기 | 행동, 저항, 대응 태그만 표시 |
| 메모로 가져가기 | 새 런 준비 메모 저장 | 자동 빌드 적용 없음 |
| 닫기 | 제안 접기 | 같은 일자에서 다시 재촉하지 않음 |

버튼은 최대 4개를 한 줄 또는 2x2로 표시합니다.

화면 중앙을 막는 모달보다, 리포트 카드 하단의 작은 행동줄을 기본으로 사용합니다.

쓰지 않는 문구:

- 반드시 선택
- 정답 카드
- 이 훈련을 완료해야 함
- 보상 증가
- 더 좋은 희귀도
- 다른 방향도 막아야 함

### 압축 정산 화면

겹친 웨이브의 보상은 "한 번에 몰아받기"가 아니라 "각 웨이브 정산을 한 화면에서 잠그기"로 보여줍니다.

M0 프로토타입에서는 겹친 웨이브가 끝나면 `Compressed settlement`와 `No bonus rewards`를 함께 표시해, 정산 패킷이 늘어도 보상 총량이 늘어난 것이 아님을 고정합니다.

표시 예시:

```text
정산 3개
8일 정산  [카드 3장 중 1장]
9일 정산  [카드 3장 중 1장]
10일 정산 [카드 3장 중 1장]
```

골드는 상단에 합산 표시하고, 세부 내역은 펼침으로 둡니다.

카드 보상은 각 정산 행마다 독립적으로 고릅니다.

행별 버튼:

| 버튼 | 의미 |
| --- | --- |
| 카드 선택 | 해당 웨이브 보상 팩에서 카드 1장을 덱에 넣습니다. |
| 골드 선택 | 해당 웨이브 보상 팩을 거절하고 골드를 받습니다. |
| 임시 선택 | 제한 시간이 끝났을 때 안전 후보를 잠그며, 상점 첫 유료 투표 전까지 되돌릴 수 있습니다. |

보상 화면에는 아래 문구를 쓰지 않습니다.

- 누적 보너스
- 추가 보상
- 연속 클리어 보상
- 겹침 보너스
- 3배 보상
- 희귀도 상승

멀티플레이에서는 각 플레이어가 자기 정산 묶음을 병렬로 선택합니다.

선택하지 않은 플레이어는 작은 대기 표시로만 보여주고, 화면 중앙을 막지 않습니다.

제한 시간이 끝나면 미선택 행만 안전한 후보가 임시 선택되며, 이미 선택한 행은 건드리지 않습니다.

### 보상/정산 문구 키

보상과 압축 정산 화면은 아래 키를 사용합니다.

| 키 | 표시 문구 | 사용 위치 |
| --- | --- | --- |
| `ui.reward.title` | 보상 선택 | 보상 화면 제목 |
| `ui.reward.pick_card` | 카드 1장을 덱에 넣습니다. | 카드 후보 설명 |
| `ui.reward.take_gold` | 카드를 고르지 않고 골드를 받습니다. | 골드 선택 버튼 |
| `ui.reward.temporary_lock` | 미선택 보상은 안전 후보로 임시 선택됩니다. | 제한 시간 안내 |
| `ui.reward.revert_until_shop` | 첫 유료 상점 투표 전까지 되돌릴 수 있습니다. | 임시 선택 배지 |
| `ui.reward.heroic_ready_badge` | 준비된 운영 | 영웅 후보 카드 상단 배지 |
| `ui.reward.heroic_support_row` | 지원 카드 {actualCount}장 / 동등 지원 +{equivalentCount} | 영웅 후보 상세 |
| `ui.reward.heroic_recent_proof` | 최근 전투에서 {proofSummary} | 영웅 후보 상세 |
| `ui.reward.heroic_tradeoff` | 남는 대가: {tradeoffSummary} | 영웅 후보 상세 |
| `ui.reward.heroic_downgrade_reason` | 아직 이 운영이 충분히 굴러가지 않았습니다. | 하향 후보 상세 |
| `ui.settlement.title` | 정산 {count}개 | 압축 정산 제목 |
| `ui.settlement.row_day` | {day}일 정산 | 정산 행 제목 |
| `ui.settlement.no_bonus` | 각 일자의 보상을 한 화면에서 정리합니다. | 압축 정산 보조 문구 |

이 화면에서 `포기`, `손해`, `3배 보상`, `겹치기 보너스`, `희귀도 상승`, `추가 선택지`는 사용하지 않습니다.

### 정비 진입 화면

보상 선택이 끝나면 바로 상점 목록을 띄우지 않습니다.

먼저 3~5초 동안 이번 선택이 다음 정비에 어떤 질문을 남겼는지 보여줍니다.

```text
정비 메모
덱: 수호자 +1장, 땜장이 골드 선택
파티 골드: 86
최근 문제: 구조물 연쇄 파괴, 손패 막힘

다음 선택: 카드 제거 / 강화 / 기지 회복 중 하나를 비교하세요
```

이 화면은 추천 구매가 아니라 토론 시작점입니다.

정비 진입 화면에서 바로 구매를 확정하지 않고, 첫 유료 상점 항목을 누를 때부터 파티 투표를 시작합니다.

저주 계약이 남아 있으면 정비 메모보다 저주 확인을 먼저 처리합니다.

## 아티팩트 선택 화면

아티팩트 선택 화면은 파티가 다음 10일의 운영 방향을 고르는 화면입니다.

후보를 크게 보여주기 전에 다음 압박과 현재 장착 슬롯을 먼저 보여줍니다.

```text
다음 10일 압박: 빠른 적 / 구조물 연쇄 파괴 / 손패 막힘
현재 슬롯: 2 / 3

[부서진 왕관]
운영 축: 도발/가시
도움: 빠른 적을 전면에 묶어두기
대가: 없음

[푸른 축전석]
운영 축: 드로우/마나 순환
도움: 손패 막힘 완화
대가: 낮은 즉시 화력
```

### 아티팩트 카드 구성

| 영역 | 표시 정보 | 규칙 |
| --- | --- | --- |
| 운영 축 | 도발, 폭발, 오라, 드로우, 보스 대응 등 | 후보 간 축이 겹치면 경고 없이 조용히 구분만 표시 |
| 다음 압박 연결 | 다음 3~10일에 도움이 되는 지점 | 정답 표시처럼 강조하지 않음 |
| 대가 또는 제한 | 비용, 약점, 발동 조건 | 장점보다 작게 숨기지 않음 |
| 현재 시너지 | 장착 중 아티팩트나 자주 쓴 카드와 연결 | 수치 랭킹 대신 연결 태그로 표시 |
| 교체 힌트 | 빼도 되는 후보, 유지 경고 | 슬롯이 가득 찼을 때만 표시 |

아티팩트 후보에는 `최고`, `추천`, `상위호환` 같은 문구를 쓰지 않습니다.

대신 `다음 압박과 관련`, `현재 빌드 핵심`, `대가 큼`처럼 토론을 돕는 태그를 씁니다.

### 슬롯이 가득 찬 경우

슬롯이 가득 찬 상태에서 새 아티팩트를 얻으면 화면은 두 단계로 나뉩니다.

```text
1단계: 새 후보 1개 선택
2단계: 교체할 기존 아티팩트 선택 또는 현재 유지
```

`현재 유지` 버튼은 항상 보입니다.

현재 유지는 보상을 버리는 실패가 아니라, 기존 운영을 지키는 선택입니다.

투표 표시:

```text
푸른 축전석을 장착하고 속삭이는 못을 교체할까요?
동의 2 / 4
```

교체 투표가 끝나기 전에는 상점 투표를 동시에 열지 않습니다.

### 휴면 보관함 표시

아티팩트 교체 화면 아래에는 작은 휴면 보관함 줄을 둡니다.

휴면 보관함은 장착 슬롯과 같은 크기로 보이지 않게 하고, 효과가 꺼져 있음을 명확히 표시합니다.

```text
휴면 보관함 1 / 2
[속삭이는 못] 효과 꺼짐
재장착: 보스 파편 1, 아티팩트 행동 1회
```

표시 규칙:

| 상태 | 표시 |
| --- | --- |
| 빈 휴면 칸 | 작은 빈 아이콘과 `휴면 없음` 툴팁 |
| 휴면 아티팩트 | 회색 카드, `효과 꺼짐`, 마지막 장착 구간 |
| 재장착 가능 | 비용과 행동 한도 표시, 투표 버튼 |
| 재장착 불가 | 이유 1개만 표시: 파편 부족, 행동 한도 소진, 전투 중 |
| 보관함 초과 | 방출할 휴면 아티팩트 1개 선택 또는 현재 유지 |

M0 테스트 장면에서는 정식 투표 대신 `휴면 대상 선택 -> 장착 중 내려보낼 대상 선택 -> 재활성화 구매` 순서의 버튼으로 검증하며, 보스 파편과 아티팩트 행동 한도를 함께 표시합니다.

휴면 보관함에는 `보상`, `추가 슬롯`, `공짜 교체`처럼 읽히는 문구를 쓰지 않습니다.

### 부작용 표시

아티팩트 카드의 대가는 장점보다 작게 숨기지 않습니다.

후보 카드에는 아래 순서로 표시합니다.

```text
효과: 웨이브 겹치기 한도 +1
대가: 겹친 전투 중 구조물 피해 증가
꺼지는 경우: 휴면 보관함에 있을 때
금지: 보상 증가 없음
```

전투 HUD에서는 부작용이 실제로 켜진 순간에만 짧은 칩으로 보여줍니다.

예시:

```text
불안정한 시계: 구조물 피해 증가
```

발동 제한형 아티팩트는 효과를 다 쓴 뒤 `오늘 발동 완료`처럼 회색 태그로 바꿉니다.

부작용 표시가 전투 정보를 가리면 안 되며, 큰 경고 슬롯을 차지하지 않습니다.

## 상점 화면

상점은 파티 토론 화면입니다.

표시 정보:

- 방금 전투 피해 진단 1~3개
- 다음 3~5일 주요 압박
- 파티 골드
- 보스 파편
- 기지 체력
- 다음 보스 또는 다음 계절 예고
- 구매 항목 5~8개
- 카드 제거 비용
- 카드 강화 비용
- 보스 후 상점의 남은 파티 구매 횟수

투표가 필요한 구매:

- 파티 골드로 기지 체력 회복
- 파티 골드로 카드 제거
- 파티 골드로 구조물 기본 강화
- 보스 파편 사용
- 아티팩트 교체

개인 결정:

- 자기 카드 보상 선택
- 상점 항목 상세 보기
- 구매 후보 즐겨찾기 표시

자기 덱에 적용되는 구매라도 파티 골드나 보스 파편을 쓰면 투표가 필요합니다.

보스 후 상점에서는 파티 자원 구매를 최대 2회까지만 허용합니다.

### 영웅 확정 조율 패널

`shop_heroic_tune`은 상점 카드 슬롯이 아니라 조건을 통과한 영웅 운영을 확정하는 파티 구매 패널입니다.

기본 배치:

```text
영웅 확정 조율
대상: 수호자

가시 왕좌
비용: 골드 55 + 보스 파편 1

준비 확인
지원 카드 1장 / 동등 지원 +1 / 최근 증거 1개

남는 대가
도발 구조물 수리 효율 감소

[대상 수락] [보류]
```

대상 플레이어가 수락한 뒤에만 파티 투표가 열립니다.

```text
가시 왕좌 조율에 파티 자원을 사용할까요?
골드 55 + 보스 파편 1
동의 2 / 4
```

패널 상태:

| 상태 | 처리 | 버튼 |
| --- | --- | --- |
| 대상 확인 전 | 카드와 대가를 보여주고 대상 플레이어 결정 대기 | 대상 수락, 보류 |
| 파티 투표 중 | 가격, 남은 구매 한도, 대체 선택 1~2개 표시 | 동의, 보류 |
| 파편 부족 | 조건 요약만 보여주고 구매 흐름 없음 | 닫기 |
| 같은 세션 구매 완료 | 이미 조율한 영웅 카드 표시 | 닫기 |
| 시간 초과 | 구매하지 않고 상점으로 복귀 | 없음 |

비교 패널은 게이트 통과 후보가 여러 개일 때만 열고, 최대 2개까지만 보여줍니다.

비교 행에는 아래 5가지만 표시합니다.

- 받을 플레이어
- 영웅 카드 이름
- 남는 대가
- 최근 증거 태그 1개
- 지금 사지 않으면 남는 대체 선택

조율 흐름:

```text
조건 요약
  -> 대상 확인
  -> 파티 투표
  -> 구매 완료 또는 구매 없음
```

대상 확인 전에는 비교 패널에서 다른 통과 후보를 볼 수 있습니다.

하지만 대상 플레이어가 `보류`를 누르거나 시간이 끝나면 같은 세션의 영웅 조율은 닫힙니다.

그 뒤에는 다른 영웅 후보를 즉시 전면에 올리지 않고, 카드 제거, 강화, 회복, 보류 같은 일반 상점 선택으로 돌아갑니다.

이 흐름은 영웅 조율이 특정 플레이어를 설득하는 압박 UI로 변하지 않게 하기 위한 장치입니다.

영웅 확정 조율 패널에서 쓰지 않는 표현:

- 이번 런 필수
- 파티 추천
- 최고 효율 영웅
- 지금 사지 않으면 손해
- 겹치기로 준비 완료
- 보스 파편 보너스
- 다른 후보로 바꾸기
- 대상 없이 파티가 결정

### 상점 투표 UX

파티 자원을 쓰는 항목은 구매 버튼 대신 투표 버튼을 사용합니다.

투표 표시:

```text
기지 체력 회복에 골드 40을 사용할까요?
동의 2 / 4
```

상점 투표는 전투 중 웨이브 호출 투표보다 느긋하게 진행합니다.

상점에서는 20초 제한 시간을 기본으로 두고, 호스트가 연장할 수 있습니다.

개인 구매는 투표를 기다리지 않고 바로 처리합니다.

파티 구매와 개인 구매가 화면에서 섞이면 안 됩니다.

### 정비 화면 흐름

상점에 들어오면 항목 목록부터 보여주지 않습니다.

먼저 3초 정도의 정비 요약을 보여준 뒤, 상점 항목을 엽니다.

```text
방금 위험: 동쪽 누수 / 구조물 연쇄 붕괴
다음 압박: 빠른 적 + 저항형
추천 축: 둔화, 경로 연장, 카드 제거
```

상점 항목은 아래 네 묶음으로 나눕니다.

| 묶음 | 예시 | 표시 규칙 |
| --- | --- | --- |
| 덱 정리 | 카드 제거, 카드 강화 | 개인 덱 대상과 파티 비용을 함께 표시 |
| 전장 정비 | 기지 회복, 구조물 체력, 수리 효율 | 다음 압박과 연결된 항목을 위로 |
| 위기 대응 | 일회성 주문, 공용 카드 | 다음 3일 안에 쓸 수 있는 항목 위주 |
| 장기 운영 | 아티팩트 교체, 보스 파편 사용 | 보스 후 상점에서만 넓게 표시 |

소모품 항목은 아래 정보를 함께 보여줍니다.

| 정보 | 표시 이유 |
| --- | --- |
| 소모품 슬롯 사용량 | 파티가 들고 갈 수 있는지 즉시 판단 |
| 유효 기간 | 사두고 잊어버리는 상황 방지 |
| 사용 창 | 전투 전, 전투 중, 다음 웨이브 시작, 보스전 구분 |
| 대상 제한 | 활성 방향, 구조물, 정예, 보스 부위 등 오사용 방지 |
| 대체 선택 | 카드 제거, 기지 회복, 강화와 비교하게 함 |

추천 항목은 빛나는 정답처럼 꾸미지 않습니다.

작은 `추천 이유` 줄만 붙입니다.

예시:

```text
추천 이유: 지난 웨이브에서 동쪽 누수가 3회 발생했습니다.
```

### 시간 제한과 연장

일반 상점은 60~90초, 보스 후 상점은 90~120초를 목표로 합니다.

남은 시간이 20초 이하가 되면 아직 처리하지 않은 파티 투표 후보만 접어서 보여줍니다.

호스트는 한 번에 30초씩 연장할 수 있지만, 연장할 때마다 화면은 선택지를 더 줄여 보여줍니다.

시간이 끝나도 강제 구매하지 않습니다.

구매 없이 다음 웨이브로 넘어가는 것도 정상 선택입니다.

## 이벤트 화면 흐름

이벤트 화면은 짧은 토론을 만들기 위한 화면입니다.

긴 이야기 문단보다 선택 결과를 먼저 읽을 수 있어야 합니다.

```text
갈라진 저장고
지난 전투에서 동쪽 방어선이 크게 흔들렸습니다.

[골드 +25 / 기지 체력 -3]
위험: 기지 체력이 10 이하입니다.

[지나가기]
현재 상태를 유지합니다.
```

### 이벤트 카드 구성

| 영역 | 표시 정보 | 규칙 |
| --- | --- | --- |
| 제목 | 이벤트 이름 | 1줄 |
| 등장 이유 | 피해 태그, 계절, 다음 압박 중 하나 | 1문장 |
| 선택 카드 | 비용, 보상, 다음 영향 | 선택지당 3줄 이하 |
| 소유권 | 개인, 파티, 혼합 | 파티 선택은 투표 버튼 표시 |
| 결과 연결 | 다음 웨이브나 상점에 반영될 태그 | 작은 하단 줄 |

선택지 이름은 멋진 문장보다 결과를 빨리 읽을 수 있는 표현을 우선합니다.

예를 들어 `저장고를 연다`만 쓰지 않고, `골드 +25 / 기지 체력 -3`을 함께 보여줍니다.

### MVP 이벤트 계약 카드

15일 이벤트는 후보 중 1개만 보여주고, 작은 상점까지 합쳐 90초 안에 끝나는 구성을 우선합니다.

25일 이벤트는 계절 전환 요약을 먼저 보여주며, 조건부 후보는 1개까지만 붙입니다.

| 시점 | 표시 이벤트 | 화면 규칙 |
| --- | --- | --- |
| 15일 | 갈라진 저장고, 침묵의 순례자, 무너진 공방 중 1개 | 선택지 2개 중심, 저주 계약은 지원자 확인 후 적용 |
| 25일 | 계절의 징표 + 조건부 후보 0~1개 | 다음 압박 정보와 소형 정비만 표시 |

25일 계절 전환 화면은 보상 화면처럼 밝게 터뜨리지 않고, 다음 5일을 읽는 작은 정비표처럼 보여줍니다.

```text
계절 전환
봄에서 남은 약점: 초반 누수, 손패 막힘
여름 전조: 빠른 라인, 방해형 예고

계절의 징표
골드 15를 쓰고 26~28일 압박 하나를 자세히 볼까요?

[징표 읽기] [그냥 넘기기]
```

조건부 후보가 있을 때도 카드 1장만 추가합니다.

```text
축전핵 위탁
대상 1명이 다음 웨이브 시작 시 시드 마나 +1
대가: 웨이브 종료 후 손패 1장을 직접 버림
중복 제한: 이번 정비의 임시 시드 마나 보강과 함께 쓸 수 없음

[대상 선택] [보류]
```

`조용한 계약서`는 보유 저주가 있는 플레이어에게만 열며, 새 저주를 받는 화면처럼 보이면 안 됩니다.

```text
조용한 계약서
이미 보유한 저주 1장의 안정화/제거 비용 -10
이번 상점에서 쓰지 않으면 사라집니다.

[내 저주에 예약] [보류]
```

25일 화면에서 쓰지 않는 표현:

- 여름 빌드 시작
- 시즌 보상
- 추가 카드 후보
- 영구 시드 마나
- 북쪽/서쪽/남쪽 위험, 솔로
- 겹치기 효율

저주 계약 선택지는 이벤트 선택 카드에서 결과를 요약하고, 실제 수령은 별도 확인 화면에서 처리합니다.

### 저주 계약 확인

저주 계약은 이벤트 선택 카드 안에서 바로 덱에 넣지 않고, 대상 플레이어의 확인 화면을 한 번 더 거칩니다.

```text
무거운 서약을 받을까요?

즉시: 전투 마나 +2, 도발 범위 증가
대가: 다음 드로우 -1장, 대상 구조물 받는 피해 증가
정비: 다음 상점에서 제거 또는 안정화 가능

[받기] [거절]
```

저주 확인 화면은 보상 화면, 아티팩트 투표, 상점 투표와 동시에 열지 않습니다.

대상 플레이어가 확인하기 전까지는 해당 저주 카드가 덱, 버린 카드 더미, 카드 보상 후보 어디에도 들어가지 않습니다.

대상 플레이어가 거절하거나 제한 시간이 끝나면 안전 선택으로 처리하고, 파티 골드나 카드 후보를 보상으로 보충하지 않습니다.

### 저주 서비스 비교 행

저주 서비스는 상점 안에 뜨지만, 카드 강화나 보상 선택처럼 보이면 안 됩니다.

기본 배치:

```text
저주 처리
대상: 수호자 / 무거운 서약

현재 대가
다음 드로우 -1장, 대상 구조물 받는 피해 증가

[안정화 40]  대가를 예측 가능하게 표시, 저주는 덱에 남음
[제거 75]    덱에서 제거, 다음 제거 비용 증가
[보류]       이번 상점에서는 처리하지 않음
```

25일 할인 예약이 있으면 가격 옆에 작게 표시합니다.

```text
조용한 계약서 예약 -10
이번 상점 종료 시 사라짐
```

처리 순서:

1. 저주 소유자가 안정화, 제거, 보류 중 하나를 먼저 고릅니다.
2. 안정화나 제거를 고르면 파티 골드 투표가 열립니다.
3. 투표가 통과되면 해당 상점의 큰 파티 구매 한도 1회를 소모합니다.
4. 보류, 시간 초과, 소유자 거절, 투표 실패는 구매 없음으로 상점에 돌아갑니다.

안정화 결과 화면:

```text
무거운 서약 안정화
바뀐 점: 드로우 손실과 피해 증가 대상이 미리 표시됩니다.
남는 대가: 드로우 -1장, 구조물 피해 부담
```

제거 결과 화면:

```text
무거운 서약 제거
덱에서 빠졌습니다.
다음 카드 제거 비용이 증가합니다.
```

저주 서비스에서 쓰지 않는 표현:

- 저주 정화
- 완전 치료
- 무료 안정화
- 손해 보기 싫으면 제거
- 강화 완료
- 보상으로 제거

표시 규칙:

- 받을 카드 이름과 희귀도 배지를 보여줍니다.
- 즉시 이득과 장기 대가를 같은 크기로 보여줍니다.
- 제거 또는 안정화 가능 시점을 표시합니다.
- 파티 이득이 있더라도 `받기`는 해당 플레이어만 누를 수 있습니다.
- 시간 종료, 지원자 없음, 거절은 안전 선택으로 처리합니다.

쓰지 않는 문구:

- 희생 필요
- 반드시 필요
- 공짜 보상
- 저주를 떠안기
- 보상 증가

### 이벤트 투표

파티 선택은 상점 투표와 같은 원칙을 사용합니다.

투표 표시:

```text
저장고를 열까요?
기지 체력 -3, 파티 골드 +25
동의 2 / 4
```

투표가 필요한 선택과 개인 선택을 같은 버튼처럼 보이게 하지 않습니다.

개인 선택은 즉시 확정할 수 있고, 파티 선택은 명확한 동의 수를 보여줍니다.

시간 종료 시 위험 선택을 자동 선택하지 않습니다.

기본 선택은 지나가기 또는 현재 상태 보존입니다.

## 보스 예고 화면

보스 예고는 긴 컷신보다 짧은 압박이 좋습니다.

표시 정보:

- 보스 이름
- 주요 압박
- 부위 힌트
- 추천 준비

예시:

```text
침묵의 거상
느리지만 방어선을 직접 짓누릅니다.
다리를 부수면 접근 속도를 늦출 수 있습니다.
```

보스 예고는 공략집이 아니라, 억울함을 줄이는 경고입니다.

## 보스전 UI

보스전 추가 표시:

- 보스 본체 체력
- 부위 체력
- 다음 패턴 예고
- 보스 경로
- 기지 도달 예상 시간

부위 표시 원칙:

- 모든 부위를 항상 같은 강도로 강조하지 않습니다.
- 현재 가장 위험한 부위에 경고를 표시합니다.
- 파괴 가능한 부위와 이미 파괴된 부위를 명확히 구분합니다.

### 첫 보스 HUD 흐름

침묵의 거상은 첫 보스이므로, 화면은 한 번에 하나의 질문만 강하게 보여줍니다.

| 단계 | HUD 우선순위 | 표시 방식 |
| ---: | --- | --- |
| 1 | 보스 경로 폭과 다리부 추천 | 동쪽 경로 폭 표시, 다리부 약한 강조 |
| 2 | 다리부 체력 | 본체 체력보다 다리부 추천 아이콘을 먼저 노출 |
| 3 | 짓누르기 대상 구조물 | 대상 구조물 표식, 수리/도발 핑 후보 |
| 4 | 등불부와 드로우 게이지 | 드로우 게이지 옆 등불 아이콘, 감소 사유 툴팁 |
| 5 | 기지 도달 5초 카운트다운 | 중앙 상단 치명 경고, 남은 지연 수단 강조 |
| 6 | 결과 원인 태그 | 다리부, 전면부, 등불부, 방어선 과밀, 겹치기 과욕 중 최대 3개 |

첫 보스 HUD는 공략 문장을 길게 띄우지 않습니다.

부위 강조, 경고 표식, 게이지 아이콘, 핑 후보처럼 전장 안의 단서로 안내합니다.

본체만 공격하는 플레이어가 있어도 화면을 강제로 막지 않고, 다리부 강조를 유지하는 방식으로 보정합니다.

### 보스 패턴 경고

보스 패턴은 연출보다 판독성이 먼저입니다.

패턴 경고 단계:

1. 낮은 저음 또는 화면 가장자리 어두워짐
2. 대상 방향 또는 구조물에 경고 표시
3. 짧은 카운트다운
4. 패턴 발생
5. 결과 표시와 다음 대응 힌트

보스가 구조물을 밟거나 짓누를 예정이라면 대상 구조물에 미리 표시합니다.

보스 경로는 전투 중 숨겨진 규칙처럼 느껴지면 안 됩니다.

보스가 기지에 가까워졌을 때는 손패 UI보다 보스 도달 예고를 위에 둡니다.

## 결과 화면

결과 화면은 승리/패배를 막론하고 같은 회고 구조를 사용합니다.

100일 결과는 `final_result_reflection_flow`로 처리합니다.

| 항목 | 내용 | 상호작용 |
| --- | --- | --- |
| 결과 확정 | 승리/패배, 도달 일자, 총 플레이 시간, 인원수 | 바로 넘길 수 있지만 자동으로 사라지지 않음 |
| 마지막 방어선 | 마지막 킬존 위치, 방어선 이전 횟수, 오래 버틴 구조물 | 미니맵에서 최종 방어선 하이라이트 |
| 선택 회수 | 95일 포기한 약점, 마지막 상점 구매, 유지한 아티팩트 | 선택 태그를 눌러 당시 기록 확인 |
| 결정적 장면 | 원인/전환점 카드 최대 3장 | 카드별로 짧은 전장 리플레이 또는 스냅샷 |
| 다음 런 제안 | 다음에 바꿔볼 운영 1~2개 | 튜토리얼/도감/새 런 준비로 연결 |
| 파티 기록 | 파티 조합, 최종 아티팩트, 기억할 태그 | 파티 기록 저장, 다시 하기, 메인으로 |

결과 화면에는 개인 딜량 순위, 개인 처치 순위, 개인 실수 목록을 넣지 않습니다.

웨이브 겹치기 사용 횟수는 "보상 효율"이 아니라 "어느 시점에 시간을 줄이려 했는가"로만 보여줍니다.

승리 화면:

- 생존 일수와 총 플레이 시간
- 선택 직업과 최종 아티팩트
- 마지막으로 유지한 킬존
- 가장 오래 버틴 구조물
- 95일에 살린 축과 남긴 위험
- 결말을 만든 전장 사건 최대 3개

패배 화면:

- 패배 일자
- 반복된 전장 원인
- 마지막으로 무너진 활성 방향
- 연쇄 붕괴가 시작된 구조 지점
- 95일에 남긴 위험이 드러난 방식
- 다음 런에서 시험할 운영 1~2개

패배 화면 문구는 플레이어를 탓하지 않습니다.

좋은 문구:

```text
빠른 라인의 돌파형 적이 반복해서 기지에 도달했습니다.
다음 런에서는 해당 경로에 둔화 함정을 먼저 배치해보세요.
```

나쁜 문구:

```text
방어 실패.
```

### 100일 결과 회고 패널 UX

결과 회고는 `result_panel_outcome_lock`부터 `result_panel_party_chronicle_save`까지 같은 화면 흐름을 씁니다.

승리와 패배는 색과 문구 톤만 다르고, 패널 순서는 바꾸지 않습니다.

| 패널 | 화면 구성 | 기본 포커스 |
| --- | --- | --- |
| `result_panel_outcome_lock` | 결과 문장, 도달 일자, 시간, 시작 인원수, 활성 방향 | 결과 문장 |
| `result_panel_last_bastion_summary` | 미니맵, 마지막 킬존, 방어선 이전 횟수, 오래 버틴 구조물 | 미니맵 |
| `result_panel_commitment_recall` | 95일 선택 태그, 포기한 약점, 최종 구매 | 선택 태그 |
| `result_panel_decisive_moments` | 결정적 장면 카드 최대 3장 | 첫 번째 카드 |
| `result_panel_next_run_suggestion` | 다음 런 메모 최대 2개, 도감/훈련장 연결 | 메모로 가져가기 |
| `result_panel_party_chronicle_save` | 파티 조합, 아티팩트, 회고 태그, 저장 버튼 | 저장 버튼 |

패널별 상호작용:

| 상호작용 | 허용 위치 | 동작 |
| --- | --- | --- |
| 짧은 스냅샷 | 결정적 장면 카드 | 5~10초 전장 장면을 한 번 보여줌 |
| 95일 선택 보기 | 선택 회수, 약점 장면 카드 | 마지막 상점 기록을 요약해서 펼침 |
| 도감 보기 | 보스 부위, 적 역할, 겹치기 템포 카드 | 관련 항목 1개로 이동 |
| 메모로 가져가기 | 다음 런 제안 | 새 런 준비 화면에 참고 문장으로만 전달 |
| 파티 기록 저장 | 마지막 패널 | 점수표가 아닌 연대기 카드로 저장 |

결과 회고의 미니맵은 활성 방향만 강하게 표시합니다.

비활성 방향은 지도 방향감으로만 흐리게 보일 수 있지만, 위험 방향, 붕괴 방향, 다음 런 보강 방향으로 쓰지 않습니다.

### 파티 연대기 저장 UX

파티 연대기 저장은 결과 회고의 마지막 패널에서 열립니다.

이 화면은 점수 저장이 아니라, 이번 런을 어떤 문장으로 기억할지 고르는 짧은 기록 단계입니다.

| 영역 | 화면 구성 | 상호작용 |
| --- | --- | --- |
| 제목 후보 | 자동 제목 3개 | 하나 선택, 짧게 수정 |
| 파티 요약 | 직업 조합, 시작 인원수, 활성 방향 | 상세 펼침 |
| 마지막 방어선 | 미니맵, 최종 킬존, 이전 횟수 | 미니맵 확대 |
| 기억 태그 | 결정적 장면, 95일 선택, 아티팩트 역할 태그 3~5개 | 태그 1개 해제/교체 |
| 다음 런 메모 | 가져갈 제안 0~2개 | 메모 유지/해제 |
| 저장 | 저장, 나중에, 로비로 | 저장하지 않아도 진행 가능 |

제목 수정은 짧은 문장만 허용합니다.

개인 이름을 넣을 수는 있지만, 개인 책임, 비난, 딜량 순위, 캐리, 최고 점수 같은 문맥이면 저장 전에 부드럽게 다른 제목을 제안합니다.

좋은 저장 화면은 "이 파티가 어떤 운영을 했는지"를 남깁니다.

나쁜 저장 화면은 "누가 제일 잘했는지"를 묻습니다.

### 파티 연대기 기록장 UX

기록장은 메인 메뉴, 메타 진행, 결과 회고 저장 완료 화면에서 열 수 있습니다.

첫 화면은 카드 목록입니다.

| 카드 앞면 | 내용 |
| --- | --- |
| 제목 | 선택한 자동 제목 또는 직접 수정한 짧은 제목 |
| 결과 줄 | 승리/패배/중단, 도달 일자, 인원수 |
| 파티 줄 | 직업 조합과 최종 아티팩트 1~4개 |
| 전장 줄 | 마지막 방어선 태그와 활성 방향 |
| 기억 태그 | 3~5개 |
| 메모 | 다음 런 메모가 있으면 1개만 미리보기 |

카드를 펼치면 마지막 방어선 미니맵, 결정적 장면, 95일 선택, 다음 런 메모를 볼 수 있습니다.

기억 태그 표시:

| 위치 | 표시 수 | 기준 |
| --- | ---: | --- |
| 결과 저장 패널 | 3~5개 | 자동 선택 후보를 보여주고 1개까지 교체 가능 |
| 연대기 카드 앞면 | 3~5개 | 묶음이 겹치지 않게 짧은 칩으로 표시 |
| 펼침 상세 | 전체 선택 태그와 원천 장면 | 왜 붙었는지 1줄로 표시 |
| 기록장 필터 | 태그 묶음별 접기 | 전선/구조물/자원/적/템포/보스/역할/결말 |

태그 칩에는 점수, 랭크, 개인 이름, 방향별 실패 낙인을 넣지 않습니다.

솔로 기록에서 태그 설명을 펼쳐도 북쪽/서쪽/남쪽을 위험 방향으로 표시하지 않습니다.

허용 필터:

| 필터 | 목적 |
| --- | --- |
| 최신/즐겨찾기 | 최근 기록이나 기억하고 싶은 기록 찾기 |
| 결과 | 승리, 패배, 중단 |
| 도달 구간 | 10일, 30일, 60일, 90일, 100일 |
| 인원수 | 1~4인 |
| 직업 조합 | 특정 직업이 포함된 기록 찾기 |
| 보스 | 본 보스 기준으로 보기 |
| 기억 태그 | 후방 킬존, 보스 부위 집중, 포기한 약점 등 |

금지 필터:

- 승률
- 최고 점수
- 평균 점수
- 플레이어별 기여도
- 딜량/처치 수
- 웨이브 겹치기 효율
- 보상 효율

기록장 비교는 "어느 판이 더 잘했는가"가 아니라 "어떤 운영을 했는가"를 다시 찾는 용도입니다.

### 패배 원인 우선순위

패배 원인은 마지막 한 방보다, 그 한 방을 가능하게 만든 반복 패턴을 먼저 봅니다.

| 우선순위 | 원인 | 판정 기준 | 추천 방향 |
| ---: | --- | --- | --- |
| 1 | 기지 직접 붕괴 | 마지막 10초 안에 같은 방향에서 기지 피해가 반복됨 | 해당 방향 경로 연장, 둔화, 도발 보강 |
| 2 | 구조물 연쇄 붕괴 | 핵심 구조물이 짧은 시간에 2개 이상 파괴됨 | 버릴 구조물과 지킬 구조물 분리, 수리 핑 |
| 3 | 빠른 적 누수 | 돌파형이 여러 번 기지에 도달함 | 첫 굴곡 지점 둔화, 넉백, 도발 타이밍 |
| 4 | 방해형 방치 | 방해형 생존 중 드로우/마나 손실이 누적됨 | 우선 처치 핑, 후열 타격, 경로 격리 |
| 5 | 손패 막힘 | 손패 10장 유지 시간이 길고 드로우 손실이 발생함 | 라운드당 버리기 사용, 저코스트 카드 비율 조정 |
| 6 | 겹치기 위험 과소평가 | 겹치기 후 20초 안에 기지 피해나 구조물 손실 급증 | 겹치기 친화도 확인, 다음 웨이브 호출 지연 |
| 7 | 보스 패턴 미대응 | 부위 방치나 예고 패턴 직후 피해 발생 | 부위 우선순위 표시 확인, 보스 전용 핑 |
| 8 | 정보 전달 실패 | 플레이어가 패배 원인을 말하지 못함 | 예고 시간, 경고 위치, 문구 수정 |

하나의 패배 화면에 모든 원인을 보여주지 않습니다.

가장 설명력이 큰 원인 1개와 보조 원인 2개까지만 보여줍니다.

### 패배 분석 카드

패배 분석은 3장 이하의 카드처럼 보여줍니다.

카드는 "결과", "원인", "다음 시도" 순서로 읽히게 배치합니다.

| 카드 슬롯 | 목적 | 보여줄 수 있는 근거 | 금지선 |
| --- | --- | --- | --- |
| 1 | 가장 설명력이 큰 원인 | 방향별 누수, 구조물 연쇄 붕괴, 보스 부위 방치, 손패 막힘 | 마지막 적 이름만 크게 표시 |
| 2 | 보조 원인 또는 놓친 대응 | 미사용 대응 태그, 경고 후 행동 시간, 반복된 위험 핑 | 특정 플레이어 이름 표시 |
| 3 | 다음 시도 | 대응 태그 1~3개, 짧은 훈련/도감 링크, 로비 메모 | 정답 빌드, 필수 직업, 특정 카드 강요 |

예시:

| 카드 | 내용 |
| --- | --- |
| 뚫린 방향 | 빠른 라인의 돌파형 적이 4회 기지에 도달 |
| 붕괴 지점 | 활성 경로 근처 바리케이드가 반복 파괴 |
| 다음 제안 | 해당 경로에 둔화 함정과 수리 요청 핑 사용 |

숫자는 원인을 설명할 만큼만 보여줍니다.

플레이어 순위표처럼 보이면 안 됩니다.

멀티에서는 개인 책임보다 파티의 전장 변화 중심으로 보여줍니다.

카드를 누르면 5~10초짜리 짧은 전장 스냅샷을 볼 수 있습니다.

스냅샷은 실패 장면을 반복 재생해 질책하는 용도가 아니라, 위험이 생긴 위치와 열린 대응 태그를 확인하는 용도입니다.

### 재도전 제안 UX

재도전 제안은 패배를 곧바로 정답으로 바꾸지 않고, 다음 런에서 시험해볼 운영 문장으로 남깁니다.

한 화면에 보이는 제안은 최대 2개입니다.

| 제안 유형 | 표시 문장 | 연결 |
| --- | --- | --- |
| 전선 운영 | `동쪽 첫 굴곡을 더 길게 쓰기` | 새 런 준비 메모, 경로 연장 도감 |
| 구조물 운영 | `표식 바리케이드는 살릴 것과 버릴 것을 나누기` | 구조물 훈련 장면 |
| 우선 처치 | `방해형이 보이면 첫 핑을 집중 화력으로 찍기` | 적 역할 도감 |
| 자원 운영 | `손패가 막히기 전에 버리기 기회를 먼저 쓰기` | 덱 순환 튜토리얼 |
| 템포 운영 | `치명 체력에서는 다음 웨이브 호출을 보류하기` | 웨이브 겹치기 도감 |
| 보스 운영 | `보스 본체보다 다리부 지연을 먼저 확인하기` | 보스 부위 훈련 |

제안 버튼:

| 버튼 | 동작 |
| --- | --- |
| 메모로 가져가기 | 새 런 준비 화면 상단에 한 줄 목표로 표시 |
| 짧게 연습 | 30~60초 훈련 장면으로 이동 |
| 도감 보기 | 관련 적, 구조물, 보스 부위, 웨이브 겹치기 설명 열기 |
| 그냥 다시 | 제안은 접어두고 새 런 준비로 이동 |

재도전 제안은 자동으로 직업, 시작 덱, 아티팩트, 활성 방향을 바꾸지 않습니다.

솔로 플레이의 제안은 현재 런에서 실제로 열린 동쪽 전선 안의 경로, 적 역할, 구조물 판단으로만 작성합니다.

### 전투 후 짧은 리포트

승리한 웨이브에도 1~2초짜리 짧은 리포트를 남깁니다.

이 리포트는 매번 클릭을 요구하지 않고, 다음 준비 단계의 상단 좌측 예고 아래에 접힌 상태로 남습니다.

| 항목 | 표시 조건 | 예시 |
| --- | --- | --- |
| 가장 위험했던 방향 | 기지 피해 또는 누수 발생 | `동쪽이 3회 압박받음` |
| 구조물 판단 | 파괴형이나 보스 패턴 발생 | `바리케이드 2개가 9초를 벌었습니다.` |
| 대응 태그 | 도발, 수리, 둔화, 경로 변경 사용 | `둔화와 수리로 돌파형을 지연했습니다.` |
| 겹치기 결과 | 웨이브 겹치기 사용 | `겹치기 후 구조물 손실이 증가했습니다.` |

웨이브 후 리포트도 추가 보상처럼 보이면 안 됩니다.

표시는 `성과`보다 `다음 판단 참고`에 가깝게 유지합니다.

## 접근성 옵션

접근성 옵션은 `accessibility_presentation_options`로 구성합니다.

첫 실행에서는 핵심 3개만 짧게 보여주고, 나머지는 설정 화면에서 조정하게 합니다.

첫 실행 핵심 옵션:

- 카드 텍스트 크기
- 화면 흔들림 강도
- 저주파 보스음 음량

필수:

- 화면 흔들림 강도
- 저주파 보스음 음량
- 카드 텍스트 크기
- 색각 보조
- 경로 항상 표시
- 적 윤곽선 강화
- UI 확대

권장:

- 자동 배속 해제 조건
- 보스 패턴 자막
- 핑 소리 개별 조절
- 손패 정렬 방식

### 접근성/연출 옵션 흐름

| 항목 | 표시 | 금지선 |
| --- | --- | --- |
| 기본 가독성 | UI 배율, 카드 텍스트 크기, 긴 문구 줄바꿈 미리보기 | 텍스트가 카드/버튼 밖으로 넘침 |
| 움직임 부담 | 화면 흔들림, 카메라 관성, 보스 접근 흔들림 미리보기 | 위험 예고 위치가 옵션에 따라 바뀜 |
| 사운드 압박 | 저주파 보스음, 경고음, 핑 소리, 자막 표시 | 소리를 끄면 필수 정보가 사라짐 |
| 전술 정보 | 경로 항상 표시, 적 윤곽선, 보스 부위 강조, 타겟 라벨 | 추천 빌드나 자동 타겟팅처럼 보임 |
| 협동 신호 | 핑 아이콘 모양, 방향 라벨, 색각 보조, 자막 로그 | 색상 하나로만 요청/위험을 구분 |
| 연출 안전선 | 점프 스케어 없음, 유혈/고어 없음, UI 왜곡 없음 | 공포를 위해 경로/타겟/패턴을 숨김 |

좋은 옵션 문구:

```text
보스 접근 흔들림: 낮음
전술 정보와 경고 위치는 그대로 유지됩니다.
```

나쁜 옵션 문구:

```text
쉬운 모드: 적 경로와 약점을 항상 보여줍니다.
```

접근성 옵션은 개인 화면과 소리 표현만 바꿉니다.

파티의 난이도, 보상, 활성 침공 방향, 카드 후보 수는 바꾸지 않습니다.

## UX 완료 기준

- 신규 플레이어가 10분 안에 기본 루프를 이해합니다.
- 웨이브 겹치기를 보상 버튼으로 오해하지 않습니다.
- 패배 원인을 결과 화면만 보고 설명할 수 있습니다.
- 보스 부위 중 무엇을 때려야 하는지 화면에서 알 수 있습니다.
- 구조물 설치 불가 이유가 즉시 이해됩니다.
