# Tutorial And First Session

이 문서는 **Last Bastion: Four Seasons**의 튜토리얼과 첫 플레이 세션을 설계합니다.

목표는 모든 규칙을 설명하는 것이 아니라, 플레이어가 직접 방어선이 무너지는 경험을 통해 핵심을 이해하게 만드는 것입니다.

## 튜토리얼 목표

첫 10분 안에 플레이어가 이해해야 할 것:

- 적은 기지로 향하는 경로를 따라옵니다.
- 구조물로 경로를 비틀 수 있습니다.
- 완전 길막은 불가능합니다.
- 구조물은 부서질 수 있습니다.
- 구조물 파괴는 전술이 될 수 있습니다.
- 적 처치가 마나와 드로우로 이어집니다.
- 웨이브 겹치기는 보상 증가가 아니라 다음 위기를 빨리 부르는 기능입니다.
- 보스는 죽이는 대상이기 전에 늦춰야 하는 압박입니다.

## 튜토리얼 원칙

튜토리얼은 플레이어를 오래 붙잡아두면 안 됩니다.

목표는 모든 시스템 설명이 아니라, 첫 실제 런에서 스스로 판단할 수 있을 만큼의 감각을 주는 것입니다.

원칙:

- 한 단계에서는 하나만 가르칩니다.
- 실패해도 즉시 재시도할 수 있게 합니다.
- 설명보다 전장 미리보기와 하이라이트를 우선합니다.
- 직업 설명은 플레이어가 선택한 직업 중심으로만 보여줍니다.
- 웨이브 겹치기는 보상 설명 없이 템포 설명으로만 다룹니다.
- 보스는 공략보다 "늦추고 부위를 부순다"는 감각만 줍니다.

튜토리얼이 끝났을 때 플레이어가 완벽해질 필요는 없습니다.

대신 첫 패배 후 "아, 다음엔 저걸 바꾸면 되겠다"라고 느껴야 합니다.

## 튜토리얼 구성

튜토리얼은 8개 짧은 장면으로 구성합니다.

| 단계 | 목표 | 예상 시간 |
| ---: | --- | ---: |
| 1 | 경로 보기 | 1분 |
| 2 | 타워 설치 | 1분 |
| 3 | 바리케이드로 경로 변경 | 1분 |
| 4 | 완전 길막 불가 학습 | 1분 |
| 5 | 구조물 파괴 학습 | 1분 |
| 6 | 카드와 마나 학습 | 2분 |
| 7 | 웨이브 겹치기 학습 | 1분 |
| 8 | 미니 보스 예고 | 2분 |

핑은 별도 장면으로 길게 가르치지 않습니다.

5단계에서 수리 요청 핑, 8단계에서 보스 부위 집중 핑만 짧게 보여줍니다.

첫 튜토리얼에서 모든 핑을 가르치면 협동 도구가 아니라 조작 숙제로 느껴집니다.

## 튜토리얼-첫 세션 6단계 루프

튜토리얼과 첫 10일 세션은 서로 다른 콘텐츠가 아닙니다.

튜토리얼에서 안전하게 한 번 본 판단을 첫 10일 세션에서 실제 압박으로 다시 묻습니다.

| 단계 | 튜토리얼 장면 | 첫 10일 확인 | 학습 문장 | 정보량 제한 |
| ---: | --- | --- | --- | --- |
| 1 | 경로 보기, 타워 설치 | 1일 | 적은 길을 따라오고, 타워는 그 길을 공격합니다. | 카드 1장, 적 1종 |
| 2 | 바리케이드, 길막 불가 | 2일 | 길은 비틀 수 있지만 완전히 닫을 수 없습니다. | 설치 후보 2~3곳 |
| 3 | 빠른 적, 군집 처리 | 3~4일 | 빠른 적과 모아 잡을 적은 대응이 다릅니다. | 새 적 1종씩 |
| 4 | 구조물 파괴, 첫 상점 | 5~7일 | 부서진 구조물은 실패이면서 전술 자원입니다. | 상점 5~6개 |
| 5 | 처치 기반 자원, 겹치기 | 8~9일 | 방어선이 안정되면 자원과 템포 선택이 열립니다. | 겹치기 보상 문구 금지 |
| 6 | 미니 보스 예고 | 10일 | 보스는 늦추고 부위를 보는 압박입니다. | 부위 2~3개, 동반 압박 약함 |

각 단계는 "배움 -> 작은 적용 -> 실제 10일 확인" 순서로 이어져야 합니다.

플레이어가 튜토리얼을 스킵해도 첫 10일에서는 이 6단계 힌트가 작은 문장으로 남아야 합니다.

## 힌트와 개입 규칙

튜토리얼은 플레이어가 막혔을 때만 더 강하게 개입합니다.

힌트 단계:

| 단계 | 조건 | 개입 |
| ---: | --- | --- |
| 1단계 | 10초 동안 입력 없음 | 목표 타일이나 버튼을 은은하게 강조 |
| 2단계 | 20초 동안 진행 없음 | 짧은 문구 표시 |
| 3단계 | 35초 동안 진행 없음 | 추천 위치 또는 추천 카드 표시 |
| 4단계 | 60초 동안 진행 없음 | 자동 예시 시연 제안 |

자동으로 해결해주지는 않습니다.

플레이어가 직접 마지막 입력을 해야 학습이 남습니다.

### 학습 잠금과 해제

튜토리얼은 조작을 지나치게 잠그지 않습니다.

다만 첫 장면에서 아직 배우지 않은 위험 행동은 짧게 막을 수 있습니다.

| 상황 | 처리 | 해제 시점 |
| --- | --- | --- |
| 첫 설치 전 웨이브 겹치기 | 버튼 비활성화, 이유 표시 | 기본 타워 설치 후 |
| 길막 학습 전 완전 길막 시도 | 설치 거부와 대체 위치 표시 | 길막 불가 피드백 확인 후 |
| 카드/마나 학습 전 고코스트 카드 표시 | 손패에서 숨기거나 비활성화 | 처치 기반 마나 확인 후 |
| 보스 부위 학습 전 본체만 강조 | 부위도 함께 하이라이트 | 부위 피해나 핑 확인 후 |

잠금 문구는 명령형보다 이유형이 좋습니다.

```text
먼저 기본 방어선을 세워야 다음 웨이브를 부를 수 있습니다.
```

나쁜 문구:

```text
아직 사용할 수 없습니다.
```

## 스킵과 재방문

튜토리얼은 스킵할 수 있어야 합니다.

다만 첫 플레이에서는 스킵 버튼을 바로 크게 보여주지 않습니다.

권장:

- 첫 플레이: 설정 메뉴 안에서 스킵 가능
- 두 번째 플레이부터: 튜토리얼 시작 화면에서 스킵 가능
- 언제든 도감/훈련장에서 단계별 재방문 가능

스킵한 플레이어에게도 첫 10일 런에서는 핵심 힌트를 짧게 보여줍니다.

예시:

```text
처음 보는 적입니다. 예고 정보를 확인하세요.
```

### 도감/훈련장 재방문 6단계

도감과 훈련장은 `knowledge_revisit_loop_6step`을 사용합니다.

| 단계 | 기능 | 기준 | 금지선 |
| ---: | --- | --- | --- |
| 1 | 재방문 이유 제시 | 패배 원인, 결과 회고, 메타 해금, 처음 만난 적 중 하나와 연결합니다. | 플레이어를 꾸짖는 문구 금지 |
| 2 | 볼 대상 선택 | 적, 보스 부위, 구조물, 상태이상, 겹치기, 직업 역할 중 하나를 고릅니다. | 한 번에 여러 규칙을 다시 가르치지 않음 |
| 3 | 짧은 도감 카드 | 행동, 저항, 대응 태그, 피해야 할 오해를 보여줍니다. | 정답 빌드, 필수 직업, 강제 카드 추천 금지 |
| 4 | 짧은 훈련 장면 | 30~60초 안에 해당 문제만 다시 시험합니다. | 보상 파밍, 메타 파워, 실제 런 자원 지급 금지 |
| 5 | 대응 비교 | 플레이어가 쓴 대응과 다른 가능성 1~2개를 보여줍니다. | 점수, 등급, 개인 평가 금지 |
| 6 | 다음 런 연결 | 새 런 준비, 즐겨찾기, 관련 첫 10일 힌트로 연결합니다. | 자동 빌드 세팅이나 직업 강제 금지 |

재방문은 필수가 아닙니다.

좋은 재방문 제안은 "방금 실패한 이유를 1분만 다시 만져볼래요?"에 가깝고, 나쁜 제안은 "이걸 완료해야 다음으로 갈 수 있습니다"에 가깝습니다.

## 단계 1: 경로 보기

상황:

빈 맵, 동쪽에서 회색 행렬 3마리가 천천히 등장합니다.

목표:

플레이어가 적 경로와 기지를 이해합니다.

UI 문구:

```text
적은 중앙 기지로 이동합니다.
경로를 확인하세요.
```

성공 조건:

- 적 경로 표시를 확인합니다.
- 적이 기지에 도달하기 전 다음 단계로 넘어갑니다.

실패 복구:

- 적이 기지에 도달해도 패배시키지 않습니다.
- 기지 체력 감소 연출만 보여주고 같은 장면을 다시 시작합니다.

추가 문구:

```text
적이 기지에 닿으면 피해를 줍니다.
다시 막아봅시다.
```

## 단계 2: 타워 설치

상황:

플레이어에게 기본 공격 타워 카드 1장을 줍니다.

UI 문구:

```text
타워를 설치해 경로 위 적을 공격하세요.
```

가이드:

- 설치 가능 타일을 밝게 표시합니다.
- 경로 타일에는 타워 설치가 불가함을 보여줍니다.

성공 조건:

- 타워를 설치합니다.
- 회색 행렬을 처치합니다.

실패 복구:

- 잘못된 타일을 누르면 설치 가능 타일을 더 강하게 표시합니다.
- 마우스를 올린 타일에 "설치 가능" 또는 "경로 타일"을 표시합니다.

## 단계 3: 바리케이드로 경로 변경

상황:

동쪽 짧은 경로에 회색 행렬이 등장합니다.

플레이어에게 바리케이드 카드를 줍니다.

UI 문구:

```text
바리케이드로 적의 길을 비틀 수 있습니다.
```

미리보기:

- 설치 전 경로
- 설치 후 경로
- 증가한 이동 시간

성공 조건:

- 바리케이드 설치 후 적 경로가 바뀝니다.

실패 복구:

- 바리케이드를 의미 없는 위치에 설치하면 경로 변화가 적다는 문구를 보여줍니다.

```text
이 위치는 경로를 거의 바꾸지 않습니다.
경로가 꺾이는 곳을 막아보세요.
```

## 단계 4: 완전 길막 불가

상황:

플레이어가 기지 입구를 완전히 막도록 유도합니다.

UI 문구:

```text
기지로 향하는 경로가 필요합니다.
```

목표:

길막 금지를 억울한 제한이 아니라 핵심 규칙으로 이해하게 합니다.

성공 조건:

- 설치 불가 피드백을 봅니다.
- 다른 위치에 설치해 경로를 남깁니다.

실패 복구:

- 길막 불가 문구를 본 뒤, 설치 가능한 대체 위치 2곳을 표시합니다.
- 대체 위치를 강제하지 않습니다.

## 단계 5: 구조물 파괴

상황:

균열 망치 1마리가 등장합니다.

UI 문구:

```text
일부 적은 구조물을 부수고 전진합니다.
부서지는 순간도 전술로 사용할 수 있습니다.
```

연출:

- 곧 공격받을 바리케이드 강조
- 구조물 체력 표시
- 수리 요청 핑 예시 표시
- 파괴 후 잔해 생성
- 잔해 뒤쪽 재건 후보 타일을 은은하게 표시

성공 조건:

- 바리케이드가 파괴됩니다.
- 잔해로 적이 잠시 느려지는 것을 봅니다.
- 수리 요청 핑을 누르면 수리 카드나 구조물이 하이라이트되는 것을 봅니다.
- 부서진 자리보다 뒤쪽에 새 방어선을 만들 수 있음을 봅니다.

실패 복구:

- 플레이어가 바리케이드를 너무 멀리 놓으면 균열 망치가 구조물을 공격하지 않을 수 있습니다.
- 이 경우 균열 망치의 목표 구조물을 하이라이트하고, 추천 설치 위치를 보여줍니다.

추가 문구:

```text
이 적은 가까운 구조물을 부수려 합니다.
부서질 위치를 정할 수 있습니다.
```

재건 문구:

```text
무너진 뒤에는 같은 자리만 보지 마세요.
뒤쪽에 새 방어선을 만들 수도 있습니다.
```

핑 문구:

```text
수리 요청 핑은 행동을 강제하지 않습니다.
위험한 구조물을 빠르게 가리키는 표시입니다.
```

## 단계 6: 카드와 마나

상황:

플레이어에게 직업별 간단 카드 3장을 줍니다.

수호자:

- 도발벽
- 방패 두르기
- 응전 태세

건축가:

- 바리케이드
- 잔해 폭발
- 회수 작업

원소술사:

- 화염구
- 빙결 지대
- 밀어내기

땜장이:

- 원격 수리
- 증폭기
- 과부하

UI 문구:

```text
적을 처치하면 마나와 드로우 게이지가 찹니다.
시간이 지나도 마나는 자동으로 회복되지 않습니다.
```

성공 조건:

- 카드 2장 이상 사용
- 적 처치로 마나 또는 드로우 게이지 증가 확인

직업별 학습 포인트:

| 직업 | 반드시 느껴야 할 것 |
| --- | --- |
| 수호자 | 적을 끌어당기고 맞으면서 시간을 버는 감각 |
| 건축가 | 구조물이 부서질 위치와 타이밍을 정하는 감각 |
| 원소술사 | 적이 모였을 때 광역 피해가 강해지는 감각 |
| 땜장이 | 수리와 오라로 방어선 수명을 늘리는 감각 |

실패 복구:

- 마나가 부족한 상태에서 카드를 누르면 처치 기반 회복을 다시 강조합니다.
- 손패가 가득 차면 버리기 버튼을 강조합니다.

## 단계 7: 웨이브 겹치기

상황:

쉬운 웨이브가 거의 끝나갑니다.

다음 웨이브 예고가 표시됩니다.

UI 문구:

```text
방어선이 안정적이라면 다음 웨이브를 지금 호출할 수 있습니다.
보상은 늘어나지 않습니다. 기다리는 시간을 줄이는 선택입니다.
```

버튼:

```text
다음 웨이브 호출
```

성공 조건:

- 플레이어가 버튼을 누릅니다.
- 두 웨이브가 겹칩니다.
- 보상 화면에서 추가 보상 문구가 없습니다.

중요한 연출:

- 버튼 클릭음은 보상음처럼 들리면 안 됩니다.
- 호출 직후 적 밀도가 올라가는 것을 화면으로 보여줍니다.
- 보상 UI는 일반 웨이브 정산과 동일하게 유지합니다.

실패 복구:

- 플레이어가 버튼을 누르지 않아도 진행은 가능합니다.
- 대신 다음 문구를 보여주고 다음 단계로 넘어갑니다.

```text
방어선이 안정적일 때는 다음 웨이브를 먼저 불러 시간을 줄일 수 있습니다.
```

튜토리얼에서는 웨이브 겹치기를 강제하지 않습니다.

강제하면 "누르는 게 정답"으로 오해할 수 있습니다.

## 단계 8: 미니 보스 예고

상황:

침묵의 거상의 축소 연출을 보여줍니다.

실제 보스전보다 짧고 약하게 구성합니다.

UI 문구:

```text
거대한 적은 빠르게 죽이는 대상이 아닙니다.
부위를 파괴해 접근을 늦추세요.
```

목표:

보스는 "늦추고 부위를 부수는 대상"이라는 감각을 줍니다.

성공 조건:

- 다리부를 공격합니다.
- 이동 속도가 줄어드는 것을 확인합니다.
- 보스 부위 집중 핑이 같은 부위를 가리키는 것을 봅니다.

실패 복구:

- 플레이어가 본체만 공격하면 다리부를 은은하게 강조합니다.
- 그래도 본체만 공격해도 장면은 실패시키지 않습니다.
- 다리부 파괴가 선택지를 만든다는 것만 보여주면 충분합니다.

추가 문구:

```text
본체를 공격해도 됩니다.
하지만 부위를 부수면 보스의 압박을 줄일 수 있습니다.
```

핑 문구:

```text
부위 집중 핑은 파티가 같은 목표를 보게 해줍니다.
```

첫 튜토리얼에서 직업 숙련을 완성하려고 하면 흐름이 길어집니다.

새 적을 많이 보여주기보다, 같은 판단을 조금 더 실제적인 압박으로 되묻습니다.

### 10일 첫 보스 학습 체크

10일의 침묵의 거상은 튜토리얼 8단계 미니 보스의 실제 시험입니다.

튜토리얼에서 부위를 봤다면, 실제 보스전에서는 긴 설명 없이 전장 단서로 다시 읽히게 해야 합니다.

| 단계 | 실제 보스 장면 | 확인할 학습 | 힌트 방식 |
| ---: | --- | --- | --- |
| 1 | 입장 예고 | 동쪽 보스 경로 폭과 다리부 추천을 봅니다. | 경로 폭과 다리부 은은한 강조 |
| 2 | 다리부 학습 | 보스를 늦추는 선택이 본체 공격보다 안정적임을 느낍니다. | 본체만 공격하면 다리부 강조 유지 |
| 3 | 짓누르기 선택 | 구조물을 지킬지 버릴지 판단합니다. | 대상 구조물 표식과 수리/도발 핑 제안 |
| 4 | 등불부 선택 | 드로우가 약해진 이유를 보스 부위와 연결합니다. | 드로우 게이지 옆 등불 아이콘 표시 |
| 5 | 마지막 접근 | 남은 카드와 제어를 최후의 지연으로 씁니다. | 기지 도달 5초 카운트다운 |
| 6 | 결과 연결 | 다음 시도에서 먼저 볼 부위나 구조물을 말합니다. | 패배 원인 태그와 관련 튜토리얼 재방문 |

본체만 공격해도 전투를 강제로 실패시키지 않습니다.

다만 본체만 공격한 시간이 길수록 결과 화면에서 "다리부 방치"나 "등불부 방치" 태그를 더 쉽게 보여줍니다.

첫 보스 동반 웨이브는 새 적 학습이 아니라 시야 분산만 담당합니다.

1인은 동쪽만, 2~4인은 활성 방향 안에서 최대 1~2개 약한 압박만 사용합니다.

```text
이 게임에서는 타워와 바리케이드를 사용해 적의 경로를 조작하고, 각종 카드를 통해 전투 중 자원을 활용하며...
```

```text
바리케이드는 적의 길을 비틉니다.
```

```text
마나는 시간이 아니라 처치로 회복됩니다.
```

- 모든 상태이상 설명
- 아티팩트와 상점 깊은 설명

## 튜토리얼 측정 지표

튜토리얼은 감으로만 평가하지 않습니다.

기록할 것:

| 지표 | 목표 |
| --- | --- |
| 튜토리얼 완료 시간 | 8~12분 |
| 단계별 재시도 횟수 | 0~2회 |
| 길막 불가 오해 횟수 | 1~3회는 정상 |
| 웨이브 겹치기 버튼 클릭률 | 50% 이상 |
| 보스 부위 공격 여부 | 70% 이상 |
| 튜토리얼 후 10일 세션 진입률 | 80% 이상 |
| 첫 10일 중 힌트 과다 노출 | 3회 이하 |
| 10일 세션 후 다시 플레이 의향 | 60% 이상 |
| 첫 패배 후 튜토리얼 재방문 클릭률 | 15~35% |

웨이브 겹치기 버튼 클릭률이 낮아도 바로 보상을 붙이지 않습니다.

먼저 버튼 위치, 문구, 웨이브 안정성, 다음 웨이브 예고를 확인합니다.

## 첫 패배 지원

첫 패배 후에는 추천을 강하게 줍니다.

예시:

```text
빠른 라인의 적이 기지에 반복해서 도달했습니다.
```

```text
균열 망치가 바리케이드를 너무 빨리 부쉈습니다.

```

```text
손패가 가득 차 드로우가 막혔습니다.
```

첫 패배 화면은 플레이어를 혼내는 것이 아니라, 다음 시도를 떠올리게 해야 합니다.
