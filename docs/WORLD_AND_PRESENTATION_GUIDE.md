# World And Presentation Guide

이 문서는 **Last Bastion: Four Seasons**의 세계관, 톤, 비주얼, 사운드, 문장 스타일을 정리합니다.

목표는 잔혹한 공포가 아니라, 거대한 무언가가 조용히 다가오는 심리적 압박을 만드는 것입니다.

## 핵심 톤

한 문장:

> 마지막 기지는 사계절을 지나며 서서히 닫히는 세계의 압력을 버틴다.

감정:

- 외로움보다 협동의 긴장
- 잔혹함보다 규모의 압박
- 절망보다 마지막까지 버티는 의지
- 화려한 승리보다 간신히 넘긴 안도감

금지:

- 유혈
- 고어
- 잔혹 절단
- 노골적 신체 훼손
- 점프 스케어 의존
- 지나치게 설명적인 공포 문구

## 세계관 기준

세계는 명확하게 설명되지 않아도 됩니다.

플레이어는 모든 설정을 읽어서 이해하기보다, 전장과 보스의 압력으로 세계가 닫히고 있다는 감각을 받아야 합니다.

기본 설정:

- 세계의 끝에서 마지막 기지가 남았습니다.
- 사계절은 자연의 순환이 아니라, 거대한 침식의 단계입니다.
- 적들은 악한 군대라기보다, 세계의 균열에서 밀려오는 형상들입니다.
- 보스는 생물이라기보다 계절과 기억, 구조물, 침묵이 뭉친 거대한 현상입니다.

## 사계절의 의미

| 계절 | 의미 | 감정 |
| --- | --- | --- |
| 봄 | 아직 방어선을 만들 수 있는 시기 | 불안한 시작 |
| 여름 | 속도와 열로 모든 것이 빨라지는 시기 | 초조함 |
| 가을 | 경로와 기억이 무너지는 시기 | 혼란 |
| 겨울 | 공간이 닫히고 마지막 선택만 남는 시기 | 압박 |

계절은 밝고 어두운 색만의 차이가 아닙니다.

각 계절은 전장의 감각을 바꿔야 합니다.

## 비주얼 원칙

### 화면 구성

- 기지는 작지만 명확해야 합니다.
- 보스는 화면의 스케일을 깨야 합니다.
- 적은 숫자가 많아도 실루엣으로 구분되어야 합니다.
- 구조물은 기능이 외형에서 읽혀야 합니다.
- 경로와 위험 정보는 분위기보다 우선합니다.

### 색 방향

색은 단일 톤으로 밀지 않습니다.

권장:

- 기지: 따뜻한 빛, 낮은 채도
- 적: 차갑고 불안정한 색
- 구조물: 재료감이 분명한 색
- 위험 UI: 강한 대비
- 보스: 배경보다 어둡거나 훨씬 큰 실루엣

피할 것:

- 모든 화면을 보라색/남색으로 통일
- 과한 붉은색으로 공포 표현
- 카드와 전장 위험 색이 충돌
- 적과 배경이 섞여 보이는 색

## 적 비주얼

적은 혐오감을 주는 괴물이 아니라, 기능이 보이는 기괴한 형상이어야 합니다.

| 적 | 실루엣 방향 |
| --- | --- |
| 회색 행렬 | 작고 비슷한 형상이 줄지어 움직임 |
| 틈새 주자 | 얇고 낮은 자세, 빠른 잔상 |
| 균열 망치 | 한쪽이 무거운 실루엣, 구조물 타격이 읽힘 |
| 유리 껍질 | 반투명 외피, 광역 피해 저항이 보임 |
| 침묵 운반자 | 등에 어두운 등불 또는 상자 |
| 검은 등짐 | 커다란 짐이 흔들리며 사망 효과를 암시 |
| 무거운 순례자 | 느린 대형 실루엣, 낮은 중심 |
| 뒤틀린 표식 | 주변 적에게 표시를 뿌리는 작은 기둥형 |

## 보스 비주얼

보스는 전장 위의 큰 적이 아니라, 전장 밖에서 들어오는 규모의 사건입니다.

### 침묵의 거상

키워드:

- 느림
- 무게
- 그림자
- 부서진 석상
- 움직이는 성벽

연출:

- 등장 전 낮은 진동음
- 먼 안개 속 실루엣
- 발걸음마다 먼지와 화면의 미세한 흔들림
- 전면부가 구조물을 짓누를 때 피가 아니라 균열과 파편
- 등불부 파괴 시 빛이 꺼지는 것이 아니라 흩어짐

### 사계의 관측자

키워드:

- 시선
- 방향 교란
- 렌즈
- 계절 조각

연출:

- 보스가 직접 빠르게 움직이지 않습니다.
- 화면 가장자리의 웨이브 예고 UI가 흔들립니다.
- 부위는 눈이 아니라 렌즈나 관측구처럼 표현합니다.

### 무너진 종탑

키워드:

- 소리 없는 종
- 기울어진 탑
- 오라 왜곡

연출:

- 종이 울리는 대신 소리가 사라집니다.
- 오라 장치 주변의 효과가 흐려집니다.
- 수리 효과가 약해지는 구역을 바닥 균열로 표시합니다.

### 겨울의 문

키워드:

- 닫힘
- 거대한 문
- 흰 침묵
- 공간 축소

연출:

- 움직이는 생물보다 다가오는 문처럼 보입니다.
- 지나간 자리에 얼어붙은 보스 압력 타일이 남습니다.
- 최종 단계에서 화면 바깥쪽이 조용히 닫히는 느낌을 줍니다.

## 구조물 비주얼

구조물은 기능이 먼저 읽혀야 합니다.

| 구조물 | 외형 방향 |
| --- | --- |
| 공격 타워 | 공격 방향과 사거리가 읽히는 포대 |
| 도발 타워 | 방패, 깃발, 울림판 같은 중심성 |
| 바리케이드 | 낮고 넓은 장애물 |
| 폭발 바리케이드 | 균열이나 불안정한 못, 파편 암시 |
| 둔화 함정 | 바닥에 박힌 말뚝, 서리, 끈적한 잔해 |
| 오라 장치 | 주변으로 미세한 파동을 보내는 장치 |
| 임시 구조물 | 덜 완성된 재료, 불안정한 실루엣 |

## 카드 문장 스타일

카드 텍스트는 짧고 기능적이어야 합니다.

좋은 문장:

```text
도발 타워를 설치합니다.
파괴될 때 주변 적에게 피해를 줍니다.
```

나쁜 문장:

```text
고대의 맹세를 담은 불굴의 벽을 소환하여 적들의 분노를 끌어냅니다.
```

분위기는 카드 이름과 일러스트에서 주고, 효과 설명은 명확하게 씁니다.

## UI 문장 스타일

UI는 공포 소설처럼 말하지 않습니다.

짧고 분명하게 말합니다.

예시:

| 상황 | 문구 |
| --- | --- |
| 길막 불가 | 기지로 향하는 경로가 필요합니다. |
| 웨이브 호출 | 다음 웨이브를 지금 호출합니다. |
| 기지 위험 | 기지가 위험합니다. 전원 동의가 필요합니다. |
| 구조물 위험 | 이 구조물이 곧 파괴됩니다. |
| 보스 부위 | 다리를 부수면 이동 속도가 감소합니다. |

## 사운드 원칙

사운드는 정보와 분위기를 동시에 담당합니다.

우선순위:

1. 기지 위험 경고
2. 보스 패턴 예고
3. 구조물 파괴
4. 웨이브 호출
5. 카드 사용
6. 적 처치
7. 배경 분위기

보스음은 크기보다 낮이 중요합니다.

너무 큰 소리는 피로를 만들고, 낮고 느린 소리는 압박을 만듭니다.

## 음악 방향

일반 전투:

- 리듬은 분명하지만 과하게 빠르지 않음
- 웨이브 겹치기 시 레이어가 추가됨
- 승리 팡파르는 짧게

상점:

- 완전한 안전보다 잠깐 숨을 고르는 느낌
- 멀리서 여전히 낮은 소리가 들림

보스:

- 음악보다 반복되는 진동과 공백
- 보스가 가까워질수록 일부 악기가 사라짐
- 부위 파괴 시 음악이 커지기보다 한순간 비는 느낌

## 연출 금지선

- 피가 튀는 이펙트
- 신체 절단 표현
- 소리로 놀라게 하는 갑작스러운 점프 스케어
- UI를 고의로 읽기 어렵게 만드는 왜곡
- 공포를 위해 경로 정보를 숨기는 연출

공포는 정보를 숨기는 것이 아니라, 정보를 봐도 압박이 느껴지는 데서 나와야 합니다.

## 접근성 연출 기준

접근성 연출은 `accessibility_presentation_options`를 따릅니다.

목표는 공포를 약하게 만드는 것이 아니라, 공포 연출이 전술 판단을 방해하지 않게 만드는 것입니다.

| 단계 | 연출 기준 | 유지할 분위기 | 반드시 지킬 정보 |
| ---: | --- | --- | --- |
| 1 | 기본 가독성 | 어둡고 낮은 채도의 화면 | 카드 비용, 경로, 기지 체력, 보스 패턴 |
| 2 | 움직임 부담 | 느린 거대감과 먼 흔들림 | 경고 위치, 타이머, 타겟 하이라이트 |
| 3 | 사운드 압박 | 낮은 진동과 긴 공백 | 자막, 시각 경고, 핑 로그 |
| 4 | 전술 정보 | 기괴한 실루엣과 압도적 크기 | 적 역할, 보스 부위, 구조물 표식 |
| 5 | 협동 신호 | 조용하고 절제된 UI 톤 | 핑 아이콘, 방향 라벨, 담당 표시 |
| 6 | 연출 안전선 | 침묵과 규모의 심리적 압박 | 유혈 없음, 점프 스케어 없음, 정보 왜곡 없음 |

화면 흔들림을 줄이면 보스의 크기, 그림자, 사운드 공백, 느린 이동으로 거대감을 유지합니다.

저주파음을 줄이면 자막, UI 박자, 보스 실루엣 변화로 같은 정보를 보완합니다.

## 브랜딩 문구 후보

짧은 문구:

- 어디서 무너질지까지 설계하라.
- 다음 웨이브를 기다리지 마라. 불러라.
- 벽은 버티기 위해서만 세우는 것이 아니다.
- 마지막 기지는 사계절을 버틴다.

스팀/스토어용 한 줄:

```text
타워와 바리케이드로 미로를 만들고, 카드를 연쇄해 무너지는 방어선을 붙잡는 1~4인 협동 덱 빌딩 타워 디펜스.
```

## 발표용 요약

```text
Last Bastion: Four Seasons는 1~4인이 함께 마지막 기지를 지키는 협동 덱 빌딩 타워 디펜스입니다.
플레이어는 타워와 바리케이드로 적의 길을 비틀고, 구조물이 부서지는 순간까지 전술로 활용합니다.
웨이브 겹치기는 보상 증가가 아니라 기다림을 줄이는 템포 조절 장치이며, 거대한 보스는 유혈 없이도 압도적인 규모와 침묵으로 긴장감을 만듭니다.
```
