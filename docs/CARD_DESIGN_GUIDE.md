# Card Design Guide

이 문서는 **Last Bastion: Four Seasons**의 카드를 계속 추가할 때 지켜야 할 설계 기준입니다.

카드는 이 게임의 액션 버튼이자, 덱 빌딩의 성장 선택이며, 직업 정체성을 보여주는 가장 작은 단위입니다.

## 카드 설계 목표

좋은 카드는 다음 조건을 만족합니다.

- 읽는 순간 대략적인 용도가 보입니다.
- 강한 상황과 약한 상황이 분명합니다.
- 직업의 고유 역할을 강화합니다.
- 다른 직업과 협동할 이유를 만듭니다.
- 전장 상태를 보고 쓸지 말지 판단하게 만듭니다.
- 웨이브 겹치기를 보상 버튼으로 만들지 않습니다.

나쁜 카드는 다음 중 하나입니다.

- 항상 좋습니다.
- 언제 써야 할지 모릅니다.
- 텍스트가 길고 결과를 예측하기 어렵습니다.
- 공용 카드가 직업 고유 역할을 대체합니다.
- 무한 마나, 무한 드로우, 무한 버리기를 만듭니다.

## 카드 재설계 원칙

카드는 단순한 효과 버튼이 아니라, 전투 중 플레이어가 "지금 이걸 써야 하나?"를 판단하게 만드는 손패 속 선택지입니다.

카드 한 장은 아래 세 질문에 답해야 합니다.

| 질문 | 좋은 답 | 나쁜 답 |
| --- | --- | --- |
| 언제 쓰는가? | 첫 접촉, 붕괴 직전, 킬존 완성 후, 보스 부위 노출처럼 타이밍이 보입니다. | 손에 잡히면 아무 때나 씁니다. |
| 무엇을 포기하는가? | 마나, 위치, 구조물 체력, 다음 드로우, 수리 효율 중 하나를 부담합니다. | 대가 없이 모든 상황을 안전하게 만듭니다. |
| 무엇과 맞물리는가? | 특정 구조물, 적 역할, 전선 상태, 다른 직업 카드와 연결됩니다. | 혼자서 전장 문제를 닫습니다. |

기존 카드 초안은 직업 역할은 잘 잡혀 있지만, 일부 카드가 "좋은 효과"에 머물러 있습니다.

리워크의 목표는 숫자를 세게 만드는 것이 아니라, 카드마다 사용 장면과 실패 가능성을 선명하게 만드는 것입니다.

### 카드 한 장의 필수 구성

| 항목 | 설명 |
| --- | --- |
| `decisionQuestionKo` | 플레이어가 이 카드를 들고 고민해야 하는 한 문장 |
| `timingWindows` | 가장 강한 사용 순간 목록 |
| `poolLaneId` | 직업 카드 풀 라인 |
| `responseTags` | 어떤 적 역할 압박을 여는지 |
| `tradeoffTags` | 비용 외에 감수하는 대가 |
| `comboHookTags` | 함께 쓰면 좋은 구조물, 카드, 직업 시너지 |
| `missCostTag` | 잘못 썼을 때 생기는 손해 |

예시:

```json
{
  "cardId": "card_guardian_reflective_oath",
  "decisionQuestionKo": "지금 맞을 전면을 반사 피해 축으로 바꿀 것인가?",
  "timingWindows": ["first_contact", "swarm_compressed"],
  "poolLaneId": "guardian_thorns_value",
  "responseTags": ["sacrifice_value", "taunt_anchor"],
  "tradeoffTags": ["repair_efficiency_down"],
  "comboHookTags": ["elementalist_area_damage", "tinkerer_repair_window"],
  "missCostTag": "played_without_incoming_hits"
}
```

### 타이밍 창

카드는 강한 순간이 있어야 하고, 그 순간을 놓치면 효율이 낮아져야 합니다.

| 타이밍 창 | 의미 | 잘 맞는 카드 |
| --- | --- | --- |
| `prebuild` | 웨이브 시작 전 첫 방어선 구축 | 바리케이드, 증폭기, 압축 설계 |
| `first_contact` | 적이 첫 구조물에 닿는 순간 | 도발벽, 가시 성장, 빙결 지대 |
| `swarm_compressed` | 적이 킬존에 모인 순간 | 화염구, 번개 연결, 잔해 폭발 |
| `structure_critical` | 구조물이 파괴 직전인 순간 | 방패 두르기, 원격 수리, 자동 복구 |
| `collapse_aftershock` | 구조물이 부서진 직후 | 회수 작업, 전장 수습, 후방 재건 카드 |
| `priority_exposed` | 정예, 지원형, 보스 부위가 노출된 순간 | 집중 사격, 원소 표식, 과부하 |
| `hand_jammed` | 손패가 막혀 다음 행동이 끊긴 순간 | 재정비, 마나 전환, 빠른 손놀림 |
| `stack_pressure` | 겹친 웨이브로 전선 밀도가 높아진 순간 | 광역, 수리 창, 경로 연장 카드 |
| `boss_commit` | 보스 부위나 마지막 접근에 자원을 몰아야 하는 순간 | 최후의 문, 대폭발, 공명 증폭기 |
| `base_critical` | 기지 체력이 낮아 다음 피해가 치명적인 순간 | 마지막 수호, 기지 회복 보조 카드 |

웨이브 겹치기는 카드 타이밍을 자주 만들 수 있지만, 보상이나 희귀도, 카드 후보 수를 바꾸지 않습니다.

### 카드 대가의 종류

대가는 카드가 불편해지기 위한 장식이 아니라, 덱 빌딩의 방향을 만드는 장치입니다.

| 대가 | 좋은 사용처 | 금지선 |
| --- | --- | --- |
| 마나 부담 | 큰 설치, 넓은 범위, 보스 대응 | 비용만 높고 효과가 단순히 강한 카드 |
| 위치 부담 | 오라, 도발, 폭발, 잔해 | 특정 방위에서만 작동하는 카드 |
| 구조물 체력 부담 | 과부하, 위험한 증폭, 계획 붕괴 | 구조물 손실을 무한 자원으로 바꾸기 |
| 드로우 부담 | 저주, 큰 임시 이득 | 다음 손패를 완전히 잠그기 |
| 수리 효율 부담 | 가시, 과부하, 위험한 오라 | 수리 직업을 무의미하게 만들기 |
| 재사용 제한 | 강한 제어, 보스 지연 | 보스 패턴 삭제 |

좋은 대가는 플레이어가 "이번 런은 이 불편함을 감당할 수 있다"고 판단하게 만듭니다.

## 카드의 5가지 역할

| 역할 | 목적 | 예시 |
| --- | --- | --- |
| 준비 | 웨이브 시작 전 방어선을 만듭니다. | 바리케이드, 증폭기 |
| 대응 | 갑작스러운 위기를 막습니다. | 밀어내기, 원격 수리 |
| 전환 | 무너지는 상황을 다른 이득으로 바꿉니다. | 잔해 폭발, 회수 작업 |
| 증폭 | 이미 만든 킬존의 성능을 높입니다. | 원소 표식, 윤활 작업 |
| 결전 | 보스나 대형 위기에 큰 영향을 줍니다. | 대폭발, 최후의 문 |

새 카드는 반드시 위 역할 중 하나 이상에 속해야 합니다.

역할이 불분명하면 카드를 추가하지 않습니다.

## 카드 생애주기

카드는 전투 안에서 다음 흐름을 가집니다.

```text
덱
-> 드로우
-> 손패
-> 사용 또는 버리기
-> 버린 카드 더미
-> 덱 재섞기
```

카드가 이 흐름을 벗어나는 경우는 특별한 의미가 있어야 합니다.

예외 카드 유형:

| 유형 | 설명 | 주의점 |
| --- | --- | --- |
| 소멸 | 사용 후 이번 런의 전투 중 다시 나오지 않습니다. | 너무 자주 쓰면 덱 빌딩 감각이 약해집니다. |
| 보존 | 라운드 종료 후에도 손패에 남습니다. | 손패 한도와 충돌하지 않게 조심합니다. |
| 생성 | 임시 카드를 손패나 덱에 만듭니다. | 카드 풀이 흐려지지 않게 임시 태그를 붙입니다. |
| 저주 삽입 | 강한 보상 대가로 저주 카드를 덱에 넣습니다. | 플레이어 선택의 결과여야 합니다. |

MVP에서는 기본 생애주기만 사용합니다.

소멸, 보존, 생성 카드는 핵심 루프가 안정된 뒤 추가합니다.

## 카드 태그

태그는 카드 검색, 보상 후보, 아티팩트 시너지, 밸런스 분석에 사용합니다.

권장 태그:

| 태그 | 의미 |
| --- | --- |
| `build` | 구조물을 설치합니다. |
| `repair` | 구조물을 회복합니다. |
| `taunt` | 적 목표를 바꿉니다. |
| `thorns` | 피해 반사를 사용합니다. |
| `barrier` | 바리케이드와 관련됩니다. |
| `debris` | 잔해와 관련됩니다. |
| `explosion` | 폭발 피해를 사용합니다. |
| `slow` | 이동 속도를 낮춥니다. |
| `freeze` | 적을 잠시 멈춥니다. |
| `knockback` | 적을 뒤로 밀어냅니다. |
| `aura` | 주변 구조물에 영향을 줍니다. |
| `overdrive` | 강한 효과와 대가가 함께 있습니다. |
| `draw` | 카드 드로우와 관련됩니다. |
| `mana` | 마나와 관련됩니다. |
| `boss` | 보스나 부위 파괴에 강합니다. |
| `economy` | 골드, 제거, 회수와 관련됩니다. |

카드 하나는 보통 2~4개 태그를 가집니다.

태그가 너무 많으면 카드 역할이 흐려졌다는 신호입니다.

### 대응 태그

대응 태그는 적 역할 프로필이 요구하는 풀이 실제 카드 보상, 상점 추천, 훈련장으로 이어지게 만드는 연결값입니다.

대응 태그는 "이 적을 삭제한다"가 아니라 "이 압박에 플레이어가 선택할 수 있는 행동을 연다"는 뜻이어야 합니다.

| 대응 태그 | 주로 여는 풀이 | 잘 맞는 적 역할 |
| --- | --- | --- |
| `area_damage` | 모인 적을 짧은 시간에 정리 | 군집형 |
| `taunt_anchor` | 적 목표를 한 지점으로 모음 | 군집형, 돌파형, 파괴형 |
| `path_extension` | 이동 시간을 늘려 딜타임 확보 | 돌파형, 압박형, 저항형 |
| `slow_or_knockback` | 빠른 적이나 대형 적의 도달 시간을 늦춤 | 돌파형, 압박형, 보스 |
| `repair_window` | 구조물을 살릴지 버릴지 결정할 시간 확보 | 파괴형, 압박형 |
| `sacrifice_value` | 부서지는 구조물에 잔해, 폭발, 회수 가치를 부여 | 파괴형, 군집형 |
| `priority_burst` | 먼저 끊어야 할 적을 짧게 집중 공격 | 방해형, 지원형, 정예형 |
| `resource_unjam` | 손패/마나 꼬임을 일시적으로 풀어 전선 유지 | 방해형 |
| `rear_rebuild` | 무너진 전선을 후방 방어선으로 이전 | 압박형, 파괴형, 보스 |
| `focus_fire_mark` | 파티가 같은 대상을 보도록 표시 | 정예형, 보스 부위, 지원형 |

카드 보상 후보를 만들 때는 직전 웨이브의 `failureHintTags`와 다음 웨이브의 `EnemyRoleProfile.minimumCounterTags`를 함께 봅니다.

단, 후보 3장을 전부 같은 대응 태그로 채우지 않습니다.

한 장은 직접 대응, 한 장은 빌드 연결, 한 장은 덱 상태를 읽게 하는 카드여야 합니다.

골드 거절은 카드 후보 슬롯이 아니라 별도 버튼이며, 덱을 가볍게 유지할 이유가 강할 때 설명 문구만 강조합니다.

## 비용 기준

| 비용 | 의미 | 카드 예시 |
| ---: | --- | --- |
| 0 | 연결, 조건부, 작은 보정 | 원소 표식, 과부하 |
| 1 | 기본 행동 | 바리케이드, 화염구, 원격 수리 |
| 2 | 라운드 방향을 바꾸는 행동 | 번개 연결, 압축 설계 |
| 3 | 위기 해결 또는 보스 대응 | 대폭발, 최후의 문 |
| 4+ | 빌드 핵심 또는 결전 카드 | 불굴의 성문, 낙뢰 의식 |

0비용 카드는 특히 조심합니다.

0비용 카드가 드로우나 마나를 직접 늘리면 무한 콤보 위험이 커집니다.

### 비용별 금지선

| 비용 | 금지선 |
| ---: | --- |
| 0 | 즉시 마나 순증가, 조건 없는 드로우, 강한 광역 피해 |
| 1 | 넓은 범위 해결, 보스 부위 큰 피해, 구조물 완전 보호 |
| 2 | 전장을 혼자 정리하는 광역, 조건 없는 대량 수리 |
| 3 | 반복 사용 가능한 완전 무력화, 보스 장기 정지 |
| 4+ | 사용하면 사실상 승리하는 효과 |

비용은 카드의 강도만이 아니라, 사용 타이밍의 부담입니다.

비용이 낮은 카드는 판단을 자주 만들고, 비용이 높은 카드는 큰 결정을 만듭니다.

### 파워 예산

카드의 힘은 여러 요소의 합으로 봅니다.

| 요소 | 파워를 올리는 요인 |
| --- | --- |
| 비용 | 낮을수록 강합니다. |
| 범위 | 넓을수록 강합니다. |
| 즉시성 | 바로 발동할수록 강합니다. |
| 대상 자유도 | 어디든 쓸 수 있을수록 강합니다. |
| 지속 시간 | 오래갈수록 강합니다. |
| 자원 회복 | 마나나 드로우를 만들수록 강합니다. |
| 안전성 | 실패 가능성이 낮을수록 강합니다. |

카드가 여러 요소에서 동시에 강하면 반드시 조건이나 대가가 필요합니다.

예시:

| 카드 성격 | 필요한 제한 |
| --- | --- |
| 낮은 비용 + 넓은 범위 | 낮은 피해, 짧은 지속, 강한 저항 |
| 즉발 수리 + 높은 회복 | 높은 비용, 대상 제한 |
| 드로우 + 마나 | 라운드당 횟수 제한 |
| 무료 설치 | 낮은 체력, 임시 지속, 파괴 대가 |
| 보스 부위 큰 피해 | 일반 적 상대 비효율 |

## 희귀도 기준

| 희귀도 | 설계 기준 |
| --- | --- |
| 일반 | 직관적이고 자주 쓸 수 있는 카드 |
| 희귀 | 특정 상황에서 강한 카드 |
| 영웅 | 덱 방향을 크게 바꾸는 카드 |
| 저주 | 강한 효과와 명확한 대가가 함께 있는 카드 |

희귀도가 높다고 항상 더 강하면 안 됩니다.

희귀도는 위력보다 조건, 리스크, 빌드 의존도를 나타냅니다.

## 전리품 카드 풀

시작 덱은 직업을 배우는 도구이고, 전리품 카드는 런의 방향을 바꾸는 선택지입니다.

전리품 카드는 라운드, 보스, 상점, 이벤트에서 얻을 수 있지만, 모든 획득 경로가 같은 풀을 쓰면 안 됩니다.

| 획득 경로 | 소유 | 목적 | 희귀도 원칙 | 금지선 |
| --- | --- | --- | --- | --- |
| 일반 라운드 전리품 | 개인 | 방금 겪은 문제와 다음 웨이브를 연결 | 구간별 기본 비율 사용 | 겹치기, 클리어 시간, 처치 수로 희귀도 보정 금지 |
| 보스 개인 카드 전리품 | 개인 | 보스에서 확인한 역할을 다음 10일 운영으로 연결 | 보스 전용 보너스가 아니라 구간 풀 안에서 역할 편향 | 보스 클리어 보너스로 영웅 확정 금지 |
| 상점 카드 | 개인 구매, 파티 골드 사용 | 특정 덱 방향을 의식적으로 구매 | 가격과 슬롯으로 희귀도 제한 | 첫 상점 영웅 카드 기본 노출 금지 |
| 이벤트 계약 카드 | 개인 또는 파티 선택 | 위험한 대가와 특수 선택 제공 | 저주, 희귀, 특수 후보를 명시적으로 제안 | 저주 강제 삽입 금지 |
| 메타 해금 카드 | 계정 후보 풀 | 새 선택지 개방 | 등장 확률 증가가 아니라 후보 풀 확장 | 공격력, 보상 배율, 희귀도 보정 금지 |

전리품 카드 후보는 항상 "새 카드를 넣을 이유"와 "골드를 받고 거절할 이유"가 함께 보여야 합니다.

### 시작 카드와 전리품 카드의 차이

| 구분 | 시작 카드 | 전리품 카드 |
| --- | --- | --- |
| 목적 | 직업 기본 조작 학습 | 런마다 다른 운영 방향 형성 |
| 복잡도 | 낮음 | 일반은 낮고, 희귀 이상은 조건과 대가가 뚜렷함 |
| 실패 비용 | 작음 | 잘못 집으면 덱이 무거워지거나 타이밍이 어긋남 |
| 등장 시점 | 런 시작 | 라운드, 보스, 상점, 이벤트 |
| 제거 가치 | 후반에 덜어낼 수 있음 | 빌드와 안 맞으면 거절하거나 제거해야 함 |

시작 카드와 같은 역할의 전리품 카드는 "더 강한 같은 카드"가 아니라, 사용 타이밍이나 대가가 다른 카드여야 합니다.

예를 들어 `화염구`가 기본 광역이라면 `화염 고리`는 미리 깔아둘 때 강해야 하고, `낙뢰 의식`은 예고 지점을 읽을 때 강해야 합니다.

### 희귀도별 전리품 역할

| 희귀도 | 전리품 역할 | 좋은 예 | 나쁜 예 |
| --- | --- | --- | --- |
| 일반 | 시작 덱의 행동을 더 안정적으로 반복하게 함 | 낮은 비용 보강, 짧은 수리, 작은 광역, 손패 정리 | 시작 카드의 순수 상위호환 |
| 희귀 | 특정 전장 문제를 다른 방식으로 풀게 함 | 위치 이동, 능동 폭파, 큰 넉백, 과부하 안정화 | 아무 조건 없이 항상 효율 좋은 카드 |
| 영웅 | 덱의 운영 축을 꺾는 빌드 중심 카드 | 전체 가시, 폭발 연쇄, 오라 공유, 예고 지점 낙뢰 | 집으면 무조건 이기는 카드 |
| 저주 | 강한 즉시 이득과 장기 대가를 함께 줌 | 무료 설치와 취약, 보스 피해와 일반 처치 자원 감소 | 원하지 않는데 덱에 들어오는 벌칙 |

일반 카드는 덱의 뼈대입니다.

희귀 카드는 플레이어가 "이번 런에서는 이 상황이 자주 오겠다"고 판단할 때 집는 카드입니다.

영웅 카드는 강한 카드가 아니라 덱의 문장을 바꾸는 카드입니다.

저주 카드는 나쁜 카드가 아니라, 제거하거나 활용할 계획까지 포함해서 고르는 위험한 전리품입니다.

| 구간 | 일반 | 희귀 | 영웅 | 저주 | 풀 방향 |
| --- | ---: | ---: | ---: | ---: | --- |
| 1~4일 | 90% | 10% | 0% | 이벤트 제외 | 시작 덱 보강과 낮은 비용 카드 |
| 5~10일 | 80% | 20% | 0% | 이벤트 제외 | 첫 상점, 파괴, 손패 정리, 첫 보스 준비 |
| 11~20일 | 70% | 30% | 0% | 선택형 이벤트/상점 | 첫 아티팩트와 맞는 운영 보완 |
| 21~30일 | 60% | 35% | 5% | 선택형 이벤트/상점 | 30일 MVP 빌드 방향 확정 |
| 31~70일 | 55% | 35% | 10% | 선택형 | 계절 압박에 맞는 빌드 변형 |

웨이브 겹치기, 클리어 시간, 처치 수, 접근성 옵션, 재접속 여부는 이 비율을 바꾸지 않습니다.

보스 후 개인 카드 전리품도 "보스 클리어 보너스"로 희귀도를 올리지 않습니다.

다만 보스에서 확인한 역할 태그를 사용해 후보 풀의 방향을 좁힐 수는 있습니다.

### 전리품 후보 생성 규칙

카드 후보 3장은 아래 구조를 기본으로 합니다.

| 슬롯 | 기본 역할 | 설명 |
| --- | --- | --- |
| 직업 직접 대응 | 방금 겪은 문제를 자기 직업 방식으로 풉니다. |
| 직업 우회 대응 | 다음 웨이브나 다른 카드 라인을 준비합니다. |
| 덱 상태 보완 | 덱 장수, 비용 곡선, 손패 막힘, 약한 빈틈을 읽게 합니다. |

후보 생성 제한:

- 같은 `poolLaneId` 후보는 기본 1장만 허용합니다.
- 같은 `responseTags` 후보는 기본 1장만 허용합니다.
- 공용 카드는 최대 1장만 권장합니다.
- 영웅 카드는 첫 10일 일반 보상에 나오지 않습니다.
- 저주 카드는 일반 라운드 보상에 무작위로 섞지 않습니다.
- 저주는 이벤트, 특수 상점, 명시된 계약형 선택에서만 등장합니다.

카드 거절 골드는 실패 보상이 아닙니다.

덱을 얇게 유지하고 상점에서 제거/강화 비용을 모으는 정상 선택입니다.

### 보상 풀 비율 적용

카드 보상 풀은 위의 `구간별 전리품 풀`을 기준으로 합니다.

희귀 카드만 많아지면 덱 방향이 흔들리고, 영웅 카드가 너무 빨리 나오면 시작 덱의 학습이 무너집니다.

희귀도는 보상량 보정이 아니라 전리품 풀의 성격입니다.

웨이브 겹치기, 클리어 시간, 처치 수는 전리품 풀 비율을 바꾸지 않습니다.

상점과 이벤트는 별도 전리품 풀을 사용할 수 있지만, 이 경우에도 저주와 영웅 카드는 명시적인 선택과 대가가 있어야 합니다.

## 100일 카드 성장 곡선

100일 풀런에서는 매일 카드 보상이 나오지만, 매일 카드를 추가하는 것이 정답이면 덱이 너무 빨리 무거워집니다.

카드 성장은 아래 네 행동의 비중이 시간에 따라 바뀌어야 합니다.

| 성장 행동 | 역할 | 강해지는 시점 |
| --- | --- | --- |
| 추가 | 새 문제에 대응할 도구를 얻습니다. | 1~40일 |
| 강화 | 자주 쓰는 카드의 역할을 선명하게 합니다. | 11~70일 |
| 제거 | 시작 카드나 빌드와 맞지 않는 카드를 덜어냅니다. | 20~90일 |
| 거절 | 카드 대신 골드를 받아 덱을 얇게 유지합니다. | 31~100일 |

후보 생성 원칙:

- 항상 카드 3장 중 1장 또는 골드 선택을 유지합니다.
- 첫 10일에는 일반 카드를 중심으로 보여주고, 희귀 카드는 역할을 명확히 이해할 수 있을 때만 섞습니다.
- 같은 보상 화면에 같은 역할 카드 3장을 모두 넣지 않습니다.
- 직업 전용 카드 2장과 공용 보완 카드 1장 구성을 기본값으로 삼습니다.
- 방금 실패한 문제를 직접 해결하는 카드 1장, 다음 날을 준비하는 카드 1장, 덱 상태를 읽게 하는 카드 1장이 보이면 좋습니다.
- 덱을 가볍게 유지해야 할 때는 카드 슬롯을 줄이지 않고 골드 거절 버튼의 이유 문구를 강조합니다.

### 1~30일 MVP 전리품 샘플 운영

1~30일 샘플은 고정 드랍표가 아닙니다.

같은 카드 3장 선택 규칙 안에서, 매일의 전투 질문이 후보 3장의 등장 이유로 이어지는지 확인하는 제작 기준입니다.

샘플은 아래 데이터 흐름을 따릅니다.

```text
MvpRewardShopEventDay
-> MvpLootSampleDay
-> MvpLootRarityLock
-> CardRewardRailPolicy
-> CardRewardCandidateGenerationTrace
```

`MvpLootSampleDay`는 후보 수, 희귀도, 골드 거절량, 웨이브 겹치기 보상을 바꾸지 않습니다.

샘플이 고정하는 것은 "몇 장을 주는가"가 아니라 "그 3장이 서로 다른 질문인가"입니다.

| 구간 | 핵심 질문 | 직접 대응 레일 | 빌드 연결 레일 | 덱 상태 레일 | 감사 포인트 |
| --- | --- | --- | --- | --- | --- |
| 1~4일 | 시작 덱의 빈틈을 이해했는가? | 첫 누수, 빠른 적, 군집, 구조물 손상 | 직업 기본 루프와 낮은 복잡도 신호 | 0~1비용, 공용 보완 최대 1장 | 영웅/저주/변형/비활성 방향 금지 |
| 5~9일 | 첫 상점과 첫 보스 준비가 연결되는가? | 파괴형, 손패 막힘, 우선 처치, 킬존 유지 | 잔해, 수리, 부위 집중, 지연 타이밍 | 거절 골드와 제거 이유 형성 | 겹치기 학습을 보상 증가로 설명 금지 |

| 15~19일 | 이벤트/상점 선택이 전투에서 검증되는가? | 계약 후유증, 반복 실패 태그, 고밀도 회복 | 강점 강화 또는 약점 보완 유지 | 쓰지 않는 카드, 버리기, 마나 꼬임 | 강제 저주, 겹치기 보상, 확정 영웅 금지 |

| 21~24일 | 준비된 빌드만 확정 질문을 받는가? | 정예, 분담, 붕괴 압박 대응 | 지원 크레딧과 전투 증거가 있는 영웅 또는 희귀 전환 | 집기와 거절 모두 정상 선택 | 영웅 2장 동시 노출 금지 |

샘플 패킷 생성 규칙:

1. 완료한 일자의 `MvpRewardShopEventDay.primaryRewardLockId`를 먼저 읽습니다.
2. 해당 일자의 `MvpLootSampleDay`는 정확히 세 레일만 요구합니다.
3. `directAnswerIntent`는 직전 전투 리포트와 다음 웨이브 최소 대응 태그를 함께 봅니다.
4. `buildBridgeIntent`는 현재 직업 아키타입, 보유 아티팩트, 다음 2~3일 압박을 봅니다.
5. `deckStateIntent`는 덱 장수, 비용 곡선, 버리기 사용률, 손패 막힘을 봅니다.
6. 후보가 3장을 채우지 못하면 직업 안전 카드, 약한 공용 보완, 같은 역할의 낮은 희귀도 순서로 내려갑니다.
7. 보스일은 보스 역할 태그로 후보 이유만 좁히고 희귀도나 후보 수를 올리지 않습니다.
8. 25일은 전환일이지만 보스일이 아니므로 `loot_lock_round_021_030` 샘플만 사용합니다.
9. 웨이브를 겹치면 완료한 일자별 `MvpLootSampleDay`를 각각 보존하고, 압축 정산 화면에서 순서대로 처리합니다.

솔로 콘텐츠 투영:

| 멀티에서의 질문 | 솔로 동쪽 전선 투영 | 카드 제작 기준 |
| --- | --- | --- |

### 1~30일 샘플 카드 ID 라우팅

`MvpLootSampleCardRouteSet`은 샘플 일자가 실제 어떤 카드 ID를 우선 후보로 볼지 정리하는 연결표입니다.

이 라우팅은 고정 드랍표가 아니며, 아래 순서로 후보를 좁히는 데만 사용합니다.

```text
일자 샘플
-> 카드 라우트 세트
-> 플레이어 직업의 직접 대응 후보 목록
-> 플레이어 직업의 빌드 연결 후보 목록
-> 덱 상태 공용 후보 목록
-> 희귀도 잠금과 반복 피로도 검사
-> 최종 3장 후보
```

라우팅 원칙:

1. 기본 라운드 보상은 `starter` 카드를 새 복사본으로 지급하지 않습니다.
2. 1~20일 일반 라운드 라우트는 `class_round_loot`와 `common_soft_gap` 카드만 우선 사용합니다.
3. 10일 보스 보상은 보스에서 확인한 태그로 후보 이유를 좁히지만, 영웅 후보를 열지 않습니다.
4. 20일 보스와 21~30일 일반 보상은 영웅 ID를 `gatedBridgeCandidateIds`로만 가질 수 있습니다.
5. 영웅 후보는 `MvpHeroicCommitGate`의 지원 크레딧, 실제 지원 카드 보유, 런 중 선택 지원, 최근 전투 증거 조건을 통과하지 못하면 같은 역할의 희귀/일반 카드로 내려갑니다.
6. 공용 후보는 한 보상 화면에 최대 1장만 들어갑니다.
7. 공용 확장 잠금 카드인 `card_common_pressure_signal`, `card_common_reposition_line`, `card_common_emergency_battery`, `card_common_joint_operation`, `card_common_silent_call`은 30일 MVP 일반 라운드 기본 라우트에 넣지 않습니다.
8. 라우트 세트는 웨이브 겹치기, 클리어 시간, 처치 수, 보스 부위 파괴 수로 바뀌지 않습니다.

### 20~30일 영웅 후보 게이트

영웅 후보는 보상 생성기의 성공 보너스가 아니라, 이미 선택한 덱 방향을 끝까지 밀지 묻는 확정 질문입니다.

`requires_two_archetype_support_credits`는 단순히 같은 태그 카드 2장을 세는 규칙이 아닙니다. 실제 판정은 아래 순서를 따릅니다.

1. 보상 출처가 20일 보스 개인 보상, 21~30일 라운드 보상, 20~30일 `shop_heroic_tune` 중 하나인지 확인합니다.
2. 해당 영웅의 `MvpHeroicCommitGate`를 읽고 실제 덱 안의 같은 아키타입 지원 카드 수를 먼저 확인합니다.
3. 강화나 장착 아티팩트가 `HeroicEquivalentSupportProfile`에 등록되어 있으면 한 게이트당 최대 1개만 지원 크레딧으로 더합니다.
4. 실제 지원 카드가 0장이면 동등 지원을 아무리 갖고 있어도 영웅을 열지 않습니다.
5. 지원 크레딧 합계가 2 이상이고, 그중 최소 1개가 런 중 선택한 보상 카드, 적용 강화, 장착 아티팩트에서 나온 것인지 확인합니다. 시작 덱에 원래 있던 카드만으로는 영웅을 열지 않습니다.
6. 최근 5일 전투 리포트 또는 직전 보스 리포트에서 해당 전술을 실제로 수행한 증거 태그 1개 이상을 확인합니다.
7. 후보 카드 상세에 남는 약점과 대가 태그가 표시되지 않으면 같은 역할의 일반/희귀 카드로 내려갑니다.
8. 게이트 실패는 후보 수, 희귀도, 골드 거절량을 바꾸지 않고 `heroic_candidate_downgraded`로만 기록합니다.

#### 영웅 카드 상세 표시 기준

영웅 카드 상세는 카드가 강하다는 사실보다, 왜 지금 이 덱에서 책임질 수 있는 선택인지 먼저 설명해야 합니다.

카드 앞면과 펼침 정보는 분리합니다.

| 위치 | 먼저 보여줄 것 | 숨기거나 펼침으로 보낼 것 |
| --- | --- | --- |
| 카드 앞면 | 비용, 희귀도, 역할 태그, `준비된 운영`, 남는 대가 1개 | 지원 카드 목록, 세부 카운트, 후보 하향 기록 |
| 카드 펼침 | 지원 카드, 동등 지원, 최근 증거, 남는 대가 | 처치 수, 클리어 시간, 웨이브 겹치기 횟수 |
| 하향 후보 펼침 | 같은 역할 대체 후보와 부드러운 이유 1개 | 잠긴 영웅 카드 실루엣, 실패 도장 |
| 상점 조율 패널 | 대상 플레이어, 가격, 증거, 대가, 대체 선택 | 랜덤 판매 슬롯, 추천 순위 |

카드 문구는 아래 순서를 따릅니다.

1. 이 카드가 어떤 운영을 확정하는지 한 문장으로 말합니다.
2. 실제 전투에서 확인된 증거를 짧게 붙입니다.
3. 남는 대가를 카드 효과 바로 아래에 둡니다.
4. 보스 정책이나 반복 상한은 상세 펼침에 둡니다.

예시:

| 카드 | 좋은 상세 문구 방향 | 피할 문구 |
| --- | --- | --- |
| `card_guardian_thorn_throne` | 도발 구조물이 실제로 맞아준 덱에서 반사 운영을 확정합니다. 수리 효율이 낮아집니다. | 이번 런 최고의 방어 영웅 |
| `card_architect_inverted_path` | 이미 경로를 읽고 늘린 덱에서 짧은 구간을 더 비틀어 시간을 법니다. 완전 길막은 할 수 없습니다. | 길막 정답 카드 |
| `card_elementalist_storm_ritual` | 표식과 후속 집중이 있는 덱에서 예고 지점에 큰 피해를 넣습니다. 자동 추적하지 않습니다. | 보스 삭제 번개 |
| `card_tinkerer_reassembly_machine` | 파괴된 핵심 구조물을 낮은 체력으로 되돌립니다. 반복 재건 대가가 남습니다. | 구조물 손실 무효화 |

영웅 게이트는 활성 방향 투영을 통과해야 합니다.

솔로에서는 동쪽 전선 안의 전방, 중간, 후방, 경로 길이, 적 역할 순서로 증거 태그를 만들며, 북쪽/서쪽/남쪽 전용 조건을 요구하지 않습니다.

#### 전투 증거 태그 생성 기준

영웅 후보의 최근 전투 증거는 `CombatReportHeroicProofTagProfile`에서 생성됩니다.

이 태그는 플레이어가 카드를 냈다는 사실이 아니라, 그 카드나 구조물이 전투에서 실제 판단을 만들었다는 기록입니다.

공통 기준:

- 최근 12초 안에 배치, 카드 사용, 수리, 표식, 경로 변경, 핑 확인 같은 플레이어 행동이 있어야 합니다.
- 활성 전선 밖에서 생긴 사건은 증거가 되지 않습니다.
- 한 전투 리포트는 플레이어당 영웅 증거 태그를 최대 2개까지만 기록합니다.
- 같은 영웅 게이트에는 한 전투 리포트당 1개 증거만 계산합니다.
- 웨이브 겹치기로 밀도가 높아진 상황에서도 태그 요구량, 보상, 가격, 후보 수, 희귀도는 바뀌지 않습니다.
- 자동 아티팩트 발동만으로는 부족하며, 플레이어가 최근에 의도한 행동이 연결되어야 합니다.

직업별 판정 질문:

| 직업 | 증거가 되는 행동 | 부족한 행동 |
| --- | --- | --- |
| 수호자 | 도발 구조물이 실제로 맞고, 가시/반사/붙잡기가 누수나 보스 부위 집중 시간을 만듦 | 도발 타워를 설치했지만 적이 거의 때리지 않음 |
| 건축가 | 의도한 구조물 파괴, 잔해 압축, 합법 경로 연장이 적의 시간을 실제로 빼앗음 | 완전 길막 실패, 미리보기 없이 막다른 배치 |
| 원소술사 | 둔화/밀침/표식/예고 공격이 후속 화력이나 누수 방지로 이어짐 | 넓은 피해만 넣었지만 제어 창이나 표식 후속이 없음 |
| 땜장이 | 오라 중심 유지, 위험한 밀집 생존, 수리/재건 창이 구조물 붕괴를 늦춤 | 오라가 켜졌지만 주변 구조물이 활용하지 못함 |

같은 라우트 세트 안에 여러 카드가 있어도 화면에 전부 나오지 않습니다.

최종 화면은 항상 `직접 대응` 1장, `빌드 연결` 1장, `덱 상태` 1장이라는 읽기 구조를 우선합니다.

### 기대 덱 크기

덱 크기는 플레이어가 매일 카드를 추가하지 않도록 유도하는 안전 지표입니다.

| 시점 | 권장 덱 크기 | 해석 |
| --- | ---: | --- |
| 시작 | 10장 | 직업 기본 루프 |
| 10일 | 13~16장 | 첫 보스 대응 카드 포함 |
| 30일 | 18~24장 | MVP 기준 빌드 방향 확인 |
| 50일 | 22~30장 | 여름 압박 대응 카드 포함 |
| 70일 | 24~32장 | 제거와 강화로 핵심 카드 비중 유지 |
| 90일 | 26~34장 | 최종 보스 준비 완료 |
| 100일 | 26~36장 | 마지막 선택 후에도 손패 순환 가능 |

권장 덱 크기를 넘는 것이 즉시 실패는 아닙니다.

다만 70일 이후 덱이 36장을 넘으면 손패 막힘, 낮은 사용률 카드, 카드 보상 피로도를 집중 점검합니다.

### 후반 카드 보상 금지선

71일 이후에는 새 아키타입을 시작하게 만드는 카드를 기본 보상으로 밀지 않습니다.

허용:

- 기존 빌드를 강화하는 카드
- 최종 보스 압력에 대응하는 위치 보정 카드
- 손패를 정리하는 카드
- 기지 위기나 구조물 이전을 돕는 카드

금지:

- 80일 이후 처음 성립하는 전용 콤보
- 91일 이후 영웅 카드 중심 새 빌드 유도
- 91일 이후 게이트 없는 영웅 후보 노출
- 카드 보상 희귀도 보정으로 후반 파워를 억지로 끌어올리기
- 웨이브 겹치기 사용 횟수에 따른 보상 풀 변경
- 100일 클리어 후 완료한 런에 영향을 주는 카드 보상

### 직업별 71~100일 후반 전리품 카드

후반 신규 전리품 카드는 직업마다 6장만 먼저 설계합니다.

각 직업은 일반 2장, 희귀 3장, 영웅 1장을 기본으로 하며, 저주는 71~100일 일반/보스 개인 보상에 새로 넣지 않습니다.

모든 후반 카드는 기존 아키타입의 `patch` 또는 `payoff` 역할만 가집니다.

`starter`, `new_archetype_signal`, `risk_accelerator` 역할로 등록하지 않습니다.

## 직업별 카드 기둥

직업 카드는 100일 동안 약점을 지우는 방식이 아니라, 각 직업의 핵심 질문을 더 어려운 상황에서 다시 풀게 만드는 방식으로 성장해야 합니다.

| 직업 | 카드 성장 방향 | 금지선 |
| --- | --- | --- |
| 수호자 | 도발 위치, 가시, 파괴 지연, 보스 저지 | 광역 정리와 경로 설계를 대체하지 않음 |
| 건축가 | 바리케이드, 잔해, 계획 붕괴, 후방 킬존 | 완전 길막과 만능 폭발 피해 금지 |
| 원소술사 | 광역, 둔화, 넉백, 부위 집중 | 구조물 유지와 모든 웨이브 단독 해결 금지 |
| 땜장이 | 수리, 오라, 과부하, 유지보수 | 무한 수리와 오라 무한 중첩 금지 |

카드가 다른 직업과의 시너지를 만들 때는 수치 합산보다 타이밍, 위치, 대상 조건을 우선합니다.

### 카드 풀 계약

직업별 카드 풀은 좋은 카드 목록이 아니라, "이 직업이 런 전체에서 어떤 질문을 계속 풀어야 하는가"를 고정하는 계약입니다.

MVP 기준은 직업당 시작 카드 6종과 보상 카드 8종, 총 14종입니다.

30일 이후 확장은 같은 계약 안에서 보상 카드 수를 늘리되, 약점을 삭제하는 새 만능 라인을 추가하지 않습니다.

| 계약 항목 | 기준 |
| --- | --- |
| 주 라인 | 직업마다 4개를 둡니다. |
| 카드 연결 | 모든 직업 전용 카드는 주 라인 1개를 반드시 가집니다. |
| 보조 라인 | 카드가 복합 역할이면 보조 라인은 1개까지만 허용합니다. |
| MVP 분포 | 시작 카드와 보상 카드를 합쳐 각 라인에 최소 2종 이상 배치합니다. |
| 보상 화면 | 같은 라인 카드 3장을 한 화면에 보여주지 않습니다. |
| 공용 보완 | 공용 카드는 빈 역할을 약하게 보완하되, 직업 고유 라인을 같은 강도로 대체하지 않습니다. |
| 방향 조건 | 특정 방위 전용 카드 대신 현재 압박 전선, 선택 전선, 가장 가까운 활성 전선을 기준으로 작동합니다. |

카드가 특정 방향에서만 작동하면 인원수별 활성 방향 규칙과 충돌합니다.

솔로는 동쪽만 쓰지만, 수호자의 보스 붙잡기, 건축가의 후방 재건, 원소술사의 우선 처치, 땜장이의 오라 타이밍을 모두 동쪽 전선 안에서 경험할 수 있어야 합니다.

### MVP 카드 카탈로그 운용 기준

카드 카탈로그는 카드 이름 목록이 아니라, 시작 덱, 전리품, 상점, 이벤트가 같은 카드를 어떤 책임으로 다루는지 잠그는 기준입니다.

MVP에서는 카드 종류를 늘리기 전에 아래 구분을 먼저 지킵니다.

| 카탈로그 역할 | 의미 | 보상 풀 사용 | 설계 의도 |
| --- | --- | --- | --- |
| `starter` | 시작 덱 10장을 구성하는 카드 | 기본 라운드 보상에서는 직접 복제하지 않음 | 첫 판에 직업 조작을 가르칩니다. |
| `class_round_loot` | 시작 덱 밖 직업 전용 보상 카드 | 라운드, 보스 개인 보상, 상점 | 시작 행동을 다른 타이밍과 대가로 확장합니다. |
| `class_heroic_commit` | 덱 방향을 확정하는 직업 영웅 카드 | 21일 이후 낮은 비율 또는 상점 | 이미 잡힌 아키타입을 마무리합니다. |
| `class_curse_contract` | 강한 즉시 이득과 장기 대가가 있는 직업 저주 | 이벤트 계약, 특수 상점 | 플레이어가 위험을 동의했을 때만 들어옵니다. |
| `common_soft_gap` | 빠진 역할을 약하게 보완하는 공용 카드 | 보상 후보 0~1장 | 협동 조합의 빈틈을 잠깐 메웁니다. |
| `common_expansion_locked` | MVP 이후 확장용 공용 카드 | 31일 이후, 아티팩트, 이벤트 후보 | 30일 MVP의 직업 정체성을 흐리지 않게 보류합니다. |

`starter` 카드는 시작 덱 안에서 중복 매수로 존재할 수 있지만, 일반 라운드 전리품에서 계속 같은 시작 카드를 복제하면 덱 빌딩이 "초기 카드 더 많이 집기"로 좁아집니다.

따라서 1~10일 보상은 시작 카드의 직접 복제보다 같은 행동을 다른 조건으로 여는 보상 카드를 우선합니다.

- `class_curse_contract` 1종은 일반 라운드, 보스 개인 보상의 랜덤 후보에 들어가지 않고, 이벤트 계약이나 특수 상점 확인 UI를 통해서만 획득합니다.
- 모든 카드 ID는 활성 전선 투영 규칙을 따릅니다. 솔로 플레이의 동쪽 전선에서도 특정 방위가 없어서 죽는 카드가 되면 안 됩니다.
- 웨이브 겹치기, 클리어 시간, 처치 수, 보스 부위 파괴 수는 이 표의 후보 수, 희귀도, 골드 총량을 바꾸지 않습니다.

#### 보상 후보 3레일

카드 3장 보상은 무작위 3장이 아니라, 서로 다른 질문을 가진 3개의 레일에서 뽑습니다.

| 레일 ID | 기본 후보 | 입력 신호 | 좋은 결과 | 금지선 |
| --- | --- | --- | --- | --- |
| `reward_rail_direct_answer` | 직업 전용 1장 | 방금 뚫린 적 역할, 피해 방향, 구조물 붕괴 태그 | 지금 겪은 문제를 자기 직업 방식으로 바로 풀게 함 | 정답 카드처럼 한 문제를 완전히 삭제 |
| `reward_rail_build_bridge` | 직업 전용 1장 | 현재 덱의 아키타입 수, 다음 3일 압박, 보유 아티팩트 | 이미 잡은 방향과 다음 압박을 연결 | 게이트 없는 영웅 확정 카드 강제 |
| `reward_rail_deck_state` | 공용 보완 또는 안전 직업 카드 | 덱 장수, 손패 막힘, 버리기 사용률, 마나 꼬임 | 덱을 더 두껍게 할 이유와 거절할 이유를 함께 읽게 함 | 공용 카드가 직업 고유 역할을 같은 강도로 대체 |

영웅 후보가 희귀도 추첨에 걸렸지만 게이트 조건을 만족하지 못하면 아래 순서로 내려갑니다.

1. 같은 아키타입의 희귀 `pivot` 카드.
2. 같은 대응 태그의 일반 또는 희귀 `signal` 카드.
3. 해당 레일에 맞는 공용 보완 카드.
4. 안전한 낮은 복잡도 직업 카드.

이 하향은 실패 보상이 아니라 카탈로그 안전장치입니다.

골드 거절은 하향 후보가 아니라 항상 열려 있는 별도 선택입니다.

덱 상태 레일이 후보를 찾기 어렵거나 덱 과밀 신호가 강하면 카드 슬롯은 안전 후보로 유지하고, 골드 거절 버튼에 `덱을 가볍게 유지` 이유를 붙입니다.

#### 보상 반복 피로도 방지

카드 풀은 작게 시작해야 하지만, 같은 카드가 너무 자주 보이면 플레이어는 선택지가 좁다고 느낍니다.

반복 피로도 방지는 카드의 등장 확률을 보상처럼 올리는 장치가 아니라, 최근 노출된 카드와 같은 계열을 잠시 뒤로 미루는 제작 규칙입니다.

| 반복 단위 | 피로 신호 | 우선 조정 |
| --- | --- | --- |
| 정확히 같은 카드 | 최근 5개 보상 팩 안에 2회 이상 노출 | 같은 레일의 다른 카드, 안전 직업 카드, 약한 공용 보완 순서로 대체 |
| 같은 카드 계열 | 기준 카드와 변형 카드가 같은 화면에 함께 등장 | 같은 계열 중 1장만 남김 |
| 같은 풀 라인 | 3팩 연속 같은 `poolLaneId`가 핵심 후보 | 다른 레일의 연결 카드로 우회 |
| 같은 대응 태그 | 매번 같은 문제의 직접 답만 노출 | 직접 대응은 유지하되 빌드 연결과 덱 상태 레일을 바꿈 |
| 반복 거절 카드 | 같은 카드가 2번 이상 골드 거절됨 | 5팩 동안 우선순위를 낮춤 |

첫 10일에는 학습 회수를 위해 같은 개념을 다시 보여줄 수 있습니다.

이때도 같은 카드 복사본을 반복하기보다, 같은 역할을 다른 비용, 대상, 타이밍으로 여는 카드를 우선합니다.

변형 카드는 기준 카드와 같은 계열로 취급합니다.

MVP 보상 화면에서는 기준 카드와 그 변형 카드를 같은 3장 안에 동시에 넣지 않습니다.

이 카드들은 31일 이후 확장, 상점 실험, 이벤트 계약, 아티팩트 해금으로 분리해 검증합니다.

#### 보상 후보 구성 규칙

1. 보상 후보는 항상 3장입니다.
2. 직업 전용 후보는 최소 1장 포함합니다.
3. 공용 보완 후보는 최대 1장만 포함합니다.
4. 같은 카드 풀 라인 후보는 기본적으로 한 화면 1장을 넘지 않습니다.
5. 영웅 확정 카드는 해당 아키타입 지원 크레딧과 최근 전투 증거가 있을 때만 일반 라운드 후보로 밀 수 있습니다.
6. 저주 카드는 이벤트 계약이나 특수 상점처럼 명시 동의 UI가 있을 때만 들어옵니다.
7. 웨이브 겹치기, 클리어 시간, 처치 수는 후보 수, 희귀도, 골드 총량을 바꾸지 않습니다.
8. 특정 방위 전용 조건은 쓰지 않고, 현재 활성 전선과 선택 전선 기준으로 효과를 투영합니다.

### 아키타입별 카드 역할

전리품 카드는 아키타입 안에서 역할이 달라야 합니다.

| 역할 | 의미 | 좋은 예 | 피해야 할 예 |
| --- | --- | --- | --- |
| 시작 보강 | 시작 덱의 행동을 안정적으로 반복하게 함 | 도발 구조물 체력 보강, 낮은 비용 바리케이드 | 기존 카드의 순수 상위호환 |
| 방향 신호 | 이 런에서 갈 수 있는 운영 축을 보여줌 | 가시 수리 효율 감소, 잔해 둔화, 과부하 안정화 | 대가 없는 만능 강화 |
| 전환 카드 | 방금 겪은 문제를 다른 방식으로 풀게 함 | 도발 위치 이동, 능동 폭파, 되감는 돌풍 | 모든 상황에서 같은 효율 |
| 확정 카드 | 준비된 덱이 큰 결정을 하게 함 | 가시 왕좌, 연쇄 붕괴, 공명 증폭기 | 준비 없이도 항상 좋은 영웅 카드 |
| 위험 가속 | 저주나 계약으로 빠른 힘과 장기 대가를 교환 | 무거운 서약, 무리한 증축, 위험한 개조 | 동의 없이 들어오는 저주 |

1~10일에는 시작 보강과 방향 신호가 중심입니다.

11~20일에는 전환 카드가 등장해 첫 보스 이후 선택한 방향의 빈틈을 보여줍니다.

21~30일에는 영웅 확정 카드가 낮은 비율로 열리지만, 준비되지 않은 덱에서는 거절할 수 있어야 합니다.

31일 이후에는 같은 아키타입 안의 변형과 약점 보완을 늘립니다.

71일 이후에는 새 아키타입을 시작하게 만드는 카드를 기본 보상으로 밀지 않습니다.

### 아키타입 보상 후보 원칙

카드 3장 보상은 "어느 아키타입을 따라갈지"를 묻되, 답을 강요하면 안 됩니다.

권장 후보 구조:

- 현재 덱에서 가장 많이 집은 아키타입을 안정화하는 카드 1장
- 방금 웨이브에서 드러난 약점을 보완하는 같은 직업 카드 1장
- 덱 상태를 읽게 하는 공용 보완 또는 안전 직업 카드 1장

아직 특정 아키타입 카드가 2장 미만이면 영웅 확정 카드를 보상 후보로 밀지 않습니다.

같은 보상 화면에 같은 아키타입 카드만 3장 보여주면, 선택이 아니라 강제가 됩니다.

상점은 아키타입 확정을 더 명확히 보여줄 수 있지만, 가격과 제거 기회 때문에 선택의 대가가 있어야 합니다.

보스 개인 카드 보상은 보스에서 잘 쓴 역할을 다음 구간 아키타입 후보로 연결합니다.

예를 들어 10일 보스에서 수호자가 도발 구조물을 오래 살렸다면 `철벽 앵커`와 `가시 성채` 후보가 조금 더 자연스럽게 보일 수 있습니다. 이때도 보스 클리어 성과로 희귀도나 후보 수가 늘어나지는 않습니다.

### 보상 후보 구성

카드 3장 보상은 작은 문제 풀이 화면이어야 합니다.

권장 구성:

- 방금 겪은 문제를 직접 푸는 직업 카드 1장
- 같은 문제를 우회하거나 다음 웨이브를 준비하는 직업 카드 1장
- 덱 상태를 읽게 하는 공용 카드 또는 안전 직업 카드 1장

골드 거절은 위 3장과 별도로 항상 표시하고, 덱 과밀이나 비용 꼬임이 강할 때만 이유 문구를 더 선명하게 보여줍니다.

피해야 할 구성:

- 같은 카드 풀 라인 3장
- 같은 대응 태그 3장
- 공용 카드가 직업 전용 카드보다 안정적이고 강한 화면
- 특정 방위에만 작동해서 솔로 또는 2인에서 죽은 카드가 되는 효과

## 카드 스펙 계약

카드 스펙 계약은 카드 한 장을 데이터로 만들 때 반드시 채워야 하는 최소 제작 단위입니다.

카드 설명이 "작은 범위에 피해"처럼 자연어로만 남아 있으면, 전리품 카드와 강화가 늘어날수록 기준선이 흔들립니다.

따라서 MVP부터 모든 카드는 아래 항목을 같은 순서로 작성합니다.

| 항목 | 의미 | 누락 시 생기는 문제 |
| --- | --- | --- |
| 비용 | 전투 마나 소모량 | 낮은 비용 카드가 과한 해결력을 갖습니다. |
| 대상 타입 | 타일, 구조물, 적, 구역, 자기 자신, 없음 | 조준 실패와 무효 사용 피드백이 흐려집니다. |
| 시전 거리 | 플레이어 또는 선택 기준점에서 허용되는 거리 | 전장 전체 카드가 너무 편해집니다. |
| 효과 범위 | 단일, 원형, 선형, 경로 구간, 오라, 전장 전체 | 광역과 단일 카드의 가치가 섞입니다. |
| 발동 지연 | 즉발인지, 예고 뒤 발동인지 | 큰 효과가 대응 불가능한 버튼이 됩니다. |
| 지속 시간 | 순간, 초 단위, 웨이브 단위 | 긴 지속 효과가 상시 패시브처럼 됩니다. |
| 반복 제한 | 시전당, 웨이브당, 대상당 발동 횟수 | 자원, 수리, CC 무한 루프가 생깁니다. |
| 보스 정책 | 보스 본체/부위/동반 웨이브 적용 방식 | 보스 패턴이 카드 하나로 삭제됩니다. |
| 실패 손해 | 빗나감, 낭비, 대가, 후속 약화 | 실패 없는 카드가 자동 선택이 됩니다. |
| UI 미리보기 | 조준선, 범위, 경로 변화, 예고 아이콘 | 플레이어가 왜 썼고 왜 실패했는지 모릅니다. |

### 비용 예산

비용은 위력 수치가 아니라 사용 타이밍의 부담입니다.

낮은 비용 카드는 자주 판단하게 만들고, 높은 비용 카드는 그날 전투의 큰 결정을 만들게 해야 합니다.

| 비용 | 기본 역할 | 허용 예 | 금지선 |
| ---: | --- | --- | --- |
| 0 | 연결, 조건부, 위험 가속 | 손패 1장 정리, 표식, 피해를 막았을 때만 자원 회수 | 조건 없는 순수 드로우, 마나 순증가, 광역 피해, 대량 수리 |
| 1 | 기본 행동 | 단일 설치, 작은 광역, 단일 수리, 짧은 버프 | 전장 전체 해결, 보스 부위 큰 피해, 구조물 완전 보호 |
| 2 | 전술 전환 | 넓지 않은 연쇄 피해, 다음 설치 준비, 구조물 위치 보정 | 전장을 혼자 정리하는 광역, 조건 없는 대량 수리 |
| 3 | 위기 해결 | 큰 예고 광역, 잠깐 버티기, 보스 부위 집중 | 반복 가능한 완전 무력화, 보스 장기 정지 |
| 4+ | 결전 선택 | 준비된 빌드의 큰 보상, 보스전 결단 | 사용하면 사실상 승리하는 효과 |

0비용 카드는 "공짜 카드"가 아니라 마나 대신 다른 대가를 쓰는 카드입니다.

0비용 카드가 드로우를 포함한다면 반드시 같은 카드 수를 버리거나, 조건 실패 시 아무 이득이 없어야 합니다.

0비용 카드가 마나를 포함한다면 즉시 순증가가 아니라 피해 방어, 구조물 파괴, 카드 버리기 같은 사건을 회수해야 합니다.

### 범위와 대상 기준

카드의 대상 자유도는 보이지 않는 비용입니다.

같은 효과라도 전장 전체에서 아무 구조물이나 고를 수 있으면, 가까운 구조물만 고르는 카드보다 훨씬 강합니다.

| 범위 구분 | MVP 기준 | 밸런스 처리 |
| --- | --- | --- |
| 자기 자신 | 거리 없음 | 수치는 높아도 되지만 파티 대체력은 낮아야 합니다. |
| 단일 구조물/적 | 기본 6~7타일 | 가장 표준적인 조준 카드입니다. |
| 작은 원형 | 반경 1.5타일 | 비용 1 광역의 기본 상한입니다. |
| 중간 원형 | 반경 2.5타일 | 비용 2 이상, 또는 낮은 피해/짧은 지속이 필요합니다. |
| 큰 원형 | 반경 3.5타일 이상 | 비용 3 이상, 예고 또는 강한 대가가 필요합니다. |
| 선형/부채꼴 | 길이 4~6타일 | 방향 예측 실패가 손해가 되어야 합니다. |
| 경로 구간 | 경로상 4~6타일 | 완전 길막과 스폰 고립 검사를 통과해야 합니다. |
| 오라 | 반경 2~3타일 | 중첩 제한과 배치 위험이 필요합니다. |
| 전장 전체/원격 | 활성 전선 전체 | 편의성이 큰 효과로 계산하고, 수치/횟수/대상 조건을 낮춥니다. |

특정 동서남북 방향만 요구하는 카드는 만들지 않습니다.

방향 관련 효과가 필요하면 "현재 압박 전선", "선택한 활성 전선", "가장 가까운 활성 전선"을 기준으로 잡습니다.

### 지속 시간과 발동 지연

지속 시간은 플레이어가 전투 중 다시 판단할 수 있는 간격을 남겨야 합니다.

| 구분 | 기준 | 좋은 사용처 | 주의점 |
| --- | ---: | --- | --- |
| 즉발 | 0초 | 작은 피해, 작은 수리, 손패 정리 | 큰 효과와 결합하면 대응 불가능합니다. |
| 짧은 예고 | 0.35~0.8초 | 화염구, 넉백, 작은 폭발 | 빗나갈 수 있어야 의미가 있습니다. |
| 큰 예고 | 1.0~1.8초 | 대폭발, 낙뢰, 큰 경로 교란 | 예고 UI와 사운드가 필수입니다. |
| 짧은 지속 | 3~5초 | 위기 수리 창, 짧은 둔화, 피해 감소 | 너무 짧으면 체감 전에 끝납니다. |
| 전술 지속 | 6~10초 | 과부하, 가시 강화, 단일 버프 | 중첩 제한이 필요합니다. |
| 긴 지속 | 12~18초 | 설치형 장판, 낮은 위력 오라 | 강한 피해나 hard CC와 같이 쓰지 않습니다. |
| 웨이브 지속 | 웨이브 종료까지 | 약한 보험, 조건부 회수, 빌드 신호 | 직접 피해, 대량 수리, 강한 CC에는 쓰지 않습니다. |

### 위험 태그

아래 태그가 붙은 카드는 제작 리뷰에서 반드시 한 번 더 봅니다.

| 태그 | 붙는 조건 | 필수 제한 |
| --- | --- | --- |
| `free_action` | 비용 0 | 선행 조건, 대가, 또는 순이득 없음 |
| `global_target` | 전장 전체 또는 거리 무시 | 낮은 수치, 대상 조건, 반복 제한 |
| `area_large` | 반경 3.5타일 이상 또는 다중 지점 | 높은 비용, 예고, 낮은 피해 중 하나 이상 |
| `hard_cc` | 빙결, 큰 넉백, 행동 중단 | 반복 저항, 보스 약화 변환 |
| `resource_positive` | 마나, 드로우, 골드 생성 | 웨이브당 상한, 사건 기반 조건 |
| `structure_save` | 파괴 방지, 자동 복구, 대량 수리 | 같은 자리 반복 제한, 낮은 체력 복구 |
| `boss_direct` | 보스 본체나 부위에 직접 강함 | 부위 중심, 본체 패턴 삭제 금지 |
| `repeat_trigger` | 처치, 피격, 파괴 때마다 발동 | 시전당 또는 웨이브당 발동 상한 |
| `path_cost_change` | 경로 비용을 바꿈 | 완전 길막 검사와 경로 미리보기 |

### MVP 카드 수치 예산 잠금

MVP 카드 수치는 "강한 카드와 약한 카드"가 아니라, 어떤 전투 질문을 얼마나 자주 열 수 있는지로 봅니다.

따라서 모든 카드 스펙은 아래 예산 등급 중 하나를 가져야 합니다.

| 예산 ID | 기본 모양 | 허용 상한 | 반드시 필요한 대가 |
| --- | --- | --- | --- |
| `stat_budget_connector_0` | 비용 0 연결 카드 | 피해/회복 없음, 순수 드로우/마나 순증가 없음 | 카드 버림, 조건 실패, 다음 드로우 손실, 구조물 피해 중 하나 |
| `stat_budget_risky_boost_0` | 비용 0 위험 가속 | 즉시 버프나 임시 설치 가능 | 구조물 피해, 수리 효율 감소, 다음 드로우 손실, 회수 가치 제외 중 하나 |
| `stat_budget_basic_1` | 비용 1 기본 행동 | 단일 대상 또는 반경 1.5타일, 3~6초 효과 | 실패 가능한 대상 조건 또는 낮은 보스 배율 |
| `stat_budget_flexible_1` | 비용 1 편의 카드 | 전장 전체/원격 대상 가능 | 낮은 수치, 반복 효율 감소, 대상 조건 |
| `stat_budget_tactical_2` | 비용 2 전술 전환 | 반경 2.5타일, 6~10초, 경로 4~6타일 중 하나 | 예고, 중첩 제한, 보스 약화 변환 |
| `stat_budget_crisis_3` | 비용 3 위기 대응 | 큰 광역, 강한 방어, 보스 부위 집중 중 하나 | 1초 이상 예고, 후유증, 웨이브당 제한 |
| `stat_budget_commit_4` | 비용 4 이상 결전 카드 | 빌드 축을 바꾸는 큰 효과 | 선행 아키타입, 큰 실패 손해, 보스 본체 약화 |
| `stat_budget_curse` | 저주 계약 카드 | 비용 대비 즉시 이득이 큼 | 장기 대가, 명시 확인, 제거/안정화 경쟁 |

예산 배정은 `effectBudgetId`와 `statBudgetLockId`를 함께 봅니다.

`effectBudgetId`는 카드의 실제 모양이고, `statBudgetLockId`는 그 모양을 어떤 안전장치로 검수할지 정하는 값입니다.

| `effectBudgetId` | 기본 `statBudgetLockId` | 대표 카드 | 추가 검수 |
| --- | --- | --- | --- |
| `budget_cost0_connector` | `stat_budget_connector_0` | 응전 태세, 원소 표식, 재정비, 빠른 손놀림 | 순수 드로우/마나 순증가 금지 |
| `budget_cost0_risky_boost` | `stat_budget_risky_boost_0` | 과부하, 긴급 배선, 위험한 개조 | 구조물 피해, 다음 드로우 손실, 회수 가치 제외 중 1개 이상 |
| `budget_cost1_single_basic` | `stat_budget_basic_1` | 도발벽, 방패 두르기, 바리케이드, 밀어내기 | 단일 대상 조건과 실패 피드백 |
| `budget_cost1_small_area_instant` | `stat_budget_basic_1` | 화염구, 빙결 지대, 원소 균열 | 작은 반경, 낮은 보스 배율, 반복 저항 |
| `budget_cost1_global_support` | `stat_budget_flexible_1` | 원격 수리, 수리 대기열 | 낮은 수치, 반복 효율 감소, 대상 조건 |
| `budget_cost1_aura_device` | `stat_budget_flexible_1` | 증폭기, 좁은 증폭장 | 오라 중첩 상한, 장치 위치 위험 |
| `budget_cost1_risky_focus` | `stat_budget_curse` | 금지된 등불 | 명시 계약/저주 확인, 일반 처치 자원 대가 |
| `budget_cost2_tactical_shift` | `stat_budget_tactical_2` | 붙잡는 맹세, 번개 연결, 예열 장치 | 예고, 중첩 제한, 보스 약화 변환 |
| `budget_cost3_crisis_answer` | `stat_budget_crisis_3` | 최후의 문, 대폭발, 정지의 눈 | 1초 이상 예고, 후유증, 웨이브 제한 |
| `budget_cost3_engine_commitment` | `stat_budget_crisis_3` | 공명 증폭기 | 위치 위험, 네트워크 상한, 밀집 붕괴 위험 |
| `budget_cost4_commitment` | `stat_budget_commit_4` | 불굴의 성문, 낙뢰 의식, 재조립 기계 | 선행 아키타입과 큰 실패 손해 |

축 초과 규칙:

- 비용 0 카드가 자원을 늘리면, 같은 행동 안에서 손패나 다음 드로우를 반드시 잃어야 합니다.
- 반경 2.5타일 이상 광역은 비용 2 이상이거나, 피해/지속/보스 배율 중 하나를 낮춥니다.
- 반경 3.5타일 이상 또는 다중 지점 광역은 비용 3 이상, 1초 이상 예고, 자동 추적 금지 중 두 가지 이상을 가져야 합니다.
- 전장 전체 또는 원격 대상 카드는 낮은 수치만으로 부족하며, 반복 효율 감소나 대상 조건을 함께 가져야 합니다.
- 웨이브 지속 효과는 직접 피해, 대량 수리, hard CC와 결합하지 않습니다.
- 보스 본체에 강하게 적용되는 카드는 패턴 취소가 아니라 부위 집중, 약한 감속, 예고 연장으로 변환합니다.

직업별 수치 상한:

| 직업 | 강하게 줄 수 있는 축 | 낮게 잡아야 하는 축 |
| --- | --- | --- |
| 수호자 | 도발 시간, 구조물 생존창, 조건부 가시 | 광역 정리, 장기 수리, 경로 설계 |
| 건축가 | 경로 시간, 잔해, 계획된 붕괴 | 즉발 광역 피해, 무한 회수, 보스 경로 차단 |
| 원소술사 | 군집 피해, 짧은 제어, 표식 | 구조물 유지, 완전 길막, 보스 본체 정지 |
| 땜장이 | 원격 편의, 오라 타이밍, 구조물 수명 연장 | 대량 광역, 경로 설계, 파괴 패턴 삭제 |
| 공용 카드 | 약한 보완, 실패 후 재정비 | 직업 전용 강점 대체 |

카드가 약해 보일 때도 예산 등급을 올리기 전에 아래 순서로 조정합니다.

1. 대상 조건과 미리보기가 충분한지 확인합니다.
2. 강한 타이밍이 실제 웨이브에서 자주 오는지 확인합니다.
3. 반복 제한과 보스 변환이 과하게 막고 있지 않은지 확인합니다.
4. 예고 시간, 지속 시간, 범위를 한 단계만 조정합니다.
5. 마지막에 피해량, 회복량, 자원량을 바꿉니다.

1. 도발 대상이 제대로 바뀌는지 확인합니다.
2. 구조물이 몇 초를 벌었는지 확인합니다.
3. 수리와 후방 재건이 필요한지 확인합니다.
4. 가시 피해가 광역 딜러를 대체하지 않는지 확인합니다.
5. 보스 본체 패턴이 도발이나 기절로 삭제되지 않는지 확인합니다.

공용 카드 스펙 조정은 아래 순서를 따릅니다.

1. 빠진 역할을 완전히 대신하지 않고 시간을 조금 버는지 확인합니다.
2. 0비용 카드가 손패, 마나, 드로우를 순증가시키지 않는지 확인합니다.
3. 집중 사격, 긴급 보수, 전장 수습이 각 직업 전용 카드보다 안정적이지 않은지 확인합니다.
4. 전술 지도가 정보 카드로만 작동하고 정답 배치를 말하지 않는지 확인합니다.
5. 임시 포탑이 직업 전용 공격 구조물이나 미로 설계를 대체하지 않는지 확인합니다.

공용 카드가 약해 보일 때도 먼저 후보 노출 위치, 실패 피드백, 대상 조건, 손패 막힘 상황을 봅니다.

수치부터 올리면 공용 카드가 파티 조합의 약점을 지우고, 직업 선택이 흐려집니다.

### 스펙 조정 순서

카드가 너무 강하거나 약할 때는 아래 순서로 고칩니다.

1. 강한 타이밍이 제대로 드러나는지 확인합니다.
2. 대상 조건과 UI 미리보기가 충분히 명확한지 확인합니다.
3. 반복 제한, 중첩 제한, 보스 정책을 조정합니다.
4. 범위, 지속 시간, 예고 시간을 조정합니다.
5. 마지막에 피해량, 회복량, 마나 획득량을 조정합니다.

피해량부터 올리면 카드가 직업 질문을 잃고 단순 효율 버튼이 됩니다.

회복량부터 올리면 구조물 파괴, 후방 재건, 희생 판단이 사라질 수 있습니다.

- 집중 사격은 원소 표식보다 안정적인 광역 피해 증폭이 아니며, 같은 대상 증폭은 높은 값만 적용합니다.
- 긴급 보수는 원격 수리와 자동 복구보다 낮은 수치, 짧은 사거리, 반복 효율 감소를 가집니다.
- 전장 수습은 잔해 생성, 폭발 피해, 회수 가치, 완전 길막을 제공하지 않습니다.
- 전술 지도는 활성 방향 정보만 더 명확히 보여주고, 정답 배치 추천이나 비활성 방향 정보 공개를 하지 않습니다.
- 임시 포탑은 도발, 오라, 잔해, 회수 가치, 직업 전용 타워 성능을 가지지 않습니다.
- 웨이브 겹치기, 처치 수, 클리어 시간, 보스 부위 파괴 수는 공용 카드 후보 수, 희귀도, 골드 총량을 바꾸지 않습니다.
- 솔로에서는 동쪽 전선의 손패 막힘, 누수, 붕괴 자리, 다음 압박 예고로만 공용 카드 판단이 투영됩니다.

### 카드 실패 피드백 체계

카드 실패 피드백은 플레이어를 혼내는 문구가 아니라, 다음 사용에서 무엇을 읽어야 하는지 알려주는 짧은 회수 문장입니다.

카드가 약하게 들어갔을 때 수치부터 올리기 전에 먼저 아래 피드백이 충분히 보이는지 확인합니다.

| 피드백 종류 | 발생 상황 | 자원/카드 처리 | 표시 위치 | 문구 톤 |
| --- | --- | --- | --- | --- |
| `hard_block` | 규칙상 사용할 수 없음 | 마나와 카드 모두 소모하지 않음 | 손패 위 작은 말풍선 | 단호한 이유 |
| `soft_miss` | 사용은 됐지만 좋은 조건이 아님 | 카드와 마나를 소모함 | 대상/구역 위 짧은 노란 태그 | 다음에 볼 조건 |
| `tradeoff_preview` | 쓰기 전에 대가를 알아야 함 | 확정 전 소모 없음 | 카드 위 확인 칩 | 잃는 것 먼저 |
| `tradeoff_resolved` | 대가가 실제로 적용됨 | 카드 효과와 함께 적용 | 구조물/손패/게이지 옆 아이콘 | 남은 후유증 |
| `resistance_conversion` | 보스/저항형에게 약화 적용 | 카드와 마나를 소모함 | 대상 체력바 옆 작은 아이콘 | 감소 이유 |
| `loop_guard_blocked` | 버리기/회수/임시 구조물 루프 차단 | 추가 보상만 발동하지 않음 | 관련 게이지 옆 툴팁 | 보상 미발동 이유 |

MVP 필수 카드 실패 문구:

| 키 | 기본 문구 | 사용처 | 연결 태그 |
| --- | --- | --- | --- |
| `ui.card.fail.not_enough_mana` | 마나가 부족합니다. | 사용 불가 | `hard_block` |
| `ui.card.fail.no_target` | 사용할 대상이 없습니다. | 사용 불가 | `hard_block` |
| `ui.card.fail.out_of_range` | 사거리가 닿지 않습니다. | 사용 불가 | `hard_block` |
| `ui.card.fail.path_blocked` | 기지로 향하는 경로가 필요합니다. | 설치 불가 | `hard_block`, `path_cost_change` |
| `ui.card.fail.need_collapse_record` | 최근 파괴 기록이 필요합니다. | 회수/수습 카드 | `collapse_record_required` |
| `ui.card.fail.scattered_targets` | 적이 흩어져 효과가 낮습니다. | 광역 카드 약화 | `soft_miss`, `low_single_target` |
| `ui.card.fail.no_followup_focus` | 후속 화력이 없으면 효과가 낮습니다. | 표식/집중 카드 | `requires_followup` |
| `ui.card.fail.control_resisted` | 반복 제어로 효과가 줄었습니다. | 둔화/빙결/넉백 | `repeat_penalty` |
| `ui.card.fail.boss_weakened` | 보스에게 약화된 효과로 적용됩니다. | 보스 대상 상태이상 | `boss_weakened_conversion` |
| `ui.card.fail.discard_no_reward` | 이 버리기는 보상을 발동하지 않습니다. | 재정비/마나 전환/빠른 손놀림 | `discard_no_reward` |
| `ui.card.fail.temporary_no_salvage` | 임시 구조물은 회수 가치가 없습니다. | 임시 구조물/임시 포탑 | `temporary_no_salvage` |
| `ui.card.fail.aura_stack_capped` | 오라 중첩 상한에 닿았습니다. | 오라 카드 | `aura_stack_cap` |
| `ui.card.fail.repair_repeated` | 반복 수리로 회복이 줄었습니다. | 수리 카드 | `repeat_penalty`, `low_repair` |
| `ui.card.fail.overdrive_debt` | 과부하 후유 피해가 남습니다. | 과부하/위험한 개조 | `structure_hp_loss`, `repair_debt` |
| `ui.card.fail.prebuild_only` | 전투 전 준비 때만 사용할 수 있습니다. | 전술 지도/일부 예고 카드 | `combat_locked` |

카드 실패 피드백 규칙:

- `hard_block`은 카드와 마나를 절대 소모하지 않습니다.
- `soft_miss`는 사용 자체는 성공한 것이므로 카드와 마나를 소모하되, 왜 낮은 효과였는지 짧게 보여줍니다.
- `tradeoff_preview`가 필요한 카드에는 확정 전 대가 칩을 보여주고, 대가를 숨긴 채 즉시 발동하지 않습니다.
- 같은 플레이어에게 동시에 보이는 카드 실패 문구는 1개, 전장 위 약화 태그는 2개까지만 표시합니다.
- 기지 도달, 보스 도달, 구조물 붕괴 직전 경고가 있으면 카드 실패 문구보다 생존 경고가 우선합니다.
- 피드백 문구에는 `실수`, `잘못`, `못함`처럼 플레이어를 탓하는 표현을 쓰지 않습니다.
- 피드백 문구는 보상, 희귀도, 후보 수, 골드, 비활성 방향 정보를 암시하지 않습니다.
- 솔로에서는 모든 카드 실패 이유가 동쪽 전선 안의 대상, 경로, 손패, 구조물 상태로만 설명됩니다.

### 수호자

핵심:

- 도발
- 가시
- 파괴 지연
- 전면 방어

좋은 수호자 카드:

- 적의 목표를 바꿉니다.
- 맞을수록 의미가 생깁니다.
- 구조물이 더 오래 버티되, 영원히 버티지는 않습니다.
- 원소술사나 건축가가 딜 타이밍을 잡게 해줍니다.

피해야 할 것:

- 모든 피해를 무효화
- 수리 없이도 무한 유지
- 높은 광역 피해
- 경로 설계를 혼자 해결

### 건축가

핵심:

- 바리케이드
- 경로 비용 조정
- 파괴 보상
- 잔해

좋은 건축가 카드:

- 적 경로를 바꿉니다.
- 파괴될 위치와 타이밍을 설계하게 합니다.
- 구조물이 부서진 뒤에도 의미를 남깁니다.
- 땜장이의 수리나 수호자의 도발과 맞물립니다.

피해야 할 것:

- 완전 길막
- 항상 같은 최적 미로
- 파괴 없이 영구 유지되는 방어선
- 너무 많은 임시 구조물로 경로가 읽히지 않게 만들기

### 원소술사

핵심:

- 광역 피해
- 둔화
- 빙결
- 넉백
- 취약

좋은 원소술사 카드:

- 적이 모였을 때 강합니다.
- 킬존을 더 오래 유지합니다.
- 보스 부위나 정예 처리에 타이밍을 요구합니다.
- 수호자와 건축가가 만든 전장 상태를 보상합니다.

피해야 할 것:

- 모든 웨이브를 단독 해결
- 상태이상 무한 유지
- 보스 완전 정지
- 저항형 적을 무시하는 만능 광역

### 상태이상 카드 설계

상태이상 카드는 적을 지우는 카드가 아니라, 위치와 시간을 사는 카드입니다.

좋은 상태이상 카드:

- 적용 위치가 중요합니다.
- 반복 사용하면 효율이 줄어듭니다.
- 보스에게도 약하게나마 의미가 있습니다.
- 다른 역할의 구조물, 도발, 수리, 킬존과 맞물립니다.
- 저항형 적에게 약해지더라도 완전히 무의미하지 않습니다.

피해야 할 상태이상 카드:

- 일반 웨이브를 무한 정지시킵니다.
- 보스 본체를 멈춰서 패턴을 삭제합니다.
- 저항 설명 없이 효과가 사라집니다.
- 넓은 범위, 긴 지속, 낮은 비용을 동시에 가집니다.
- 빙결과 넉백을 반복해 적을 경로 밖에 가둡니다.

상태이상 카드의 힘은 아래 중 하나만 크게 줍니다.

| 힘의 축 | 예시 | 대가 |
| --- | --- | --- |
| 넓은 범위 | 넓은 빙결 지대 | 짧은 지속 또는 높은 비용 |
| 긴 지속 | 오래 남는 둔화 장판 | 낮은 감속률 |
| 강한 순간 제어 | 큰 넉백 | 좁은 범위 또는 긴 쿨다운성 조건 |
| 보스 대응 | 부위 취약 또는 약한 감속 | 본체 정지 불가 |
| 연계 보상 | 빙결 대상 추가 피해 | 빙결 자체는 짧음 |

### 땜장이

핵심:

- 수리
- 오라
- 과부하
- 유지보수

좋은 땜장이 카드:

- 구조물 파괴 타이밍을 늦춥니다.
- 밀집 배치를 강화하지만 위험도 만듭니다.
- 과부하로 순간 화력을 만들고 대가를 남깁니다.
- 다른 직업의 구조물과 잘 맞물립니다.

피해야 할 것:

- 모든 구조물 완전 회복
- 오라 무한 중첩
- 파괴 긴장감 제거
- 파티 전체를 항상 안정화하는 만능 지원

## 공용 카드 설계

공용 카드는 직업 약점을 "약하게" 보완합니다.

공용 카드가 직업 전용 카드보다 강하면 안 됩니다.

공용 카드의 역할:

- 손패 정리
- 최소 수리
- 우선 처치 지원
- 경로 실수 약한 보정
- 정보 확인

공용 카드가 하면 안 되는 것:

- 수호자만큼 강한 도발
- 건축가만큼 강한 미로 설계
- 원소술사만큼 강한 광역 피해
- 땜장이만큼 강한 수리와 오라

### 공용 카드 안전 기준

공용 카드는 어떤 파티에서도 쓸 수 있으므로, 강도가 낮아도 선택률이 높아질 수 있습니다.

공용 카드가 강해지는 방식은 "만능 해결"보다 "작은 보정"이어야 합니다.

허용:

- 카드 1장 정리
- 소량 수리
- 짧은 집중 피해 증가
- 다음 웨이브 정보 확인
- 작은 위치 보정

금지:

- 도발 주력 카드
- 대형 바리케이드 설치
- 넓은 광역 피해
- 대량 수리
- 웨이브 겹치기 보상 증가

## 강화 설계

강화는 카드의 역할을 더 선명하게 만들고, 플레이어가 이미 선택한 아키타입을 더 의식적으로 다루게 만드는 장치입니다.

강화는 새 카드를 대신하는 시스템이 아닙니다.

카드가 완전히 다른 전장 문제를 풀어야 한다면 강화가 아니라 새 카드로 분리합니다.

### 강화 기본 규칙

MVP 강화 규칙:

- 카드 1장은 영구 강화 1회만 받을 수 있습니다.
- 강화된 카드는 덱 안에서 같은 카드의 다른 복사본과 구분됩니다.
- 시작 카드와 일반 카드는 안정 강화 또는 특화 강화 중 하나를 고릅니다.
- 희귀 카드는 안정 강화, 특화 강화, 전환 강화 중 카드별로 최대 2개 후보만 가집니다.
- 영웅 카드는 확정 조율만 허용하고, 게이트 없이 강해지는 강화는 금지합니다.
- 저주 카드는 안정화 강화만 허용하되, 대가를 완전히 제거하지 않습니다.

강화 후보가 3개 이상이면 상점 체류 시간이 늘어나고, 플레이어가 카드 효과보다 강화 트리를 외우게 됩니다.

따라서 한 카드의 강화 후보는 MVP에서 최대 2개로 제한합니다.

### 강화 유형

| 유형 | 목적 | 자주 바꾸는 값 | 실패하면 생기는 문제 |
| --- | --- | --- | --- |
| 안정 강화 | 카드의 실패 손해를 낮춥니다. | 대상 선택, 예고, 작은 체력/지속 보정 | 모든 카드가 무난한 정답이 됩니다. |
| 특화 강화 | 강한 타이밍을 더 날카롭게 만듭니다. | 범위, 피해, 지연, 조건부 발동 | 조건 없이 순수 수치 상승이 됩니다. |
| 전환 강화 | 보조 아키타입 하나를 약하게 지원합니다. | `archetypeIds`, `comboHookTags`, 작은 부가 효과 | 직업 약점이나 아키타입 약점을 지웁니다. |
| 안정화 강화 | 위험 카드의 대가를 다룰 수 있게 합니다. | 페널티 크기, 페널티 시점, 회수 조건 | 저주나 과부하가 공짜 이득이 됩니다. |
| 확정 조율 | 이미 준비된 영웅 카드의 마무리 선택을 만듭니다. | 게이트 조건 설명, 실패 손해, 발동 창 | 준비 없이도 무조건 집는 카드가 됩니다. |

### 강화 후보 설계 질문

강화 후보를 만들 때는 아래 질문을 먼저 채웁니다.

| 질문 | 이유 |
| --- | --- |
| 이 강화는 카드의 강한 타이밍을 바꾸는가, 실패 손해를 줄이는가? | 둘 다 하면 자동 선택이 되기 쉽습니다. |
| 이 강화는 어떤 `archetypeIds`를 더 선명하게 만드는가? | 강화가 빌드 방향과 연결되어야 합니다. |
| 이 강화로 새로 생기는 대가나 조건은 무엇인가? | 특화 강화에는 대부분 새 조건이 필요합니다. |
| 강화 전 카드가 여전히 선택될 이유가 있는가? | 강화가 필수 세금처럼 보이면 안 됩니다. |
| 같은 카드의 다른 강화 후보를 고를 이유가 있는가? | 두 후보가 수치 차이뿐이면 실패입니다. |

### 강화 후보 예시

| 카드 | 안정 강화 | 특화 강화 또는 전환 강화 |
| --- | --- | --- |
| 도발벽 | 체력과 설치 피드백을 조금 보강합니다. | 도발 범위가 늘지만 더 많은 적에게 맞아 수리 부담이 커집니다. |
| 방패 두르기 | 피해 감소 지속이 조금 늘어납니다. | 구조물이 치명 상태일 때만 더 강하게 막습니다. |
| 잔해 폭발 | 폭발 예고와 범위 표시가 더 읽기 쉬워집니다. | 오래 버틴 구조물이 터질수록 폭발이 강해집니다. |
| 급조 통로 | 임시 구조물 지속 시간이 조금 늘어납니다. | 사라질 때 작은 잔해를 남기지만 경로 가독성이 낮아집니다. |
| 화염구 | 조준 범위가 조금 넓어집니다. | 도발 또는 둔화된 적에게 더 강하지만 흩어진 적에게는 그대로입니다. |
| 빙결 지대 | 첫 적용 시간이 안정됩니다. | 더 오래 얼리지만 이후 둔화 저항을 더 줍니다. |
| 원격 수리 | 치명 상태 구조물 선택이 쉬워집니다. | 오라 안 구조물을 더 수리하지만 오라 밖 수리량은 줄어듭니다. |
| 과부하 | 종료 피해 예고가 명확해집니다. | 우선 대상 처치 시 종료 피해가 줄지만 처치 실패 시 피해가 커집니다. |

### 전리품 변형 카드

전리품 변형 카드는 기존 카드의 이름 옆에 `+1`을 붙인 강화 카드가 아닙니다.

기준 카드의 핵심 질문을 빌리되, 사용 타이밍이나 대가를 바꾼 별도 `CardData`입니다.

예를 들어 `화염구`의 변형 카드는 "더 강한 화염구"가 아니라, "즉발 피해를 낮추고 예고를 붙여 킬존 체류를 더 요구하는 다른 광역 카드"여야 합니다.

| 변형 종류 | 주로 바꾸는 축 | 남겨야 할 약점 | 좋은 사용처 |
| --- | --- | --- | --- |
| 안정 변형 | 조준, 예고, 대상 판독성 | 피해, 회복량, 지속 시간은 그대로이거나 낮음 | 기본 카드가 손에 잡혀도 사용 장면을 자주 놓치는 덱 |
| 타이밍 변형 | 강한 시점과 예고 시간 | 즉발성이 낮아지고 빗나갈 수 있음 | 킬존, 도발, 붕괴, 오라처럼 준비된 전장 |
| 대가 전환 변형 | 드로우 손실, 구조물 피해, 위치 부담의 형태 | 대가는 사라지지 않음 | 저주 또는 위험 가속을 감당할 수 있는 덱 |
| 아키타입 연결 변형 | 보조 아키타입 태그 1개 | 주 직업 약점은 유지 | 이미 한 방향으로 치우친 덱의 좁은 연결 |
| 보스 대응 변형 | 부위, 정예, 우선 대상 판독 | 보스 본체 패턴 취소 금지 | 20일 이후 준비된 빌드 |

전리품 변형 제작 규칙:

- 변형 카드는 반드시 별도 카드 ID와 별도 `CardSpecProfile`을 가집니다.
- 변형 카드는 기준 카드의 강화 후보를 자동 상속하지 않습니다.
- MVP 변형 카드는 기본적으로 `upgradeOptions: []`로 시작합니다.
- 변형 카드 이름은 기준 카드와 구분되는 이름을 사용하고, `강화`, `상급`, `+` 같은 등급 표현을 쓰지 않습니다.
- 변형 카드가 피해, 범위, 지속, 회복량, 대상 편의 중 하나를 올리면 다른 축의 대가를 명확히 붙입니다.
- 아티팩트는 변형 카드 풀을 열 수 있지만 후보 수, 희귀도, 골드, 보스 파편을 늘릴 수 없습니다.
- 변형 카드는 현재 활성 전선 안에서만 의미를 가져야 하며, 솔로에서는 동쪽 전선 안의 앞/중간/후방 판단으로 투영됩니다.

#### 전리품 변형 보상 UX 규칙

변형 카드가 보상 후보로 등장할 때의 목표는 "좋은 카드가 더 좋아졌다"가 아니라 "익숙한 질문이 다른 비용과 타이밍으로 돌아왔다"를 읽히게 하는 것입니다.

카드 표면에는 아래 정보를 고정 순서로 둡니다.

1. `변형 카드` 배지
2. `기준 카드: {cardName}`
3. 바뀐 축 1개
4. 남는 약점 1~2개
5. 등장 이유 태그 1개

이때 희귀도는 일반 카드와 같은 위치에 두고, 변형 배지는 희귀도나 파워 상승처럼 보이지 않는 얇은 보조 배지로 처리합니다.

상세 패널의 버튼 이름은 `차이 보기`이며, `강화 비교`, `상위 효과`, `+1` 같은 표현을 쓰지 않습니다.

선택 연출은 새 카드가 덱 목록 끝에 들어가는 방식으로 처리하고, 기준 카드 위에 덮어씌우거나 교체되는 연출을 쓰지 않습니다.

위험한 대가가 큰 `tradeoff_swap` 변형은 제한 시간 종료 시 자동 임시 선택 대상에서 제외합니다.

### MVP 대표 강화 옵션

MVP에서는 모든 카드의 강화 후보를 한 번에 완성하지 않고, 시작 카드와 각 직업의 위험 축을 먼저 검증합니다.

먼저 직업별 대표 강화 24종과 공용 안정 강화 4종을 제작해, 강화가 실제 선택으로 읽히는지 확인합니다.

대표 강화 옵션의 목적은 "강한 카드 만들기"가 아니라, 강화가 실제로 덱 방향을 읽게 만드는지 확인하는 것입니다.

### 아키타입과 강화

강화는 아키타입 확정을 돕되, 아키타입을 강제하면 안 됩니다.

강화 후보는 아래 세 가지 중 하나로 분류합니다.

| 분류 | 설명 | 예 |
| --- | --- | --- |
| 아키타입 안정 | 이미 많이 집은 방향의 실패 손해를 줄입니다. | 가시 성채 덱의 수리 효율 손해 완화 |
| 아키타입 특화 | 특정 타이밍에서 더 큰 보상을 줍니다. | 계획 철거 덱의 오래 버틴 바리케이드 폭발 강화 |
| 아키타입 전환 | 보조 라인 하나와 연결합니다. | 철벽 앵커 카드가 성문 교대 후보로도 약하게 연결 |

`commitmentLevel: commit` 카드는 강화로 더 쉽게 확정되면 안 됩니다.

확정 카드 강화는 지원 크레딧, 실제 지원 카드 수, 현재 덱 크기, 남은 약점 태그를 UI에 함께 보여줘야 합니다.

### 강화와 저주

저주 안정화는 저주를 지우는 기능이 아닙니다.

예를 들어 다음 드로우 1장 감소를 없애는 대신 "다음 드로우 중 가장 높은 비용 카드가 늦게 들어온다"처럼 대가의 형태를 바꿀 수는 있습니다.

구현상 `CardUpgradeOption.upgradeType: curse_stabilize`를 쓰더라도, 화면에서는 일반 강화처럼 보여주지 않습니다.

상승 화살표, 강화 완료, 상급 카드 같은 표현 대신 `대가를 예측 가능하게 바꿈`, `남는 대가`, `제거와 비교`를 먼저 표시합니다.

좋은 저주 안정화:

- 대가가 더 예측 가능해집니다.
- 활용 아키타입이 선명해집니다.
- 제거와 안정화 사이에 고민이 생깁니다.

나쁜 저주 안정화:

- 대가가 사라집니다.
- 비용 대비 항상 이득입니다.
- 일반 카드보다 안전한 고효율 카드가 됩니다.

### 강화 비용과 빈도

카드 강화는 덱 압축과 경쟁해야 합니다.

강화가 너무 싸면 플레이어는 새 카드 선택보다 기존 카드 강화만 고르게 됩니다.

기준:

- 일반 카드 강화는 중간 가격입니다.
- 희귀 카드 강화는 일반보다 비쌉니다.
- 영웅 카드 강화는 상점이나 이벤트에서 제한적으로만 제공합니다.
- 저주 카드 안정화는 대가를 없애지 않으므로, 제거보다 낮거나 비슷한 가격에서 경쟁하게 합니다.

권장 기본 가격:

| 강화 대상 | 기본 가격 | 비고 |
| --- | ---: | --- |
| 첫 안정 강화 학습 | 25골드 | 5일 첫 상점에서 런당 1회 |
| 안정 강화 | 30골드 | 판독성과 실패 손해 보정 |
| 특화 강화 | 40골드 | 새 조건이나 대가가 필요 |
| 전환/희귀 카드 강화 | 45골드 | 보조 아키타입 연결 |
| 영웅 카드 확정 조율 | 55골드 + 보스 파편 1개 | 20일/30일 허용 세션에서 `MvpHeroicCommitGate` 통과 |
| 저주 카드 안정화 | 40골드 | 대가 제거가 아니라 형태 변경 |

같은 플레이어가 이미 강화한 카드가 많거나, 같은 상점에서 두 번째 파티 골드 강화를 사거나, 같은 진단 태그를 강화로만 반복 해결하면 다음 강화 비용은 조금씩 오릅니다.

반복 증가 가격은 한 제안당 최대 +25까지만 적용하고, 파티 전체가 특정 한 명의 덱만 강화하는 정답을 막습니다.

강화 빈도 목표:

| 런 구간 | 기대 강화 수 |
| --- | ---: |
| 10일 테스트 | 0~1회 |
| 30일 MVP | 2~4회 |
| 100일 풀런 | 8~14회 |

강화가 너무 많으면 카드 선택의 긴장이 줄어듭니다.

### 강화 UX

상점에서 강화 후보를 보여줄 때는 수치보다 판단 변화를 먼저 보여줍니다.

표시 원칙:

- 강화 전 카드와 강화 후 카드를 나란히 보여줍니다.
- 바뀐 문장만 강조합니다.
- 연결되는 아키타입과 약해지는 상황을 함께 표시합니다.
- 대가가 추가되거나 형태가 바뀌면 별도 위험 배지를 표시합니다.
- 같은 카드의 복사본이 여러 장이면 어느 복사본을 강화하는지 명확히 선택하게 합니다.

강화 버튼은 "강화하기" 하나만 두지 않고, 후보 이름으로 선택하게 합니다.

예를 들어 `도발벽 강화`보다 `넓은 도발`과 `튼튼한 전면`이 더 좋은 선택 문장입니다.

## 저주 카드 설계

저주 카드는 나쁜 카드가 아닙니다.

강한 효과를 위해 덱에 불편함을 받아들이는 선택입니다.

좋은 저주:

- 특정 빌드에서는 쓰고 싶습니다.
- 제거하고 싶은 유혹도 있습니다.
- 대가가 명확합니다.
- 플레이어가 선택한 결과로 들어옵니다.

나쁜 저주:

- 그냥 손패를 망칩니다.
- 설명이 모호합니다.
- 대응 방법이 없습니다.
- 강제 삽입되어 억울합니다.

저주 카드 금지:

- 웨이브 겹치기 보상 증가
- 시간 경과 마나 회복
- 완전 길막 허용
- 마지막 타격 보너스

### MVP 저주 계약 카드 운용

MVP 저주는 일반 라운드 랜덤 보상에 섞지 않습니다.

저주는 이벤트 계약, 특수 상점, 명시된 개인 선택에서만 등장하며, 플레이어가 카드 수령을 직접 확인해야 덱에 들어갑니다.

| 카드 | 직업 | 즉시 이득 | 장기 대가 | 잘 쓰는 빌드 | 안정화 방향 |
| --- | --- | --- | --- | --- | --- |
| 무거운 서약 | 수호자 | 전투 마나 +2, 선택 도발 구조물 반경 증가 | 다음 드로우 -1장, 대상 구조물 받는 피해 증가 | 철벽 앵커, 성문 교대 | 드로우 손실을 숨기지 않고 다음 드로우 화면에 예약 표시 |
| 무리한 증축 | 건축가 | 취약 바리케이드 2개 무료 설치 | 회수/파편 회수 가치 없음, 받는 피해 증가 | 후방 재건, 계획 철거 | 취약 상태와 회수 제외 표시를 더 선명하게 함 |
| 금지된 등불 | 원소술사 | 정예/보스 부위 피해 증가 | 일반 적 처치 마나 게이지 감소 | 표식 처형, 보스 부위 집중 | 마나 감소가 적용되는 적과 적용되지 않는 대상을 명확히 표시 |
| 위험한 개조 | 땜장이 | 공격 속도와 사거리 크게 증가 | 종료 피해와 수리 효율 감소 | 과부하 폭주, 오라 엔진 | 종료 피해 타이머와 수리 효율 감소 종료 시점 표시 |

저주 안정화는 대가 삭제가 아니라 대가 판독성 강화 또는 대가 형태 조정입니다.

예를 들어 `무거운 서약`의 안정화는 다음 드로우 손실을 없애는 것이 아니라, 다음 보상/정비 화면까지 해당 손실이 언제 적용될지 명확하게 예약 표시하는 방향이 좋습니다.

저주 계약 후보는 아래 조건을 만족해야 합니다.

- 즉시 이득이 전투 중 바로 체감됩니다.
- 장기 대가가 다음 1~3웨이브 안에 실제로 고민됩니다.
- 제거와 안정화가 모두 말이 됩니다.
- 특정 직업이 없으면 완전히 죽은 카드가 되지 않게, 자기 직업 카드로만 제안합니다.
- 솔로에서도 동쪽 활성 전선 안에서 사용 장면이 생깁니다.

공용 저주 후보인 `무음 호출`은 30일 MVP 일반 풀에 넣지 않습니다.

이 카드는 31일 이후 템포 계약, 특수 상점, 아티팩트 해금에서 별도 검증합니다.

## 콤보 제한

무한 콤보를 막기 위한 기준입니다.

위험 조합:

- 0비용 드로우 + 0비용 마나
- 버리기 횟수 증가 + 버리기 마나 증가
- 처치 시 드로우 + 광역 반복 피해
- 구조물 파괴 시 마나 + 무료 구조물 설치
- 과부하 페널티 무효화 + 과부하 재사용

제한 방법:

- 라운드당 발동 횟수 제한
- 같은 카드 연속 사용 페널티
- 게이지 충전 보정
- 전투 마나 한도
- 손패 한도
- 버리기 횟수 제한

제한은 플레이어가 느끼기에 자연스러워야 합니다.

카드 설명에 없는 숨은 제한이 많으면 신뢰가 깨집니다.

## 타겟 규칙

카드는 대상이 명확해야 합니다.

대상 유형:

| --- | --- |
| 타일 | 구조물 설치, 함정 설치 |
| 구조물 | 수리, 강화, 과부하 |
| 적 | 집중 사격, 취약 |
| 구역 | 화염 고리, 빙결 지대 |

| 전장 전체 | 영웅 카드, 보스전 카드 |

대상 자유도가 높을수록 카드는 강해집니다.

전장 전체에 영향을 주는 카드는 높은 비용, 희귀도, 제한 조건 중 하나 이상을 가져야 합니다.

### 사용 불가 피드백

카드가 사용할 수 없는 이유는 UI에서 바로 보여야 합니다.

대표 문구:

| 상황 | 문구 |
| --- | --- |
| 마나 부족 | 마나가 부족합니다. |
| 대상 없음 | 사용할 대상이 없습니다. |
| 설치 불가 | 이 타일에는 설치할 수 없습니다. |

| 손패 한도 | 손패가 가득 찼습니다. |

카드 실패는 플레이어 실수처럼 느껴지면 안 됩니다.

규칙을 배웠다는 느낌이 나야 합니다.

예시:

```text

키워드: 폭발

약한 상황: 적이 흩어져 있거나 경로가 바뀔 때
어울리는 카드: 둔화 말뚝, 잔해 폭발
위험한 조합: 연쇄 붕괴

사용 불가 조건: 대상이 바리케이드가 아님
```

## 카드 리뷰 절차

새 카드는 바로 데이터에 넣지 않습니다.

리뷰 순서:

1. 역할 확인
2. 직업 정체성 확인
3. 비용과 희귀도 확인
4. 위험 조합 확인
5. 텍스트 2줄 제한 확인
6. 데이터 구현 가능성 확인
7. 테스트 지표 설정
8. MVP 포함 여부 결정

리뷰에서 하나라도 막히면 보류합니다.

보류된 카드는 버리지 말고 `parking_lot` 목록으로 따로 둡니다.

### 카드 상태

| 상태 | 의미 |
| --- | --- |
| `idea` | 아이디어만 있음 |
| `draft` | 효과와 비용이 있음 |
| `reviewed` | 설계 리뷰 통과 |
| `implemented` | 데이터와 코드 구현 완료 |
| `testing` | 플레이테스트 중 |
| `approved` | 현재 풀에 유지 |
| `rework` | 재설계 필요 |
| `cut` | 제거 |

콘텐츠 제작표에는 최소 `reviewed` 상태 이상만 올립니다.

## 카드 폐기 기준

카드는 추가보다 폐기가 중요합니다.

아래에 해당하면 제거하거나 재설계합니다.

- 5회 테스트 동안 선택률이 매우 낮습니다.
- 선택률은 높지만 사용률이 낮습니다.
- 플레이어가 효과를 자주 오해합니다.
- 특정 직업의 정체성을 침범합니다.
- 밸런스 조정으로도 항상 좋거나 항상 나쁩니다.
- 웨이브 겹치기 금지선과 충돌합니다.
