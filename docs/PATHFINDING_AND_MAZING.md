# Pathfinding And Mazing

이 문서는 **Last Bastion: Four Seasons**의 경로 탐색, 미로 설계, 길막 판정 기준을 정리합니다.

이 게임의 핵심 재미는 방어선을 세우는 것이 아니라, 적이 지나갈 길과 무너질 지점을 설계하는 데 있습니다.

## 목표

- 플레이어는 구조물로 적 경로를 유도할 수 있습니다.
- 완전 길막은 허용하지 않습니다.
- 구조물 파괴는 경로를 다시 바꾸는 전술 이벤트입니다.
- 경로 변화는 플레이어가 이해할 수 있게 표시합니다.
- 보스는 일반 적과 다른 경로 폭과 압박을 가집니다.

## 맵 표현

맵은 타일 기반 그리드입니다.

MVP 기준:

- 전체 맵: 21x21
- 기지: 중앙 3x3
- 일반 경로 폭: 2타일
- 보스 경로 폭: 3타일
- 진입 방향: 북, 동, 남, 서

네 진입 방향은 맵과 경로 테스트 기준입니다.

일반 웨이브가 실제로 사용하는 진입 방향은 런 시작 인원수에 따른 활성 침공 방향 규칙을 따릅니다.

각 타일은 아래 정보를 가집니다.

| 필드 | 설명 |
| --- | --- |
| tileType | 일반, 경로, 강화, 잔해, 불안정, 보스 압력 |
| baseCost | 기본 이동 비용 |
| buildable | 구조물 설치 가능 여부 |
| pathable | 적 이동 가능 여부 |
| bossPathable | 보스 이동 가능 여부 |
| structureId | 설치된 구조물 |
| temporaryCost | 잔해나 상태 효과로 인한 임시 비용 |

## 경로 비용

적은 가장 짧은 거리보다 가장 낮은 비용 경로를 선택합니다.

기본 비용:

| 타일 | 비용 |
| --- | ---: |
| 일반 이동 가능 타일 | 1 |
| 기본 경로 타일 | 1 |
| 굴곡 경로 | 1.2 |
| 잔해 타일 | 2~4 |
| 둔화 함정 타일 | 1.5 |
| 불안정 지점 | 1 |
| 구조물 점유 타일 | 통과 불가 또는 높은 비용 |

바리케이드는 기본적으로 통과 불가에 가깝게 처리하지만, 길막 판정이 실패하면 설치할 수 없습니다.

파괴형 적은 특정 상황에서 구조물을 공격해 통과할 수 있습니다.

## 길막 판정

구조물을 설치하기 전, 모든 활성 입구에서 기지까지 경로가 있는지 검사합니다.

검사 대상:

- 현재 활성화된 웨이브 입구
- 다음 예고 웨이브 입구
- 보스 경로가 활성화된 경우 보스 입구

설치가 거부되는 경우:

- 활성 입구 중 하나라도 기지 경로가 없어집니다.
- 보스 경로 폭 3타일을 만족하지 못합니다.
- 이미 스폰된 적이 진행 불가능 상태가 됩니다.

설치가 허용되는 경우:

- 경로가 길어지지만 남아 있습니다.
- 일부 적이 도발 때문에 구조물을 공격합니다.
- 파괴형 적이 구조물을 공격할 수 있는 후보가 생깁니다.

## 길막 판정 결과 코드

배치 시스템은 단순한 성공/실패가 아니라 아래 결과 코드를 반환합니다.

| 코드 | 결과 | 플레이어 표시 |
| --- | --- | --- |
| allowed | 설치 가능 | 새 경로와 증가 시간 표시 |
| allowed_risky | 설치 가능하지만 위험 | 경로가 많이 길어져 파괴형 적의 공격 가능성 표시 |
| blocked_all_paths | 설치 불가 | 기지로 향하는 경로가 필요합니다 |
| blocked_boss_width | 설치 불가 | 보스가 지나갈 3타일 폭이 필요합니다 |
| blocked_spawned_enemy | 설치 불가 | 이미 진입한 적이 갇힙니다 |
| blocked_core_tile | 설치 불가 | 핵심 기지 연결 타일에는 설치할 수 없습니다 |
| preview_only | 아직 판정 보류 | 마우스 위치 이동 중 임시 미리보기 |

개발 로그와 UI 문구는 같은 코드를 기준으로 움직여야 합니다.

예를 들어 `allowed_risky`는 배치를 막지 않지만, 플레이어에게 이 구조물이 곧 공격받을 수 있음을 알려줍니다.

## 경로 증가 한도

미로 설계는 강력해야 하지만, 무한히 적을 걷게 만드는 퍼즐이 되면 안 됩니다.

기본 경로 대비 증가 시간을 아래 단계로 관리합니다.

| 증가 시간 | 판정 | 의도 |
| ---: | --- | --- |
| +0~15초 | 안정 | 정상적인 미로 설계 |
| +16~30초 | 우수 | 킬존 형성이 잘 된 상태 |
| +31~45초 | 위험 | 파괴형 적이 구조물 공격을 고려 |
| +46초 이상 | 과부하 | `allowed_risky` 또는 설치 거부 후보 |

웨이브 후반부나 보스전에서는 이 한도를 낮출 수 있습니다.

겹친 웨이브에서는 보상 증가 없이 적 밀도만 늘어나므로, 경로 증가 한도는 그대로 유지합니다.

경로가 너무 길어졌을 때 바로 설치를 막기보다, 먼저 파괴형 적의 공격 욕구와 보스 압력을 높여 미로를 자연스럽게 흔듭니다.

## 방어선 재건 루프

방어선은 한 번 완성한 뒤 끝까지 유지하는 퍼즐이 아닙니다.

구조물 파괴와 잔해는 경로를 다시 읽게 만드는 전투 이벤트입니다.

### 6단계 경로 변화

1. 구조물 설치 전 경로 미리보기를 보여줍니다.

2. 설치 후 `structurePurposeTag`에 따라 주요 역할을 기록합니다.

3. 파괴형 적, 보스 압력, 계절 타일이 위험한 구조물을 표식합니다.

4. 구조물이 파괴되면 잔해와 빈 타일을 반영해 경로를 다시 계산합니다.

5. 완전 길막이 생기면 잔해를 약화하거나 가장 오래된 잔해를 `밟힌 잔해`로 바꿉니다.

6. 다음 준비 단계에서 후방 킬존, 보조 오라, 새 도발 앵커 후보를 미리 보여줍니다.

### 재건 방향

| 상황 | 좋은 재건 | 피해야 할 재건 |
| --- | --- | --- |
| 전방 바리케이드 붕괴 | 뒤쪽 굴곡에 새 바리케이드와 둔화 배치 | 같은 자리 즉시 반복 설치 |
| 오라 장치 표식 | 오라 범위를 나눠 보조선 형성 | 모든 타워를 한곳에 다시 밀집 |
| 도발 타워 파괴 | 도발 앵커를 한 칸 뒤로 옮김 | 수리만 믿고 같은 위치 고집 |
| 보스 압력 권역 발생 | 압력 밖 후방 킬존으로 이전 | 압력 안에 핵심 타워 재건 |
| 잔해가 오래 남음 | 잔해를 임시 경로 비용으로 활용 | 잔해로 완전 길막 시도 |

재건 UI는 정답 위치를 찍어주는 공략이 아니라, 가능한 후보를 보여주는 미리보기입니다.

## 경로 미리보기

플레이어가 구조물을 배치하려고 할 때 경로 변화를 미리 보여줍니다.

표시:

- 기존 경로
- 새 경로
- 이동 시간이 얼마나 늘어나는지
- 길막 불가 여부
- 보스 경로 영향 여부

문구:

```text
경로 +8초
```

```text
기지로 향하는 경로가 필요합니다.
```

색상:

| 상태 | 색 |
| --- | --- |
| 기존 경로 | 얇은 회색 선 |
| 새 경로 | 밝은 청록 선 |
| 위험한 우회 | 노란 선 |
| 설치 불가 | 붉은 타일 하이라이트 |
| 보스 경로 영향 | 굵은 흰색 테두리 |

경로 미리보기는 숫자를 너무 많이 보여주지 않습니다.

전투 중에는 색과 선 굵기로 빠르게 읽히게 합니다.

배치 버튼을 누르기 전까지는 화면을 멈추지 않습니다.

다만 설치 불가 상태에서는 커서 근처에 짧은 이유를 반드시 보여줍니다.

## 경로 재계산 조건

경로 재계산은 아래 이벤트에서 발생합니다.

- 구조물 설치
- 구조물 파괴
- 잔해 생성
- 잔해 소멸
- 보스 압력 타일 생성
- 보스 압력 타일 소멸
- 도발 구조물 생성
- 도발 구조물 파괴
- 임시 구조물 생성/소멸

경로 재계산은 즉시 요청하되, 같은 프레임에 여러 요청이 있으면 하나로 합칩니다.

## 경로 캐시와 재계산 우선순위

적이 많아질수록 모든 적이 독립적으로 경로를 계산하면 전투가 불안정해집니다.

경로 캐시 단위:

- 입구
- 목표 기지 타일
- 적 크기
- 적 유형
- 현재 경로 비용 버전

재계산 우선순위:

1. 이미 길이 끊긴 적
2. 보스와 정예형 적
3. 기지에 가장 가까운 적 무리
4. 새로 스폰되는 적
5. 멀리 있는 일반 군집형 적

겹친 웨이브에서는 입구별 대표 경로를 먼저 계산하고, 개별 적은 대표 경로를 따라가다가 막히는 순간에만 개인 경로를 요청합니다.

구조물 파괴 직후에는 모든 적을 즉시 새 경로로 꺾지 않습니다.

짧은 반응 지연을 둬서 적들이 한꺼번에 방향을 바꾸며 부자연스럽게 튀는 장면을 줄입니다.

## 적별 경로 행동

| 적 유형 | 경로 행동 |
| --- | --- |
| 군집형 | 가장 낮은 비용 경로를 따라갑니다. |
| 돌파형 | 이동 시간이 짧은 경로를 더 선호합니다. |
| 파괴형 | 경로가 길어지면 가까운 구조물을 공격합니다. |
| 저항형 | 경로는 기본과 같지만 느리게 압박합니다. |
| 방해형 | 다른 적 뒤에 섞여 이동합니다. |
| 정예형 | 기본 경로를 따르되 특수 효과를 가집니다. |
| 지원형 | 주변 적이 많은 경로를 선호할 수 있습니다. |

## 파괴형 적의 구조물 공격

파괴형 적은 무조건 벽을 때리지 않습니다.

공격 조건:

- 현재 경로가 기본 경로보다 일정 시간 이상 길어졌습니다.
- 도발 상태입니다.
- 보스 또는 정예 패턴이 구조물 공격을 지시합니다.
- 가까운 구조물이 핵심 경로 비용을 크게 올리고 있습니다.

공격 예고:

- 파괴형 적은 공격 전 0.6~1.2초 동안 구조물을 바라봅니다.
- 대상 구조물에는 금 간 테두리나 낮은 진동 효과를 표시합니다.
- 이 예고 시간 동안 수리, 보호막, 도발 전환으로 대응할 수 있습니다.

공격 대상 우선순위:

1. 도발 구조물
2. 경로를 가장 많이 늘린 구조물
3. 가장 가까운 바리케이드
4. 가장 가까운 타워

공격 대상 점수:

| 요소 | 점수 |
| --- | ---: |
| 도발 중인 구조물 | +100 |
| 현재 경로 증가에 크게 기여 | +40 |
| 기지에 가까운 병목을 만들고 있음 | +25 |
| 파괴 시 새 경로가 열림 | +20 |
| 적과 가까움 | +10 |
| 체력이 낮음 | +5 |
| 최근 이미 공격받음 | -20 |

점수가 가장 높은 구조물이 공격 대상이 됩니다.

같은 구조물만 계속 맞지 않도록 최근 공격받은 구조물에는 짧은 감점 시간을 둡니다.

이 규칙 덕분에 플레이어는 파괴될 구조물을 어느 정도 예측할 수 있어야 합니다.

## 보스 경로

보스는 일반 적보다 넓은 경로를 요구합니다.

기본:

- 보스 경로 폭: 3타일
- 작은 구조물 일부는 보스가 밟고 지나갈 수 있습니다.
- 핵심 구조물은 보스가 짓누르거나 파괴합니다.
- 보스 경로는 UI에 별도 표시합니다.

보스 경로를 완전히 막을 수 없습니다.

보스전의 목표는 보스를 막는 것이 아니라, 최대한 늦추고 부위를 파괴하는 것입니다.

보스가 구조물을 대하는 방식:

| 구조물 등급 | 예시 | 보스 반응 |
| --- | --- | --- |
| 낮은 장애물 | 작은 잔해, 약한 임시물 | 밟고 지나감 |
| 전술 장애물 | 바리케이드, 둔화 함정 | 짓누르며 속도 감소 |
| 핵심 구조물 | 강화 타워, 도발 타워 | 짧게 멈춰 파괴 |
| 금지 구조물 | 기지 연결 핵심 타일 위 구조물 | 설치 불가 |

보스가 구조물을 밟고 지나가는 것은 규칙 위반이 아니라 보스 전용 경로 판정입니다.

대신 밟히는 구조물은 미리 UI로 표시되어야 합니다.

보스 경로를 지나치게 자주 숨기면 불공정하게 느껴지므로, 보스 등장 1라운드 전부터 폭 3타일 예고선을 보여줍니다.

## 도발과 경로

도발은 경로 자체를 바꾸는 것이 아니라 적의 목표를 임시로 바꿉니다.

도발 중인 적은 도발 구조물까지의 접근 경로를 계산합니다.

도발 구조물이 공격 범위 안에 있으면 경로 이동보다 공격을 우선합니다.

도발이 끝나면 기지 경로로 돌아갑니다.

## 잔해와 경로

잔해는 임시 비용 증가 타일입니다.

잔해의 목적:

- 적을 잠시 늦춥니다.
- 경로를 약간 비틀어 전투를 유동적으로 만듭니다.
- 구조물 파괴가 전술적 흔적을 남기게 합니다.

잔해의 금지:

- 기지 경로 완전 차단
- 보스 경로 완전 차단
- 너무 오래 남아서 맵을 읽기 어렵게 만들기

## 경로 품질 지표

플레이테스트에서 볼 지표:

| 지표 | 의미 |
| --- | --- |
| 평균 경로 증가 시간 | 미로 설계가 얼마나 영향을 주는지 |
| 길막 거부 횟수 | 배치 규칙이 답답한지 |
| 구조물 파괴 후 경로 변화 횟수 | 계획된 붕괴가 일어나는지 |
| 적이 기지에 도달한 방향 | 약한 라인 파악 |
| 보스 경로 차단 시도 횟수 | 보스 규칙이 이해됐는지 |

목표 수치:

| 지표 | 초반 1~20라운드 | 중반 21~60라운드 | 후반 61~100라운드 |
| --- | ---: | ---: | ---: |
| 평균 경로 증가 시간 | +8~18초 | +12~28초 | +10~25초 |
| 설치 시도 중 길막 거부 비율 | 5~12% | 8~15% | 8~18% |
| 파괴 후 새 경로 발생률 | 15~25% | 25~40% | 35~55% |
| 보스 경로 오해 발생률 | 10% 이하 | 7% 이하 | 5% 이하 |

길막 거부 비율이 너무 낮으면 미로 설계가 헐겁고, 너무 높으면 배치가 답답합니다.

## 미로 설계 성공 기준

좋은 상태:

- 플레이어가 경로를 의도적으로 늘립니다.
- 적이 킬존을 지나갑니다.
- 파괴형 적이 예상 가능한 구조물을 때립니다.
- 구조물이 부서진 뒤 새 경로가 생깁니다.
- 플레이어가 다음 판에서 다른 미로를 시도합니다.

나쁜 상태:

- 항상 같은 미로가 정답입니다.
- 길막 거부가 너무 자주 발생합니다.
- 적이 왜 그 길로 가는지 이해되지 않습니다.
- 보스가 경로 규칙을 무시하는 것처럼 보입니다.
- 구조물 파괴 후 경로가 너무 혼란스럽습니다.

## 반복 정답 미로 방지

항상 같은 미로가 정답이 되면 협동 토론과 현장 대응의 재미가 줄어듭니다.

반복을 줄이는 장치:

- 입구 조합을 라운드마다 다르게 섞습니다.
- 보스 압력 타일이 자주 쓰는 병목을 잠시 무력화합니다.
- 잔해 지속 시간이 지형을 매번 다르게 만듭니다.
- 일부 적은 최단 비용보다 밀집도나 구조물 밀도를 더 크게 봅니다.
- 상점과 카드 보상은 특정 미로만 강화하지 않도록 분산됩니다.

금지:

- 랜덤으로 길을 막아 플레이어 설계를 부정하지 않습니다.
- 이미 성공한 미로를 즉시 카운터치는 방식으로 처벌하지 않습니다.
- 같은 직업 조합이 매번 같은 정답 타일을 밟게 만들지 않습니다.

목표는 정답을 숨기는 것이 아니라, 같은 원칙으로도 매판 다른 배치 판단이 나오게 만드는 것입니다.

## 디버그 표시

개발 중 필요한 표시:

- 타일 비용 숫자
- 현재 최단 경로
- 배치 후 예상 경로
- 길막 실패 원인
- 구조물별 경로 영향도
- 파괴형 적의 공격 대상 이유
- 보스 경로 폭
- 잔해 지속 시간
- 길막 판정 결과 코드
- 경로 캐시 버전
- 재계산 요청 수
- `allowed_risky` 발생 이유

## 구현 주의점

- 매 프레임 전체 경로를 재계산하지 않습니다.
- 경로 요청을 큐로 모아 처리합니다.
- 경로 미리보기는 마우스 위치가 바뀔 때만 갱신합니다.
- 적이 많을 때는 같은 입구/목표를 공유하는 적끼리 경로를 캐싱합니다.
- 구조물 파괴 직후 적이 순간이동하지 않게 보간합니다.
- 경로 판정 코드는 UI, 로그, QA 리포트에서 같은 이름을 씁니다.
- 설치 거부는 입력을 먹통으로 만들지 않고, 같은 위치 재시도 시 같은 이유를 보여줍니다.

## 금지선

- 완전 길막 허용 금지
- 보스 경로 완전 차단 금지
- 경로 표시 없이 배치 거부 금지
- 경로 규칙을 보스만 예외적으로 숨겨서 무시 금지
- 파괴형 적이 이유 없이 무작위 구조물 공격 금지
- 경로를 지나치게 길게 만든 배치를 아무 경고 없이 허용 금지
- 보스가 밟을 구조물을 사전 표시 없이 파괴 금지
