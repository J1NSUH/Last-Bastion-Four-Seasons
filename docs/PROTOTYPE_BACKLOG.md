# Prototype Backlog

이 문서는 첫 프로토타입을 만들기 위한 작업 백로그입니다.

작업은 기능 단위로 쪼개며, 각 항목은 완료 조건을 가집니다.

## 작업 우선순위

우선순위는 다음 기준을 따릅니다.

1. 핵심 재미를 검증하는가?
2. 다른 시스템의 기반이 되는가?
3. 테스트에서 바로 관찰 가능한가?
4. 임시 리소스로도 구현 가능한가?

## Epic 0: 런 기반 데이터

### P0-000 RunState 생성

설명:

로비 설정을 전투에서 사용할 런 상태로 확정합니다.

완료 조건:

- 런 시작 시 `playerCountAtStart`가 확정됩니다.
- 인원수에 맞는 `activeDirections`가 확정됩니다.
- 인원수에 맞는 `scalingProfileId`가 확정됩니다.
- 런 도중 현재 접속 인원이 바뀌어도 위 값이 바뀌지 않습니다.
- 디버그 패널에서 세 값을 확인할 수 있습니다.

### P0-000A 인원수별 활성 방향 테이블

설명:

1~4인 활성 침공 방향을 데이터로 관리합니다.

완료 조건:

- 1명: 동쪽
- 2명: 북쪽, 동쪽
- 3명: 서쪽, 북쪽, 동쪽
- 4명: 서쪽, 북쪽, 동쪽, 남쪽
- 비활성 방향은 일반 웨이브 스폰 후보에서 제외됩니다.
- 웨이브 겹치기로 비활성 방향이 열리지 않습니다.

### P0-000B 스케일링 프로필 적용

설명:

인원수별 위험도, 적 수, 보스 체력 배율을 조회합니다.

완료 조건:

- 1~4인 스케일링 프로필을 읽을 수 있습니다.
- 2인 기준 배율 1.0이 적용됩니다.
- 1인에서는 적 수와 위험도 예산이 감소합니다.
- 3~4인에서는 적 체력보다 위험도 예산과 방향 압박이 먼저 증가합니다.
- 스케일링 프로필은 보상, 희귀도, 시간 경과 마나 회복에 영향을 주지 않습니다.

## Epic 1: 맵과 경로

### P0-001 기본 맵 생성

완료 조건:

### P0-002 적 경로 탐색

설명:

적이 입구에서 기지까지 경로를 찾아 이동합니다.

완료 조건:

- 경로 테스트 모드에서는 북/동/남/서 입구에서 기지까지 이동합니다.

- 경로가 없으면 배치 불가 피드백을 낼 수 있습니다.

### P0-003 구조물 배치

설명:

플레이어가 타일에 구조물을 배치합니다.

완료 조건:

- 일반 타일에 타워를 설치할 수 있습니다.
- 경로 타일에는 기본 타워를 설치할 수 없습니다.
- 바리케이드는 경로 비용에 영향을 줍니다.
- 완전 길막은 거부됩니다.

### P0-004 경로 재계산

설명:

구조물 배치와 파괴 후 적 경로가 다시 계산됩니다.

완료 조건:

- 바리케이드 설치 시 적이 우회합니다.
- 바리케이드 파괴 시 적이 짧은 경로로 돌아옵니다.
- 전투 중 경로 변경이 끊기지 않습니다.

### P0-013 WaveSpawnPlan 생성

- 방향 대체 이유를 디버그 로그에 남깁니다.

### P0-013A WaveScheduler

설명:

확정된 WaveSpawnPlan의 시작 시점과 예약 상태를 관리합니다.

완료 조건:

- 1~10일 WaveSpawnPlan이 순서대로 예약됩니다.
- 현재 웨이브와 다음 웨이브 예약을 구분합니다.
- 웨이브 겹치기 시 다음 WaveSpawnPlan을 앞당깁니다.
- 웨이브 겹치기는 새 방향을 만들지 않습니다.
- 보상 데이터와 스폰 예약은 분리됩니다.

### P0-013B 웨이브 스폰

설명:

WaveScheduler가 넘긴 WaveSpawnPlan을 기반으로 적을 소환합니다.

완료 조건:

- 1~10일 웨이브가 순서대로 실행됩니다.
- 현재 활성 방향 입구에서 적이 등장합니다.
- 비활성 방향에서는 일반 웨이브가 등장하지 않습니다.
- EnemySystem은 인원수나 활성 방향을 다시 계산하지 않습니다.
- 웨이브 종료를 감지합니다.

- 재개 중 `playerCountAtStart`, `activeDirections`, `scalingProfileId`, `WaveSpawnPlan.directions`를 다시 계산하지 않습니다.
- `session_savepoint_created`, `session_interrupt_detected`, `player_role_reserved`, `resume_snapshot_delivered`, `long_absence_resolved`, `session_resume_confirmed`를 기록합니다.

- 불안정한 시계는 기본 10일 후보 풀에서 제외합니다.
- 불안정한 시계가 웨이브 겹치기 최대치를 1 늘립니다.
- 해당 아티팩트는 보상 증가를 제공하지 않습니다.
