# Enemy Wave Cookbook

이 문서는 **Last Bastion: Four Seasons**의 적과 웨이브를 계속 만들 때 쓰는 조합 레시피입니다.

웨이브는 단순히 적을 많이 던지는 것이 아니라, 방어선에 특정 질문을 던지는 도구입니다.

## 웨이브 설계 목표

좋은 웨이브는 다음을 만족합니다.

- 주요 문제가 하나 있습니다.
- 보조 문제가 하나 더 있습니다.
- 플레이어가 실패 원인을 이해할 수 있습니다.
- 특정 직업이 없다고 불가능하지 않습니다.
- 웨이브 겹치기 없이도 과밀하지 않습니다.
- 웨이브 겹치기 시 위험은 커지지만 보상 총량은 늘지 않습니다.

## 웨이브 구성 공식

기본 구성:

```text
주력 적 1종
+ 보조 적 1종
+ 선택적 정예 1종
+ 활성 방향 중 1~2개
```

후반 구성:

```text
주력 적 1종
+ 보조 적 1~2종
+ 정예 1종
+ 활성 방향 중 2~3개
+ 계절 타일 압박
```

웨이브 방향은 항상 현재 런의 활성 침공 방향 안에서 고릅니다.

비활성 방향은 일반 웨이브 스폰 후보가 아닙니다.

## WaveIntent와 LaneProjection

웨이브는 방향별 콘텐츠가 아니라 전투 질문입니다.

먼저 `WaveIntent`로 "무엇을 묻는 웨이브인가"를 정하고, 그다음 `LaneProjection`으로 "현재 인원수와 활성 방향 안에서 이 질문을 어떻게 보여줄 것인가"를 정합니다.

| 요소 | 설명 |
| --- | --- |
| `WaveIntent` | 핵심 질문, 주 압박, 보조 압박, 권장 대응, 금지 조합, 실패 원인을 정의 |
| `LaneProjection` | 같은 의도를 실제 방향, 경로 길이, 샛길, 스폰 타이밍, 동시 전선 수로 변환 |

예시:

| `WaveIntent` | 1인 투영 | 2인 투영 | 3~4인 투영 |
| --- | --- | --- | --- |
| 빠른 적 대응 | 동쪽 짧은 샛길에 돌파형 소량 | 동쪽 빠른 타이밍과 북쪽 느린 군집 | 서쪽 주 압박과 다른 활성 방향의 약한 보조 압박 |
| 느린 누적 압박 | 동쪽 긴 우회 경로에 느린 대형 적 | 북쪽 장기 압박과 동쪽 기본 군집 | 북쪽/남쪽 중 활성 방향에 장기 압박 배치 |
| 킬존 압축 | 동쪽 안쪽 굴곡에 군집형 유도 | 한 방향은 군집, 다른 방향은 약한 보조 압박 | 남쪽 또는 굴곡이 큰 활성 방향에 군집 압축 |

솔로는 콘텐츠가 줄어드는 모드가 아닙니다.

1인 런은 동쪽만 사용하지만 모든 핵심 `WaveIntent`를 경험해야 합니다. 멀티플레이는 새 웨이브 의도를 해금하는 대신, 같은 의도를 여러 전선에 나누어 처리하게 만듭니다.

## 인원수별 방향 풀

런 시작 인원수에 따라 웨이브가 사용할 수 있는 방향 풀이 정해집니다.

| 인원수 | 방향 풀 | 기본 역할 분담 |
| ---: | --- | --- |
| 1명 | 동쪽 | 한 라인에 집중해 카드와 설치 조작을 익힙니다. |
| 2명 | 북쪽, 동쪽 | 북쪽 장기 압박과 동쪽 단기 압박을 나눠 봅니다. |
| 3명 | 서쪽, 북쪽, 동쪽 | 서쪽 빠른 압박이 추가되어 순회 지원이 필요합니다. |
| 4명 | 서쪽, 북쪽, 동쪽, 남쪽 | 네 방향 전체를 열어 완전한 파티 방어를 만듭니다. |

방향 풀은 런 시작 시 고정됩니다.

플레이어가 중간에 나가거나 재접속해도 웨이브 방향 풀은 바뀌지 않습니다.

### 방향 선택 원칙

인원이 늘어도 모든 웨이브가 항상 모든 활성 방향에서 나오면 피로도가 너무 높습니다.

기본 원칙:

- 초반 학습 웨이브는 활성 방향 중 1개만 사용합니다.
- 2인 이상에서는 중요한 학습이 끝난 뒤 2방향 압박을 사용합니다.
- 3인 이상에서는 서쪽 돌파 압박을 가끔 섞어 순회 지원을 요구합니다.
- 4인에서는 네 방향 동시 압박을 후반 또는 보스 동반 상황에 제한적으로 사용합니다.
- 웨이브 겹치기는 비활성 방향을 새로 열지 않습니다.

### 인원수별 금지선

| 인원수 | 금지 |
| ---: | --- |
| 1명 | 동쪽 외 일반 웨이브 스폰 금지 |
| 2명 | 3방향 이상 동시 압박 금지 |
| 3명 | 남쪽 일반 웨이브 스폰 금지 |
| 4명 | 초반부터 4방향 동시 압박 남발 금지 |

인원수별 방향 제한은 난이도를 낮추기 위한 장치만이 아니라, 각 인원수에서 협동의 모양을 다르게 만들기 위한 장치입니다.

## 웨이브 설계 절차

웨이브는 아래 순서로 만듭니다.

- 이 웨이브가 던질 핵심 질문을 정합니다.
- `WaveIntent`에 주 압박, 보조 압박, 권장 대응, 금지 조합, 실패 원인을 적습니다.
- 현재 일자와 계절에 맞는 위험도 예산을 정합니다.
- 인원수별 `LaneProjection`으로 실제 방향, 경로 성격, 스폰 타이밍을 정합니다.
- 위험도 예산 안에서 적 수량을 맞춥니다.
- 예고 문구와 실패 리포트 태그를 작성합니다.
- 웨이브 겹치기 시 무엇이 위험해지는지 기록합니다.
- 1인, 2인, 3인, 4인 모두 같은 핵심 질문을 경험하는지 확인합니다.

웨이브를 먼저 만들고 질문을 나중에 붙이면 안 됩니다.

질문이 없는 웨이브는 대부분 단순 물량전이 됩니다.

## 웨이브 질문 유형

웨이브는 플레이어에게 아래 질문 중 하나를 던져야 합니다.

| 질문 유형 | 의미 | 대표 적 |
| --- | --- | --- |
| 화력 질문 | 이 적들을 제시간에 처치할 수 있는가? | 회색 행렬, 무거운 순례자 |
| 속도 질문 | 빠른 적을 놓치지 않을 수 있는가? | 틈새 주자 |
| 구조물 질문 | 어떤 구조물이 먼저 부서질지 예측할 수 있는가? | 균열 망치 |
| 제어 질문 | 둔화, 빙결, 넉백을 적절히 쓸 수 있는가? | 틈새 주자, 군집형 |
| 우선순위 질문 | 어떤 적을 먼저 잡아야 하는가? | 침묵 운반자, 검은 등짐 |
| 덱 질문 | 손패와 마나가 꼬여도 대응할 수 있는가? | 방해형 |
| 경로 질문 | 현재 미로가 특정 방향 압박을 버티는가? | 방향별 혼합 웨이브 |
| 보스 질문 | 일반 웨이브와 보스 부위를 동시에 볼 수 있는가? | 보스 동반 웨이브 |
| 구조물 생애주기 질문 | 어떤 구조물을 살리고, 어떤 구조물을 전술적으로 버릴 것인가? | 파괴형, 과열, 압력 권역 |

하나의 웨이브에 질문이 3개 이상 들어가면 대부분 과합니다.

MVP에서는 질문 1개, 후반에는 질문 2개까지를 기본으로 봅니다.

### 구조물 생애주기 질문

구조물 생애주기 질문은 파괴 자체가 아니라 선택을 묻습니다.

| 질문 | 좋은 웨이브 신호 | 나쁜 웨이브 신호 |
| --- | --- | --- |
| 이 구조물을 왜 세웠는가? | 설치 목적이 표식과 위험에 연결됩니다. | 아무 구조물이나 맞고 부서집니다. |
| 살릴 것인가, 버릴 것인가? | 수리, 강화, 희생, 이전이 모두 말이 됩니다. | 살릴 방법도 버릴 보상도 없습니다. |
| 부서진 뒤 어디로 옮길 것인가? | 후방 킬존이나 보조 오라 후보가 보입니다. | 같은 자리에 반복 재건합니다. |
| 파괴가 경로를 어떻게 바꾸는가? | 잔해가 시간 벌기와 경로 변화로 읽힙니다. | 잔해가 완전 길막처럼 보입니다. |

구조물 생애주기 질문은 파괴형 적, 과열 강화 지점, 결빙, 보스 압력 권역과 잘 맞습니다.

단, 초반에는 구조물 파괴와 빠른 적 누수와 방해형을 동시에 강하게 묻지 않습니다.

## 핵심 WaveIntent 카탈로그

`WaveIntent`는 특정 방향, 특정 적 이름, 특정 직업 요구를 고정하지 않습니다.

같은 의도는 솔로에서는 동쪽 안의 경로 성격, 샛길, 스폰 타이밍, 표식 위치로 표현하고, 멀티플레이에서는 활성 방향 안의 역할 분담으로 표현합니다.

| ID | 핵심 질문 | 주 압박 | 보조 압박 | 좋은 실패 |
| --- | --- | --- | --- | --- |
| `intent_route_read` | 적이 어느 길로 기지에 닿는지 읽는가? | `route_read` | 없음 | 기지 앞만 막다가 먼 경로의 위험을 늦게 봅니다. |
| `intent_path_stretch` | 구조물로 이동 시간을 늘리는가? | `path_extend` | `simple_swarm` | 경로가 거의 늘지 않는 곳에 구조물을 씁니다. |
| `intent_fast_response` | 빠른 적을 일반 군집과 다르게 처리하는가? | `runner_burst` | `light_swarm` | 일반 킬존만 믿다가 빠른 적이 새어 나갑니다. |
| `intent_swarm_compression` | 적을 모아 광역, 가시, 폭발 가치를 만드는가? | `swarm_clear` | `positioning` | 적이 흩어진 채 화력이 분산됩니다. |
| `intent_planned_structure_break` | 부서질 구조물을 정하고 그 시간을 활용하는가? | `planned_collapse` | `repair_or_abandon` | 모든 구조물을 살리려다 손패와 마나가 꼬입니다. |
| `intent_priority_target` | 지금 먼저 끊어야 할 적을 찾는가? | `priority_target` | `light_swarm` | 체력 높은 적만 치다가 방해형을 놓칩니다. |
| `intent_resource_disruption_recovery` | 손패나 마나가 꼬였을 때 전선을 유지하는가? | `resource_disruption` | `stable_swarm` | 카드가 막힌 원인을 전선 압박과 연결하지 못합니다. |
| `intent_secondary_killzone` | 주 킬존이 흔들리기 전에 보조 방어선을 여는가? | `secondary_killzone` | `route_shift` | 한 지점만 고집하다 후방 준비 없이 무너집니다. |
| `intent_relocation_after_loss` | 무너진 전방을 포기하고 후방으로 이전하는가? | `relocation` | `structure_loss` | 같은 자리에 반복 재건하며 자원을 소모합니다. |
| `intent_final_focus` | 남은 자원을 어디에 집중할지 정하는가? | `final_focus` | `boss_or_elite` | 보스, 정예, 동반 웨이브 사이에서 화력이 흩어집니다. |

### 인원수별 투영 메모

| ID | 1인 투영 | 멀티 투영 |
| --- | --- | --- |
| `intent_route_read` | 동쪽 기본 경로와 예고 UI만으로 경로 읽기를 묻습니다. | 활성 방향 중 하나를 주 경로로 고르고 나머지는 예고 또는 약한 보조 압박으로 둡니다. |
| `intent_path_stretch` | 동쪽 굴곡이나 긴 우회 경로에 느린 군집을 배치합니다. | 한 방향은 긴 압박, 다른 방향은 짧은 보조 압박으로 역할을 나눕니다. |
| `intent_fast_response` | 동쪽 짧은 샛길에 빠른 적을 소량 배치합니다. | 빠른 방향을 하나 정하고, 다른 활성 방향은 느린 군집이나 약한 주의 분산만 담당합니다. |
| `intent_swarm_compression` | 동쪽 안쪽 굴곡에 군집형을 몰아 광역 가치를 묻습니다. | 굴곡이 큰 활성 방향을 주 킬존 후보로 정하고 다른 방향은 과하게 열지 않습니다. |
| `intent_planned_structure_break` | 동쪽 표식 구조물 하나를 명확히 보여주고 살림/희생을 묻습니다. | 표식 구조물은 한 활성 방향에만 두고, 다른 방향은 수리 판단을 방해하지 않을 정도로 낮춥니다. |
| `intent_priority_target` | 동쪽에 방해형을 시간차로 섞어 우선순위를 읽게 합니다. | 위협 방향 하나와 약한 교란 방향 하나를 둬서 콜과 핑을 유도합니다. |
| `intent_resource_disruption_recovery` | 동쪽에 소수 방해형과 안정 군집을 섞되 예고를 강하게 줍니다. | 방해형은 한 방향에만 배치하고, 다른 플레이어가 지원 판단을 할 시간을 둡니다. |
| `intent_secondary_killzone` | 동쪽 후방 굴곡을 보조 방어선 후보로 강조합니다. | 주 전선과 보조 전선을 서로 다른 활성 방향 또는 같은 방향의 후방 구간으로 나눕니다. |
| `intent_relocation_after_loss` | 동쪽 전방 압박 후 후방 이전 후보 타일을 보여줍니다. | 한 전선의 전방이 무너지고 다른 활성 전선이 후방 엄호를 맡도록 설계합니다. |
| `intent_final_focus` | 동쪽 보스 경로와 시간차 동반 웨이브로 집중 대상을 묻습니다. | 보스, 정예, 동반 웨이브를 활성 방향에 나누되 동시에 전부 최대치로 올리지 않습니다. |

## 적 역할과 직업 대응 매트릭스

적은 특정 직업을 요구하는 열쇠 구멍이 아니라, 파티가 가진 역할을 어떻게 조합하는지 묻는 압박 장치입니다.

따라서 모든 적 역할은 최소 2개 이상의 유효 대응을 가져야 합니다.

가장 잘 맞는 직업이 있더라도, 다른 직업은 위치 선정, 공용 카드, 수리, 제어, 구조물 희생으로 느리지만 납득 가능한 대응을 할 수 있어야 합니다.

### 적용 흐름

- 적 역할이 던지는 핵심 질문을 한 문장으로 씁니다.
- 가장 자연스럽게 대응하는 직업을 정합니다.
- 같은 문제를 다른 방식으로 풀 수 있는 보조 대응을 2개 이상 붙입니다.
- 이 적과 같이 나오면 과부하가 되는 역할 조합을 표시합니다.
- 실패했을 때 플레이어가 원인을 이해할 수 있는 예고와 피드백을 정합니다.
- 플레이테스트에서 이 적이 특정 직업 강제가 되었는지 확인합니다.

### 직업 대응 매트릭스

| 적 역할 | 던지는 질문 | 편한 대응 | 보조 대응 | 실패 신호 |
| --- | --- | --- | --- | --- |
| 군집형 | 킬존에 모인 적을 제때 정리하는가? | 원소술사 광역, 건축가 경로 압축 | 수호자 도발 군집, 땜장이 오라 화력 증폭 | 체력만 많은 물량전처럼 보임 |
| 돌파형 | 빠른 적을 예고 후 즉시 붙잡는가? | 원소술사 빙결/넉백, 수호자 도발 타이밍 | 건축가 짧은 우회로, 땜장이 과부하 화력 | 어디서 새었는지 알기 전에 기지가 맞음 |
| 파괴형 | 어떤 구조물이 부서질지 계획하는가? | 건축가 계획 붕괴, 땜장이 원격 수리 | 수호자 가시 탱킹, 원소술사 집중 화력 | 구조물이 무작위로 지워진 느낌 |
| 저항형 | 한 가지 피해 방식에만 의존하지 않는가? | 땜장이 오라 지속 화력, 원소술사 속성 전환 | 수호자 지연, 건축가 긴 경로 | 특정 직업의 핵심 공격이 완전히 무효화됨 |
| 방해형 | 자원과 손패가 흔들릴 때 우선순위를 잡는가? | 원소술사 우선 처치, 수호자 도발 분리 | 건축가 경로 격리, 땜장이 수리로 시간 벌기 | 디버프가 보이지 않아 억울함 |
| 지원형 | 위험한 보조 적을 먼저 끊는가? | 원소술사 후열 타격, 건축가 격리 경로 | 수호자 끌어당김, 땜장이 오라로 전선 유지 | 지원 효과와 본체 위협이 동시에 과함 |
| 압박형 | 긴 경로와 지속 화력을 유지하는가? | 건축가 경로 연장, 땜장이 유지보수 | 수호자 장기 지연, 원소술사 둔화 | 전투가 길기만 하고 판단이 없음 |
| 정예형 | 파티가 같은 타겟을 함께 보는가? | 공동 집중 화력 | 도발 고정, 수리 유지, 경로 격리, 부위 우선순위 | 그냥 체력 높은 일반 적처럼 보임 |

### 적 역할 프로필과 WaveIntent 연결

적 역할은 `WaveIntent`를 표현하는 재료입니다.

한 적 역할이 여러 의도에 쓰일 수 있지만, 한 웨이브 안에서는 주 역할과 보조 역할을 분리해야 합니다. 주 역할은 플레이어가 반드시 읽어야 하는 질문이고, 보조 역할은 그 질문을 더 선명하게 만드는 배경입니다.

| 적 역할 | 잘 맞는 WaveIntent | 필요한 예고 | 기본 대응 창 | 과부하 금지 |
| --- | --- | --- | --- | --- |
| 군집형 | `intent_swarm_compression`, `intent_path_stretch` | 경로 미리보기, 군집 도착 타이밍 | 광역/도발/잔해가 1번 이상 의미 있는 시간 | 저항형 대량과 섞어 체력전으로 만들기 |
| 돌파형 | `intent_fast_response`, `intent_route_read` | 빠른 적 아이콘, 짧은 경로 강조 | 둔화, 넉백, 도발, 짧은 우회로 중 하나가 닿는 시간 | 방해형, 파괴형과 동시에 강하게 투입 |
| 파괴형 | `intent_planned_structure_break`, `intent_relocation_after_loss` | 표식 구조물, 공격 전 지연, 파괴 후 결과 | 수리/희생/후방 재건 중 하나를 고를 시간 | 예고 없는 구조물 삭제 |
| 저항형 | `intent_path_stretch`, `intent_final_focus` | 저항 아이콘, 약하게 통하는 대응 표시 | 긴 경로, 지속 화력, 약화된 CC가 누적될 시간 | 완전 면역으로 특정 직업 무효화 |
| 방해형 | `intent_priority_target`, `intent_resource_disruption_recovery` | 영향 범위, 막히는 게이지, 우선 처치 핑 후보 | 방해가 누적되기 전 끊거나 전선을 유지할 시간 | 손패와 마나를 동시에 완전 봉쇄 |
| 지원형 | `intent_priority_target`, `intent_secondary_killzone` | 강화 대상 연결선, 후열 위치, 지원 범위 | 지원형을 먼저 잡거나 격리할 시간 | 지원 효과와 정예/돌파형 최대치 동시 사용 |
| 압박형 | `intent_secondary_killzone`, `intent_relocation_after_loss` | 느린 진군선, 기지 도달 예상 시간 | 후방 킬존을 열거나 경로를 늘릴 시간 | 체력만 높은 장기전 |
| 정예형 | `intent_priority_target`, `intent_final_focus` | 처치 타이밍, 강화/약화 조건, 집중 핑 후보 | 지금 잡을지 묶어둘지 합의할 시간 | 다방향 돌파형과 함께 공동 타겟을 흐림 |

1인 투영에서는 주 역할 질문을 하나만 강하게 둡니다.

2~4인 투영에서는 적 역할을 더 많이 추가하기보다 같은 역할의 위치, 등장 순서, 지원 요청 방향을 나눕니다.

### 소프트 카운터 규칙

- 특정 적 역할은 하나의 직업을 가장 빛나게 만들 수는 있지만, 그 직업이 없다고 실패가 확정되면 안 됩니다.
- 저항은 완전 면역보다 부분 저항을 기본으로 합니다.
- 핵심 기믹을 막는 적은 막는 범위, 지속 시간, 해제 조건을 전투 전에 보여줘야 합니다.
- 솔로에서는 강한 역할 질문을 한 번에 하나만 냅니다.
- 2~4인에서는 강한 질문을 늘리기보다 방향과 타이밍을 나눠 협동을 요구합니다.

### 역할 과부하 금지선

아래 조합은 후반 예고 웨이브나 보스 리허설이 아니면 피합니다.

| 조합 | 문제 |
| --- | --- |
| 돌파형 + 방해형 + 파괴형 | 빠른 실패, 자원 꼬임, 구조물 손실이 동시에 와서 학습이 어렵습니다. |
| 저항형 + 압박형 대량 | 전투 시간이 늘지만 판단은 늘지 않습니다. |
| 지원형 + 방해형 다수 | 무엇을 먼저 잡아야 하는지 흐려집니다. |
| 정예형 + 돌파형 다방향 | 공동 타겟 집중과 라인 분산 요구가 충돌합니다. |

### 적 역할별 시너지 트리거

| 시너지 | 주로 발동시키는 적 역할 | 의도 |
| --- | --- | --- |
| 도발 군집 | 군집형, 돌파형 | 수호자가 적을 모으고 원소술사/건축가가 정리합니다. |
| 계획 붕괴 | 파괴형, 군집형, 압박형 | 건축가의 바리케이드 손실을 광역 피해와 경로 재설계로 바꿉니다. |
| 지연 수리 | 파괴형, 정예형, 보스 동반 웨이브 | 땜장이가 무너질 구조물을 살려 딜타임을 늘립니다. |
| 후방 킬존 이전 | 압박형, 겨울 웨이브, 보스 압력 | 기존 전선이 좁아질 때 파티가 새 킬존을 함께 옮깁니다. |
| 부위 집중 | 정예형, 보스 부위, 지원형 | 단일 대상 판단을 파티 전체의 같은 목표로 묶습니다. |

## 적 역할별 레시피

### 군집형

목적:

광역 피해와 킬존 설계를 검증합니다.

좋은 조합:

- 군집형 + 파괴형
- 군집형 + 방해형
- 군집형 + 정예형

피해야 할 조합:

- 군집형만 너무 오래 반복
- 군집형 + 군집형 + 군집형

군집형은 통쾌함을 주지만, 너무 자주 쓰면 전투가 반복됩니다.

### 돌파형

목적:

즉발 대응, 둔화, 넉백, 빠른 라인 보강을 요구합니다.

좋은 조합:

- 돌파형 + 저항형
- 돌파형 + 지원형
- 돌파형 + 파괴형 소량

피해야 할 조합:

- 초반 돌파형 대량
- 예고 없는 다방향 돌파형

돌파형은 실패 원인이 명확해야 합니다.

플레이어가 "저 빠른 적을 놓쳤다"고 이해해야 합니다.

### 파괴형

목적:

구조물 파괴를 전술로 받아들이게 만듭니다.

좋은 조합:

- 파괴형 + 군집형
- 파괴형 + 둔화에 약한 적
- 파괴형 + 보스

피해야 할 조합:

- 파괴형만 대량
- 파괴형 + 도발 저항형 과다

파괴형은 랜덤으로 구조물을 부수면 안 됩니다.

어떤 구조물이 위험한지 예측 가능해야 합니다.

### 저항형

목적:

단일 전략 의존을 견제합니다.

좋은 조합:

- 저항형 + 돌파형
- 저항형 + 방해형
- 저항형 + 압박형

피해야 할 조합:

- 모든 피해 유형에 강한 저항형
- 초반 저항형 대량

저항형은 "다른 해결책을 써라"라는 질문이어야지, "딜이 부족하다"로 느껴지면 안 됩니다.

### 저항형 상태이상 기준

저항형은 모든 CC를 막는 적이 아닙니다.

하나의 대응을 약하게 만들고, 다른 대응의 가치를 올리는 적입니다.

| 약하게 받는 것 | 여전히 통하는 것 | 의도 |
| --- | --- | --- |
| 광역 피해 | 단일 집중, 취약 | 화력 배분 질문 |
| 빙결 정지 | 둔화, 긴 경로 | 완전 정지 대신 시간 벌기 |
| 넉백 거리 | 도발, 수리, 지속 화력 | 경로 밖 고립 방지 |
| 도발 지속 | 경로 설계, 우선 처치 | 수호자 단독 해결 방지 |

금지:

- 모든 피해와 모든 CC에 동시에 강한 저항형
- 저항 아이콘 없이 효과가 사라지는 적
- 초반에 저항형을 대량 투입해 카드 선택을 부정하는 웨이브

### 방해형

목적:

자원과 손패 템포를 흔듭니다.

좋은 조합:

- 방해형 + 군집형
- 방해형 + 정예형
- 방해형 + 보스 부위

피해야 할 조합:

- 방해형 효과 중첩 과다
- 예고 없는 방해형 등장

방해형은 반드시 UI로 알아볼 수 있어야 합니다.

플레이어가 왜 드로우가 느려졌는지 모르면 실패입니다.

### 지원형

목적:

특정 방어 방식에 의존하는 플레이를 흔듭니다.

좋은 조합:

- 지원형 + 돌파형
- 지원형 + 정예형
- 지원형 + 파괴형 소량

피해야 할 조합:

- 지원형 효과 중첩 과다
- 지원형이 직접 위협도 높은 조합

지원형은 혼자 강하면 안 됩니다.

다른 적이 더 위험하게 보이도록 만드는 역할이어야 합니다.

### 압박형

목적:

느리지만 큰 기지 피해로 장기 화력과 경로 설계를 시험합니다.

좋은 조합:

- 압박형 + 군집형
- 압박형 + 저항형
- 압박형 + 방해형 소량

피해야 할 조합:

- 압박형 대량
- 압박형 + 돌파형 대량

압박형은 빨리 죽이지 못하면 위험하지만, 대응할 시간이 충분해야 합니다.

## 방향별 웨이브 레시피

### 북쪽

성격:

느리고 넓은 압박.

추천:

- 무거운 순례자
- 유리 껍질
- 회색 행렬

질문:

긴 경로와 지속 화력으로 버틸 수 있는가?

### 동쪽

성격:

경로가 짧지만 설치 공간이 많습니다.

추천:

- 회색 행렬
- 균열 망치
- 침묵 운반자

질문:

짧은 경로를 충분한 설치와 화력으로 커버할 수 있는가?

### 남쪽

성격:

굴곡이 많아 킬존을 만들기 좋습니다.

추천:

- 회색 행렬
- 침묵 운반자
- 유리 껍질

질문:

좋은 킬존이 방해형 압박에도 유지되는가?

### 서쪽

성격:

직선에 가까워 빠른 적이 위협적입니다.

추천:

- 틈새 주자
- 검은 등짐
- 뒤틀린 표식

질문:

빠른 적과 도발 저항을 즉시 대응할 수 있는가?

## 위험도 예산 단계

위험도 예산은 일자와 학습 단계에 따라 올라갑니다.

| 구간 | 예산 범위 | 구성 기준 |
| --- | ---: | --- |
| 1~3일 | 6~10 | 단일 적 또는 약한 보조 |
| 4~6일 | 10~16 | 주력 + 보조 1종 |
| 7~9일 | 16~24 | 복합 압박 |
| 10일 | 보스 | 일반 예산보다 보스 규칙 우선 |
| 11~20일 | 20~34 | 저항형/방해형 추가 |
| 21~30일 | 30~48 | 정예와 두 방향 압박 |
| 31~50일 | 45~70 | 계절 타일과 빠른 압박 |
| 51~75일 | 65~95 | 경로 변화와 방해형 강화 |
| 76~100일 | 85~130 | 공간 축소와 대형 적 |

예산은 절대값이 아니라 조합 강도를 비교하는 기준입니다.

같은 예산이라도 돌파형과 방해형이 섞이면 체감 난이도가 더 높을 수 있습니다.

### 예산 보정

| 조건 | 보정 |
| --- | ---: |
| 새 적 첫 등장 | 예산 -20% |
| 새 계절 규칙 첫 등장 | 예산 -15% |
| 활성 방향 2개 이상에서 두 방향 동시 압박 | 예산 +10%까지만 |
| 세 방향 동시 압박 | 후반 전용 |
| 보스 동반 | 일반 웨이브 예산 -30% |
| 방해형 포함 | 예산을 숫자보다 낮게 체감 조정 |
| 돌파형 다수 | 예산을 숫자보다 높게 체감 조정 |

새로운 것을 가르칠 때는 난이도를 낮춥니다.

이미 배운 것을 확인할 때만 예산을 올립니다.

## 웨이브 템플릿

### 학습 웨이브

목적:

새 적이나 새 규칙을 소개합니다.

구성:

- 새 적 1종
- 기존 약한 적 1종
- 단일 방향

금지:

- 새 적 + 새 계절 규칙 + 다방향 압박 동시 사용

### 숙련 확인 웨이브

목적:

이미 배운 적을 조합해 플레이어 이해도를 확인합니다.

구성:

- 주력 적 1종
- 보조 압박 1종
- 활성 방향 중 1~2개

### 붕괴 테스트 웨이브

목적:

구조물 파괴와 복구를 시험합니다.

구성:

- 파괴형 적
- 군집형 적
- 경로가 짧은 방향

관찰:

- 플레이어가 파괴될 구조물을 예측하는가?
- 수리와 폭발을 함께 쓰는가?

### 템포 테스트 웨이브

목적:

플레이어가 웨이브 겹치기를 누를지 판단하게 만듭니다.

구성:

- 안정적으로 막을 수 있는 적
- 다음 웨이브 예고가 명확함
- 기지 체력이 안전한 상태

주의:

보상 증가를 암시하지 않습니다.

### 보스 동반 웨이브

목적:

보스와 일반 웨이브를 동시에 보는 판단을 만듭니다.

구성:

- 보스가 멀리 있을 때 약한 일반 웨이브
- 보스가 중간 거리일 때 방해형 소량
- 보스가 기지 근처일 때 돌파형 금지 또는 매우 소량

보스전 웨이브는 보스 패턴을 읽을 시간을 빼앗으면 안 됩니다.

### 정비 전 웨이브

목적:

상점이나 이벤트 직전에 파티 상태를 살짝 흔들어, 정비 선택이 의미 있게 느껴지도록 만듭니다.

구성:

- 낮은 체력 군집형
- 약한 방해형 또는 파괴형 1~2마리
- 단일 방향 또는 쉬운 두 방향

주의:

정비 전 웨이브에서 기지 체력을 크게 깎으면 상점 선택이 강제로 기지 회복으로 고정됩니다.

정비 전 웨이브는 "어디를 고칠까?"를 묻는 정도가 좋습니다.

### 회복 웨이브

목적:

어려운 웨이브나 보스 이후 플레이어가 성장한 덱을 느끼게 합니다.

구성:

- 군집형 중심
- 방해형 없음
- 파괴형 없음 또는 소량
- 킬존이 잘 작동하면 빠르게 정리 가능

주의:

회복 웨이브는 공짜 보상이 아닙니다.

지루할 정도로 쉬우면 웨이브 겹치기를 누르게 만드는 용도로만 남습니다.

## 10일 테스트 웨이브 레시피

10일 테스트는 모든 시스템을 보여주는 구간이 아닙니다.

첫 보스까지 도달하면서 아래 다섯 문장을 차례대로 배우게 만드는 구간입니다.

1. 적은 경로를 따라오고, 구조물로 길을 비틀 수 있습니다.
2. 빠른 적은 군집형 적과 다르게 대응해야 합니다.
3. 구조물 파괴는 손실이 아니라 설계 가능한 전술입니다.
4. 웨이브 겹치기는 기다림을 줄이는 선택입니다.
5. 보스는 죽이기 전에 늦추고 부위를 봐야 합니다.

두 날씩 묶어 같은 판단을 안전한 상황과 실제 압박 상황에서 한 번씩 되묻습니다.

`WaveSpawnPlan`이 런 시작 인원수의 활성 방향 안에서 실제 방향을 확정합니다.

1인에서는 모든 패킷이 동쪽으로 투영됩니다.

2인에서는 `slow`가 북쪽, `short`와 `fast`가 동쪽을 우선합니다.

3인에서는 `fast`가 서쪽을 사용할 수 있고, 남쪽은 사용하지 않습니다.

4인에서도 1~10일은 실제 동시 방향 수를 1~2개로 제한합니다.

### 1~10일 스폰 패킷 조정 규칙

첫 프로토타입에서 수치가 맞지 않으면 아래 순서로 조정합니다.

| 문제 | 먼저 조정 | 마지막에 조정 |
| --- | --- | --- |
| 적이 너무 빨리 기지에 닿음 | 첫 스폰, 경로 길이, 빠른 적 수량 | 적 체력 |
| 전투가 밋밋함 | 두 번째 패킷 시작 시점, 예고 문구, 방향 역할 | 적 피해 |
| 구조물 파괴가 억울함 | 균열 망치 첫 스폰, 표식 예고, 구조물 대상선 | 구조물 체력 |
| 손패가 꼬여 아무것도 못 함 | 방해형 등장 시점, 방해 범위, 드로우 경고 | 마나 보상량 |
| 4인이 너무 쉽다고 느낌 | 동시 방향 수보다 보조 패킷 타이밍 | 적 체력 대량 증가 |

새 적을 배우는 날에는 동시 방향 수를 늘리지 않습니다.

스폰 패킷은 보상 팩을 추가하지 않습니다.

### 일자별 직업 대응 체크

이 표는 특정 직업이 없으면 실패하게 만들기 위한 표가 아닙니다.

각 웨이브가 네 직업의 핵심 역할을 어떻게 읽히게 하는지 확인하기 위한 제작 체크입니다.

| 일자 | 수호자 체크 | 건축가 체크 | 원소술사 체크 | 땜장이 체크 | 공용/파티 체크 |
| ---: | --- | --- | --- | --- | --- |

| 2 | 맞게 둘 구조물 후보가 보임 | 바리케이드로 경로 시간이 늘어남 | 모인 적을 작은 광역으로 정리 가능 | 핵심 구조물 보강 가치가 보임 | 완전 길막 거부가 납득됨 |

| 4 | 도발 군집이 광역 타이밍을 만듦 | 킬존 압축이 보임 | 군집과 빠른 적 카드 타이밍을 나눔 | 오라 화력 보강이 체감됨 | 같은 적처럼 보여도 대응이 다름 |

| 7 | 버릴 전면을 정함 | 잔해와 폭발을 딜타임으로 씀 | 붕괴 직후 모인 적을 정리 | 같은 자리 자동 복구보다 후방 보강 | 파괴가 손실과 이득을 함께 가짐 |
| 8 | 안정 여부를 전면 체력으로 판단 | 미로가 안정적인지 보고 겹치기 판단 | 손패와 광역 타이밍을 확인 | 수리 여유가 있으면 호출 제안 가능 | 보상이 아니라 시간 단축으로 말함 |
| 9 | 침묵 운반자를 도발 범위에 묶음 | 방해형을 돌아가게 하거나 격리 | 우선 처치로 드로우 방해를 끊음 | 방해 중에도 핵심 구조물을 살림 | 먼저 잡을 대상 핑이 뜸 |

### 날짜별 의도

#### 1일: 동쪽 첫 진입

처음부터 여러 방향을 보여주지 않습니다.

모든 인원수에서 동쪽을 먼저 강조합니다.

1인은 실제로 동쪽만 사용하고, 2~4인은 다른 입구가 있다는 것을 UI에 희미하게만 보여줍니다.

성공 기준:

- 플레이어가 적 경로를 봅니다.
- 기본 타워가 적을 공격하는 것을 이해합니다.
- 처치로 마나와 드로우 게이지가 조금 차는 것을 봅니다.

#### 2일: 긴 경로 학습

2인 이상에서는 북쪽 선호 웨이브로 긴 경로 압박을 보여줍니다.

1인은 북쪽을 열지 않고 동쪽 안에서 더 긴 우회 경로를 만들도록 유도합니다.

성공 기준:

- 바리케이드 하나로 경로 시간이 늘어납니다.
- 완전 길막 불가 피드백이 억울하지 않게 보입니다.
- 플레이어가 "더 오래 걷게 만들면 된다"는 감각을 얻습니다.

#### 3일: 빠른 적 첫 등장

3인 이상에서는 서쪽 빠른 라인을 처음 보여줍니다.

1~2인은 서쪽을 열지 않고, 활성 방향 안에서 가장 짧거나 돌파 압박이 잘 드러나는 방향으로 대체합니다.

성공 기준:

- 틈새 주자가 회색 행렬보다 먼저 튀어나오는 것을 알아봅니다.
- 둔화, 넉백, 도발, 집중 공격 중 하나로 대응합니다.
- 실패하더라도 "빠른 적을 놓쳤다"는 원인이 보입니다.

#### 4일: 모으고 구분하기

회색 행렬을 킬존에 모으되, 틈새 주자가 먼저 새어나갈 수 있게 만듭니다.

목표는 광역 카드와 즉발 대응의 차이를 느끼게 하는 것입니다.

성공 기준:

- 군집형은 모아서 처리합니다.
- 빠른 적은 별도 대응이 필요하다는 것을 압니다.
- 한 직업이 없어도 해결책이 남아 있습니다.

#### 5일: 첫 정비

5일은 어려운 전투가 아니라 첫 상점을 의미 있게 만들기 위한 짧은 점검입니다.

전투 후 상점은 선택지를 적게 보여줍니다.

권장 상점 후보:

- 카드 제거 1칸
- 카드 강화 1칸
- 기지 보강 1칸
- 저렴한 공용 카드 1칸

성공 기준:

- 플레이어가 전투에서 느낀 문제를 상점 선택과 연결합니다.
- 상점 시간이 60~90초를 넘지 않습니다.
- 기지 회복이 항상 정답처럼 보이지 않습니다.

#### 6일: 균열 망치 첫 등장

균열 망치는 소량만 등장합니다.

파괴 자체보다 "어떤 구조물이 다음 표적인가"를 읽게 하는 것이 목표입니다.

성공 기준:

- 곧 공격받을 구조물이 UI로 강조됩니다.
- 파괴 후 잔해가 적을 잠시 늦춥니다.
- 땜장이는 수리 타이밍, 건축가는 파괴 위치, 수호자는 도발 위치, 원소술사는 딜타임을 봅니다.

#### 7일: 파괴를 이용하기

6일이 파괴를 보는 날이라면, 7일은 파괴를 이용하는 날입니다.

회색 행렬 뒤에 균열 망치를 지연 스폰해, 바리케이드가 무너지는 순간 적이 묶이도록 만듭니다.

성공 기준:

- 플레이어가 일부 구조물을 버릴 수 있습니다.
- 구조물 파괴가 전술 자원처럼 느껴집니다.
- 파괴가 너무 랜덤하게 보이지 않습니다.

#### 8일: 웨이브 겹치기 자연 유도

8일은 겹치기 버튼을 누르게 만들기 위한 안정 웨이브입니다.

보상이 아니라 시간을 줄이는 판단이 되어야 하므로, 전투 자체는 읽기 쉽고 다음 웨이브 예고가 명확해야 합니다.

성공 기준:

- 파티가 "지금 불러도 되나?"를 짧게 이야기합니다.
- 버튼 문구와 보상 화면에 추가 보상 암시가 없습니다.
- 누르지 않아도 손해처럼 느껴지지 않습니다.

#### 9일: 우선 처치 첫 확인

침묵 운반자는 소량만 등장합니다.

이 날의 목표는 강한 방해가 아니라, 먼저 잡아야 하는 적을 눈으로 읽게 하는 것입니다.

성공 기준:

- 침묵 운반자에게 명확한 아이콘과 예고가 있습니다.
- 드로우 방해가 발생해도 원인을 이해할 수 있습니다.
- 겹치기 상태에서는 위험도가 높다는 UI 경고가 뜹니다.

#### 10일: 침묵의 거상

첫 보스는 체력 싸움이 아니라 접근을 늦추는 싸움입니다.

보스전 중 일반 웨이브는 아주 약하게 두거나, 첫 테스트에서는 생략해도 됩니다.

성공 기준:

- 플레이어가 다리부 또는 핵심 부위를 공격합니다.
- 구조물로 보스 이동 시간을 벌 수 있습니다.
- 보스가 기지에 가까워질수록 화면과 사운드가 무거워집니다.
- 보스전 웨이브 겹치기는 첫 테스트에서 권장하지 않습니다.

### 인원수별 10일 적용

| 인원수 | 1~10일 방향 적용 |
| ---: | --- |
| 1명 | 모든 웨이브가 동쪽으로 대체됩니다. 북쪽, 서쪽, 남쪽 예고는 표시하지 않습니다. |
| 2명 | 동쪽과 북쪽만 사용합니다. 서쪽 선호 웨이브는 동쪽 돌파 압박으로 대체합니다. |
| 3명 | 3일부터 서쪽 빠른 압박을 사용할 수 있습니다. 남쪽은 사용하지 않습니다. |
| 4명 | 네 방향이 활성화되어 있지만 10일 테스트에서는 1~2방향 압박을 기본으로 합니다. 남쪽은 8일 안정 웨이브에서만 가볍게 보여줄 수 있습니다. |

4인이라고 해서 초반부터 사방 동시 압박을 쓰지 않습니다.

사방이 열려 있다는 사실과, 사방에서 동시에 몰려오는 고난도 상황은 분리합니다.

### 10일 테스트에서 미루는 요소

아래 요소는 11일 이후로 미룹니다.

- 유리 껍질
- 검은 등짐
- 무거운 순례자
- 강한 정예형
- 남쪽 킬존 전용 웨이브
- 3방향 이상 동시 압박
- 보스전 중 강한 돌파형 동반

첫 10일은 콘텐츠 양보다 규칙 이해가 중요합니다.

## 20일 MVP 확장 웨이브 레시피

11~20일은 첫 보스 후 고른 아티팩트와 상점 선택이 바로 의미를 갖는 구간입니다.

이 구간의 핵심 문장:

```text
이제 한 가지 정답 빌드만으로는 모든 압박을 해결할 수 없습니다.
```

11~20일은 새 규칙을 많이 넣기보다, 1~10일에 배운 방어선을 저항형과 방해형으로 흔듭니다.

### 11~20일 상세 진행표

### 날짜별 의도

#### 11일: 유리 껍질 첫 등장

11일은 첫 보스 후 성장 선택을 바로 시험합니다.

유리 껍질은 광역 피해를 덜 받지만 단일 집중 피해에 약합니다.

목표는 원소술사나 광역 킬존이 약해졌다는 느낌이 아니라, "이번 적은 집중 사격으로 풀어야 한다"는 판단을 주는 것입니다.

성공 기준:

- 플레이어가 유리 껍질의 외피 표시를 알아봅니다.
- 광역으로 시간이 오래 걸리는 이유를 이해합니다.
- 집중 사격, 도발 고정, 단일 강화 타워 중 하나로 대응합니다.

#### 12일: 성장 체감

12일은 쉬운 회복 웨이브입니다.

10일 보상, 아티팩트, 상점 선택이 실제로 강해졌다는 느낌을 줍니다.

주의:

- 회복 웨이브는 공짜 보상이 아닙니다.
- 너무 길면 지루하고, 너무 강하면 10일 보상 선택이 무의미해집니다.

#### 13일: 침묵 운반자 재확인

침묵 운반자는 9일에 이미 소량 등장했습니다.

13일은 첫 등장이 아니라, 방해형을 실제 조합 안에서 먼저 잡아야 하는지 묻는 날입니다.

성공 기준:

- 침묵 운반자의 방해 범위가 명확하게 보입니다.
- 방해를 방치하면 드로우 템포가 느려집니다.
- 처치 후 자원 흐름이 회복되는 것이 보입니다.

#### 14일: 빠른 적과 저항형 조합

틈새 주자와 유리 껍질을 함께 넣습니다.

목표는 화력 부족이 아니라 화력 배분입니다.

성공 기준:

- 빠른 적은 먼저 새지 않게 잡습니다.
- 유리 껍질은 단일 집중으로 천천히 녹입니다.
- 한 방향 전체가 무너지기 전에 우선순위를 말로 공유합니다.

#### 15일: 이벤트와 상점

15일은 어려운 전투가 아니라 운영 방향을 다시 고르는 날입니다.

추천 이벤트:

- 갈라진 저장고
- 무너진 공방
- 묻힌 지도

상점은 5~6개 항목만 보여줍니다.

첫 보스 후 상점보다 작아야 합니다.

#### 16일: 두 방향 저항 압박

2인 이상에서 2방향 압박을 본격적으로 사용합니다.

1인은 동쪽 안에서 두 타이밍 압박으로 대체합니다.

성공 기준:

- 2인 이상은 북쪽과 동쪽을 나누어 봅니다.
- 3~4인은 서쪽 빠른 라인을 보조 압박으로 의식합니다.
- 남쪽은 4인에서도 아직 가벼운 보조 역할만 합니다.

#### 17일: 구조물 압박 재검증

10일 보스 이후 플레이어는 구조물을 더 믿게 됩니다.

17일은 그 믿음을 균열 망치로 다시 묻습니다.

성공 기준:

- 강화한 구조물이 실제로 오래 버팁니다.
- 하지만 모든 구조물을 지킬 수는 없습니다.
- 건축가와 땜장이의 판단이 전투 결과에 보입니다.

#### 18일: 웨이브 겹치기 선택 압박

8일은 겹치기 기능을 배우는 날이었습니다.

18일은 겹치기를 누를지 말지 판단하는 날입니다.

보상 증가를 암시하지 않고, 다음 웨이브 예고와 현재 방어선 안정성을 보고 판단하게 만듭니다.

성공 기준:

- 안정 상태에서는 겹치기를 누르고 싶습니다.
- 방해형이 남아 있으면 겹치기가 위험해 보입니다.
- 누르지 않아도 손해처럼 보이지 않습니다.

#### 19일: 정예 예고

정예를 본격 투입하기 전 예고형 압박을 사용합니다.

검은 등짐을 바로 강한 정예로 쓰지 않고, 약한 예고형 또는 지원형으로 보여줍니다.

#### 20일: 침묵의 거상 변형

20일 보스는 10일 보스를 완전히 새 보스로 바꾸지 않습니다.

반복 보스 규칙에 따라 아래 중 하나만 추가합니다.

- 등불부 효과가 조금 일찍 켜집니다.
- 전면부 짓누르기 예고 시간이 짧아집니다.
- 아주 약한 일반 웨이브가 보스 중간에 1회 동반됩니다.

첫 변형 보스에서는 새 부위와 새 패턴을 동시에 추가하지 않습니다.

### 날짜별 의도

#### 21일: 검은 등짐 첫 등장

검은 등짐은 정예형 첫 본격 투입입니다.

사망 시 주변 적의 속도를 잠시 높이므로, 무조건 가장 먼저 죽이는 것이 항상 정답은 아닙니다.

성공 기준:

- 파티가 검은 등짐을 언제 죽일지 짧게 이야기합니다.
- 주변 적이 너무 많을 때 처치하면 위험해진다는 것을 이해합니다.
- 정예는 체력만 높은 적이 아니라 타이밍 질문이라는 인상을 줍니다.

#### 22일: 킬존 재설계

21일의 정예 타이밍 이후, 22일은 방어선 모양을 다시 보게 만듭니다.

4인에서는 남쪽 킬존 성격을 가볍게 보여줄 수 있지만, 1~3인에서는 활성 방향 안에서 대체합니다.

성공 기준:

- 기존 킬존을 그대로 쓰지 않고 방향 성격에 맞춰 조정합니다.
- 유리 껍질 때문에 광역만으로 끝나지 않습니다.
- 남쪽이 비활성인 인원수에서는 남쪽 예고를 표시하지 않습니다.

#### 23일: 뒤틀린 표식 첫 등장

뒤틀린 표식은 도발 의존 방어선을 흔드는 지원형입니다.

수호자를 약하게 만드는 것이 아니라, 도발만으로 모든 문제를 해결할 수 없게 만드는 역할입니다.

성공 기준:

- 뒤틀린 표식 주변 적이 도발에 덜 끌리는 이유를 UI로 이해합니다.
- 표식 자체는 약하지만, 방치하면 라인이 흔들립니다.
- 수호자도 집중 사격, 경로 조정, 다른 직업 도움을 요청하게 됩니다.

#### 24일: 빠른 라인 분산 압박

24일은 서쪽 빠른 압박과 동쪽 짧은 압박을 함께 보는 날입니다.

1~2인은 활성 방향 제한 때문에 서쪽 압박을 동쪽 또는 북쪽의 빠른 타이밍으로 대체합니다.

성공 기준:

- 빠른 적이 새기 전에 누가 볼지 정합니다.
- 방해형을 방치하면 손패 흐름이 막힙니다.
- 3~4인에서는 순회 지원 역할이 자연스럽게 생깁니다.

#### 25일: 계절 전환 선택

25일은 계절 전환입니다.

전투는 너무 어렵지 않게 두고, 선택이 중요하게 느껴지게 합니다.

선택 후보:

- 기지 체력 소량 회복
- 카드 1장 강화
- 공용 카드 1장 제거 비용 할인
- 다음 3일 동안 시드 마나 +1

계절 전환 보상은 보스 보상보다 작아야 합니다.

#### 26일: 여름 속도 예고

26일부터 여름입니다.

MVP에서는 새 여름 전용 적을 많이 추가하지 않고, 틈새 주자의 배치와 스폰 간격으로 빠른 템포를 먼저 보여줍니다.

성공 기준:

- 플레이어가 "여름은 더 빨리 온다"고 느낍니다.
- 새 규칙 설명 없이도 스폰 간격과 방향 예고로 압박을 이해합니다.
- 구조물 파괴보다 빠른 라인 보강이 우선됩니다.

### 낙엽 타일 기본 규칙

낙엽 타일은 적 경로 비용을 바꾸는 계절 타일입니다.

플레이어가 갑자기 당했다는 느낌을 받지 않도록, 낙엽 위치와 변화 타이밍은 전투 시작 전에 예고합니다.

| 항목 | 기본값 |
| --- | ---: |
| 하루 시작 낙엽 타일 수 | 활성 방향당 1~2개 |
| 웨이브 중 변화 횟수 | 최대 1회 |
| 경로 비용 변화 | 보통에서 높음으로 변화 |
| 낙엽 위 적 이동 속도 | -10% |
| 가을 잔해 지속 시간 | +50% |

낙엽 타일은 무작위 함정이 아닙니다.

적이 낙엽 타일을 피하면 기존 킬존을 비껴갈 수 있고, 낙엽 타일을 지나가면 조금 느려집니다.

즉 플레이어는 "우회하게 둘 것인가, 느려진 길에서 잡을 것인가"를 고릅니다.

낙엽 타일과 오래 남는 잔해는 비활성 방향을 열지 않습니다.

잔해와 낙엽 때문에 모든 경로가 막힐 경우, 가장 오래된 잔해가 `밟힌 잔해`로 바뀌어 약한 둔화 타일이 되고 경로를 다시 엽니다.

### 날짜별 의도

#### 51일: 낙엽 타일 첫 학습

51일은 가을의 첫날입니다.

새 적보다 새 타일을 먼저 보여줍니다.

성공 기준:

- 낙엽 위치와 변화 타이밍이 전투 전에 보입니다.
- 적이 낙엽을 피하거나 밟는 이유가 경로 표시로 이해됩니다.
- 플레이어가 킬존을 한 칸이라도 옮겨 봅니다.

#### 52일: 가을의 묵자 첫 등장

가을의 묵자는 주변 처치의 마나 게이지 충전량을 낮추는 방해형 적입니다.

침묵 운반자가 드로우 흐름을 흔들었다면, 가을의 묵자는 마나 대응 타이밍을 늦춥니다.

성공 기준:

- 묵자의 영향 범위가 UI로 표시됩니다.
- 마나가 막히는 이유가 적 오라로 보입니다.
- 플레이어가 방해형을 우선 처치할지, 경로 재설계를 먼저 할지 토론합니다.

#### 53일: 오래 남는 잔해

53일은 여름의 파괴 판단을 가을식 경로 판단으로 바꿉니다.

구조물이 파괴된 자리에 남은 잔해가 조금 더 오래 유지되어, 적 경로와 킬존 위치에 영향을 줍니다.

성공 기준:

- 잔해가 완전 길막이 아니라 임시 경로 비용으로 보입니다.
- 가장 오래된 잔해가 밟힌 잔해로 바뀌어 길을 다시 여는 규칙을 이해합니다.
- 건축가가 잔해를 공격 자원뿐 아니라 경로 자원으로 사용합니다.

#### 54일: 낙엽 우회 경로

54일은 낙엽 변화가 실제로 킬존을 비껴가게 만드는 날입니다.

다만 예고 없이 방향을 바꾸지 않습니다.

성공 기준:

- 변경될 낙엽 타일이 미리 강조됩니다.
- 플레이어가 주 화력 위치를 옮기거나 보조 킬존을 준비합니다.
- 1인은 동쪽 안에서만 우회 경로를 봅니다.

#### 55일: 무너진 길 상점

55일은 작은 정비 구간입니다.

상점 후보:

- 다음 5일 동안 잔해 지속 시간 감소
- 낙엽 변화 예고 시간 증가
- 수리 효율 보정
- 방해형 영향 범위 감소
- 카드 제거

이 상점은 가을을 쉽게 넘기는 보상이 아니라, 어떤 불편을 줄일지 고르는 운영 선택입니다.

#### 56일: 오라 분산 시험

56일은 60일 보스의 예고입니다.

땜장이 오라와 주요 타워를 한곳에 모두 몰아두면, 방해형 오라와 경로 변화에 함께 흔들립니다.

성공 기준:

- 오라 밀집 배치가 강하지만 위험하다는 것을 봅니다.
- 두 번째 작은 화력 지점을 만드는 선택이 의미 있습니다.
- 땜장이가 모든 구조물을 한 번에 살릴 수 없습니다.

#### 57일: 경로 변화 중 겹치기

57일은 웨이브 겹치기 자체보다 경로 변화가 예정된 상태에서 겹치기를 누를지 묻습니다.

보상 증가는 없습니다.

성공 기준:

- UI가 "낙엽 변화 예정"과 "겹치기 위험"을 함께 보여줍니다.
- 안정적인 보조 킬존이 있으면 빠른 진행을 선택할 수 있습니다.
- 손상된 방어선만 있는 상태라면 쉬어가는 선택이 자연스럽습니다.

#### 58일: 이동하는 킬존

58일은 남쪽 킬존 성격을 활용할 수 있는 날이지만, 남쪽이 비활성인 런에서는 활성 방향 안의 굴곡 경로로 대체합니다.

성공 기준:

- 킬존을 한곳에 고정하지 않습니다.
- 잔해 둔화와 낙엽 우회를 함께 읽습니다.
- 뒤틀린 표식이 도발 의존을 흔들어도 경로 판단이 남습니다.

#### 59일: 가을 1장 총정리

59일은 새 요소를 넣지 않습니다.

낙엽 타일, 오래 남는 잔해, 가을의 묵자, 뒤틀린 표식을 조합합니다.

성공 기준:

- 플레이어가 다음 경로 변화를 말로 예측합니다.
- 오라를 분산할지 밀집할지 합의합니다.
- 60일 보스 전에 수리와 오라 의존을 재점검합니다.

#### 60일: 무너진 종탑

60일 보스는 가을 1장의 결산입니다.

핵심은 오라와 수리를 금지하는 것이 아니라, 예고된 약화 권역을 보고 방어선을 분산하는 것입니다.

### 51~60일 금지선

- 낙엽 타일이 예고 없이 경로를 바꾸지 않습니다.
- 낙엽이나 잔해가 완전 길막을 만들지 않습니다.
- 비활성 방향에 낙엽 타일, 잔해 압박, 일반 웨이브를 만들지 않습니다.
- 가을의 묵자가 마나 사용을 완전히 봉쇄하지 않습니다.
- 방해형 효과를 여러 개 겹쳐 손패와 마나를 동시에 막지 않습니다.
- 1인에게 두 방향 재설계를 요구하지 않습니다.
- 웨이브 겹치기에 보상 증가를 붙이지 않습니다.
- 60일 보스가 오라와 수리를 0으로 만들지 않습니다.


### 우선순위 조합 기본 규칙

61~70일은 신규 적을 늘리지 않고 기존 적의 조합과 스폰 순서로 난도를 올립니다.

주요 조합:

| 조합 | 묻는 질문 | 주의점 |
| --- | --- | --- |
| 가을의 묵자 + 검은 등짐 | 자원 방해를 먼저 끊을지, 정예 처치 타이밍을 먼저 볼지 | 두 적을 동시에 대량 투입하지 않습니다. |
| 침묵 운반자 + 가을의 묵자 | 드로우와 마나 중 어느 흐름을 먼저 회복할지 | 손패와 마나를 동시에 완전 봉쇄하지 않습니다. |

| 오래 남는 잔해 + 무거운 순례자 | 둔화된 경로에서 지속 화력을 유지할 수 있는가 | 체력만 높은 장벽으로 만들지 않습니다. |

정예는 단순히 체력이 높은 적이 아닙니다.

정예는 파티가 동시에 보고 "지금 자를까, 조금 더 묶어둘까"를 말하게 만드는 타이밍 질문입니다.

### 날짜별 의도

#### 61일: 종탑 후 재배치

61일은 60일 보스 이후 방어선을 복구하는 날입니다.

새 적을 넣지 않고, 무음 권역을 겪은 뒤 오라와 수리 위치를 다시 보게 합니다.

성공 기준:

- 플레이어가 오라 장치를 한곳에 몰아두지 않습니다.
- 낙엽 변화와 잔해 위치를 보고 새 보조 킬존을 준비합니다.
- 65일 상점 전까지 부족한 대응 방향을 말로 설명합니다.

#### 62일: 방해형 + 정예 우선순위

62일은 가을 2장의 핵심 질문을 처음 던집니다.

가을의 묵자는 마나 대응을 늦추고, 검은 등짐은 처치 타이밍을 흔듭니다.

성공 기준:

- 두 적의 위험이 UI로 구분됩니다.
- 플레이어가 어느 적을 먼저 자를지 합의합니다.
- 실패 시 "자원 방해를 방치했다" 또는 "정예 처치 타이밍을 놓쳤다"가 원인으로 보입니다.

#### 63일: 후미 정예 압박

63일은 정예를 앞에 세우지 않고 일반 무리 뒤에 숨겨 둡니다.

숨긴다는 것은 예고 없이 속이는 것이 아니라, 스폰 순서를 읽게 만든다는 뜻입니다.

성공 기준:

- 예고 UI가 후미 정예를 표시합니다.
- 광역으로 일반 무리를 정리한 뒤 정예 집중 시간이 남습니다.
- 빠른 동쪽 라인에서도 조작 부담이 과하지 않습니다.

#### 64일: 낙엽 교차 압박

64일은 경로 변화와 자원 방해를 동시에 묻습니다.

낙엽 변화로 킬존 위치가 살짝 어긋나고, 묵자가 마나 대응을 늦춥니다.

성공 기준:

- 변경될 경로와 묵자 오라가 모두 전투 전에 보입니다.
- 플레이어가 카드를 아낄지, 미리 써서 라인을 안정화할지 선택합니다.
- 방해형 효과가 손패와 마나를 동시에 완전히 막지 않습니다.

#### 65일: 수확 상점

65일은 작은 정비 구간입니다.

상점 후보:

- 정예 대상 피해 증가 카드
- 방해형 영향 범위 감소
- 낙엽 변화 예고 시간 증가
- 잔해 정리 비용 감소
- 카드 제거

이 상점은 정답 구매가 아니라, 어떤 우선순위 문제를 덜 위험하게 만들지 고르는 선택입니다.

#### 66일: 분산 우선순위

66일은 2인 이상에서 두 방향에 서로 다른 위험을 둡니다.

한쪽은 묵자, 다른 한쪽은 검은 등짐을 배치해 파티가 분담할지 한쪽을 먼저 도울지 정하게 합니다.

성공 기준:

- 1인은 동쪽 안에서 시간차 압박으로 대체합니다.
- 2인은 북쪽/동쪽 안에서만 분담합니다.
- 3~4인은 순회 지원 플레이어가 의미를 가집니다.

#### 67일: 침묵 속 겹치기

67일은 방해형이 살아 있는 상태에서 웨이브 겹치기를 누르는 위험을 묻습니다.

보상 증가는 없습니다.

성공 기준:

- UI가 남은 방해형과 겹치기 위험을 함께 보여줍니다.
- 방어선이 안정적이면 빠른 진행을 선택할 수 있습니다.
- 자원 흐름이 막힌 상태라면 쉬어가는 선택이 자연스럽습니다.

#### 68일: 잔해 정예 라인

68일은 오래 남는 잔해와 무거운 순례자를 결합합니다.

잔해가 적을 늦추지만, 정예가 오래 살아남아 지속 화력 검증이 됩니다.

성공 기준:

- 잔해가 적을 잡아두는 시간으로 보입니다.
- 무거운 순례자를 체력만 높은 적처럼 느끼지 않습니다.
- 원소술사와 수호자의 군중 제어가 완전 무효처럼 느껴지지 않습니다.

#### 69일: 가을 2장 총정리

69일은 새 요소를 넣지 않습니다.

가을의 묵자, 검은 등짐, 뒤틀린 표식, 낙엽 변화, 오래 남는 잔해를 조합합니다.

성공 기준:

- 플레이어가 우선 처치 대상을 말로 정합니다.
- 다음 낙엽 변화와 정예 스폰 순서를 함께 읽습니다.
- 70일 보스 전에 오라 분산과 정예 대응을 재점검합니다.

#### 70일: 무너진 종탑 변형

70일 보스는 60일 보스에 새 부위나 새 패턴을 동시에 추가하지 않습니다.

반복 보스 규칙에 따라 동반 웨이브 조합 변화만 사용합니다.

## 겨울 1장 웨이브 레시피: 71~80일

71~80일은 공간 축소를 처음으로 본격 학습하는 구간입니다.

71~75일은 25일 계절 구조상 가을의 마지막이지만, 겨울 전조로 외곽 결빙을 약하게 보여줍니다.

76일부터 겨울 규칙이 본격 작동합니다.

```text
겨울은 적을 빠르게 몰아치는 계절이 아니라, 플레이어가 쓸 수 있는 좋은 자리를 천천히 줄이는 계절입니다.
```

### 얼어붙은 외곽 기본 규칙

얼어붙은 외곽은 외곽 설치 구역에 생기는 계절 타일입니다.

새 구조물을 설치할 수 없지만, 이미 설치된 구조물은 즉시 사라지지 않습니다.

| 항목 | 기본값 |
| --- | ---: |
| 71~75일 하루 시작 결빙 수 | 활성 방향당 0~1개 |
| 76일 이후 하루 시작 결빙 수 | 활성 방향당 1~2개 |
| 웨이브 중 추가 결빙 | 최대 1회 |
| 결빙 예고 | 준비 단계 시작 전 표시 |
| 새 구조물 설치 | 불가 |
| 기존 구조물 공격 속도 | -15% |
| 기존 구조물 수리 효율 | -20% |

얼어붙은 외곽은 경로 타일을 막지 않습니다.

적이 기지까지 가는 길을 차단하지 않고, 플레이어의 설치 선택지를 줄이는 역할만 합니다.

비활성 방향에는 결빙 예고, 결빙 타일, 결빙 압박을 만들지 않습니다.

### 겨울 껍질 기본 규칙

겨울 껍질은 72일에 처음 등장하는 느린 저항형 적입니다.

체력만 큰 벽이 아니라, 좁아진 공간에서 지속 화력과 군중 제어 유지가 충분한지 묻는 적입니다.

기본 성격:

- 이동 속도는 낮습니다.
- 넉백과 짧은 기절 효과를 약하게 받습니다.
- 둔화와 지속 피해는 정상적으로 의미가 있습니다.
- 처치 시 주변 결빙을 제거하지 않습니다.

겨울 껍질을 보상 타겟으로 만들지 않습니다.

죽이면 특별 보상이 더 나오는 적이 아니라, 공간 압박을 버틸 수 있는지 확인하는 테스트입니다.

### 날짜별 의도

#### 72일: 겨울 껍질 첫 등장

겨울 껍질은 빠른 대응보다 지속 화력 유지가 중요한 적입니다.

성공 기준:

- 둔화와 지속 피해가 의미 있습니다.
- 넉백과 짧은 기절이 완전 무효처럼 느껴지지 않습니다.

#### 73일: 좁아진 방어선

73일은 외곽 설치 공간이 줄어들 때 보조 킬존을 어디에 만들지 묻습니다.

성공 기준:

- 플레이어가 기존 외곽 타워에만 의존하지 않습니다.
- 안쪽 설치 구역의 가치가 올라갑니다.
- 결빙이 비활성 방향에 생기지 않습니다.

#### 74일: 느린 압박 라인

74일은 무거운 순례자와 겨울 껍질을 조합합니다.

목표는 체력 벽을 세우는 것이 아니라, 줄어든 공간에서 지속 화력이 충분한지 보는 것입니다.

성공 기준:

- 대형 적이 기지에 천천히 다가오는 압박이 보입니다.
- 플레이어가 둔화, 도발, 잔해, 오라 위치를 함께 조정합니다.
- 빠른 적 대량 투입으로 조작 피로를 올리지 않습니다.

#### 75일: 계절 전환 정비

75일은 계절 전환 정비입니다.

상점 후보:

- 다음 5일 동안 결빙 예고 시간 증가
- 구조물 1개 위치 이전
- 결빙 예정 타일 1개 해동
- 대형 적 대상 피해 카드
- 카드 제거

75일 선택은 겨울을 없애는 보상이 아니라, 어떤 공간 압박을 덜 위험하게 만들지 고르는 운영 선택입니다.

#### 76일: 겨울 본격화

76일부터 겨울 규칙이 본격 작동합니다.

활성 방향별 결빙 수가 증가하고, 결빙 예고를 보고 설치 계획을 세워야 합니다.

```text
수리와 버릴 바리케이드가 시간을 벌 수 있습니다.
```

나쁜 대응 카드:

```text
건축가가 3번 타일에 바리케이드를 설치해야 합니다.
```

## 웨이브 겹치기 친화도

각 웨이브는 겹쳤을 때 얼마나 위험한지 기록합니다.

| 등급 | 의미 | 예시 |
| --- | --- | --- |
| 낮음 | 겹쳐도 큰 변수가 적습니다. | 회색 행렬 중심 |
| 중간 | 겹치면 밀도가 올라가지만 읽을 수 있습니다. | 군집형 + 파괴형 소량 |
| 높음 | 겹치면 방어선 붕괴 위험이 큽니다. | 돌파형 + 방해형 |
| 금지 | 보스 패턴 학습이나 튜토리얼 중 겹치기 비권장 | 첫 보스 부위 학습 |

친화도는 보상과 관계없습니다.

이 값은 UI 경고와 테스트 분석을 위한 값입니다.

예시:

```text
겹치기 위험: 높음
이유: 활성 방향 중 빠른 라인 돌파형과 킬존 라인 방해형이 동시에 들어오면 손패 대응이 늦어질 수 있음
```

## 금지 웨이브

아래 웨이브는 만들지 않습니다.

- 보상 증가를 전제로 설계된 웨이브
- 웨이브 겹치기를 누르지 않으면 손해인 웨이브
- 특정 직업이 없으면 불가능한 웨이브
- 예고 없는 방해형 대량 웨이브
- 초반 다방향 돌파형 대량 웨이브
- 보스 패턴 학습 중 시야를 가리는 군집 웨이브
