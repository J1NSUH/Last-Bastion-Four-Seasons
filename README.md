# Last Bastion: Four Seasons

**Last Bastion: Four Seasons**는 솔로부터 최대 4인 협동까지 즐길 수 있는 **비대칭 턴제 오토배틀러 로그라이트**입니다.

플레이어는 용사, 대장장이, 성직자 중 하나를 선택해 마지막 국가를 지킵니다. 봄, 여름, 가을, 겨울이 지날수록 동서남북에서 몬스터가 몰려오고, 플레이어는 카드와 에너지를 사용해 침공을 막아야 합니다.

> 선택은 단순하게, 결과는 크게 터지게.

## 핵심 컨셉

- 한 런은 사계절 동안 진행됩니다.
- 각 턴마다 손패를 받고, 에너지 안에서 여러 카드를 사용합니다.
- 몬스터는 동서남북 전선에서 국가를 향해 한 칸씩 전진합니다.
- 전투는 자동으로 처리됩니다.
- 몬스터를 막지 못하면 성 안으로 흘러들어갑니다.
- 일정 수 이상 몬스터를 흘리면 루프가 리셋됩니다.
- 겨울 최종 보스를 막아내면 런을 클리어합니다.

## 장르

- 솔로 / 최대 4인 협동
- 턴제 전략
- 카드 기반 덱빌딩
- 오토배틀러
- 타워 디펜스
- 로그라이트

## 한 줄 소개

동서남북에서 다가오는 몬스터를 막기 위해, 용사는 밖으로 출격하고, 대장장이는 타워를 만들고, 성직자는 국가에 축복을 내리는 사계절 루프 덱빌딩 로그라이트.

## 기본 자원

게임에서 관리하는 핵심 자원은 단순하게 유지합니다.

| 자원 | 설명 |
| --- | --- |
| 누수 한도 | 이 수만큼 몬스터를 흘리면 런 실패 |
| 재료 | 타워, 장비, 카드 강화에 사용 |
| 시간 결정 | 루프 이후에도 남는 영구 성장 자원 |

이 게임에는 국가 HP가 없습니다. 몬스터를 막지 못하면 피해량을 계산하는 대신 그대로 성 안으로 흘러들어가고, 흘린 몬스터 수가 누수 한도에 도달하면 패배합니다.

```text
흘린 몬스터: 3 / 10
```

## 누수 규칙

기본 몬스터는 1마리당 누수 1을 발생시킵니다. 강한 몬스터는 더 큰 누수값을 가집니다.

| 몬스터 종류 | 누수값 |
| --- | ---: |
| 잡몹 | 1 |
| 빠른 몬스터 | 1 |
| 정예 몬스터 | 2 |
| 거대 몬스터 | 3 |
| 계절 보스 | 4~5 |
| 최종 보스 | 흘리면 즉시 패배 |

누수 한도는 난이도에 따라 달라질 수 있습니다.

- 쉬움: 15
- 기본: 10
- 어려움: 7
- 지옥: 5

## 동서남북 전선

국가는 네 방향에서 공격받습니다.

| 전선 | 특징 |
| --- | --- |
| 북부 | 느리지만 강한 몬스터가 등장 |
| 동부 | 보상과 이벤트가 많은 변칙 전선 |
| 남부 | 독, 저주, 지속 피해 몬스터가 등장 |
| 서부 | 빠르고 위험하지만 보상이 큰 전선 |

각 전선은 3칸짜리 침공 트랙을 가집니다.

```text
[먼 곳] -> [가까움] -> [성문]
```

매 턴 몬스터는 국가를 향해 한 칸씩 전진합니다.

- 먼 곳: 용사가 미리 처리하기 좋은 위치
- 가까움: 다음 턴 위험해지는 위치
- 성문: 타워와 축복으로 막아야 하는 위치

성문에 도착한 몬스터를 막지 못하면 누수가 발생합니다.

## 인원별 진행

| 인원 | 진행 방식 |
| --- | --- |
| 1인 | 한 직업과 한 방향 전선으로 솔로 루프 진행 |
| 2인 | 두 방향 전선 개방 |
| 3인 | 세 방향 전선 개방 |
| 4인 | 동서남북 모든 전선 개방 |

인원이 늘어날수록 단순히 몬스터 수만 늘어나는 것이 아니라, 관리해야 할 전선이 늘어납니다. 각 플레이어는 한 직업과 한 방향을 중심으로 판단합니다.

## 카드와 에너지

매 턴 각 플레이어는 자신의 직업 덱에서 카드를 뽑고, 에너지 안에서 원하는 만큼 카드를 사용합니다.

기본 규칙:

- 매 턴 카드 5장 드로우
- 기본 에너지 3
- 카드는 0~3 비용을 가짐
- 사용한 카드는 버림 더미로 이동
- 전투 후 카드, 강화, 유물, 재료 중 보상 선택

이 구조 덕분에 매 턴 행동 하나만 고르는 것이 아니라, 여러 카드를 조합해 콤보를 만들 수 있습니다.

## 플레이어 직업

### 용사

용사는 국가 밖으로 출격해 몬스터가 성문에 도착하기 전에 처리하는 직업입니다.

용사의 카드는 요격, 돌진, 정예 사냥, 전리품 획득처럼 직접 전선을 줄이는 효과를 가집니다.

카드 예시:

- **요격** `1코스트`: 가까움 칸의 몬스터 1마리에게 피해
- **돌진** `2코스트`: 먼 곳 칸의 몬스터도 공격 가능
- **방패 올리기** `1코스트`: 이번 전투에서 용사가 받는 피해 감소
- **정예 사냥** `2코스트`: 정예 몬스터에게 큰 피해
- **전리품 회수** `0코스트`: 이번 턴 처치한 몬스터가 재료를 추가 드랍
- **필사의 일격** `3코스트`: 큰 피해를 주지만 다음 턴 손패 감소

용사의 재미는 위험한 몬스터가 성문에 도착하기 전에 잘라내고, 큰 보상을 노리는 데 있습니다.

### 대장장이

대장장이는 국가 안에서 타워와 방어 장치를 제작하는 직업입니다.

대장장이의 카드는 포탑 설치, 포탑 강화, 폭발 함정처럼 성문에 도착한 몬스터를 한 번에 처리하는 효과를 가집니다.

카드 예시:

- **포탑 설치** `1코스트`: 선택한 전선 성문에 기본 포탑 설치
- **포탑 강화** `1코스트`: 선택한 포탑의 공격력 증가
- **폭발 함정** `2코스트`: 성문에 도착한 몬스터 무리에게 광역 피해
- **긴급 수리** `1코스트`: 이번 턴 누수 1 감소
- **과열** `0코스트`: 다음 제작 카드 효과 증가, 대신 이번 턴 추가 카드 드로우 불가
- **자동 망치** `2코스트`: 성문 몬스터에게 반복 피해

대장장이의 재미는 재료를 모아 강한 방어선을 만들고, 몬스터 무리를 한 번에 터뜨리는 데 있습니다.

### 성직자

성직자는 국가와 전선을 강화하는 버퍼 직업입니다.

성직자의 카드는 피해를 줄이거나, 누수를 막거나, 타워와 용사의 효과를 증폭시키는 방향으로 구성됩니다.

카드 예시:

- **공격 축복** `1코스트`: 이번 턴 선택한 전선의 피해량 증가
- **보호 결계** `1코스트`: 이번 턴 발생하는 누수 2 감소
- **회복 기도** `1코스트`: 누수 한도 +1
- **정화** `1코스트`: 독, 저주, 약화 효과 제거
- **성스러운 종소리** `2코스트`: 모든 전선의 몬스터 전진을 1턴 지연
- **최후의 기적** `3코스트`: 이번 턴 첫 누수를 전부 무효화

성직자는 직접 몬스터를 잡지는 않지만, 한 번의 축복으로 전투 결과를 크게 바꿀 수 있습니다.

## 한 턴 흐름

1. **예고**  
   이번 턴 등장할 몬스터와 위험한 전선이 공개됩니다.

2. **드로우**  
   각 플레이어가 카드 5장을 뽑고 에너지 3을 받습니다.

3. **카드 사용**  
   플레이어들은 에너지 안에서 원하는 만큼 카드를 사용합니다.

4. **자동 처리**  
   용사의 공격, 대장장이의 타워, 성직자의 축복이 자동으로 처리됩니다.

5. **몬스터 전진**  
   살아남은 몬스터가 한 칸씩 국가 쪽으로 이동합니다.

6. **성문 전투**  
   성문에 도착한 몬스터와 방어 시설이 자동전투를 합니다.

7. **누수 계산**  
   막지 못한 몬스터가 누수로 기록됩니다.

8. **보상 선택**  
   카드 3장 중 1장, 재료, 강화, 유물 중 보상을 선택합니다.

## 사계절 진행

한 런은 봄, 여름, 가을, 겨울로 구성됩니다.

| 계절 | 역할 |
| --- | --- |
| 봄 | 기본 몬스터, 초반 덱 구성 |
| 여름 | 속성 몬스터와 희귀 재료 등장 |
| 가을 | 여러 전선 압박, 정예 몬스터 등장 |
| 겨울 | 최종 침공, 보스전 |

기본 런은 계절당 4턴으로 구성됩니다.

```text
봄 4턴 -> 여름 4턴 -> 가을 4턴 -> 겨울 4턴 -> 최종 보스
```

MVP에서는 계절당 2턴으로 줄여 빠르게 테스트합니다.

```text
봄 2턴 -> 여름 2턴 -> 가을 2턴 -> 겨울 2턴 -> 최종 보스
```

## 도파민 포인트

이 게임은 복잡한 관리보다 빠른 선택과 큰 결과를 목표로 합니다.

- 용사가 둥지를 부수면 다음 웨이브가 통째로 줄어듭니다.
- 대장장이가 강화한 포탑이 몬스터 무리를 한 번에 터뜨립니다.
- 성직자의 축복으로 모든 타워가 동시에 강화됩니다.
- 보호 결계로 새어 나가던 몬스터 무리를 한 번에 무효화합니다.
- 희귀 재료를 얻으면 전설 타워나 강력한 축복이 열립니다.
- 겨울 보스를 막아내면 큰 영구 보상이 해금됩니다.

## 승리와 패배

승리 조건:

- 겨울 최종 보스를 막아내고 누수 한도에 도달하지 않습니다.

패배 조건:

- 흘린 몬스터 수가 누수 한도에 도달합니다.
- 최종 보스가 성 안으로 들어옵니다.

패배하면 시간은 봄 첫 턴으로 되돌아갑니다. 하지만 시간 결정, 해금된 카드, 축복, 몬스터 정보는 유지됩니다.

## 로그라이트 성장

런이 끝나면 일부 성장 요소가 남습니다.

- 새 카드 해금
- 새 타워 해금
- 새 축복 해금
- 용사 무기 해금
- 시작 재료 증가
- 누수 한도 증가
- 시간 결정 보관량 증가
- 몬스터 도감 정보 유지

실패해도 다음 루프에서는 더 강한 선택지로 다시 도전할 수 있습니다.

첫 번째 목표는 작고 빠른 버전으로 핵심 재미를 확인하는 것입니다.

포함할 요소:

- 용사 솔로 모드
- 대장장이 솔로 모드
- 성직자 솔로 모드

- 자동전투
- 몬스터 6종

## 프로젝트 방향성

**Last Bastion: Four Seasons**는 복잡한 시뮬레이션보다 빠른 판단과 큰 보상감을 목표로 합니다.

매 턴 핵심 질문은 단순합니다.

> 어느 전선을 막을 것인가?  
> 어떤 카드를 조합할 것인가?  
> 이번 선택이 얼마나 크게 터질 것인가?

솔로에서는 한 직업만으로 빠르게 루프를 돌고, 멀티플레이에서는 최대 4명의 플레이어가 각자의 덱과 전선을 맡아 마지막 국가의 사계절을 함께 버팁니다.
