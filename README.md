# Last Bastion: Four Seasons

**Last Bastion: Four Seasons**는 1~4인이 함께 마지막 기지를 지키는 **협동 하이브리드 타워 디펜스 + 액션 덱 빌딩 로그라이크**입니다.

플레이어는 인원수에 따라 열린 침공 방향에서 몰려오는 적을 막기 위해 타워와 바리케이드를 설치하고, 길을 비틀어 킬존을 만들며, 전투 중 카드를 사용해 무너지는 방어선을 끝까지 붙잡아야 합니다.

> 막는 게임이 아니라, 어디서 무너질지까지 설계하는 게임.

## 게임 정체성

### 장르

- 1~4인 협동
- 타워 디펜스
- 액션 덱 빌딩
- 로그라이크
- 미로 설계
- 기지 방어

### 핵심 타겟

이 게임은 복잡한 아이템 트리나 정해진 빌드 암기에 피로를 느낀 유저를 겨냥합니다.

플레이어가 외워야 하는 것은 적고, 매 순간 판단해야 하는 것은 선명해야 합니다.

특히 여러 명이 같은 화면을 보며 "지금 웨이브 더 부를까?", "저 벽은 터뜨리는 게 낫지 않나?", "수리할까 버릴까?"처럼 짧고 강한 의사소통을 나누는 협동 감성을 중심에 둡니다.

### 핵심 감정

- 방어선이 잘 맞물릴 때의 안도감
- 적이 킬존에 몰려들 때의 통쾌함
- 구조물이 하나씩 부서질 때의 긴장감
- 웨이브를 앞당겨 부르는 순간의 집단 판단
- 거대한 보스가 말없이 다가올 때의 압박감

## 설계 원칙

1. **기다림은 줄이고, 판단은 남긴다.**
   웨이브 겹치기는 보상을 늘리는 도박이 아니라 전투 템포를 조절하는 기능입니다.

2. **완벽한 벽보다 계획된 붕괴가 재미있다.**
   구조물 파괴는 실패만이 아니라, 시간 벌기와 폭발 피해, 어그로 전환을 만드는 전술 자원입니다.

3. **협동은 역할 분담보다 공동 판단에서 나온다.**
   각 직업은 자기 역할이 뚜렷하지만, 중요한 순간에는 모두가 같은 전장을 보고 함께 결정을 내려야 합니다.

4. **보스는 많이 때리는 적이 아니라, 다가오는 재앙이다.**
   보스는 높은 체력만 가진 대상이 아니라 맵의 구조, 시야, 소리, 경로 판단을 바꾸는 사건이어야 합니다.

5. **성장은 강하지만, 룰은 직관적이어야 한다.**
   카드, 아티팩트, 상점은 플레이 방식을 바꾸되 복잡한 계산식 암기를 요구하지 않습니다.

## 목표

플레이어는 100일 동안 기지를 방어합니다.

- 매일 적 웨이브가 현재 인원수에 맞춰 열린 방향에서 접근합니다.
- 10일마다 거대한 보스가 등장합니다.
- 보스를 처치하면 상점, 덱 압축, 아티팩트 선택으로 파티를 성장시킵니다.
- 100일째 최종 보스를 막아내면 승리합니다.

### 목표 플레이 시간

목표 플레이 시간은 협동 게임의 피로도를 기준으로 잡습니다.

| 모드 | 목표 시간 | 설명 |
| --- | ---: | --- |
| 튜토리얼 | 10분 | 기본 설치, 파괴, 자원, 웨이브 겹치기 학습 |
| 10일 테스트 | 12~18분 | 첫 보스까지 핵심 루프 확인 |
| MVP 20~30일 | 25~40분 | 직업과 덱 방향 검증 |
| 100일 풀런 | 75~100분 | 숙련 파티 기준, 웨이브 겹치기 사용 전제 |

웨이브 겹치기는 풀런 시간을 줄이는 핵심 장치입니다.

하지만 클리어 효율이나 보상 총량을 높이는 장치가 되면 안 됩니다.

### 100일 풀런 리듬

100일 풀런은 계속 강해지는 일직선 난이도가 아니라, **압박의 봉우리**와 **정비의 골짜기**가 반복되는 구조입니다.

기본 리듬:

| 위치 | 역할 |
| ---: | --- |
| 챕터 1일차 | 보스/상점 이후 낮은 밀도의 재정렬 |
| 챕터 2~4일차 | 새 압박 소개와 약한 조합 |
| 챕터 5일차 | 쉬운 웨이브 뒤 상점 또는 이벤트 |
| 챕터 6일차 | 방금 고른 카드/상점 선택의 체감 |
| 챕터 7~8일차 | 웨이브 겹치기 판단이 생기는 챕터 봉우리 |
| 챕터 9일차 | 보스 전 리허설 |
| 챕터 10일차 | 보스, 아티팩트, 다음 챕터 준비 |

105분을 넘는 풀런은 고난도라기보다 템포 문제로 봅니다.

먼저 상점 시간, 보상 정산 시간, 보스 반복 시간을 줄이고, 웨이브 겹치기에 보상을 붙여 해결하지 않습니다.

### 100일 성장 리듬

카드와 아티팩트 성장은 초반부터 후반까지 같은 속도로 커지지 않습니다.

초반에는 도구를 늘리고, 중반에는 빌드 방향을 확정하며, 후반에는 덱과 아티팩트를 정리합니다.

| 구간 | 성장 초점 |
| --- | --- |
| 1~20일 | 직업 기본 루프 보완, 첫 아티팩트 체감 |
| 21~40일 | 정예, 다방향, 계절 압박에 대응할 카드 추가 |
| 41~60일 | 핵심 카드 강화, 구조물 손실과 경로 변화 활용 |
| 61~80일 | 덱 압축, 아티팩트 교체, 손패 막힘 감소 |
| 81~100일 | 새 빌드 시작 금지, 최종 보스 약점 보완 |

30일 이후부터는 카드 보상을 거절하고 골드를 고르는 것도 정상적인 성장 선택입니다.

91일 이후에는 새 아키타입을 시작하게 만드는 카드나 아티팩트를 기본 보상으로 밀지 않습니다.

### 첫 10일 덱 성장 6단계

첫 10일의 카드 보상은 덱 빌딩을 가르치는 첫 번째 실전입니다.

플레이어가 매일 카드를 무조건 집게 만들기보다, "내 덱에 지금 필요한 역할이 무엇인가?"를 짧게 판단하게 만드는 것이 목표입니다.

| 단계 | 일자 | 보상 후보의 역할 | 플레이어가 배워야 할 선택 |
| ---: | --- | --- | --- |
| 1 | 1~2일 | 직업 기본 카드 보강 | 내 시작 덱의 핵심 버튼을 한 번 더 쓰기 |
| 2 | 3~4일 | 빠른 적, 군집 대응 카드 | 당장 새 적에게 필요한 대응 고르기 |
| 3 | 5일 | 첫 상점과 덱 정리 카드 | 카드를 넣는 것과 골드를 받는 것이 둘 다 선택임을 이해 |
| 4 | 6~7일 | 파괴, 수리, 후방 재건 카드 | 무너지는 구조물을 손실이 아니라 전술로 바꾸기 |
| 5 | 8~9일 | 손패 순환, 우선 처치, 템포 카드 | 겹친 전투에서 손패를 풀되 보상 증가를 기대하지 않기 |
| 6 | 10일 | 보스 부위, 집중 화력, 지연 카드 | 첫 보스에서 내 직업이 맡을 한 가지 일을 확정 |

첫 10일 보상 후보는 무작위 3장 선택 규칙을 유지합니다.

다만 후보 풀은 플레이어가 방금 겪은 문제 태그와 직업 태그를 참고해 부드럽게 좁힙니다.

이 보정은 카드 후보 수, 희귀도, 보상 총량을 늘리지 않습니다.

10일 종료 시 개인 덱은 보통 13~16장을 목표로 합니다.

그보다 많아도 즉시 실패는 아니지만, 플레이어가 "안 집으면 손해"라고 느낀다면 보상 UI와 거절 골드 가치를 먼저 조정합니다.

### 직업 성장과 시너지

4개 직업은 100일 동안 약점을 지우는 방식으로 성장하지 않습니다.

각 직업은 자기 핵심 질문을 유지한 채, 더 어려운 상황에서 그 질문을 다시 풀어야 합니다.

| 직업 | 100일 동안 유지할 질문 |
| --- | --- |
| 수호자 | 어디서 맞게 만들고, 언제 버틸 것인가? |
| 건축가 | 어디서 무너뜨리고, 어디로 돌릴 것인가? |
| 원소술사 | 언제 모인 적을 정리하고, 어디서 늦출 것인가? |
| 땜장이 | 무엇을 살리고, 무엇을 과부하시킬 것인가? |

멀티 시너지는 수치 합산보다 타이밍, 위치, 목표 공유에서 나와야 합니다.

솔로 보완은 직업 기믹 변경이 아니라 활성 방향, 적 수, 시드 마나, 공용 카드, 상점 추천으로 처리합니다.

### 적 역할과 직업 대응

적은 특정 직업을 요구하는 열쇠가 아니라, 파티가 어떤 방식으로 문제를 풀지 묻는 압박 장치입니다.

각 적 역할은 최소 2개 이상의 유효 대응을 가져야 하며, 특정 직업이 가장 편한 해법이더라도 다른 직업과 공용 카드로 느리지만 납득 가능한 대응이 가능해야 합니다.

| 적 역할 | 주로 묻는 판단 |
| --- | --- |
| 군집형 | 킬존 압축, 광역 타이밍, 도발 군집 |
| 돌파형 | 빠른 예고 대응, 둔화/넉백, 짧은 라인 보강 |
| 파괴형 | 계획된 구조물 희생, 수리 타이밍, 가시 탱킹 |
| 저항형 | 피해 방식 전환, 긴 경로, 지속 화력 |
| 방해형 | 우선 처치, 손패 꼬임 대응, 전선 유지 |
| 지원형 | 후열 목표 제거, 경로 격리, 공동 타겟 콜 |
| 압박형 | 장기 유지보수, 경로 연장, 둔화 유지 |
| 정예형 | 파티 공동 집중 화력과 부위 우선순위 |

자세한 대응표와 금지 조합은 [docs/ENEMY_WAVE_COOKBOOK.md](docs/ENEMY_WAVE_COOKBOOK.md)에 둡니다.

### 자원 소유권

처치 기반 보상은 개인 독식이 아니라 파티 협동 결과로 처리합니다.

| 자원 | 소유 방식 | 이유 |
| --- | --- | --- |
| 골드 | 파티 공유 | 상점과 기지 보강을 공동 판단하게 만듭니다. |
| 시드 마나 | 개인 | 각자 자기 직업의 시작 행동을 보장합니다. |
| 전투 마나 | 개인 충전, 파티 처치 기반 | 누구의 타워가 막타를 쳤는지 따지지 않게 합니다. |
| 드로우 게이지 | 개인 충전, 파티 처치 기반 | 모든 플레이어가 전투 템포에 참여합니다. |
| 보스 파편 | 파티 공유 | 아티팩트와 고급 선택을 공동 결정합니다. |

처치가 발생하면 모든 플레이어의 전투 마나와 드로우 게이지가 조금씩 찹니다.

직접 피해를 많이 준 플레이어에게 별도 보너스를 주지 않습니다.

이 게임의 핵심은 경쟁 딜량이 아니라 공동 방어선입니다.

## 전체 진행

게임은 100일 동안 진행되며, 10일 단위로 큰 결정을 제공합니다.

```text
1~9일: 일반 웨이브
10일: 거대 보스
보스 처치 후: 상점, 덱 압축, 아티팩트 선택, 기지 보강
```

100일은 네 계절로 나뉩니다.

| 구간 | 계절 | 방향성 |
| --- | --- | --- |
| 1~25일 | 봄 | 기본 규칙 학습, 약한 적, 방어선 형성 |
| 26~50일 | 여름 | 빠른 적, 화재나 과열 계열 압박, 전투 템포 증가 |
| 51~75일 | 가을 | 정예 적 증가, 경로 교란, 자원 선택 압박 |
| 76~100일 | 겨울 | 느리지만 거대한 적, 시야와 이동 압박, 최종 방어 |

계절은 매번 완전히 다른 게임이 되는 것이 아니라, 같은 룰 위에 다른 압박을 얹는 장치입니다.

### 계절별 규칙 기준

계절은 맵을 완전히 갈아엎는 규칙이 아니라, 플레이어가 같은 시스템을 다르게 쓰게 만드는 압박이어야 합니다.

MVP에서는 계절별 규칙을 미루고, 확장 단계에서 추가합니다.

| 계절 | 핵심 압박 | 전장 변화 | 적 경향 | 플레이어 질문 |
| --- | --- | --- | --- | --- |
| 봄 | 학습과 성장 | 기본 타일 중심 | 약한 군집형 | 방어선의 기본 형태를 어떻게 만들 것인가? |
| 여름 | 속도와 과열 | 일부 강화 지점이 과열되어 구조물 피해 증가 | 돌파형, 파괴형 | 빠른 적을 어디에서 늦출 것인가? |
| 가을 | 선택 압박 | 잔해와 낙엽 타일로 경로가 자주 변함 | 방해형, 정예형 | 무너진 경로를 어떻게 다시 설계할 것인가? |
| 겨울 | 공간 축소 | 일부 외곽 타일이 얼어 설치 제한 | 저항형, 압박형 | 남은 공간으로 최종 킬존을 만들 수 있는가? |

계절 규칙은 플레이어가 외워야 하는 특수 룰이 아니라, 화면을 보면 바로 이해되는 변화여야 합니다.

### 계절 전환 보상

25일 단위로 계절이 바뀔 때, 플레이어는 작은 방향 선택을 합니다.

예시:

- 기지 체력 회복
- 카드 1장 강화
- 공용 카드 1장 제거
- 아티팩트 슬롯 재배치
- 다음 계절 첫 3일 동안 시드 마나 증가

계절 전환 보상은 보스 보상보다 작아야 합니다.

10일 단위 보스가 큰 성장 변곡점이고, 계절 전환은 운영 방향을 정리하는 중간 정비에 가깝습니다.

## 하루의 흐름

하루는 다음 흐름으로 진행됩니다.

1. **예고**
   적의 등장 방향, 주요 적 타입, 위험도를 보여줍니다.

2. **시드 마나 지급**
   각 플레이어는 최소한의 시드 마나를 받습니다.

3. **준비**
   타워, 바리케이드, 함정, 오라를 배치하거나 강화합니다.

4. **웨이브 시작**
   적이 경로를 따라 기지로 이동합니다.

5. **전투 중 카드 사용**
   플레이어는 마나와 손패를 사용해 즉발 카드, 수리, 군중 제어, 설치 카드를 사용합니다.

6. **처치 기반 자원 회복**
   적을 처치하면 마나 게이지와 드로우 게이지가 차오릅니다.

7. **정산**
   웨이브가 끝나면 피해, 골드, 카드 보상을 정산합니다.

8. **선택**
   새 카드 3장 중 1장을 선택하거나, 카드 대신 골드를 고릅니다.

### 매일의 핵심 판단

매일 플레이어가 고민해야 하는 질문은 많지 않아야 합니다.

대신 각 질문의 결과가 크게 느껴져야 합니다.

- 어디에 구조물을 세울 것인가?
- 어떤 적을 먼저 처리할 것인가?
- 지금 카드를 써서 버틸 것인가, 다음 웨이브를 위해 아낄 것인가?
- 무너질 구조물을 수리할 것인가, 터뜨릴 것인가?
- 현재 웨이브가 끝나기 전에 다음 웨이브를 부를 것인가?

이 질문들이 매일 반복되되, 적 조합과 보스 압박, 카드 보상에 따라 답이 달라지는 것이 목표입니다.

## 전장 설계

### 미로 만들기

플레이어는 타일 위에 구조물을 배치해 적의 이동 경로를 유도합니다.

완전 차단은 허용하지 않습니다. 적은 항상 기지로 향하는 최소 하나의 경로를 가져야 합니다.

하지만 플레이어는 다음 방식으로 경로를 통제할 수 있습니다.

- 적이 더 긴 길을 걷게 만들기
- 특정 구역에 적을 모으기
- 도발 오라로 적의 목표를 바꾸기
- 바리케이드를 일부러 맞게 만들기
- 둔화, 빙결, 넉백으로 킬존 체류 시간을 늘리기

### 경로 재계산

적은 구조물이 설치되거나 파괴될 때 경로를 다시 판단합니다.

경로가 너무 길어지거나, 도발 상태에 걸리거나, 특정 파괴형 적이 등장하면 적은 구조물을 공격해 길을 뚫으려 합니다.

이때 플레이어는 구조물 파괴를 손해로만 보지 않고, 다음 전술로 연결해야 합니다.

- 적을 한 지점에 오래 붙잡기
- 파괴 폭발로 광역 피해 넣기
- 수리로 파괴 타이밍 늦추기
- 넉백으로 다시 킬존 안으로 밀어넣기

### 기지 체력

기지는 별도의 체력을 가집니다.

적이 기지에 도달하면 적 타입에 따라 기지 피해를 줍니다.

- 일반 적은 낮은 피해를 줍니다.
- 정예 적은 더 큰 피해를 줍니다.
- 보스가 기지에 도달하면 매우 큰 피해를 주거나 즉시 패배 조건을 유발할 수 있습니다.

기지 체력이 30% 이하가 되면 웨이브 겹치기 조건이 더 엄격해집니다.

### 체력과 피해 기준

첫 프로토타입은 작은 숫자로 시작합니다.

숫자가 작아야 플레이어가 피해량을 직관적으로 이해하고, 밸런스 조정도 빠릅니다.

| 대상 | 기본 체력 | 비고 |
| --- | ---: | --- |
| 기지 | 30 | 0이 되면 패배 |
| 기본 공격 타워 | 8 | 공격은 좋지만 오래 버티지 못함 |
| 도발 타워 | 14 | 맞는 역할이므로 높게 설정 |
| 기본 바리케이드 | 12 | 경로 조정과 시간 벌기 |
| 폭발 바리케이드 | 8 | 낮은 체력, 높은 파괴 가치 |
| 오라 장치 | 6 | 보호가 필요한 핵심 지원 구조물 |
| 임시 구조물 | 4 | 짧은 시간 버티는 소모품 |

적의 기지 피해:

| 적 등급 | 기지 피해 |
| --- | ---: |
| 약한 적 | 1 |
| 보통 적 | 1 |
| 위험 적 | 2 |
| 정예 적 | 3 |
| 압박형 적 | 4 |
| 보스 | 특수 처리 |

보스는 단순 피해보다 패배 압박으로 다룹니다.

MVP 첫 보스는 기지에 도달하면 기지 체력 15 피해를 주고, 5초 뒤 두 번째 피해를 예고합니다.

즉시 패배보다 "마지막으로 밀어낼 기회"를 한 번 주는 편이 더 극적입니다.

### 맵 구조 기준

기본 맵은 중앙 기지를 기준으로 네 방향 입구를 가진 구조입니다.

MVP에서는 맵을 크게 늘리기보다, 하나의 맵에서 미로 설계가 충분히 달라지는지 먼저 확인합니다.

기본 구성:

- 중앙: 기지
- 북쪽: 느리지만 튼튼한 적이 들어오기 좋은 넓은 진입로
- 동쪽: 경로가 짧지만 설치 공간이 많은 진입로
- 남쪽: 굴곡이 많아 킬존을 만들기 쉬운 진입로
- 서쪽: 직선에 가까워 돌파형 적이 위협적인 진입로

각 방향은 완전히 다른 규칙을 갖기보다, 같은 구조물과 카드를 다르게 쓰게 만드는 정도의 차이를 가집니다.

### 인원수별 활성 침공 방향

모든 런에서 맵은 네 방향을 가지고 있지만, 실제로 적이 침공하는 방향은 런 시작 인원수에 따라 열립니다.

| 인원수 | 활성 침공 방향 | 의도 |
| ---: | --- | --- |
| 1명 | 동쪽 | 짧은 경로 하나에 집중해 솔로 조작 부담을 낮춥니다. |
| 2명 | 북쪽, 동쪽 | 한 명은 짧은 동쪽, 한 명은 느린 북쪽을 맡아 기본 분담을 만듭니다. |
| 3명 | 서쪽, 북쪽, 동쪽 | 빠른 서쪽이 추가되어 전담 수비와 순회 지원이 필요해집니다. |
| 4명 | 서쪽, 북쪽, 동쪽, 남쪽 | 네 방향 전체 압박으로 완전한 협동 방어를 만듭니다. |

활성 방향은 런 시작 시 고정됩니다.

전투 중 플레이어가 재접속하거나 이탈해도 이미 열린 방향은 닫히지 않습니다.

이 규칙의 목적은 인원이 늘수록 적 체력만 올리는 것이 아니라, **동시에 봐야 할 전선 수를 늘려 협동 대화를 만드는 것**입니다.

### MVP 맵 수치

MVP 기본 맵은 21x21 타일을 기준으로 합니다.

중앙 3x3 영역은 기지로 사용합니다.

| 영역 | 기준 |
| --- | --- |
| 전체 맵 | 21x21 타일 |
| 기지 | 중앙 3x3 |
| 기본 경로 폭 | 2타일 |
| 보스 경로 폭 | 3타일 |
| 일반 타워 사거리 | 3~4타일 |
| 기본 설치 가능 구역 | 경로 주변 2~4타일 |
| 강화 지점 | 방향당 1~2개 |
| 초기 장애물 | 방향당 2~3개 |

경로 길이 기준:

| 방향 | 기지까지 기본 이동 시간 | 설계 의도 |
| --- | ---: | --- |
| 북쪽 | 약 45초 | 느린 압박과 튼튼한 적 |
| 동쪽 | 약 35초 | 짧은 경로, 설치 공간 보상 |
| 남쪽 | 약 50초 | 굴곡이 많아 킬존 학습에 좋음 |
| 서쪽 | 약 30초 | 빠른 대응과 돌파형 압박 |

이동 시간은 적 기본 속도 기준입니다.

웨이브 겹치기를 쓰지 않아도 한 웨이브가 지나치게 길게 늘어지지 않게 합니다.

### 타일 종류 기준

| 타일 | 기능 | 설계 의도 |
| --- | --- | --- |
| 일반 타일 | 대부분의 구조물을 설치할 수 있습니다. | 기본 건설 공간입니다. |
| 경로 타일 | 적이 이동하는 길입니다. 일부 함정만 설치할 수 있습니다. | 완전 길막을 방지합니다. |
| 강화 지점 | 타워를 설치하면 공격 범위나 방어력이 증가합니다. | 주요 방어 거점을 만듭니다. |
| 과열 강화 지점 | 공격 속도가 증가하지만 구조물이 더 많은 피해를 받고 수리 효율이 낮아집니다. | 여름의 위험한 고효율 자리입니다. |
| 불안정 지점 | 구조물이 더 빨리 피해를 받지만 파괴 효과가 강해집니다. | 건축가식 붕괴 설계를 유도합니다. |
| 잔해 타일 | 파괴된 구조물이 남긴 임시 장애물입니다. | 전투 중 경로 변화를 만듭니다. |

### 구조물 종류 기준

구조물은 모두 같은 방식으로 오래 버티는 벽이 되면 안 됩니다.

각 구조물은 "왜 여기에 놓는가"가 달라야 합니다.

| 구조물 | 기본 역할 | 약점 | 주로 쓰는 직업 |
| --- | --- | --- | --- |
| 공격 타워 | 경로 위 적에게 지속 피해를 줍니다. | 파괴형 적에게 취약합니다. | 공용, 땜장이 |
| 도발 타워 | 주변 적의 목표를 자신에게 돌립니다. | 피해를 많이 받아 수리가 필요합니다. | 수호자 |
| 바리케이드 | 이동 경로를 비틀고 시간을 법니다. | 직접 화력은 낮습니다. | 건축가 |
| 폭발 바리케이드 | 파괴될 때 주변에 피해를 줍니다. | 원하는 타이밍에 터지지 않을 수 있습니다. | 건축가 |
| 둔화 함정 | 지나가는 적의 이동 속도를 낮춥니다. | 보스나 저항형 적에게 효과가 약합니다. | 건축가, 원소술사 |
| 오라 장치 | 주변 구조물을 강화합니다. | 밀집 배치를 유도해 광역 파괴에 취약합니다. | 땜장이 |
| 임시 구조물 | 짧은 시간만 유지되는 싸고 빠른 구조물입니다. | 장기 방어선으로는 부적합합니다. | 건축가, 수호자 |

구조물은 "영구 건물"보다 "전투 중 소비되는 전술 자산"에 가깝게 설계합니다.

### 구조물 생애주기

구조물은 설치한 순간부터 파괴될 때까지 같은 의미를 갖지 않습니다.

좋은 구조물 판단은 아래 6단계로 흐릅니다.

| 단계 | 질문 | 플레이어 선택 |
| ---: | --- | --- |
| 1 | 왜 여기에 세우는가? | 킬존 압축, 도발, 오라, 임시 지연 중 목적을 정합니다. |
| 2 | 어떤 위험을 받을 것인가? | 파괴형 표식, 과열, 결빙, 보스 압력을 예고로 읽습니다. |
| 3 | 살릴 것인가, 버릴 것인가? | 수리, 강화, 도발 이전, 후방 재건, 의도적 희생 중 고릅니다. |
| 4 | 부서질 때 무엇을 남기는가? | 폭발, 잔해, 둔화, 가시, 회수 같은 전술 가치를 만듭니다. |
| 5 | 경로가 어떻게 바뀌는가? | 잔해와 빈 타일 때문에 새 경로와 킬존 위치를 다시 봅니다. |
| 6 | 어디에 다시 세우는가? | 같은 자리 고집이 아니라 후방, 보조선, 새 오라 범위를 검토합니다. |

수리는 구조물을 영구 보존하는 수단이 아니라, 필요한 순간을 몇 초 늦추는 선택입니다.

파괴는 실패만이 아니라, 적을 묶고 경로를 흔들며 다음 방어선을 만드는 전환점입니다.

단, 구조물 파괴가 무한 자원 루프가 되거나 완전 길막을 만드는 것은 금지합니다.

### 구조물 배치 제한

배치 제한은 플레이어를 답답하게 만들기 위한 장치가 아닙니다.

좋은 미로와 나쁜 미로의 차이를 만들기 위한 최소한의 규칙입니다.

- 기지로 향하는 경로를 완전히 막을 수 없습니다.
- 보스가 지나가야 하는 핵심 경로에는 일부 구조물만 설치할 수 있습니다.
- 같은 오라 효과는 무한 중첩되지 않습니다.
- 함정은 경로 타일에 설치할 수 있지만, 타워는 기본적으로 경로 밖 타일에 설치합니다.
- 잔해 타일은 짧은 시간 뒤 사라지거나 약한 장애물로 변합니다.

## 웨이브 겹치기

웨이브 겹치기는 보상을 더 받기 위한 시스템이 아닙니다.

이 기능은 방어선이 안정적일 때 다음 웨이브를 미리 불러와, 기다리는 시간을 줄이고 전투 밀도를 높이기 위한 템포 조절 장치입니다.

### 기본 규칙

- 현재 웨이브가 끝나기 전 다음 웨이브를 호출할 수 있습니다.
- 솔로에서는 플레이어가 즉시 결정합니다.
- 멀티에서는 기본적으로 과반수 동의 시 실행됩니다.
- 기지 체력이 30% 이하일 때는 전원 동의가 필요합니다.
- 기본 최대 3개 웨이브까지 겹칠 수 있습니다.
- 기본 최대치를 넘기는 효과는 이후 아티팩트로만 제공합니다.

### 보상 규칙

웨이브를 겹쳐도 총 보상량은 늘어나지 않습니다.

- 추가 골드 보너스 없음
- 카드 선택지 증가 없음
- 희귀 보상 확률 증가 없음
- 별도 클리어 보너스 없음

여러 웨이브를 짧은 시간 안에 처리하므로 마나, 드로우, 골드가 빠르게 들어오는 것처럼 느껴질 수 있습니다.

하지만 이는 원래 받을 보상이 시간적으로 압축되는 것이며, 총량이 증가하는 것은 아닙니다.

### 정산 방식

겹친 웨이브가 모두 끝나면, 각 웨이브의 기본 보상을 순서대로 정산합니다.

예를 들어 3개 웨이브를 겹쳐 막았다면 보상도 3번 정산하지만, 각 보상은 일반 라운드와 동일한 기준을 사용합니다.

### 버리기와 웨이브 겹치기

버리기 기회는 웨이브 수에 맞춰 함께 정산됩니다.

다만 이것도 보너스가 아니라, 각 웨이브가 원래 제공해야 할 최소 손패 정비권을 한 전투 안에 압축해서 받는 구조입니다.

- 기본적으로 웨이브당 버리기 1회
- 겹친 전투에서는 최대 3회까지 보유
- 버리기로 얻는 마나는 소량
- 무한 리롤이나 무한 마나 회복은 불가능해야 함

## 자원과 카드

### 시드 마나

매 라운드 시작 시 플레이어에게 최소한의 시드 마나가 지급됩니다.

시드 마나는 첫 방어선을 구축하기 위한 기본 자원입니다.

시간 경과만으로 마나가 자동 회복되지는 않습니다.

### 처치 기반 자원 회복

적을 처치하면 마나 게이지와 드로우 게이지가 차오릅니다.

이 보상은 마지막 타격을 한 플레이어만 가져가지 않습니다.

방어선 전체가 함께 만든 결과로 보고, 파티 전체가 전투 템포를 이어갈 수 있도록 설계합니다.

기본 방향:

- 약한 적은 소량 충전합니다.
- 정예 적은 더 많이 충전합니다.
- 보스의 부위를 파괴하면 큰 보상을 즉시 제공합니다.
- 짧은 시간 안에 처치가 몰릴 경우, 무한 콤보를 막기 위한 완만한 보정이 필요합니다.

### 자원 충전 공식

처치 기반 자원은 너무 정확한 수식보다 직관적인 등급으로 시작합니다.

각 적은 마나 충전값과 드로우 충전값을 가집니다.

| 적 등급 | 마나 충전 | 드로우 충전 | 비고 |
| --- | ---: | ---: | --- |
| 약한 적 | 3 | 5 | 군집형 기본 적 |
| 보통 적 | 5 | 8 | 일반 웨이브 핵심 적 |
| 위험 적 | 8 | 12 | 돌파형, 파괴형 |
| 정예 적 | 15 | 25 | 우선 처치 대상 |
| 보스 부위 | 25 | 40 | 부위 파괴 보상 |

게이지 기준:

- 마나 게이지 100 도달 시 전투 마나 1 회복
- 드로우 게이지 100 도달 시 카드 1장 드로우
- 한 번에 초과한 게이지는 이월
- 전투 마나는 최대 10까지 저장
- 손패 한도를 넘는 드로우는 발생하지 않음

### 처치 몰림 보정

웨이브 겹치기나 광역 콤보로 짧은 시간에 처치가 몰릴 수 있습니다.

이때 자원 폭주를 막기 위해 같은 3초 안에 발생한 처치 보상에는 완만한 보정을 적용합니다.

| 3초 내 처치 순서 | 자원 획득률 |
| ---: | ---: |
| 1~10번째 | 100% |
| 11~25번째 | 80% |
| 26~50번째 | 60% |
| 51번째 이후 | 40% |

보정은 총 보상을 깎아 체감 손해를 만들기보다, 무한 콤보만 막는 안전장치입니다.

필요하다면 이 보정은 MVP 이후에 더 부드러운 곡선으로 바꿉니다.

### 손패

- 기본 패 한도는 8장입니다.
- 성장 요소를 통해 최대 10장까지 증가합니다.
- 0~1코스트 카드는 콤보의 연결부 역할을 합니다.
- 2~3코스트 카드는 전투의 방향을 바꾸는 핵심 카드 역할을 합니다.
- 고비용 카드는 보스전이나 위기 상황의 한 방으로 사용합니다.

### 카드 유형

| 유형 | 역할 |
| --- | --- |
| 설치 카드 | 타워, 바리케이드, 함정을 배치합니다. |
| 강화 카드 | 기존 구조물의 공격력, 방어력, 범위, 오라를 강화합니다. |
| 즉발 카드 | 피해, 수리, 넉백, 빙결처럼 전투 중 바로 효과를 냅니다. |
| 조건부 카드 | 구조물 파괴, 적 처치, 도발 성공 같은 상황에 반응합니다. |
| 경제 카드 | 골드, 마나, 드로우, 카드 제거와 연결됩니다. |

### 핵심 키워드

키워드는 카드 설명을 짧게 만들기 위한 공용 언어입니다.

키워드 수는 처음부터 많이 늘리지 않습니다.

MVP에서는 아래 정도만 사용합니다.

| 키워드 | 의미 | 사용처 |
| --- | --- | --- |
| 도발 | 적이 일정 시간 해당 구조물을 우선 공격합니다. | 수호자, 일부 보스 패턴 |
| 가시 | 구조물이 피해를 받을 때 공격자에게 반사 피해를 줍니다. | 수호자 |
| 잔해 | 구조물이 파괴된 자리에 임시 장애물이 남습니다. | 건축가, 파괴형 적 |
| 폭발 | 구조물 파괴 또는 카드 사용 시 주변 적에게 피해를 줍니다. | 건축가, 원소술사 |
| 둔화 | 적의 이동 속도를 낮춥니다. | 건축가, 원소술사 |
| 빙결 | 적을 짧게 멈추지만, 반복 적용 시 효과가 줄어듭니다. | 원소술사 |
| 넉백 | 적을 경로 뒤쪽으로 밀어냅니다. | 원소술사 |
| 과부하 | 일시적으로 성능을 높이는 대신 이후 피해나 약화를 받습니다. | 땜장이 |
| 수리 | 구조물 체력을 회복합니다. | 땜장이, 공용 보조 카드 |
| 회수 | 파괴되거나 사용한 자원의 일부를 돌려받습니다. | 건축가, 경제 카드 |

### 상태이상 규칙

상태이상은 적을 완전히 무력화하는 장치가 아니라, 방어선이 작동할 시간을 벌어주는 장치입니다.

기본 원칙:

- 같은 군중 제어를 짧은 시간 안에 반복 적용하면 효과가 줄어듭니다.
- 보스는 대부분의 상태이상에 면역이 아니라, 약화된 형태로 영향을 받습니다.
- 상태이상 저항은 적 설명에서 명확하게 보여줘야 합니다.
- 플레이어가 "왜 안 먹혔는지"를 몰라서 답답해하면 안 됩니다.

상태이상별 방향:

| 상태 | 일반 적 | 정예 적 | 보스 |
| --- | --- | --- | --- |
| 둔화 | 강하게 적용 | 중간 적용 | 약하게 적용 |
| 빙결 | 짧게 정지 | 매우 짧게 정지 | 이동 속도 잠시 감소 |
| 넉백 | 경로 뒤로 밀림 | 짧게 밀림 | 부위 파괴 중일 때만 약하게 밀림 |
| 도발 | 목표 변경 | 일부 저항 | 특정 부위나 패턴에만 적용 |
| 취약 | 받는 피해 증가 | 짧게 적용 | 부위별로 제한 적용 |

상태이상은 아래 6단계로 판정합니다.

| 단계 | 내용 |
| ---: | --- |
| 1 | 대상이 일반 적, 정예, 보스, 보스 부위 중 무엇인지 확인합니다. |
| 2 | 카드나 구조물이 주는 기본 효과량과 지속 시간을 읽습니다. |
| 3 | 대상의 기본 저항과 현재 역할 저항을 적용합니다. |
| 4 | 짧은 시간 안에 같은 상태이상이 반복됐는지 확인해 효과를 줄입니다. |
| 5 | 도발, 넉백, 빙결처럼 서로 충돌하는 효과의 우선순위를 정합니다. |
| 6 | 플레이어가 이해할 수 있도록 감소, 저항, 해소 피드백을 표시합니다. |

금지선:

- 일반 적을 제외한 주요 적을 영구 정지시키지 않습니다.
- 보스를 완전히 멈추는 대신, 이동 속도 감소나 부위 취약처럼 약화된 결과로 바꿉니다.
- 저항형 적도 모든 상태이상을 완전히 무시하지 않습니다.
- 침묵과 방해 효과는 카드 사용 자체를 막기보다, 마나/드로우 흐름을 읽을 수 있게 흔듭니다.
- 상태이상 저항은 숨은 수치가 아니라 아이콘, 색, 짧은 문구로 보여줍니다.

### 카드 설계 원칙

카드는 읽는 순간 대략적인 용도가 보여야 합니다.

좋은 카드는 복잡한 설명보다 명확한 사용 타이밍을 가집니다.

예시:

- 지금 막기 좋은 카드
- 나중에 터뜨리기 좋은 카드
- 특정 직업과 함께 쓰면 강해지는 카드
- 보스 부위 파괴에 유리한 카드
- 웨이브 겹치기 상황에서 손패를 풀어주는 카드

카드 한 장이 모든 상황에 좋으면 안 됩니다.

각 카드는 강한 상황과 약한 상황이 분명해야 하고, 플레이어가 "이번 런에서는 이 카드가 맞다"고 느끼게 해야 합니다.

## 카드 콘텐츠 기준

### 시작 덱 기준

각 직업의 시작 덱은 10장으로 시작합니다.

시작 덱은 직업의 핵심 재미를 바로 보여줘야 하며, 첫 판부터 복잡한 조건부 콤보를 요구하지 않습니다.

구성 기준:

- 기본 설치 카드 2~3장
- 즉발 대응 카드 2~3장
- 직업 고유 기믹 카드 2~3장
- 위기 대응 카드 1~2장
- 경제 또는 드로우 보조 카드 1장 이하

초기 카드는 강력하기보다 이해하기 쉬워야 합니다.

플레이어가 첫 10분 안에 자기 직업의 역할을 감각적으로 이해하는 것이 우선입니다.

수호자 시작 덱은 "맞아도 되는 위치"를 만드는 데 집중합니다.

단, 수호자가 혼자 모든 웨이브를 붙잡으면 안 되므로 피해량은 낮고, 도발과 생존에 더 치중합니다.

공용 카드는 약한 보완책이어야 합니다.

특정 직업의 고유 역할을 대체할 만큼 강해지면 안 됩니다.

### 카드 희귀도

희귀도는 단순한 위력 등급이 아니라, 카드가 요구하는 판단 난이도와 빌드 의존도를 나타냅니다.

| 희귀도 | 방향 | 예시 |
| --- | --- | --- |
| 일반 | 바로 이해되고 자주 쓰는 기본 카드 | 바리케이드, 화염구, 원격 수리 |
| 희귀 | 특정 상황에서 강한 카드 | 잔해 폭발 강화, 보스 부위 취약, 과부하 연쇄 |
| 영웅 | 덱 방향을 바꾸는 카드 | 도발 구조물 전체 가시화, 폭발 연쇄, 오라 범위 재설계 |
| 저주 | 강한 보상과 불편한 조건이 함께 있는 카드 | 비용은 낮지만 손패를 잠그거나 구조물 피해 증가 |

희귀 카드가 항상 일반 카드보다 좋으면 안 됩니다.

일반 카드는 덱의 뼈대이고, 희귀 이상 카드는 운영 방향을 꺾는 선택이어야 합니다.

### 카드 강화

카드 강화는 숫자만 올리는 방식보다 사용 방식이 조금 바뀌는 쪽이 좋습니다.

강화 방향 예시:

| 강화 방향 | 효과 예시 |
| --- | --- |
| 비용 감소 | 카드 비용이 1 줄어듭니다. |
| 범위 증가 | 타워, 폭발, 오라, 빙결 범위가 넓어집니다. |
| 지속 시간 증가 | 도발, 둔화, 강화 효과가 오래갑니다. |
| 조건부 보상 | 적 처치나 구조물 파괴 시 마나를 소량 회복합니다. |
| 안정화 | 과부하나 저주 카드의 페널티가 줄어듭니다. |

모든 카드는 강화 방향을 1~2개만 가집니다.

강화 선택지가 너무 많으면 덱 빌딩보다 강화 트리 암기가 중심이 됩니다.

### 저주 카드 방향

저주 카드는 플레이어를 괴롭히기 위한 쓰레기 카드가 아닙니다.

강한 선택의 대가로 덱에 들어오는 위험 요소입니다.

예시:

| 카드 | 효과 | 대가 |
| --- | --- | --- |
| 균열 계약 | 즉시 많은 마나를 얻습니다. | 다음 드로우 게이지 충전량 감소 |
| 무리한 증축 | 구조물 2개를 싸게 설치합니다. | 둘 다 최대 체력이 낮습니다. |
| 금지된 등불 | 보스 부위 피해가 증가합니다. | 일반 적 처치 마나가 감소합니다. |
| 급속 호출 | 다음 웨이브를 즉시 부릅니다. | 보상 증가는 없고, 해당 전투 중 구조물 피해 증가 |

저주 카드는 제거하고 싶은 대상이 될 수도 있고, 특정 아티팩트와 함께 활용할 수도 있어야 합니다.

## 덱 순환

### 버리기

손패가 막혔을 때 필요 없는 카드를 버리고 소량의 마나를 회복할 수 있습니다.

버리기는 비상 탈출구입니다.

무한 리롤을 위한 기능이 아니며, 덱을 마음대로 뒤지는 기능도 아닙니다.

기본 규칙:

- 웨이브당 1회 사용할 수 있습니다.
- 겹친 전투에서는 최대 3회까지 보유합니다.
- 버린 카드는 버린 카드 더미로 이동합니다.
- 버리기로 얻는 마나는 다음 카드를 겨우 사용할 수 있는 정도로 제한합니다.

### 영구 덱 압축

10일 단위 보스를 처치한 뒤 열리는 상점에서 카드를 영구 제거할 수 있습니다.

- 골드 또는 희귀 재화를 지불합니다.
- 제거 비용은 사용할수록 증가합니다.
- 시작 카드 제거는 특히 높은 비용을 가질 수 있습니다.
- 덱 압축은 강력하지만 신중하게 선택해야 하는 성장 수단입니다.

## 보상과 성장

### 라운드 보상

라운드가 끝나면 무작위 카드 3장 중 1장을 선택합니다.

원하지 않는 경우 카드 대신 골드를 선택할 수 있습니다.

웨이브를 겹쳐도 라운드 보상은 증가하지 않습니다.

### 골드

골드는 적 처치, 라운드 클리어, 보스 처치로 획득합니다.

사용처:

- 카드 제거
- 카드 강화
- 일회성 마법 구매
- 기지 보강
- 특수 타워 또는 함정 구매

### 아티팩트

아티팩트는 거대한 보스를 처치하고 얻는 파티 공유 전리품입니다.

기지에 장착하면 파티 전원에게 영구 패시브를 제공합니다.

아티팩트는 단순한 수치 보상이 아니라, 파티의 운영 방식을 바꾸는 핵심 변곡점이어야 합니다.

예시:

- 패 한도 증가
- 시드 마나 증가
- 마나 획득량 증가
- 수리 효율 증가
- 바리케이드 폭발 범위 증가
- 도발 범위 증가
- 웨이브 겹치기 최대치 증가
- 보스 부위 파괴 효과 강화
- 특정 직업 카드 비용 감소

### 아티팩트 슬롯

기지는 제한된 아티팩트 슬롯을 가집니다.

따라서 보스를 처치할 때마다 얻은 아티팩트를 모두 누적하는 것이 아니라, 현재 파티 조합과 덱 방향에 맞게 장착할 것을 선택해야 합니다.

이 구조는 후반부 파워 인플레이션을 줄이고, 파티가 "이번 런의 운영 방식"을 직접 고르게 만듭니다.

### 아티팩트 선택 6단계

아티팩트 선택은 "가장 강한 보상 고르기"가 아니라, 파티의 다음 10일 운영 방향을 정하는 짧은 회의입니다.

| 단계 | 역할 |
| ---: | --- |
| 1 | 방금 보스전 결과와 다음 10일의 주요 압박을 먼저 보여줍니다. |
| 2 | 아티팩트 후보 3개의 운영 축을 비교합니다. 안정, 약점 보완, 위험한 전술처럼 서로 다른 제안이어야 합니다. |
| 3 | 현재 장착 아티팩트와의 시너지, 충돌, 비어 있는 슬롯 수를 표시합니다. |
| 4 | 빈 슬롯이 있으면 장착 여부를 투표하고, 슬롯이 가득 찼으면 교체 대상 또는 현재 유지 중 하나를 고릅니다. |
| 5 | 선택 결과를 "이번 파티가 어떤 방식으로 버틸지" 한 문장으로 요약합니다. |
| 6 | 다음 상점과 다음 웨이브 예고에서 선택한 아티팩트가 도움이 되는 지점을 다시 보여줍니다. |

첫 30일은 아티팩트로 파티의 뼈대를 세우는 구간입니다.

40~70일은 기존 뼈대를 유지할지, 다가오는 계절 압박에 맞춰 일부를 교체할지 고민하는 구간입니다.

80일 이후는 새 빌드를 시작하기보다 이미 만든 운영을 최종 보스에 맞게 정리하는 구간입니다.

### 아티팩트 교체 기준

교체는 실수 수정이 아니라 운영 방향 재선택입니다.

| 판단 | 좋은 상황 | 피해야 할 상황 |
| --- | --- | --- |
| 유지 | 기존 아티팩트가 핵심 카드, 구조물, 다음 압박과 계속 연결됩니다. | 단순히 새 후보 수치가 조금 높다는 이유로 바꿉니다. |
| 교체 | 기존 효과가 거의 발동하지 않고, 새 후보가 다음 10일 압박을 직접 해결합니다. | 한 플레이어 덱만 강해지고 파티 운영은 바뀌지 않습니다. |
| 포기 | 후보 3개가 모두 새 빌드 시작을 요구하거나 현재 파티와 맞지 않습니다. | 빈손으로 지나가면 손해라는 느낌 때문에 억지로 고릅니다. |

슬롯이 가득 찬 상태에서는 항상 **현재 유지** 선택지를 제공합니다.

후반으로 갈수록 아티팩트 후보는 새 아키타입 시작보다 약점 보완, 최종 보스 대응, 손패/방어선 정리를 우선해야 합니다.

### 아티팩트 1차 목록

아티팩트는 숫자만 올리는 장비가 아니라, 파티가 어떤 방식으로 방어할지 바꾸는 선택이어야 합니다.

| 이름 | 효과 | 열리는 플레이 |
| --- | --- | --- |
| 균열난 종 | 시드 마나가 증가하지만 하루 시작 손패가 1장 줄어듭니다. | 초반 설치를 강하게 가져갑니다. |
| 낡은 관측 렌즈 | 다음 웨이브의 방향과 주요 적 타입을 더 일찍 확인합니다. | 미리 미로를 설계합니다. |
| 부서진 왕관 | 도발 중인 구조물의 가시 피해가 증가합니다. | 수호자 중심 방어선을 강화합니다. |
| 속삭이는 못 | 바리케이드가 파괴될 때 주변 적에게 둔화를 겁니다. | 건축가의 붕괴 설계를 강화합니다. |
| 푸른 축전석 | 드로우 게이지가 가득 찰 때 추가 마나를 소량 얻습니다. | 카드 연쇄를 부드럽게 만듭니다. |
| 과열된 증폭 코어 | 오라 효과가 강해지지만 오라 구조물의 체력이 낮아집니다. | 땜장이의 밀집 배치를 위험하게 강화합니다. |

| 불안정한 시계 | 웨이브 겹치기 최대치가 1 증가하지만 겹친 전투 중 구조물이 받는 피해가 증가합니다. | 빠른 진행을 원할 때 위험을 감수합니다. |
| 침묵의 금고 | 아티팩트 슬롯이 1개 증가하지만 상점 가격이 상승합니다. | 장기 성장을 노립니다. |
| 마지막 등불 | 기지 체력이 낮을 때 모든 수리 효과가 증가합니다. | 위기 상황에서 버티는 힘을 줍니다. |

아티팩트는 가능하면 장점만 있는 효과보다, 운영 방향을 바꾸는 가벼운 대가를 함께 가지는 편이 좋습니다.

| 태엽 성가대 | 오라 장치 범위 증가 | 오라 장치 설치 비용 증가 | 땜장이 중심 |
| 깨진 나침반 | 웨이브 예고가 빨라짐 | 이벤트 등장 빈도 감소 | 안정 운영 |
| 비어 있는 왕좌 | 아티팩트 슬롯 +1 | 보스 파편 획득량 감소 | 장기 운영 |
| 역류하는 모래시계 | 웨이브 겹치기 최대치 +1 | 겹친 전투 중 적 이동 속도 증가 | 숙련 파티 |
| 유리 종자 | 카드 보상 후보 1회를 교체할 수 있음 | 카드 제거 비용 증가 | 덱 탐색 |
| 철의 뿌리 | 바리케이드 최대 체력 증가 | 바리케이드 설치 비용 증가 | 장기 미로 |
| 마지막 지도 | 기지 체력이 낮을 때 다음 웨이브 방향 전체 공개 | 기지 체력이 높을 때 효과 없음 | 위기 회복 |
| 부서진 태양 | 폭발 피해 증가 | 폭발이 아군 구조물에도 약한 피해 | 폭발 빌드 |
| 고요한 망치 | 구조물 파괴 시 골드 소량 획득 | 구조물 수리 효율 감소 | 회수 경제 |
| 은빛 회로 | 과부하 페널티 감소 | 오라 효과 기본값 감소 | 과부하 빌드 |
| 닫힌 문장 | 시작 손패 +1 | 시드 마나 -1 | 카드 중심 |
| 검은 예비품 | 첫 번째 버리기는 마나를 더 많이 회복 | 하루 시작 드로우 -1 | 콤보 정리 |

아티팩트 보상은 3개 후보 중 1개를 선택합니다.

후보 3개는 되도록 서로 다른 운영 방향을 제안해야 합니다.

예를 들어 도발 강화, 폭발 강화, 경제 강화가 함께 뜨면 좋은 선택이 됩니다.

도발 강화 3개처럼 같은 계열만 나오면 선택의 재미가 줄어듭니다.

### 보스 후 성장 흐름

10일 보스 처치 후에는 아래 순서로 성장 선택을 진행합니다.

```text
보스 결과 요약
-> 개인 보스 카드 보상
-> 아티팩트 선택
-> 챕터 상점
-> 11일 예고
```

첫 보스 기본 정산:

| 항목 | 값 |
| --- | ---: |
| 파티 골드 | +35 |
| 보스 파편 | +1 |
| 아티팩트 후보 | 3개 중 1개 |
| 추가 보상 배율 | 없음 |

첫 보스의 부위 파괴는 추가 파편 파밍이 아니라 전투 중 보상으로 처리합니다.

다리부는 이동 속도를 낮추고, 등불부는 드로우를 제공하며, 전면부는 파괴 패턴을 약화합니다.

첫 보스 후 상점은 7~8개 항목만 보여주고, 파티가 해야 하는 큰 구매 결정은 최대 2개로 제한합니다.

상세 흐름은 [docs/REWARD_SHOP_AND_ARTIFACT_FLOW.md](docs/REWARD_SHOP_AND_ARTIFACT_FLOW.md)에 정리합니다.

### 상점 설계

상점은 단순히 강해지는 장소가 아니라, 다음 10일을 어떤 방식으로 버틸지 고르는 장소입니다.

상점에서 선택할 수 있는 항목:

- 카드 제거
- 카드 강화
- 일회성 고성능 주문
- 기지 체력 회복
- 구조물 최대 체력 증가
- 시작 시드 마나 증가
- 특정 직업 카드 구매

상점의 핵심 고민:

- 지금 약한 카드를 지울 것인가?
- 다음 보스를 위해 고성능 주문을 살 것인가?
- 기지 체력을 회복해 안전하게 갈 것인가?
- 덱을 강화할 것인가, 전장을 강화할 것인가?

상점은 매번 정답이 같으면 안 됩니다.

현재 덱, 남은 기지 체력, 다음 계절, 보스 예고에 따라 선택이 달라져야 합니다.

### 정비 구간 루프

정비 구간은 단순 쇼핑 시간이 아니라, 방금 전투의 상처를 다음 압박과 연결하는 짧은 판단 구간입니다.

| 단계 | 역할 |
| ---: | --- |
| 1 | 전투 요약으로 가장 위험했던 방향, 적 역할, 구조물 손실을 봅니다. |
| 2 | 피해 진단 태그로 기지, 구조물, 손패, 우선순위 문제를 압축합니다. |
| 3 | 개인 카드 보상에서 덱에 넣을지, 거절하고 골드를 받을지 고릅니다. |
| 4 | 다음 3~5일 압박을 보고 어떤 문제가 다시 올지 확인합니다. |
| 5 | 파티 골드와 보스 파편으로 최대 1~2개의 큰 정비 결정을 합니다. |
| 6 | 다음 웨이브 예고에서 방금 고른 선택이 어디에 도움이 되는지 봅니다. |

상점 추천은 정답 표시가 아니라, 피해 진단과 다음 압박을 연결하는 짧은 힌트입니다.

시간이 끝나도 강제 구매하지 않으며, 구매 없이 넘어가는 것도 정상 선택입니다.

### 경제 기준

경제는 복잡한 재화 여러 개보다, 사용처가 분명한 소수의 재화로 시작합니다.

| 재화 | 획득처 | 사용처 | 설계 의도 |
| --- | --- | --- | --- |
| 골드 | 적 처치, 라운드 정산, 보스 처치 | 카드 제거, 카드 강화, 기지 보강, 일회성 주문 | 대부분의 선택을 담당하는 기본 재화입니다. |
| 보스 파편 | 보스 부위 파괴, 보스 처치 | 아티팩트 교체, 고급 카드 제거, 특수 상점 | 10일 단위 큰 결정을 담당합니다. |
| 시드 마나 | 하루 시작 시 지급 | 전투 준비와 첫 카드 사용 | 라운드 시작 안정성을 보장합니다. |
| 전투 마나 | 처치 기반 충전 | 전투 중 카드 사용 | 잘 만든 방어선이 행동 기회로 이어지게 합니다. |

경제의 핵심은 "더 많이 벌기"보다 "어디에 쓸지 고민하기"입니다.

특히 웨이브 겹치기는 재화 총량을 늘리지 않으므로, 경제 성장 수단으로 취급하지 않습니다.

### 전투 사이 이벤트

이벤트는 매번 등장하지 않습니다.

전투 리듬을 끊지 않기 위해, 3~5일에 한 번 정도 짧게 등장하는 것이 좋습니다.

이벤트의 목적:

- 파티가 다음 운영 방향을 짧게 토론하게 만들기
- 기지 체력, 카드, 골드, 아티팩트 사이의 교환을 만들기
- 이번 런의 이야기를 조금씩 다르게 만들기

이벤트는 보상 화면이 아니라 **짧은 협동 딜레마**입니다.

좋은 이벤트는 "무엇을 얻는가"보다 "무엇을 감수하고 다음 압박을 어떻게 바꿀 것인가"를 먼저 묻습니다.

### 이벤트 선택 6단계

| 단계 | 역할 |
| ---: | --- |
| 1 | 이벤트가 왜 등장했는지 보여줍니다. 지난 피해, 계절, 다음 압박 중 하나와 연결합니다. |
| 2 | 각 선택지의 즉시 비용과 다음 3~5일 영향을 숨기지 않고 보여줍니다. |
| 3 | 개인 선택인지 파티 선택인지 표시합니다. 파티 자원을 쓰면 투표가 필요합니다. |
| 4 | 최대 2~3개 선택지만 놓고 짧게 결정합니다. 일반 이벤트는 30~60초 안에 끝납니다. |
| 5 | 결과를 한 문장으로 확정합니다. 설명하지 않은 숨은 벌칙은 주지 않습니다. |
| 6 | 다음 웨이브 예고나 상점 추천에 이벤트 결과를 다시 표시합니다. |

### 이벤트 선택지 유형

| 유형 | 예시 | 설계 기준 |
| --- | --- | --- |
| 경제 교환 | 골드 획득, 기지 체력 손실 | 낮은 체력에서는 위험 경고를 더 강하게 표시합니다. |
| 덱 압박 | 저주 카드 획득, 카드 제거 할인 | 저주는 플레이어가 선택한 결과로만 들어옵니다. |
| 방향 압박 | 특정 활성 방향 둔화, 다음 웨이브 밀도 변화 | 비활성 방향을 적 스폰이나 필수 방어 압박으로 열지 않습니다. |
| 구조물 계약 | 수리 비용 감소, 취약 구조물 추가 | 구조물 파괴를 전술로 쓰되 무한 회수 루프를 만들지 않습니다. |
| 아티팩트 탐색 | 후보 미리보기, 교체 비용 변화 | 파티 공유 효과이므로 투표와 미리보기가 필요합니다. |
| 템포 계약 | 다음 웨이브 즉시 호출, 준비 시간 축소 | 보상 증가 없이 대기 시간을 줄이는 선택으로만 씁니다. |

이벤트 예시:

| 이벤트 | 선택지 A | 선택지 B | 핵심 경고 |
| --- | --- | --- | --- |
| 갈라진 저장고 | 파티 골드를 얻고 기지 체력을 잃습니다. | 아무것도 얻지 않고 지나갑니다. | 기지 체력 10 이하에서는 위험 선택으로 표시합니다. |
| 침묵의 순례자 | 지원자 1명이 저주 카드 1장을 받고, 파티가 아티팩트 후보 정보를 엿봅니다. | 골드를 지불하고 안전하게 보냅니다. | 저주는 강제 삽입하지 않습니다. |
| 무너진 공방 | 다음 상점의 구조물 강화 비용이 감소합니다. | 다음 상점의 카드 제거 비용이 감소합니다. | 파티가 최근에 겪은 피해 태그와 연결합니다. |
| 얼어붙은 길 | 다음 2일 동안 가장 위험한 활성 방향의 적 이동이 느려집니다. | 대신 같은 기간 적 수가 소폭 증가합니다. | 비활성 방향은 열지 않습니다. |
| 오래된 종소리 | 다음 보스 부위 예고가 빨라집니다. | 다음 보스가 첫 압력 패턴을 조금 더 일찍 사용합니다. | 보스 보상 배율은 올리지 않습니다. |

이벤트는 정답 선택이 있으면 안 됩니다.

현재 덱과 기지 상태, 다음 웨이브 예고에 따라 매번 다른 선택이 좋아 보여야 합니다.

시간이 끝나면 무작위 선택이나 가혹한 선택을 하지 않습니다.

기본값은 "아무것도 얻지 않고 지나가기" 또는 "현재 상태를 보존하는 선택"입니다.

### 상점 가격 방향

정확한 수치는 프로토타입에서 조정하지만, 상대적 가격 방향은 미리 정합니다.

| 항목 | 가격 방향 | 이유 |
| --- | --- | --- |
| 일반 카드 구매 | 낮음 | 덱 방향을 빨리 잡게 합니다. |
| 카드 강화 | 중간 | 좋은 카드를 더 좋게 만들지만 남발은 막습니다. |
| 카드 제거 | 높음 | 덱 압축이 너무 쉬워지면 덱 빌딩 긴장이 줄어듭니다. |
| 시작 카드 제거 | 매우 높음 | 기본 덱을 너무 빨리 지우지 못하게 합니다. |
| 기지 체력 회복 | 상황에 따라 높음 | 실수를 돈으로 완전히 지우지 못하게 합니다. |
| 일회성 주문 | 중간~높음 | 다음 보스나 위기를 대비하는 선택지입니다. |
| 아티팩트 교체 | 보스 파편 요구 | 장기 운영 방향을 바꾸는 고급 선택입니다. |

MVP 기준 골드 가격입니다.

| 항목 | 기본 가격 | 가격 변화 |

| 일반 카드 구매 | 20 | 희귀도에 따라 증가 |

보스 파편 가격:

| 항목 | 보스 파편 |
| --- | ---: |

상점은 모든 항목을 항상 보여주지 않습니다.

일반 상점은 5~6개 항목만 보여주고, 보스 후 상점은 7~8개 항목을 보여줍니다.

선택지가 너무 많으면 협동 토론이 아니라 메뉴 검토가 됩니다.

## 적 설계

적은 단순히 체력과 속도만 다른 대상이 아니라, 방어선에 서로 다른 질문을 던져야 합니다.

| 적 유형 | 설계 목적 |
| --- | --- |
| 군집형 | 광역 피해와 킬존 설계를 검증합니다. |
| 돌파형 | 빠른 이동으로 느린 방어선을 흔듭니다. |
| 파괴형 | 바리케이드와 타워를 직접 공격해 미로를 망가뜨립니다. |
| 저항형 | 특정 피해나 군중 제어에 강해 단일 전략을 견제합니다. |
| 방해형 | 수리 방해, 마나 감소, 드로우 지연처럼 전투 운영을 흔듭니다. |
| 정예형 | 일반 적 무리 안에 섞여 우선 처치 판단을 요구합니다. |

좋은 웨이브는 많은 적을 한꺼번에 던지는 것이 아니라, 서로 다른 압박을 섞어 플레이어가 방어선의 약점을 발견하게 만드는 것입니다.

### 웨이브 조합 원칙

웨이브는 한 가지 문제만 던지면 쉽게 반복됩니다.

하지만 너무 많은 문제를 한 번에 던지면 플레이어가 원인을 파악하지 못합니다.

기본 웨이브는 다음 조합을 권장합니다.

- 주력 적 1종
- 보조 압박 적 1종
- 가끔 정예 적 1종

예시:

| 조합 | 플레이어에게 던지는 질문 |
| --- | --- |
| 군집형 + 파괴형 | 광역으로 먼저 녹일 것인가, 파괴형을 우선 처치할 것인가? |
| 돌파형 + 저항형 | 빠른 적을 늦출 것인가, 튼튼한 적을 오래 붙잡을 것인가? |
| 방해형 + 군집형 | 손패와 마나가 꼬인 상태에서 킬존을 유지할 수 있는가? |
| 정예형 + 일반 적 다수 | 정예를 먼저 자를 것인가, 무리를 먼저 정리할 것인가? |

### 적 1차 목록

적 이름은 과하게 설명적일 필요는 없지만, 기능은 명확해야 합니다.

| 이름 | 유형 | 행동 | 대응 포인트 |
| --- | --- | --- | --- |
| 회색 행렬 | 군집형 | 약한 적이 많이 몰려옵니다. | 광역 피해와 킬존 성능을 검증합니다. |
| 틈새 주자 | 돌파형 | 빠르게 이동하고 둔화 효과를 짧게 받습니다. | 넉백, 도발, 즉발 피해가 필요합니다. |
| 균열 망치 | 파괴형 | 가까운 구조물을 우선 공격합니다. | 먼저 처치하거나 일부러 폭발 바리케이드에 묶습니다. |
| 유리 껍질 | 저항형 | 광역 피해를 덜 받지만 단일 집중 피해에 약합니다. | 원소술사 단일 의존을 견제합니다. |
| 침묵 운반자 | 방해형 | 주변에서 드로우 게이지 충전량을 낮춥니다. | 우선 처치 판단을 요구합니다. |
| 검은 등짐 | 정예형 | 쓰러질 때 주변 적의 속도를 잠시 높입니다. | 처치 타이밍을 조절해야 합니다. |
| 무거운 순례자 | 압박형 | 느리지만 기지 피해가 큽니다. | 긴 경로와 지속 화력이 필요합니다. |
| 뒤틀린 표식 | 지원형 | 근처 적이 도발에 덜 끌리게 만듭니다. | 수호자 중심 방어선을 흔듭니다. |

초반에는 회색 행렬, 틈새 주자, 균열 망치 정도만으로도 핵심 재미를 검증할 수 있습니다.

이후 저항형과 방해형을 추가해 단일 전략을 견제합니다.

### 적 기본 스펙

아래 수치는 MVP 첫 조정 기준입니다.

속도는 기본 적 이동 속도를 1.0으로 둔 상대값입니다.

| 이름 | 체력 | 속도 | 구조물 피해 | 기지 피해 | 자원 등급 | 특수 규칙 |
| --- | ---: | ---: | ---: | ---: | --- | --- |
| 회색 행렬 | 3 | 1.0 | 1 | 1 | 약한 적 | 다수 등장 |
| 틈새 주자 | 2 | 1.8 | 1 | 1 | 보통 적 | 둔화 지속 시간 50% 감소 |
| 균열 망치 | 8 | 0.8 | 3 | 2 | 위험 적 | 가까운 구조물 우선 공격 |
| 유리 껍질 | 10 | 0.7 | 1 | 2 | 위험 적 | 광역 피해 40% 감소 |
| 침묵 운반자 | 6 | 0.9 | 1 | 1 | 위험 적 | 주변 드로우 게이지 획득량 감소 |
| 검은 등짐 | 12 | 1.0 | 2 | 3 | 정예 적 | 사망 시 주변 적 속도 증가 |
| 무거운 순례자 | 18 | 0.5 | 2 | 4 | 정예 적 | 넉백 효과 크게 감소 |
| 뒤틀린 표식 | 7 | 0.9 | 1 | 1 | 위험 적 | 주변 적 도발 저항 증가 |

적 체력은 낮게 시작하고, 웨이브 수량과 조합으로 난이도를 만듭니다.

초반부터 체력이 높은 적을 많이 쓰면 덱 빌딩보다 단순 화력 부족으로 느껴질 수 있습니다.

### 웨이브 생성 규칙

웨이브는 완전 무작위로 만들지 않습니다.

무작위성은 반복 플레이를 살리지만, 플레이어가 억울하게 느끼면 안 됩니다.

웨이브 생성은 다음 단계를 따릅니다.

1. 현재 날짜와 계절에 맞는 위험도를 정합니다.
2. 주력 적 유형을 하나 고릅니다.
3. 보조 압박 적 유형을 하나 고릅니다.
4. 일정 날짜 이후부터 정예 적을 낮은 확률로 섞습니다.
5. 등장 방향을 정합니다.
6. 예고 UI에 주요 위험을 표시합니다.

웨이브 생성에서 피해야 할 것:

- 같은 카운터를 요구하는 적만 반복 등장
- 특정 직업이 없으면 대응 불가능한 조합
- 예고 없이 방해형 적을 대량 투입
- 초반부터 파괴형과 돌파형을 과하게 섞기
- 웨이브 겹치기를 누르지 않았는데도 항상 과밀한 전투 만들기

### 위험도 예산

각 웨이브는 보이지 않는 위험도 예산을 가집니다.

적마다 위험도 비용을 부여하고, 날짜가 지날수록 사용할 수 있는 예산이 늘어납니다.

예시:

| 적 | 위험도 비용 |
| --- | ---: |
| 회색 행렬 | 1 |
| 틈새 주자 | 2 |
| 균열 망치 | 3 |
| 유리 껍질 | 3 |
| 침묵 운반자 | 4 |
| 검은 등짐 | 5 |
| 무거운 순례자 | 5 |
| 뒤틀린 표식 | 4 |

위험도 예산은 정확한 수치보다 콘텐츠 조합을 통제하기 위한 도구입니다.

예산이 높아질수록 단순히 적 수만 늘리는 것이 아니라, 서로 다른 문제를 섞을 수 있게 됩니다.

### 난이도 곡선

난이도는 세 축으로 올라갑니다.

- 적 수 증가
- 적 조합 복잡도 증가
- 전장 압박 증가

처음부터 세 축을 모두 올리면 플레이어가 원인을 파악하지 못합니다.

권장 흐름:

| 구간 | 난이도 상승 방식 | 목적 |
| --- | --- | --- |
| 1~5일 | 적 수와 기본 속도만 증가 | 기본 조작과 킬존 이해 |
| 6~10일 | 파괴형과 돌파형 등장 | 구조물 파괴와 즉발 대응 학습 |
| 11~20일 | 저항형과 방해형 조합 추가 | 단일 정답 빌드 견제 |
| 21~25일 | 정예와 활성 방향 분산 압박 | 협동과 전장 분배 학습 |
| 26~30일 | 여름 진입과 빠른 템포 예고 | 다음 계절 압박 준비 |
| 31~40일 | 과열 타일과 빠른 적 추가 | 킬존 이동과 템포 대응 |
| 41~50일 | 파괴형과 빠른 붕괴 압박 강화 | 구조물 손실을 전술로 전환 |
| 51~60일 | 낙엽과 잔해로 경로 변화 | 고정 방어선 의존 견제 |
| 61~70일 | 방해형 정예와 우선순위 압박 | 팀 내 역할 재분배 |
| 71~80일 | 결빙과 설치 공간 축소 | 마지막 킬존 위치 학습 |
| 81~90일 | 보스 압력 타일과 다방향 위기 | 최종 재설계 준비 |
| 91~100일 | 장기 압력 권역과 최종 보스 | 남은 공간으로 마지막 방어 완성 |

MVP에서는 1~10일 구간의 학습 흐름이 가장 중요합니다.

첫 10일이 잘 읽히지 않으면 100일 구조는 의미가 없습니다.

### 11~20일 첫 운영 6단계 루프

11~20일은 첫 보스 후 얻은 아티팩트와 상점 선택을 실제 전투에서 확인하는 첫 운영 구간입니다.

새 규칙을 많이 넣기보다, 1~10일에 배운 방어선을 저항형과 방해형으로 흔듭니다.

| 단계 | 일자 | 운영 압박 | 플레이어 질문 | 금지선 |
| ---: | --- | --- | --- | --- |
| 1 | 11~12일 | 첫 성장 체감과 유리 껍질 | 내 첫 보상 선택이 어떤 문제를 잘 푸는가? | 보상 선택을 틀린 선택처럼 만들기 |
| 2 | 13~14일 | 침묵 운반자와 빠른 저항 조합 | 먼저 잡을 대상과 오래 붙잡을 대상을 나누는가? | 방해형과 저항형을 예고 없이 대량 투입 |
| 3 | 15일 | 작은 이벤트와 상점 | 지금 빌드의 약점을 보완할 것인가, 강점을 밀 것인가? | 상점 항목 과다, 강제 구매 |
| 4 | 16~17일 | 2방향 분담과 구조물 재검증 | 첫 아티팩트가 다른 방향 압박에서도 의미 있는가? | 1인 동쪽 외 스폰, 4인 사방 동시 압박 |
| 5 | 18~19일 | 겹치기 판단과 정예 예고 | 안정 상태와 위험 상태를 구분해 템포를 고르는가? | 겹치기 보상 증가 암시 |
| 6 | 20일 | 침묵의 거상 변형 | 10일에 배운 부위 판단을 한 가지 변형 속에서도 쓰는가? | 새 부위, 새 패턴, 강한 동반 웨이브 동시 추가 |

11~20일의 좋은 실패는 "딜이 부족했다"보다 "유리 껍질을 오래 붙잡고 침묵 운반자를 먼저 잘랐어야 했다"처럼 우선순위가 남는 실패입니다.

### 21~30일 MVP 협동 6단계 루프

21~30일은 30일 MVP 런의 마무리입니다.

이 구간의 목적은 모든 시스템을 더 어렵게 만드는 것이 아니라, 파티가 같은 전장을 보고 우선순위를 말로 맞출 수 있는지 확인하는 것입니다.

| 단계 | 일자 | 협동 압박 | 플레이어 질문 | 금지선 |
| ---: | --- | --- | --- | --- |
| 1 | 21일 | 첫 정예 타이밍 | 정예를 지금 잡을지, 조금 더 묶어둘지 합의하는가? | 정예를 체력만 높은 적으로 만들기 |
| 2 | 22~24일 | 킬존 재설계와 방향 분담 | 빠른 라인, 방해 라인, 지원형을 나눠 볼 수 있는가? | 비활성 방향 예고, 2인 3방향 압박 |
| 3 | 25일 | 계절 전환 선택 | 봄 빌드를 마무리하고 여름 속도에 대비하는가? | 보스 보상급 대형 보상 |
| 4 | 26~27일 | 여름 템포와 우선 타겟 | 더 빠른 스폰 속도 속에서도 정예/방해형 우선순위를 정하는가? | 새 여름 규칙 과다 투입 |
| 5 | 28~29일 | 고밀도 리허설 | 3웨이브 겹치기와 MVP 총정리를 보상 없이 위험 판단으로 쓰는가? | 겹치기 보상 증가 문구 |
| 6 | 30일 | 사계의 관측자 예고형 | 불완전한 예고 속에서도 활성 방향 안에서 나누어 준비하는가? | 거짓 예고, 비활성 방향 스폰 |

30일 MVP의 좋은 결말은 "이제 다음에는 다른 직업이나 다른 빌드로 다시 해보고 싶다"입니다.

30일 보스는 런의 끝을 화려하게 터뜨리는 장면보다, 다음 50일 완성형 관측자를 기대하게 만드는 약한 예고여야 합니다.

### 방향별 웨이브 성격

네 방향 입구는 플레이어가 방어선을 다르게 설계하게 만드는 장치입니다.

아래 표는 맵 입구의 성격입니다.

실제 일반 웨이브는 런 시작 인원수에 따른 활성 방향 안에서만 등장합니다.

| 방향 | 기본 성격 | 자주 등장하는 적 |
| --- | --- | --- |
| 북쪽 | 넓고 느린 압박 | 무거운 순례자, 유리 껍질 |
| 동쪽 | 설치 공간은 많지만 경로가 짧음 | 회색 행렬, 균열 망치 |
| 남쪽 | 굴곡이 많고 킬존을 만들기 쉬움 | 회색 행렬, 침묵 운반자 |
| 서쪽 | 직선 압박과 빠른 돌파 | 틈새 주자, 검은 등짐 |

방향별 개성은 있어야 하지만, 특정 방향이 항상 쉽거나 항상 어려우면 안 됩니다.

웨이브 예고를 보고 플레이어가 "이번엔 빠른 라인을 먼저 보강하자"처럼 말하게 만드는 것이 목표입니다.

## 보스 설계

보스는 거대한 체력을 가진 적이 아니라, 전장 전체의 규칙을 바꾸는 사건입니다.

### 보스의 기본 방향

- 화면을 압도하는 크기를 가집니다.
- 이동 속도는 느리지만, 접근 자체가 강한 압박이 됩니다.
- 여러 부위를 가지고 있어 공격 우선순위를 만듭니다.
- 특정 부위를 파괴하면 패턴을 약화시키거나 자원을 얻습니다.
- 일정 구간마다 방어선을 직접 파괴하거나 경로를 바꿉니다.

### 보스가 만드는 질문

- 어느 부위를 먼저 부술 것인가?
- 킬존을 보스용으로 다시 설계할 것인가?
- 일반 웨이브와 보스를 동시에 감당할 수 있는가?
- 이 구조물은 지킬 가치가 있는가, 터뜨릴 가치가 있는가?
- 지금 웨이브를 더 부르면 보스전이 짧아지는가, 기지가 무너지는가?

### 연출 방향

폭력성, 유혈, 고어 표현은 배제합니다.

공포는 잔혹함이 아니라 규모와 침묵에서 나옵니다.

- 화면 밖에서 먼저 들리는 낮은 진동음
- 멀리서 보이는 거대한 실루엣
- 기지 위로 천천히 드리우는 그림자
- 보스가 가까워질수록 작아지는 배경음
- 부위 파괴 시 피가 아니라 빛, 먼지, 균열, 금속음으로 피드백

목표는 플레이어가 "죽인다"보다 "버텨야 한다"고 느끼게 만드는 것입니다.

### 첫 번째 보스 기준

MVP의 첫 보스는 복잡한 패턴보다 이 게임의 핵심을 검증하는 역할을 맡습니다.

목표:

- 플레이어가 만든 미로를 직접 압박합니다.
- 구조물 파괴가 보스전에서 의미 있게 작동합니다.
- 부위 파괴와 처치 기반 자원 회복을 동시에 검증합니다.

구성 예시:

- 본체: 느리게 기지로 이동합니다.
- 전면부: 일정 시간마다 가장 가까운 구조물을 공격합니다.
- 다리부: 파괴하면 일정 시간 보스 이동 속도가 느려집니다.
- 등불부: 파괴하면 모든 플레이어가 카드 1장을 뽑습니다.

이 보스는 화려한 패턴보다 "다가오는 큰 덩어리를 어떻게 늦출 것인가"에 집중합니다.

### 침묵의 거상 상세 스펙

침묵의 거상은 MVP 첫 보스입니다.

목표는 보스전의 모든 규칙을 보여주는 것이 아니라, "거대한 적이 천천히 다가오고, 플레이어가 방어선을 다시 설계한다"는 핵심 경험을 검증하는 것입니다.

기본값:

| 항목 | 값 |
| --- | ---: |
| 등장일 | 10일 |
| 본체 체력 | 120 |
| 이동 속도 | 일반 적의 0.35배 |
| 기지 도달 첫 피해 | 15 |
| 기지 도달 후 두 번째 피해 예고 | 5초 |
| 두 번째 피해 | 즉시 패배 |
| 보스 경로 폭 | 3타일 |
| 기본 상태이상 저항 | 둔화 40%, 빙결 80%, 넉백 90% 감소 |

부위:

다리부는 화면에서 좌우 다리처럼 보일 수 있지만, 첫 보스 UI와 데이터에서는 하나의 논리 타겟으로 묶습니다.

| 부위 | 체력 | 효과 | 파괴 보상 |
| --- | ---: | --- | --- |
| 전면부 | 35 | 12초마다 가까운 구조물에 큰 피해 | 파괴 주기 12초에서 20초로 증가 |
| 다리부 | 50 | 보스 이동 담당 | 이동 속도 25% 감소 |
| 등불부 | 25 | 주변 드로우 게이지 획득량 20% 감소 | 모든 플레이어 카드 1장 드로우 |

부위에 준 피해의 30%는 본체 피해로 전이됩니다.

패턴:

| 패턴 | 발동 조건 | 효과 | 대응 |
| --- | --- | --- | --- |
| 무언의 발걸음 | 상시 | 천천히 기지로 이동 | 경로 지연, 둔화, 다리 파괴 |
| 짓누르기 | 12초마다, 전면부 파괴 후 20초마다 | 가까운 구조물 1개에 큰 피해 | 도발 타워, 수리, 임시 구조물 |
| 침묵의 등불 | 체력 70% 이하, 등불부 생존 | 보스 주변 드로우 게이지 획득량 감소 | 등불부 파괴 |
| 마지막 접근 | 기지 근처 도달 | 화면 흔들림과 두 번째 피해 예고 | 전력 집중, 넉백/둔화 약화 적용 |

첫 보스 6단계 루프:

| 단계 | 장면 | 플레이어가 배워야 할 것 |
| ---: | --- | --- |
| 1 | 입장 예고 | 보스 경로 폭과 추천 다리부 타겟을 확인합니다. |
| 2 | 다리부 학습 | 보스를 죽이기 전에 늦추는 선택을 봅니다. |
| 3 | 짓누르기 선택 | 지킬 구조물과 버릴 구조물을 나눕니다. |
| 4 | 등불부 선택 | 드로우 약화 원인을 보고 방해 부위를 처리합니다. |
| 5 | 마지막 접근 | 남은 카드와 제어를 모두 써 마지막 시간을 법니다. |
| 6 | 결과 연결 | 실패 원인이나 승리 태그를 다음 상점과 아티팩트 선택으로 넘깁니다. |

10일 첫 보스의 동반 웨이브는 약한 시야 테스트까지만 담당합니다.

인원수와 상관없이 3방향 이상 동시 보스 압박을 만들지 않고, 웨이브 겹치기 보상도 붙이지 않습니다.

침묵의 거상은 플레이어가 처음으로 "보스를 잡는 것"보다 "보스를 늦추는 것"을 배우게 해야 합니다.

보스를 빠르게 처치하지 못해도, 다리부와 등불부를 부수며 시간을 벌면 승산이 생깁니다.

상세한 전투 흐름, 인원수별 적용, 실패 피드백은 [docs/BOSS_DESIGN_AND_PATTERNS.md](docs/BOSS_DESIGN_AND_PATTERNS.md)에 정리합니다.

### 보스 1차 목록

MVP 이후에는 보스마다 "전장을 어떻게 망가뜨리는가"가 달라져야 합니다.

| 이름 | 핵심 압박 | 주요 패턴 | 플레이어 질문 |
| --- | --- | --- | --- |
| 침묵의 거상 | 느린 접근과 구조물 파괴 | 가장 가까운 구조물을 짓누르고 부위 파괴 시 느려집니다. | 방어선을 얼마나 오래 붙잡을 것인가? |
| 사계의 관측자 | 웨이브 방향 교란 | 30일에는 약한 예고형, 50일에는 활성 방향 안에서 후보 예고를 흔드는 강화형으로 등장합니다. | 불완전한 정보로 어디를 막을 것인가? |
| 무너진 종탑 | 오라와 수리 견제 | 60일에는 예고된 무음 권역을, 70일 변형에서는 정예 동반 웨이브 조합을 사용합니다. | 밀집 방어선을 포기하고 분산할 것인가? |
| 겨울의 문 | 최종 압박 | 80일 예고형, 90일 본체, 100일 완전체로 확장되며 완전체는 장기 압력 권역을 사용합니다. | 남은 공간으로 마지막 킬존을 만들 수 있는가? |

보스는 매번 새로운 미니게임이 되기보다, 기존 시스템을 다른 방식으로 시험해야 합니다.

플레이어가 배운 미로, 파괴, 수리, 도발, 광역 피해를 모두 다시 생각하게 만드는 것이 목표입니다.

### 보스 단계 규칙

보스는 체력 비율에 따라 단순히 더 세지는 것이 아니라, 플레이어의 방어선 이해를 다른 방식으로 시험해야 합니다.

기본 3단계 구조:

| 단계 | 보스 상태 | 플레이어 경험 |
| --- | --- | --- |
| 1단계 | 멀리서 천천히 접근 | 기존 방어선으로 얼마나 늦출 수 있는지 확인합니다. |
| 2단계 | 일부 부위 활성화 | 특정 부위를 먼저 부술지, 일반 웨이브를 정리할지 판단합니다. |
| 3단계 | 기지 근처 압박 | 남은 구조물을 지킬지 터뜨릴지 결정합니다. |

각 단계는 새로운 규칙을 하나만 추가하는 것이 좋습니다.

한 번에 여러 패턴이 열리면 플레이어가 무엇 때문에 무너졌는지 알기 어렵습니다.

### 보스 부위 설계

부위는 약점 표시 이상의 역할을 해야 합니다.

좋은 부위는 "부수면 보상이 있다"와 "안 부수면 문제가 생긴다"를 동시에 가집니다.

| 부위 | 역할 | 파괴 보상 | 방치 시 문제 |
| --- | --- | --- | --- |
| 전면부 | 구조물 직접 파괴 | 보스의 파괴 주기 감소 | 방어선이 빠르게 무너짐 |
| 다리부 | 이동 담당 | 보스 이동 속도 감소 | 기지 도달 시간이 빨라짐 |
| 등불부 | 방해 효과 담당 | 카드 드로우 또는 마나 회복 | 드로우나 시야 방해 발생 |
| 외피부 | 방어 담당 | 받는 피해 증가 | 보스전이 지나치게 길어짐 |
| 핵심부 | 마지막 약점 | 큰 피해 기회 | 최종 단계 압박 지속 |

부위는 너무 많으면 타겟팅 피로가 생깁니다.

MVP 보스는 3개 부위 정도로 시작합니다.

### 보스와 웨이브 겹치기

보스전 중에도 웨이브 겹치기는 가능하지만, 보상은 여전히 증가하지 않습니다.

보스전에서 웨이브를 앞당기는 이유는 다음 중 하나여야 합니다.

- 보스가 멀리 있을 때 시간을 압축하고 싶다.
- 처치 기반 마나와 드로우를 빠르게 당겨 보스 부위를 부수고 싶다.
- 현재 방어선이 안정적이라 다음 일반 웨이브를 미리 처리하고 싶다.

보스전 웨이브 겹치기는 강력한 선택이지만, 보상 효율 때문에 강제되면 안 됩니다.

보스가 기지 근처에 있거나 기지 체력이 낮을 때는 매우 위험해야 합니다.

## 초기 직업

각 직업은 솔로와 멀티에서 같은 고유 메커니즘을 사용합니다.

인원수에 따라 수치만 조정되고, 역할 정체성은 변하지 않습니다.

### 수호자

역할: 방어, 도발, 반사 피해

수호자의 타워는 주변 적을 끌어들이는 도발 오라를 가집니다.

적에게 공격받을 때 방어력에 비례한 가시 피해를 줍니다.

전술적 정체성:

적의 동선을 꺾고, 일부러 맞으면서 딜타임을 벌어주는 전장의 중심축입니다.

대표 카드:

- 도발벽 설치
- 방어력 증가
- 가시 피해 증폭
- 일정 시간 파괴 불가
- 도발 범위 확장

주의할 점:

수호자가 너무 단단하면 미로 설계가 단순해집니다. 맞으면서 버티되, 수리와 위치 선정 없이는 결국 무너져야 합니다.

### 건축가

역할: 미로 설계, 바리케이드, 파괴 연계

건축가의 바리케이드는 저렴하고 튼튼하며, 파괴될 때 주변 적에게 광역 피해를 줍니다.

전술적 정체성:

방어선의 모양과 적의 이동 시간을 설계하는 직업입니다.

구조물이 부서지는 순간까지 공격 계획에 포함합니다.

대표 카드:

- 바리케이드 대량 설치
- 둔화 함정 설치
- 잔해 폭발 강화
- 파괴 시 골드 또는 마나 회수
- 임시 우회로 생성

주의할 점:

건축가가 혼자 모든 경로를 해결하면 다른 직업의 의미가 줄어듭니다. 건축가는 시간을 벌고 판을 만들지만, 마무리 화력과 유지보수는 다른 직업과 맞물려야 합니다.

### 원소술사

역할: 광역 피해, 군중 제어, 킬존 마무리

원소술사는 단일 대상보다 범위 피해에 특화되어 있습니다.

적을 밀쳐내거나 얼려 이동을 방해합니다.

전술적 정체성:

잘 모인 적을 한 번에 정리하는 메인 화력입니다.

킬존의 성능을 폭발시키는 역할을 맡습니다.

대표 카드:

- 화염 폭격
- 빙결 지대
- 넉백 충격파
- 감전 연쇄
- 원소 취약 부여

주의할 점:

원소술사의 광역 피해가 너무 안정적이면 모든 웨이브가 같은 방식으로 정리됩니다. 저항형 적과 보스 부위 패턴으로 타이밍 판단을 요구해야 합니다.

### 땜장이

역할: 버프, 수리, 유지보수

땜장이의 타워는 주변 모든 타워의 공격 속도와 방어력을 증가시킵니다.

또한 전장의 타워를 원격으로 수리할 수 있습니다.

전술적 정체성:

방어선의 지속력을 책임지는 지원가입니다.

타워를 밀집 배치할수록 파티 전체 효율을 크게 끌어올립니다.

대표 카드:

- 원격 수리
- 공격 속도 오라
- 방어력 오라
- 파괴 직전 자동 복구
- 과부하 강화

주의할 점:

땜장이의 수리가 너무 강하면 구조물 파괴의 긴장감이 사라집니다. 수리는 완전 회복보다 파괴 타이밍을 늦추는 역할에 가까워야 합니다.

## 직업 간 시너지

| 조합 | 기대 경험 |
| --- | --- |
| 수호자 + 건축가 | 일부러 맞고 터지는 방어선을 설계합니다. |
| 수호자 + 원소술사 | 도발로 적을 모은 뒤 광역 피해로 정리합니다. |
| 수호자 + 땜장이 | 오래 버티는 전면 방어선을 만듭니다. |
| 건축가 + 원소술사 | 미로와 둔화로 적을 모아 폭격 효율을 높입니다. |
| 건축가 + 땜장이 | 바리케이드를 오래 유지하거나, 터질 타이밍을 조절합니다. |
| 원소술사 + 땜장이 | 공격 속도와 제어 효과를 증폭해 킬존을 강화합니다. |

## 협동 구조

협동은 단순히 각자 맡은 라인을 막는 구조에 머물면 안 됩니다.

좋은 협동 상황은 모든 플레이어가 같은 위험을 보고 서로 다른 해결책을 제안할 때 생깁니다.

### 협동을 만드는 장치

- 웨이브 겹치기 투표
- 기지 체력 공유
- 파티 공유 아티팩트
- 서로의 타워에 영향을 주는 오라
- 특정 위치에 화력을 모아야 하는 보스 부위
- 한 플레이어의 구조물 파괴가 다른 플레이어의 카드 효과를 발동시키는 연계

### 피해야 할 상황

- 각자 자기 구역만 보느라 대화가 사라지는 구조
- 한 직업이 모든 문제를 혼자 해결하는 구조
- 웨이브 겹치기가 보상 효율 때문에 강제되는 구조
- 특정 카드나 아티팩트 조합이 항상 정답이 되는 구조

### 커뮤니케이션 도구

플레이어가 말로만 모든 정보를 전달하게 만들면 협동 피로가 커집니다.

게임 안에서 빠르게 의도를 표시할 수 있어야 합니다.

필요한 도구:

- 위치 핑
- 적 우선 처치 핑
- 구조물 수리 요청 핑
- 웨이브 겹치기 제안 버튼
- 기지 위험 경고
- 보스 부위 집중 공격 표시

핑은 채팅을 대체하는 기능이 아니라, 말로 하는 협동을 더 빠르게 만드는 보조 장치입니다.

### 핑과 협동 콜

핑은 명령이 아니라 제안입니다.

다른 플레이어의 카드, 마나, 구조물 조작을 자동으로 실행하지 않습니다.

협동 콜은 아래 6단계로 흐릅니다.

| 단계 | 역할 |
| ---: | --- |
| 1 | 예고 UI나 전투 경고가 위험을 보여줍니다. |
| 2 | 플레이어가 수리, 집중 화력, 경로 확인, 도발 전환 같은 핑을 남깁니다. |
| 3 | 파티원이 체크하거나 `내가 볼게` 표시로 대응 의사를 남깁니다. |
| 4 | 요청형 핑을 누르면 관련 카드, 구조물, 경로 미리보기가 하이라이트됩니다. |
| 5 | 위험이 해소되거나 시간이 지나면 핑이 자동으로 접힙니다. |
| 6 | 웨이브 후 리포트에 어떤 대응 핑이 실제 행동으로 이어졌는지 짧게 남습니다. |

한 플레이어의 직접 핑은 동시에 3개까지만 유지합니다.

핑 텔레메트리는 개인 평가가 아니라 협동 요청의 읽힘과 해소 여부만 기록합니다.

## 솔로와 멀티 스케일링

직업의 고유 메커니즘은 인원수와 상관없이 바뀌지 않습니다.

대신 게임은 다음 요소를 조정합니다.

- 활성화되는 적 진입 방향 수
- 웨이브당 적 수
- 정예 적 등장 빈도
- 기지 체력
- 시작 시드 마나
- 보스 부위 체력
- 상점 가격

솔로에서는 한 직업만으로도 완주 가능해야 합니다.

다만 모든 상황을 완벽히 해결하는 것이 아니라, 선택한 직업의 강점으로 문제를 우회하는 방식이어야 합니다.

인원수별 기본 활성 방향:

| 인원수 | 방향 |
| ---: | --- |
| 1명 | 동쪽 |
| 2명 | 북쪽, 동쪽 |
| 3명 | 서쪽, 북쪽, 동쪽 |
| 4명 | 서쪽, 북쪽, 동쪽, 남쪽 |

비활성 방향은 맵에는 보이지만 일반 웨이브 스폰 후보에서 제외됩니다.

보스, 이벤트, 아티팩트가 비활성 방향을 연출이나 정보 표시로 사용할 수는 있지만, 적 스폰이나 필수 방어 압박으로 열지는 않습니다.

## 조작과 세션 규칙

### 기본 조작

MVP는 키보드와 마우스 기준으로 설계합니다.

| 행동 | 조작 방향 |
| --- | --- |
| 카드 선택 | 숫자키 또는 클릭 |
| 카드 사용 | 대상 클릭 또는 드래그 앤 드롭 |
| 구조물 설치 | 카드 선택 후 타일 클릭 |
| 구조물 수리 | 수리 카드 선택 후 구조물 클릭 |
| 카메라 이동 | WASD 또는 화면 가장자리 |
| 확대/축소 | 마우스 휠 |
| 핑 | Alt + 클릭 |
| 웨이브 겹치기 제안 | 전용 버튼 또는 단축키 |
| 일시정지 | 솔로 전용 완전 정지, 멀티는 전술 느림 모드 |

패드 조작은 정식 출시 후보이지만 MVP 우선순위는 아닙니다.

### 멀티플레이 의사결정

멀티플레이에서 모든 결정을 투표로 만들면 템포가 죽습니다.

투표는 게임 속도를 바꾸거나 파티 전체 자원을 쓰는 결정에만 사용합니다.

투표가 필요한 행동:

- 웨이브 겹치기
- 보스 파편 사용
- 아티팩트 장착 또는 교체
- 파티 골드로 기지 체력 회복
- 다음 계절 전환 보상 선택

투표가 필요 없는 행동:

- 개인 카드 사용
- 개인 마나 사용
- 자기 카드 보상 선택
- 자기 덱 카드 강화
- 자기 손패 버리기

### 웨이브 겹치기 UI 결정

웨이브 겹치기는 투표형 제안 버튼으로 구현합니다.

기본 흐름:

1. 플레이어가 `다음 웨이브 호출` 버튼을 누릅니다.
2. 화면 상단에 8초짜리 투표 알림이 뜹니다.
3. 과반수가 동의하면 즉시 다음 웨이브가 호출됩니다.
4. 기지 체력 30% 이하에서는 모든 플레이어가 동의해야 합니다.
5. 반대가 과반수에 도달하면 투표는 즉시 취소됩니다.

솔로에서는 버튼을 누르면 즉시 호출됩니다.

웨이브 겹치기 투표에는 보상 증가 문구를 절대 표시하지 않습니다.

표시 문구는 "위험을 앞당깁니다" 또는 "다음 웨이브를 지금 호출합니다"에 가깝게 유지합니다.

### 일시정지와 배속

솔로에서는 완전 일시정지를 허용합니다.

멀티에서는 완전 정지 대신 전술 느림 모드를 사용합니다.

| 모드 | 솔로 | 멀티 |
| --- | --- | --- |
| 1배속 | 기본 | 기본 |
| 2배속 | 가능 | 과반수 동의 |
| 3배속 | 가능 | 모든 플레이어 동의 |
| 일시정지 | 가능 | 전술 느림 모드로 대체 |

배속은 자원 회복에 직접 영향을 주지 않습니다.

자원은 시간 경과가 아니라 처치와 웨이브 정산으로 발생합니다.

### 저장과 재접속

런은 긴 편이므로 저장 규칙이 필요합니다.

저장 기준:

- 하루 시작 시 자동 저장
- 보스 처치 후 자동 저장
- 상점 진입 시 자동 저장
- 멀티에서는 호스트 기준 저장

재접속:

- 멀티에서 플레이어가 나가면 해당 직업은 자동 방어 모드로 전환됩니다.
- 자동 방어 모드는 카드를 사용하지 않고, 기존 구조물만 유지합니다.
- 2분 안에 재접속하면 같은 직업을 다시 조작합니다.
- 장기 이탈 시 MVP에서는 해당 직업을 보류 모드로 유지합니다.
- AI 보조 조작은 후순위 확장으로만 검토하며, MVP에서는 카드를 대신 사용하지 않습니다.

### 중단/저장/재개 6단계

긴 런과 협동 세션은 `session_resume_loop_6step`으로 처리합니다.

목표는 끊긴 플레이어를 벌주거나 남은 플레이어에게 보상을 주는 것이 아니라, 이미 확정된 런 기준을 지키면서 최대한 자연스럽게 같은 판으로 돌아오게 만드는 것입니다.

| 단계 | 이름 | 처리 | 금지선 |
| ---: | --- | --- | --- |
| 1 | 안정 저장점 생성 | 하루 시작, 보스 처치 후, 상점 진입, 아티팩트 선택 완료 시 자동 저장 | 전투 중 완전 저장을 MVP에 넣지 않음 |
| 2 | 세션 끊김 감지 | 입력 없음, 연결 끊김, 호스트 응답 지연을 구분해 표시 | 끊김을 패배 원인이나 개인 실수처럼 표시 금지 |
| 3 | 직업 보류 전환 | 해당 직업의 구조물은 유지하고 손패/마나는 잠급니다 | AI가 카드를 자동 사용하거나 자원을 소비하지 않음 |
| 4 | 복귀 스냅샷 전달 | 현재 일자, 웨이브, 손패, 자원, 구조물 소유권을 복원 | 현재 접속 인원으로 방향/스케일링 재계산 금지 |
| 5 | 장기 이탈 처리 | 2분이 지나면 다음 안정 저장점까지 보류 모드 유지 | 남은 플레이어에게 추가 보상이나 난이도 보정 지급 금지 |
| 6 | 재개 확정 | 복귀한 플레이어가 같은 직업을 이어받고 진행 중 투표에는 남은 시간으로 합류 | 재개를 새 런 시작이나 리롤 기회로 사용 금지 |

솔로에서는 완전 일시정지 후 저장점으로 돌아오는 단순 재개를 사용합니다.

멀티에서는 전투를 마음대로 멈추기보다 전술 느림 모드, 보류 모드, 다음 안정 저장점 저장을 조합합니다.

MVP에서는 온라인 멀티보다 로컬/동일 세션 협동 흐름을 먼저 검증합니다.

## 밸런스 주의점

### 웨이브 겹치기

웨이브 겹치기는 효율 버튼이 되면 안 됩니다.

플레이어가 "안 누르면 손해"라고 느끼는 순간, 이 시스템은 템포 조절 기능이 아니라 강제 최적화가 됩니다.

따라서 웨이브 겹치기는 다음 원칙을 지킵니다.

- 보상 총량 증가 금지
- 희귀도 보정 금지
- 추가 선택지 금지
- 기본 최대 3개 유지
- 최대치 증가는 아티팩트로만 제공

### 처치 기반 자원

처치 기반 자원은 전투를 시원하게 만들지만, 무한 콤보 위험이 있습니다.

필요한 제한:

- 마나 저장 한도
- 드로우 게이지 발동 간격
- 짧은 시간 내 반복 처치 보정
- 같은 카드 무한 반복 방지
- 버리기 횟수 제한

### 구조물 파괴

구조물이 너무 약하면 플레이어는 설치를 포기합니다.

구조물이 너무 강하면 미로가 고정되고 전투가 반복됩니다.

따라서 구조물은 버티되, 결국 파괴될 수 있어야 합니다.

파괴는 위기이면서 동시에 카드 효과와 폭발, 자원 회수의 발동점이어야 합니다.

### 초기 튜닝 기준

아래 수치는 확정값이 아니라, 첫 프로토타입에서 감을 잡기 위한 기준입니다.

| 항목 | 초기 기준 |
| --- | --- |
| 기본 손패 한도 | 8장 |
| 성장 후 손패 한도 | 최대 10장 |
| 기본 웨이브 겹치기 최대치 | 3개 |
| 웨이브당 기본 버리기 | 1회 |
| 겹친 전투의 버리기 보유 한도 | 3회 |
| 보스 등장 주기 | 10일 |
| 계절 전환 주기 | 25일 |
| MVP 런 길이 | 20~30일 |

첫 밸런스 테스트에서 가장 먼저 봐야 할 값:

- 한 웨이브 평균 시간
- 웨이브 겹치기 사용 빈도
- 구조물 평균 생존 시간
- 한 라운드 평균 카드 사용 수
- 손패가 막히는 빈도
- 기지 체력이 급격히 무너지는 구간

### 1차 플레이테스트 시나리오

첫 테스트는 100일이 아니라 10일짜리 축소 런으로 진행합니다.

목표는 모든 콘텐츠를 보여주는 것이 아니라, 핵심 루프가 살아 있는지 확인하는 것입니다.

| 일자 | 등장 요소 | 테스트 목적 |
| ---: | --- | --- |
| 1일 | 회색 행렬 | 기본 설치와 적 경로 확인 |
| 2일 | 회색 행렬 증가 | 바리케이드로 경로 시간을 늘리는 감각 확인 |
| 3일 | 틈새 주자 | 빠른 적 대응 확인 |
| 4일 | 회색 행렬 + 틈새 주자 | 광역 처리와 즉발 대응 구분 확인 |
| 5일 | 쉬운 웨이브 + 첫 상점 | 전투에서 느낀 문제를 상점 선택과 연결하는지 확인 |
| 6일 | 균열 망치 | 구조물 파괴가 전술로 느껴지는지 확인 |
| 7일 | 회색 행렬 + 균열 망치 | 파괴 위치와 잔해 활용 확인 |
| 8일 | 안정 웨이브 + 웨이브 겹치기 유도 | 보상 없이도 템포 기능을 쓰는지 확인 |
| 9일 | 회색 행렬 + 침묵 운반자 소량 | 우선 처치와 방해 원인 이해 확인 |
| 10일 | 침묵의 거상 | 첫 보스 압박과 부위 파괴 확인 |

### 1~10일 웨이브 6단계 압박 루프

첫 10일 웨이브는 모든 적을 소개하는 미니 도감이 아닙니다.

튜토리얼에서 배운 판단을 실제 전투 압박으로 되묻는 6단계 루프입니다.

| 단계 | 일자 | 압박 이름 | 핵심 질문 | 새로 강하게 묻지 않는 것 |
| ---: | --- | --- | --- | --- |
| 1 | 1~2일 | 경로 읽기 | 적이 어디로 오고, 구조물로 얼마나 늦출 수 있는가? | 빠른 적, 파괴형, 다방향 |
| 2 | 3~4일 | 속도 구분 | 빠른 적과 군집형을 같은 방식으로 막지 않는가? | 방해형, 파괴형, 상점 복잡도 |
| 3 | 5일 | 정비 골짜기 | 쉬운 전투 뒤에 덱과 상점을 연결하는가? | 새 적 대량, 겹치기 압박 |
| 4 | 6~7일 | 계획된 붕괴 | 어떤 구조물을 살리고, 어떤 구조물을 버릴 것인가? | 돌파형 대량, 예고 없는 파괴 |
| 5 | 8~9일 | 템포와 우선순위 | 안정되면 앞당기고, 위험한 적은 먼저 볼 수 있는가? | 겹치기 보상, 손패 완전 봉쇄 |
| 6 | 10일 | 첫 거상 | 보스를 죽이기 전에 늦추고 부위를 볼 수 있는가? | 3방향 이상 보스 압박 |

1~4일은 모든 인원수에서 실제 스폰 방향을 1개로 제한합니다.

7일과 9일은 2인 이상에서만 2방향 압박을 약하게 사용할 수 있습니다.

10일 첫 보스는 인원수와 상관없이 3방향 이상 동시 압박을 사용하지 않습니다.

1명은 1~10일 내내 동쪽만 사용합니다.

이 10일 테스트에서 재미가 살아야 20~30일 MVP로 확장할 가치가 있습니다.

### 플레이테스트 기록 항목

테스트 후에는 감상만 적지 않고, 반복해서 비교할 수 있는 항목을 기록합니다.

- 플레이 인원
- 선택 직업
- 클리어 여부
- 패배했다면 패배 일자와 원인
- 가장 많이 사용한 카드
- 거의 사용하지 않은 카드
- 웨이브 겹치기 사용 횟수
- 웨이브 겹치기를 누른 이유
- 구조물 파괴가 긍정적으로 느껴진 순간
- 구조물 파괴가 짜증으로 느껴진 순간
- 가장 위협적이었던 적
- 가장 이해하기 어려웠던 정보
- 다시 플레이하고 싶은지 여부

## 온보딩

처음 플레이어에게 모든 규칙을 한 번에 설명하지 않습니다.

이 게임은 직접 방어선이 무너지는 경험을 통해 배우는 편이 좋습니다.

### 첫 10분 학습 목표

플레이어는 첫 10분 안에 다음을 이해해야 합니다.

- 적은 기지로 향하는 경로를 따라 이동합니다.
- 구조물을 배치해 경로를 비틀 수 있습니다.
- 완전 길막은 불가능합니다.
- 구조물은 부서질 수 있습니다.
- 부서지는 구조물도 전술적으로 쓸 수 있습니다.
- 적 처치가 마나와 드로우로 이어집니다.
- 웨이브 겹치기는 보상을 늘리는 기능이 아니라 전투를 빨리 진행하는 기능입니다.

### 첫 학습 6단계 루프

첫 플레이는 설명을 읽는 시간이 아니라, 작은 실패를 통해 방어 언어를 익히는 시간입니다.

| 단계 | 튜토리얼 장면 | 첫 10일 반복 | 플레이어가 얻어야 할 감각 |
| ---: | --- | --- | --- |
| 1 | 경로 보기와 타워 설치 | 1일 | 적은 길을 따라 오고, 타워는 그 길을 읽어야 합니다. |
| 2 | 바리케이드와 길막 불가 | 2일 | 경로를 비틀 수 있지만 완전히 닫을 수는 없습니다. |
| 3 | 빠른 적과 킬존 | 3~4일 | 적을 모으는 자리와 즉시 대응할 적을 구분합니다. |
| 4 | 첫 상점과 파괴형 | 5~7일 | 전투에서 느낀 약점이 상점 선택과 구조물 파괴 판단으로 이어집니다. |
| 5 | 처치 기반 자원과 겹치기 | 8~9일 | 잘 만든 방어선이 마나, 드로우, 빠른 진행 판단을 만듭니다. |
| 6 | 미니 보스 예고와 첫 보스 | 10일 | 보스는 빠르게 죽이는 대상이 아니라 늦추고 부위를 보는 압박입니다. |

첫 학습에서는 한 번에 하나만 가르칩니다.

새 정보가 뜨는 날에는 웨이브 겹치기, 상점 선택지, 방향 압박을 함께 강하게 밀지 않습니다.

### 튜토리얼 순서

튜토리얼은 별도 설명창보다 실제 작은 전투로 구성합니다.

1. 빈 맵에서 기본 타워 설치
2. 적 경로 표시
3. 바리케이드 설치로 경로 변경
4. 완전 길막 시도와 불가 피드백
5. 구조물 파괴 발생
6. 파괴 효과 또는 수리 카드 사용
7. 처치 기반 마나와 드로우 확인
8. 다음 웨이브 미리 호출
9. 첫 카드 보상 선택
10. 짧은 보스 예고 연출

### 실패 피드백

패배는 납득 가능해야 합니다.

플레이어가 왜 졌는지 알 수 있어야 다음 판을 하고 싶어집니다.

패배 화면에서 보여줄 정보:

- 가장 많이 기지에 도달한 적 유형
- 가장 먼저 무너진 방어 구역
- 가장 많이 파괴된 구조물
- 사용하지 못하고 남은 평균 손패 수
- 웨이브 겹치기 이후 급격히 위험해진 시점
- 다음 판 추천 한 줄

추천 문구는 정답을 알려주는 공략이 아니라, 다시 시도할 방향을 제안하는 정도가 좋습니다.

## UI와 정보 전달

이 게임은 협동 판단이 중요하므로, 정보가 명확해야 합니다.

우선적으로 보여줘야 할 정보:

- 다음 웨이브의 방향
- 적 타입과 위험도
- 현재 적 경로
- 구조물 체력
- 도발 대상
- 곧 파괴될 구조물
- 기지 체력
- 웨이브 겹치기 투표 상태
- 각 플레이어의 마나와 손패 수

화려한 연출보다 중요한 것은 "지금 무엇이 위험한지"를 즉시 읽게 하는 것입니다.

### 주요 화면 흐름

MVP에 필요한 화면은 많지 않습니다.

첫 버전은 아래 흐름만 완성해도 충분합니다.

```text
타이틀
-> 로비 / 인원 선택
-> 직업 선택
-> 런 시작
-> 전투 화면
-> 라운드 보상
-> 상점 / 아티팩트 선택
-> 보스전
-> 승리 / 패배 결과
```

### 새 런 준비 6단계

새 런 준비는 `new_run_setup_loop_6step`으로 처리합니다.

결과 회고, 메타 진행, 도감/훈련장에서 넘어온 다음 런 제안은 참고 정보일 뿐이며, 런 시작 조건을 자동으로 바꾸지 않습니다.

| 단계 | 화면 역할 | 확인할 것 | 금지선 |
| ---: | --- | --- | --- |
| 1 | 다음 런 제안 확인 | 결과 회고나 도감에서 온 운영 제안 1~2개 | 정답 빌드, 필수 직업, 자동 세팅 금지 |
| 2 | 인원/방향 확인 | 시작 인원수와 활성 침공 방향 | 시작 후 재접속/이탈로 방향 재계산 금지 |
| 3 | 런 길이 선택 | 10일 테스트, 30일 런, 100일 표준 런 | 웨이브 겹치기 보상 모드 제공 금지 |
| 4 | 직업 선택 | 각 직업 역할, 시작 덱, 파티 역할 빈틈 | 특정 직업을 필수처럼 표시 금지 |
| 5 | 준비 합의 | 파티가 이번 런의 실험 목표를 한 줄로 확인 | 투표가 아닌 자동 추천 강제 금지 |
| 6 | RunState 확정 | `playerCountAtStart`, `activeDirections`, `scalingProfileId`, 시드 | 런 시작 뒤 런 기준값 변경 금지 |

좋은 로비는 "이번에는 북쪽/동쪽 2인 런에서 방해형 우선 처치를 연습해보자"처럼 파티의 실험 목표를 짧게 맞춥니다.

나쁜 로비는 "이 조합이 정답입니다", "이 훈련을 완료했으니 자동으로 강해집니다"처럼 선택을 빼앗습니다.

### 전투 HUD

전투 화면에서 항상 보여야 하는 정보:

| 위치 | 정보 |
| --- | --- |
| 상단 중앙 | 현재 일자, 계절, 웨이브 진행도 |
| 상단 좌측 | 다음 웨이브 예고, 등장 방향, 주요 적 |
| 상단 우측 | 웨이브 겹치기 투표 상태, 배속 |
| 좌측 | 파티 기지 체력, 파티 골드, 보스 파편 |
| 하단 | 내 손패, 마나, 드로우 게이지, 버리기 횟수 |
| 전장 위 | 적 경로, 구조물 체력, 도발 연결, 위험 핑 |
| 보스전 전용 | 보스 부위 체력, 다음 패턴 예고 |

### 경고 우선순위

모든 위험을 같은 강도로 표시하면 아무것도 읽히지 않습니다.

경고 우선순위:

1. 기지에 곧 도달하는 적
2. 곧 파괴될 핵심 구조물
3. 보스 패턴 예고
4. 웨이브 겹치기 투표
5. 손패 한도 초과 위험
6. 상점 또는 보상 선택 가능

UI는 플레이어를 놀라게 하기보다, 중요한 결정을 놓치지 않게 도와야 합니다.

### 예고와 피드백 루프

공포는 정보를 숨기는 데서 나오지 않습니다.

이 게임의 긴장은 위험을 알고도 막아야 하는 압박에서 나와야 합니다.

예고와 피드백은 아래 6단계로 이어집니다.

| 단계 | 역할 |
| ---: | --- |
| 1 | 하루 시작에 활성 방향, 실제 스폰 방향, 주요 적 역할을 보여줍니다. |
| 2 | 준비 중 예상 경로, 설치 위험 권역, 구조물 파괴 표식을 전장 위에 표시합니다. |
| 3 | 웨이브 시작 시 예고와 실제 스폰이 일치함을 확인시킵니다. |
| 4 | 전투 중 기지 도달, 구조물 파괴, 손패 막힘, 보스 패턴만 치명 경고로 승격합니다. |
| 5 | 웨이브 후 가장 위험했던 방향과 사용한 대응을 짧게 요약합니다. |
| 6 | 패배 시 원인 카드 3장 이하로 다음 시도에서 바꿔볼 지점을 제안합니다. |

예고 UI는 비활성 방향을 위험 방향처럼 강조하지 않습니다.

웨이브 겹치기 위험 문구에는 보상, 효율, 보너스 표현을 쓰지 않습니다.

패배 분석은 개인 책임이나 딜량 순위가 아니라, 파티가 다음 판에서 논의할 전장 원인을 보여줍니다.

### 카드 UI 규칙

카드는 빠르게 읽혀야 합니다.

카드 표기 순서:

```text
카드 이름
비용
키워드
짧은 효과 설명
대상 조건
강화 상태
```

카드 설명은 가능하면 두 줄 안에 들어가야 합니다.

복잡한 조건은 키워드와 아이콘으로 분리합니다.

카드가 사용할 수 없는 상태라면 이유를 짧게 표시합니다.

예시:

- 마나 부족
- 대상 없음
- 경로 차단 불가
- 손패 한도 초과
- 보스에게 효과 감소

## 비주얼과 분위기

폭력성, 유혈, 고어 표현은 배제합니다.

공포는 잔혹함이 아니라 규모와 침묵에서 나옵니다.

### 기본 톤

- 낮은 채도의 배경
- 선명한 구조물 실루엣
- 적은 기괴하지만 잔혹하지 않은 형태
- 보스는 화면을 압도하는 크기와 느린 움직임으로 표현
- 타격감은 피보다 충격파, 균열, 빛, 금속음으로 표현

### 화면 연출

- 보스 등장 전 배경음이 줄어듭니다.
- 먼 곳의 안개나 그림자에서 거대한 형체가 보입니다.
- 보스가 가까워질수록 UI가 미세하게 흔들립니다.
- 기지 근처에 도달하면 화면 일부가 가려질 정도의 존재감을 줍니다.

### 접근성 원칙

공포 분위기를 만들더라도 플레이 정보가 흐려지면 안 됩니다.

특히 협동 게임에서는 모든 플레이어가 같은 위험을 빠르게 읽을 수 있어야 합니다.

필수 옵션:

- 화면 흔들림 강도 조절
- 낮은 주파수 진동음 음량 조절
- 색상만으로 위험을 표시하지 않기
- 적 경로와 타겟 표시를 항상 켤 수 있는 옵션
- 보스 실루엣 연출 중에도 UI 가독성 유지
- 카드 텍스트 크기 조절

### 접근성/연출 옵션 6단계

접근성과 연출은 `accessibility_presentation_loop_6step`으로 관리합니다.

이 루프는 공포 분위기를 제거하기 위한 설정이 아니라, 모든 플레이어가 같은 전술 정보를 안정적으로 읽게 만드는 안전장치입니다.

| 단계 | 이름 | 처리 | 금지선 |
| ---: | --- | --- | --- |
| 1 | 기본 가독성 확인 | 글자 크기, UI 배율, 카드 텍스트 줄 수를 확인합니다 | 옵션 확인이 새 런 준비를 1분 이상 늘리지 않음 |
| 2 | 움직임 부담 조절 | 화면 흔들림, 카메라 관성, 보스 접근 흔들림 강도를 낮출 수 있습니다 | 흔들림을 줄여도 보스 치명 예고를 숨기지 않음 |
| 3 | 사운드 압박 조절 | 저주파 보스음, 경고음, 핑 소리를 별도 조절합니다 | 소리만으로 필수 정보를 전달하지 않음 |
| 4 | 전술 정보 보조 | 경로선, 적 윤곽선, 타겟, 보스 부위 강조를 항상 켤 수 있습니다 | 정보 보조가 보상, 추천 빌드, 자동 플레이로 변하지 않음 |
| 5 | 협동 신호 보조 | 핑 색상, 아이콘 모양, 자막, 방향 라벨을 보강합니다 | 색상만으로 위험 단계나 소유권을 구분하지 않음 |
| 6 | 연출 안전선 확정 | 유혈/고어/점프 스케어/정보 왜곡 금지를 최종 확인합니다 | 공포를 위해 경로, 타겟, 보스 패턴을 숨기지 않음 |

이 옵션들은 난이도, 보상, 웨이브 수, 활성 침공 방향, 카드 후보 수를 바꾸지 않습니다.

접근성 설정은 개인별 화면/소리 표현만 바꾸며, 협동 규칙과 전투 판정은 동일하게 유지합니다.

심리적 공포는 정보를 숨기는 방식보다, 정보를 보여주는데도 압박이 느껴지는 방식이 더 좋습니다.

### 사운드 방향

사운드는 공포감을 만들지만, 전투 정보를 방해하면 안 됩니다.

핵심 원칙:

- 낮은 진동음은 보스 존재감을 위해 사용합니다.
- 적 처치음은 짧고 명확하게 둡니다.
- 구조물 파괴음은 위기 신호로 크게 구분합니다.
- 카드 사용음은 직업별 질감이 달라야 합니다.
- 웨이브 겹치기 호출음은 보상음처럼 들리면 안 됩니다.
- 기지 위험 경고음은 다른 효과음보다 우선합니다.

직업별 사운드 질감:

| 직업 | 사운드 방향 |
| --- | --- |
| 수호자 | 낮은 금속음, 방패 울림, 둔탁한 반사음 |
| 건축가 | 나무와 쇠가 맞물리는 소리, 폭발보다 파편음 |
| 원소술사 | 불꽃, 냉기 균열, 낮은 전기음 |
| 땜장이 | 톱니, 증기, 작은 기계 진동 |

보스 사운드는 음악보다 환경음에 가깝게 시작합니다.

플레이어가 "무언가 오고 있다"고 먼저 느끼고, 화면으로 확인하게 만드는 순서가 좋습니다.

## 제작 범위

### MVP 에셋 목록

MVP는 최종 퀄리티보다 규칙 검증이 우선입니다.

그래도 플레이 감각을 확인하려면 최소한의 시각/청각 구분은 필요합니다.

| 분류 | 필요한 수량 | 비고 |
| --- | ---: | --- |
| 직업 아이콘 | 4개 | 수호자, 건축가, 원소술사, 땜장이 |
| 카드 일러스트 | 임시 30~40개 | 아이콘 기반 임시 이미지 가능 |
| 타워 모델/스프라이트 | 6~8개 | 공격, 도발, 바리케이드, 함정, 오라, 임시 구조물 |
| 적 모델/스프라이트 | 5~8개 | 실루엣과 크기로 구분 우선 |
| 보스 | 1개 | 침묵의 거상, 부위 구분 필요 |
| 맵 타일 | 6종 | 일반, 경로, 강화, 잔해, 불안정, 보스 압력 |
| UI 아이콘 | 30개 내외 | 마나, 드로우, 골드, 핑, 상태이상 |
| 효과음 | 20개 내외 | 카드, 설치, 파괴, 처치, 경고 |
| 배경음 | 2~3개 | 일반 전투, 보스 접근, 상점 |

### 임시 리소스로 가능한 것

초기 프로토타입에서는 아래 항목은 임시 리소스로 둬도 됩니다.

- 카드 일러스트
- 상세 보스 애니메이션
- 계절별 배경
- 직업별 고급 이펙트
- 이벤트 삽화
- 최종 UI 스킨

반대로 아래 항목은 임시라도 명확해야 합니다.

- 적 경로 표시
- 구조물 체력 표시
- 도발 대상 표시
- 보스 부위 체력
- 웨이브 겹치기 투표 상태
- 기지 위험 경고

### 개발 우선순위

기획 검증 우선순위:

1. 경로 탐색과 구조물 배치
2. 구조물 파괴와 경로 재계산
3. 처치 기반 자원 루프
4. 카드 사용과 손패 순환
5. 웨이브 겹치기
6. 직업별 시작 덱
7. 첫 보스
8. 상점과 아티팩트
9. UI 가독성
10. 비주얼/사운드 고도화

이 순서가 바뀌면 겉보기는 빨리 좋아질 수 있지만, 핵심 재미 검증이 늦어집니다.

## MVP 범위

첫 번째 목표는 모든 시스템을 크게 만들기보다, 핵심 재미를 작게 검증하는 것입니다.

### MVP 목표

MVP는 "이 게임의 핵심 재미가 실제로 작동하는가"를 확인해야 합니다.

검증할 질문:

- 타워와 바리케이드로 길을 비트는 재미가 있는가?
- 구조물 파괴가 짜증이 아니라 전술로 느껴지는가?
- 처치 기반 마나와 드로우가 전투를 시원하게 만드는가?
- 웨이브 겹치기가 보상 없이도 템포 조절 기능으로 쓰이는가?
- 4개 직업의 역할이 서로 다르게 느껴지는가?
- 보스가 단순 체력 덩어리가 아니라 압박으로 느껴지는가?

### MVP 성공 기준

MVP는 콘텐츠 양보다 반복 플레이 의사로 판단합니다.

성공 기준:

- 플레이어가 웨이브가 끝나기 전에 다음 웨이브를 자발적으로 부릅니다.
- 구조물이 파괴됐을 때 짜증보다 "계획대로 터졌다"는 감각이 생깁니다.
- 적이 새는 원인을 플레이어가 이해할 수 있습니다.
- 직업마다 같은 맵을 다르게 푸는 느낌이 납니다.
- 보스가 등장하면 플레이어가 방어선을 다시 짜야 한다고 느낍니다.
- 패배 후 "다음엔 저 위치를 바꿔보자"는 말이 나옵니다.

### MVP 포함 요소

- 1~4인 협동 기본 구조
- 4개 직업의 시작 덱
- 기본 타일 맵 1종
- 맵 입구 4개와 인원수별 활성 침공 방향
- 경로 탐색과 경로 재계산
- 타워, 바리케이드, 함정 배치
- 적의 이동과 구조물 파괴
- 시드 마나
- 처치 기반 마나 및 드로우 게이지
- 버리기와 덱 순환
- 라운드 보상
- 웨이브 겹치기
- 상점과 카드 제거
- 보스 1종
- 아티팩트 3~5종

### MVP 우선 구현 순서

첫 구현은 재미를 가장 빨리 검증하는 순서로 진행합니다.

1. 기본 타일 맵과 기지 배치
2. 적 경로 탐색과 기지 도달 처리
3. 타워와 바리케이드 설치
4. 구조물 파괴와 경로 재계산
5. 기본 적 3종 구현
6. 시드 마나와 카드 사용
7. 처치 기반 마나와 드로우 게이지
8. 직업별 시작 덱 적용
9. 웨이브 겹치기
10. 라운드 보상
11. 상점과 카드 제거
12. 첫 번째 보스
13. 아티팩트 장착

이 순서에서 가장 중요한 분기점은 4번입니다.

구조물 파괴와 경로 재계산이 재미있게 작동하지 않으면, 이 게임의 핵심 문장인 "계획된 붕괴"가 살아나지 않습니다.

### MVP 최소 콘텐츠 수량

MVP는 양보다 조합 검증이 중요합니다.

최소 수량:

| 분류 | 수량 | 기준 |
| --- | ---: | --- |
| 직업 | 4개 | 수호자, 건축가, 원소술사, 땜장이 |
| 시작 카드 | 직업당 6종 | 중복 매수로 10장 시작 덱 구성 |
| 공용 카드 | 5종 | 직업 약점을 약하게 보완 |
| 기본 적 | 3종 | 군집형, 돌파형, 파괴형 |
| 추가 적 | 2종 | 저항형, 방해형 |
| 보스 | 1종 | 침묵의 거상 |
| 아티팩트 | 5종 | 각 직업 또는 핵심 시스템을 하나씩 강화 |
| 맵 | 1종 | 네 방향 입구와 중앙 기지 |
| 상점 항목 | 5종 | 카드 구매, 강화, 제거, 기지 회복, 일회성 주문 |

최소 수량으로도 플레이어가 여러 판 다른 선택을 하게 된다면, 그때 콘텐츠를 늘립니다.

### MVP에서 미루는 요소

- 계절별 전용 맵 규칙
- 100일 전체 콘텐츠
- 많은 수의 보스와 정예 적
- 직업별 전용 아티팩트
- 카드 강화 트리
- 장기 메타 진행
- 보스별 전용 컷신
- 고급 난이도 모드

MVP는 100일 전체를 구현하기보다, 20~30일 정도의 짧은 런으로 핵심 루프를 검증하는 편이 좋습니다.

## 이후 확장 방향

MVP 이후에는 다음 순서로 확장합니다.

1. 적 타입 추가
2. 직업별 카드 풀 확장
3. 보스 3~4종 추가
4. 계절별 전장 규칙 추가
5. 아티팩트 슬롯과 교체 전략 강화
6. 웨이브 겹치기 최대치를 늘리는 아티팩트 추가
7. 100일 풀런 구조 구현
8. 장기 메타 진행 추가

## 장기 메타 진행

장기 메타 진행은 실패한 플레이어를 위로하는 장치이지만, 게임의 긴장을 없애면 안 됩니다.

영구 성장으로 인해 초반이 완전히 무의미해지거나, 실패를 반복하면 결국 자동으로 이기는 구조가 되면 안 됩니다.

### 메타 성장 원칙

- 직접적인 공격력 증가보다 선택지 해금을 우선합니다.
- 시작 자원 증가는 작게 제한합니다.
- 직업 고유성을 흐리는 공용 강화는 피합니다.
- 실패해도 정보와 선택지가 남는 느낌을 줍니다.
- 숙련된 플레이어가 메타 성장 없이도 클리어 가능해야 합니다.

### 런 이후 메타 진행 6단계

런 이후 메타 진행은 `post_run_meta_loop_6step`으로 처리합니다.

결과 회고가 "이번 런을 어떻게 기억할 것인가"라면, 메타 진행은 "다음 런에서 무엇을 다르게 시도할 것인가"를 여는 흐름입니다.

| 단계 | 화면 역할 | 해금/기록 기준 | 금지선 |
| ---: | --- | --- | --- |
| 1 | 런 기록 수집 | 도달 일자, 만난 적, 본 보스 부위, 마지막 방어선 태그 | 딜량, 처치 수, 겹치기 횟수로 보상 차등 금지 |
| 2 | 학습 태그 정리 | 반복된 실패 원인, 포기한 약점, 자주 쓴 대응 태그 | 개인 책임 태그를 메타 조건으로 사용 금지 |
| 3 | 정보/훈련 해금 | 적 도감, 보스 기록, 튜토리얼 재방문, 훈련 장면 | 공격력/체력/마나 같은 영구 스탯 증가 금지 |
| 4 | 선택지 해금 후보 | 새 카드, 새 아티팩트, 외형 보상, 변형 규칙 후보 | 해금 후보가 기존 풀을 난잡하게 만들거나 정답 빌드가 되면 안 됨 |
| 5 | 다음 런 준비 | 다음에 시도할 운영 1~2개, 관련 직업/카드/도감 연결 | 특정 직업 필수, 특정 카드 강요, 자동 추천 빌드 금지 |
| 6 | 프로필/연대기 저장 | 파티 기록, 발견 기록, 해금 상태, 훈련 재방문 링크 | 메타 진행도를 승률 보정이나 보상 배율로 환산 금지 |

좋은 메타 해금은 "다음에는 방해형 도감을 보고 우선 처치 운영을 해보자"처럼 학습을 돕습니다.

나쁜 메타 해금은 "몇 번 지면 시작 공격력이 올라 결국 깬다"처럼 전투 판단을 무의미하게 만듭니다.

### 도감/훈련장 재방문 6단계

도감과 훈련장은 `knowledge_revisit_loop_6step`으로 처리합니다.

이 화면의 목적은 플레이어에게 공부를 시키는 것이 아니라, 방금 헷갈린 전장 사건을 짧게 다시 만져보게 하는 것입니다.

| 단계 | 화면 역할 | 내용 | 금지선 |
| ---: | --- | --- | --- |
| 1 | 재방문 이유 제시 | 패배 원인, 결과 회고, 메타 해금, 처음 만난 적 중 연결 이유 1개 | 강제 재교육, 긴 튜토리얼 반복 금지 |
| 2 | 볼 대상 선택 | 적, 보스 부위, 상태이상, 구조물, 웨이브 겹치기, 직업 역할 중 1개 | 한 화면에 모든 정보를 펼치지 않음 |
| 3 | 짧은 도감 카드 | 행동, 저항, 대응 태그, 조심할 금지선 | 정답 빌드나 필수 직업 표시 금지 |
| 4 | 30~60초 훈련 장면 | 해당 문제만 따로 시험하는 작은 전장 | 실제 보상, 메타 파워, 희귀도 증가 없음 |
| 5 | 대응 비교 | 플레이어가 쓴 대응 태그와 다른 가능성 1~2개 | 점수, 등급, 개인 평가 금지 |
| 6 | 다음 런으로 연결 | 새 런 준비, 관련 카드/도감/훈련 즐겨찾기 | 자동 빌드 세팅, 직업/카드 강제 금지 |

좋은 훈련장은 "아, 방해형은 먼저 끊어야 하는구나"를 1분 안에 느끼게 합니다.

나쁜 훈련장은 긴 강의, 정답 빌드, 보상 파밍, 숙제 체크리스트가 됩니다.

### 메타 해금 후보

| 해금 | 효과 | 주의점 |
| --- | --- | --- |
| 새 카드 해금 | 보상 풀에 새 카드가 등장합니다. | 덱이 너무 난잡해지지 않게 직업별 풀을 관리합니다. |
| 새 아티팩트 해금 | 보스 보상 후보가 늘어납니다. | 무조건 강한 아티팩트보다 운영 변화를 줍니다. |
| 적 도감 | 적의 저항과 행동을 미리 확인합니다. | 정보 보상 중심이라 안정적입니다. |
| 보스 기록 | 부위와 패턴 정보를 저장합니다. | 반복 도전의 학습감을 줍니다. |
| 시작 카드 선택 | 시작 덱 일부를 바꿉니다. | 너무 강한 조합이 초반 정답이 되지 않게 합니다. |
| 외형 보상 | 기지, 카드, 타워 스킨을 해금합니다. | 밸런스에 영향을 주지 않는 안전한 보상입니다. |

메타 진행은 "숫자가 커져서 이긴다"보다 "다음 판에 더 똑똑하게 준비한다"에 가까워야 합니다.

## QA와 검증 기준

### 기능 QA 체크리스트

프로토타입에서 반드시 확인할 항목입니다.

- 적은 항상 기지까지 도달 가능한 경로를 찾습니다.
- 완전 길막을 시도하면 즉시 명확한 피드백을 줍니다.
- 구조물이 설치되거나 파괴되면 적 경로가 다시 계산됩니다.
- 구조물 파괴가 카드 효과, 잔해, 폭발, 회수 효과를 정상 발동합니다.
- 웨이브 겹치기는 최대 3개까지만 기본 허용됩니다.
- 웨이브 겹치기로 보상 총량이 증가하지 않습니다.
- 웨이브 겹치기 최대치 증가는 아티팩트가 있을 때만 적용됩니다.
- 시간 경과만으로 마나가 회복되지 않습니다.
- 처치 기반 마나와 드로우가 모든 플레이어에게 정상 충전됩니다.
- 손패 한도와 버리기 횟수 제한이 정상 작동합니다.
- 보스 부위 파괴 효과가 정상 적용됩니다.
- 기지 체력 30% 이하에서 웨이브 겹치기 투표 조건이 전원 동의로 바뀝니다.

### 재미 QA 체크리스트

테스터 관찰과 인터뷰로 확인할 항목입니다.

- 플레이어가 자발적으로 웨이브 겹치기를 누릅니다.
- 웨이브 겹치기를 누르는 이유가 보상 때문이 아니라 기다림을 줄이기 위해서입니다.
- 구조물이 부서질 때 짜증만 나지 않고, 의도한 파괴가 통쾌하게 느껴집니다.
- 적이 새는 이유를 플레이어가 설명할 수 있습니다.
- 각 직업이 서로 다른 방식으로 문제를 해결합니다.
- 보스 등장 시 방어선을 다시 설계해야 한다는 압박이 생깁니다.
- 패배 후 다음 판에서 바꿔보고 싶은 지점이 생깁니다.
- 멀티에서 플레이어들이 같은 위험을 보고 짧게 토론합니다.

### 밸런스 경고 신호

아래 현상이 보이면 기획 방향이 흔들리고 있는 것입니다.

| 현상 | 의미 | 우선 조치 |
| --- | --- | --- |
| 모두가 항상 웨이브 겹치기를 즉시 누름 | 위험이 낮거나 효율 버튼이 됨 | 겹친 전투 위험 증가, 보상 문구 제거 확인 |
| 아무도 웨이브 겹치기를 누르지 않음 | 기본 템포가 충분하거나 위험이 과함 | 기본 웨이브 간 대기 조정, 겹치기 UI 개선 |
| 구조물을 거의 설치하지 않음 | 구조물 가치가 낮음 | 구조물 체력 또는 파괴 보상 증가 |
| 구조물이 거의 안 부서짐 | 계획된 붕괴가 사라짐 | 파괴형 적과 보스 압박 강화 |
| 원소술사만 강함 | 광역 피해가 모든 문제를 해결 | 저항형 적과 보스 부위 저항 조정 |
| 땜장이가 있으면 절대 안 무너짐 | 수리 효율이 과함 | 수리량 감소, 과부하 대가 증가 |
| 솔로가 특정 직업만 가능 | 스케일링 실패 | 공용 카드와 맵 압박 재조정 |
| 패배 원인을 모름 | 정보 전달 실패 | 경고 UI와 패배 분석 강화 |

### 기획 완료 기준

이 문서는 아래 항목을 충족하면 1차 완성으로 봅니다.

- 핵심 경험이 한 문장으로 설명됩니다.
- 금지 규칙이 명확합니다.
- 1~30일 MVP 런 흐름이 있습니다.
- 100일 풀런의 큰 구조가 있습니다.
- 4개 직업의 역할과 시작 덱이 있습니다.
- 보상 카드 풀이 있습니다.
- 적 타입, 적 스펙, 웨이브 생성 규칙이 있습니다.
- 첫 보스의 상세 스펙이 있습니다.
- 아티팩트와 상점 경제가 있습니다.
- UI, 온보딩, 실패 피드백, 접근성 기준이 있습니다.
- QA 체크리스트와 밸런스 경고 신호가 있습니다.
- 남은 결정 사항이 열린 질문이 아니라 기본 결정값으로 정리되어 있습니다.

## 현재 꼭 지켜야 할 금지 규칙

- 웨이브 겹치기에 추가 보상 배율을 붙이지 않습니다.
- 웨이브 겹치기에 희귀도 보정을 붙이지 않습니다.
- 완전 길막을 허용하지 않습니다.
- 시간 경과 마나 자동 회복을 넣지 않습니다.
- 유혈, 고어, 잔혹 표현에 기대지 않습니다.
- 한 직업이 모든 역할을 해결하게 만들지 않습니다.
- 구조물 파괴를 단순 페널티로만 만들지 않습니다.

## 확정된 설계 결정

이전까지 열려 있던 질문은 1차 프로토타입 기준으로 아래처럼 결정합니다.

| 항목 | 결정 |
| --- | --- |
| 기지 체력 | 기본 30 |
| 하루 평균 시간 | 일반 웨이브 45~70초, 보스일 2~4분 |
| 100일 풀런 목표 시간 | 숙련 파티 기준 75~100분 |
| 웨이브 겹치기 UI | 제안 버튼 + 8초 투표 |
| 웨이브 겹치기 동의 조건 | 기본 과반수, 기지 체력 30% 이하 전원 동의 |
| 처치 기반 마나 | 개인 자원이지만 파티 처치 결과로 모두 충전 |
| 처치 기반 드로우 | 개인 게이지지만 파티 처치 결과로 모두 충전 |
| 아티팩트 슬롯 | 기본 3개, 아티팩트로 4개까지 확장 |
| 보스 부위 파괴 효과 | 카드 드로우, 마나, 패턴 약화 중심 |
| 솔로 보완 | 솔로 시 시드 마나 +1, 활성 방향과 적 수 조정 |
| 메타 성장 | 직접 스탯 증가보다 카드, 아티팩트, 정보 해금 중심 |

이 값들은 최종 밸런스가 아니라 시작점입니다.

테스트를 통해 조정하더라도, 같은 역할을 하는 다른 값으로 바꾸는 것이지 설계 의도를 뒤집지는 않습니다.

## 프로젝트 방향성

**Last Bastion: Four Seasons**는 빠른 판단과 협동의 압박을 중심에 둡니다.

플레이어가 매 라운드 던지는 질문은 단순합니다.

> 지금 방어선은 다음 압력을 버틸 수 있는가?

방어선이 안정적이라면 웨이브를 앞당겨 속도를 높입니다.

불안정하다면 멈춰서 수리하고, 카드를 아끼고, 다음 붕괴 지점을 다시 설계합니다.

이 게임의 협동은 정답을 외우는 데서 나오지 않습니다.

같은 화면을 보며 지금 부를지, 어디를 막을지, 어떤 구조물은 지키고 어떤 구조물은 터뜨릴지 함께 판단하는 순간에서 나옵니다.
